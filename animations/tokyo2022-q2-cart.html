磁場を通過する台車とコイルの回路（東京大学 2022年 第2問）

細い帯状の磁場を、コイルを載せた台車が通り抜けます。磁束が変化する区間だけ誘導起電力が生じ、電流が流れて台車は減速します。抵抗だけの回路、電池とダイオードを入れた回路、2つのコイルと接続パネルの回路で、磁束の変化 → 起電力 → 電流 → 力 → 速さの変化のつながりを追いかけます。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。磁場の幅 \(d\)、コイルの一辺 \(L\ (> d)\)、磁束密度 \(B\)（鉛直上向き）、台車の質量 \(m\) です。\(Q_1\to Q_2\) はコイルの右辺が磁場を横切る区間、\(Q_3\to Q_4\) は左辺が横切る区間です。

I(1)　磁束の変化 ΔΦ とジュール熱答 ア \(BLd\)　イ \(\dfrac{v_aB^2L^2d}{R}\)

磁束 ＝ 磁束密度 × 磁場の中にある面積

\(Q_1\) ではコイルの右辺が磁場に入る直前で、磁場の中にあるコイルの面積は 0 です。\(Q_2\) では右辺が磁場を通り抜けた直後で、幅 \(d\) の磁場全体がコイルの内側にあります（\(L > d\) なので左辺はまだ磁場の手前）。面積は \(Ld\) です。

$$\Delta\Phi = B\cdot Ld - 0 = BLd$$

起電力の大きさ → 電流 → ジュール熱

かかる時間は \(\Delta t = \dfrac{d}{v_a}\) なので、起電力の大きさは

$$|\overline{E}| = \frac{\Delta\Phi}{\Delta t} = \frac{BLd}{d/v_a} = v_aBL$$

これは「長さ \(L\) の導線が速さ \(v_a\) で磁場を横切るときの起電力 \(vBL\)」と同じです。抵抗で発生するジュール熱は

$$Q = \frac{\overline{E}^{\,2}}{R}\,\Delta t = \frac{(v_aBL)^2}{R}\cdot\frac{d}{v_a} = \frac{v_aB^2L^2d}{R}$$
式の立て方：電磁誘導は ①磁束 \(\Phi = BS\) の \(S\) を「磁場の中にある部分の面積」として位置の関数で書く → ②\(E = -\dfrac{\Delta\Phi}{\Delta t}\)（または動く導線の \(vBL\)）→ ③回路の式（キルヒホッフ）で電流 → ④電流が磁場から受ける力 \(IBL\)、の順に立てます。
アニメーションで確かめよう：下のグラフで、磁束 \(\Phi\) は \(Q_1Q_2\) で増え、\(Q_2Q_3\) では一定、\(Q_3Q_4\) で減ります。起電力が生じるのは磁束が変化している区間だけです。
I(2)　P₁ での速さ v₁答 \(v_1 = v_0 - \dfrac{B^2L^2d}{mR}\)

\(P_1\)（\(x = 0\)）は \(Q_2\) と \(Q_3\) の間にあるので、\(P_0\) から \(P_1\) までに電流が流れるのは \(Q_1Q_2\) の区間だけです。失った運動エネルギーがジュール熱になるので

$$\frac12mv_0^{\,2} - \frac12mv_1^{\,2} = \frac{v_aB^2L^2d}{R}$$

左辺を \(\dfrac12m(v_0+v_1)(v_0-v_1) = mv_a(v_0-v_1)\) と変形すると \(v_a\) が消えて

$$v_1 = v_0 - \frac{B^2L^2d}{mR}$$

別の立て方：力積と電気量

力 \(F = -IBL\) の力積は \(-BL\displaystyle\int I\,dt = -BLq\)。流れた電気量は \(q = \dfrac{\Delta\Phi}{R} = \dfrac{BLd}{R}\) なので、\(m(v_1 - v_0) = -\dfrac{B^2L^2d}{R}\)。この方法では近似を使わずに同じ結果が出ます。速さの変化は通過する速さによらないことが分かります。

式の立て方：抵抗だけの回路で「通過前後の速さ」を聞かれたら、エネルギー（ジュール熱）と力積（電気量 \(q = \Delta\Phi/R\)）の2通りで立てられます。速さの変化量が欲しいときは、力積の方が直接的です。
アニメーションで確かめよう：下のグラフは位置 \(x\) と速さ \(v\) の関係です。\(Q_1Q_2\) と \(Q_3Q_4\) で同じだけ直線的に減ります。\(B\) を大きくして変化を目立たせても、数値計算の \(v_1\) と公式の値は一致します。
II(1)(2)(3)　電池とダイオードを入れた回路答 (1) \(\dfrac{v_aBL - V}{R}\)　(2) \(-\dfrac{(v_aBL - V)BL}{R}\)　(3) 0

(1) 誘導起電力と電池の向きを比べる

\(Q_1Q_2\) では磁束が増えるので、上から見て時計回りの起電力 \(v_aBL\) が生じます。ダイオードはこの向きの電流を通し、電池は逆向きに \(V\) の起電力をもつように入っています。台車が減速した（電流が流れた）ので \(v_aBL > V\) で、キルヒホッフの第2法則より

$$v_aBL - V = RI\qquad\therefore\quad I = \frac{v_aBL - V}{R}$$

(2) 磁場中の右辺が受ける力

磁場の中にあるのは右辺だけで、力 \(IBL\) は運動を妨げる向き（\(-x\) 向き）です。

$$F = -IBL = -\frac{(v_aBL - V)BL}{R}$$

(3) 左辺が通過するとき

\(Q_3Q_4\) では磁束が減るので、起電力は反時計回りです。これはダイオードの逆方向で、電池の起電力もさらに同じ向きに加わるだけなので、電流は流れません。力は 0 です。

エネルギーの行き先：\(Q_1Q_2\) で失う運動エネルギーは \(|F|d = (v_aBL)I\Delta t\)。このうち \(RI^2\Delta t\) がジュール熱、\(VI\Delta t\) は電池の充電に使われます。
式の立て方：ダイオードを含む回路は「流れると仮定して式を立て、電流の向きが順方向になるか確かめる」か「ダイオードの両端の電位を比べる」のどちらかで判断します。誘導起電力 \(vBL\) は電池と同じように扱い、向きをそろえて足し引きします。
アニメーションで確かめよう：\(V\) を大きくすると電流が小さくなり、\(vBL < V\) になると電流は流れません。左辺が磁場を通るときは、どんな設定でも電流は 0 です。
II(4)(5)　周回をくり返したときの運動エネルギーと最終的な速さ答 (4) ③　(5) \(v_\infty = \dfrac{V}{BL}\)

(5) 電流が流れなくなる速さ

速さが落ちて \(vBL = V\) になると、\(Q_1Q_2\) でも電流が流れなくなり、それ以上減速しません。

$$v_\infty BL = V\qquad\therefore\quad v_\infty = \frac{V}{BL}$$

(4) 1周ごとの減り方

\(n\) 周目の速さを \(v_n\) とすると、1回の通過で失う運動エネルギーは

$$K_{n-1} - K_n = |F|d = \frac{(v_nBL - V)BLd}{R} = \frac{B^2L^2d}{R}\,(v_n - v_\infty)$$

減る量は \(v_n - v_\infty\) に比例するので、はじめは大きく減り、\(v_\infty\) に近づくほど減り方が小さくなります。\(v_\infty\) にぴったり到達することはなく、近づき続けます。したがって「はじめが急で、だんだん平らになり、一定値に漸近する」③です。

②・④ は有限の回数で一定値に到達して折れ曲がっているので不適、① は最初の減り方が小さいので不適です。

式の立て方：くり返しの変化は「\(n\) 回目から \(n+1\) 回目への変化量」を式にします（漸化式）。変化量が「目標値との差」に比例するなら、差は毎回一定の割合で縮み（等比数列）、グラフは一定値に漸近します。コンデンサーの充電や物体の冷却と同じ形です。
アニメーションで確かめよう：下のグラフは数値計算で求めた \(K_n\) です。\(V\) を変えると漸近する値 \(\dfrac12mv_\infty^{\,2}\)（点線）が変わり、\(B\) を大きくすると速く近づきます。
III(1)　端子 A, B の電位答 A：\(2v_aBL\)　B：\(v_aBL\)

2本のコイルは重なっているので、\(Q_1Q_2\) ではどちらにも同じ向き・同じ大きさの起電力 \(v_aBL\) が生じます。コイル1 は A–B 間、コイル2 は C–D 間につながっていて、起電力の向き（時計回り）から A は B より、C は D より \(v_aBL\) だけ電位が高くなります。

接続パネルの中では B と C が導線でつながって（R₁ と R₂ の間の点と同じ電位で）います。D を 0 とすると

$$V_C = v_aBL,\qquad V_B = V_C = v_aBL,\qquad V_A = V_B + v_aBL = 2v_aBL$$

このとき A 側のダイオード（A → R₁）も、R₂ → D のダイオードも順方向なので、R₁ と R₂ にはどちらも \(v_aBL\) の電圧がかかり、電流が流れます。コイル1 と R₁、コイル2 と R₂ がそれぞれ独立な回路になっていると考えられます。

\(Q_3Q_4\) では起電力が逆向きになり、両方のダイオードに逆向きの電圧がかかるので、電流は流れません。

式の立て方：電位を求める問題は、基準点（0 V）を決めて、導線でつながった点は同じ電位、起電力をまたぐと起電力の分だけ上がる（下がる）、抵抗を電流の向きに通ると \(RI\) 下がる、とたどっていきます。
アニメーションで確かめよう：下の回路図で、電流が流れている部分が赤くなり、各端子の電位が表示されます。左辺が通過するときは、ダイオードで止まります。
III(2)　速さの変化 |v₂ − v₀| と、それを最小にする R₁答 \(|v_2 - v_0| = \dfrac{(R_1 + R_2)B^2L^2d}{mR_1R_2}\)、最小になるのは \(R_1 = 3R\)

\(Q_1Q_2\) で R₁ と R₂ に電圧 \(v_aBL\) がかかるので、ジュール熱の合計とエネルギー収支は

$$\frac12mv_0^{\,2} - \frac12mv_1^{\,2} = \frac{(v_aBL)^2}{R_1}\cdot\frac{d}{v_a} + \frac{(v_aBL)^2}{R_2}\cdot\frac{d}{v_a}\qquad\therefore\quad |v_1 - v_0| = \frac{(R_1+R_2)B^2L^2d}{mR_1R_2}$$

\(Q_3Q_4\) では電流が流れないので \(v_2 = v_1\)。よって \(|v_2 - v_0|\) も同じ式です。

R₁ + R₂ = 6R のもとで最小にする

$$|v_2 - v_0| = \frac{6RB^2L^2d}{mR_1(6R - R_1)} = \frac{6RB^2L^2d}{m}\cdot\frac{1}{9R^2 - (R_1 - 3R)^2}$$

分母 \(R_1(6R - R_1)\) は \(R_1 = 3R\) で最大になるので、そのとき \(|v_2 - v_0|\) は最小で、値は \(\dfrac{2B^2L^2d}{3mR}\) です。

考え方：電圧が一定 \(v_aBL\) のとき、消費電力 \(\dfrac{V^2}{R}\) は抵抗が小さいほど大きくなります。R₁ か R₂ のどちらかを小さくすると、そちらで大きな熱が出て強くブレーキがかかります。両方を等しく（3R ずつ）するのが、ブレーキを最も弱くする選び方です。並列合成抵抗 \(\dfrac{R_1R_2}{R_1+R_2}\) が最大になる条件、と見ることもできます。
式の立て方：和が一定の2数の積 \(R_1R_2\) を最大にするには、平方完成（または相加・相乗平均）を使います。
アニメーションで確かめよう：\(R_1\) のスライダーを動かすと、下のグラフの点が曲線上を動き、\(R_1 = 3R\) で最小になります。台車を走らせて求めた値（数値計算）も表示されます。
