極板間引力とばねのつり合い・スイッチの開閉と RC 回路（東京科学大学（旧 東京工業大学） 2019年 第2問）

前半は、ばねでつながれた平行板コンデンサーの極板 P₂ にはたらく静電気力・ばねの力・重力のつり合いです。P₂ を動かすのに必要な手の力 F を位置 x のグラフにし、つり合いの位置が2つあること、手を放すとどちらへ動くかを確かめます。後半は、スイッチを順に開閉する RC 回路で、ジュール熱・静電エネルギー・電流の時間変化を電流の流れとグラフで追います。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。前半は鉛直上向きを正とします。図の色：静電気力（赤）、ばねの力（オレンジ）、重力（緑）、手の力 F（紫）、電流 I・コンデンサー（青）。

⒜　P₂ にはたらく静電気力 FE答 \(F_\mathrm E=-\dfrac{\varepsilon_0SV^2}{2x_0^{\,2}}\)

極板の間隔 \(x_0\) のコンデンサーの電気容量は \(C_0=\dfrac{\varepsilon_0S}{x_0}\) です。電池の電圧 \(V\) がかかるので、P₂ には正、P₁ には負の電気量がたまります。

コンデンサーの電気量（Q = CV）

$$Q_2=\frac{\varepsilon_0SV}{x_0},\qquad Q_1=-\frac{\varepsilon_0SV}{x_0}$$

P₁ だけがつくる電場は、極板の両側に向かって \(\dfrac{|Q_1|}{2\varepsilon_0S}\) の大きさで出入りします。P₂ の位置では P₁ に向かう向き（下向き）です。

P₁ がつくる電場（実際の極板間の電場の半分）

$$E_1=\frac{Q_1}{2\varepsilon_0S}=-\frac{V}{2x_0}$$

静電気力（電気量 × 電場）

$$\cfrc{F_\mathrm E}=Q_2E_1=-\frac{\varepsilon_0SV^2}{2x_0^{\,2}}$$

負なので下向き、つまり P₂ は P₁ に引きつけられます。

着眼点：なぜ「半分」の電場を使うのか

極板間の電場 \(\frac V{x_0}\) は、P₁ がつくる電場と P₂ がつくる電場の重ね合わせです（間では強め合い、外では打ち消し合う）。P₂ 自身がつくる電場は P₂ を押したり引いたりしないので、相手の P₁ がつくる半分だけを使います。全体の電場 \(\frac V{x_0}\) をそのままかけると2倍の間違いになります。

式の立て方：極板にはたらく力は「自分の電気量 × 相手がつくる電場」で求めます。相手の極板1枚がつくる電場は \(\dfrac{\sigma}{2\varepsilon_0}\)（\(\sigma\) は面密度）です。
アニメーションで確かめよう：P₁ のまわりの細い矢印が P₁ だけの電場、点線が P₂ だけの電場です。極板の間では同じ向きに重なり、外側では逆向きで打ち消し合っています。
⒝　P₂ にはたらく力のつり合い答 \(-\dfrac{\varepsilon_0SV^2}{2x_0^{\,2}}-k(x_0-L)-mg=0\)

P₂ には、静電気力 \(F_\mathrm E\)、ばねの力、重力の3つがはたらきます。ばねの長さは \(x_0\) なので、自然長からの伸びは \(x_0-L\) です。ばねの力は伸びと逆向きなので \(-k(x_0-L)\) です。

力のつり合い（上向きを正）

$$\cfrc{-\frac{\varepsilon_0SV^2}{2x_0^{\,2}}}\cfr{-k(x_0-L)}\cgrav{-mg}=0$$

静電気力も重力も下向きなので、ばねは縮んでいて（\(x_0\lt L\)）、上向きに押し上げています。

式の立て方：ばねの力は、伸び縮みの向きを考えずに「\(-k\times\)（いまの長さ − 自然長）」と符号つきで書くと、縮んでいる場合も自動で正しい向きになります。
アニメーションで確かめよう：上向きのオレンジの矢印（ばね）の長さが、下向きの赤（静電気力）と緑（重力）の合計に等しくなっています。右下の棒グラフでも合計が 0 です。
⒞　P₂ を x で静止させる手の力 F答 (ア) \(k-\dfrac{\varepsilon_0SV^2(x+x_0)}{2x_0^{\,2}x^2}\)

電池はつながったままなので、間隔が \(x\) になると電気量は \(\frac{\varepsilon_0SV}{x}\) に変わり、静電気力は \(-\dfrac{\varepsilon_0SV^2}{2x^2}\) になります。

力のつり合い（位置 x，手の力 F を加える）

$$\cfic{F}-\frac{\varepsilon_0SV^2}{2x^2}-k(x-L)-mg=0$$

⒝ の式を引くと、わからない \(L\) と \(mg\) が消えます。

$$\cfic{F}=k(x-x_0)+\frac{\varepsilon_0SV^2}{2}\Bigl(\frac1{x^2}-\frac1{x_0^{\,2}}\Bigr)$$

\(\dfrac1{x^2}-\dfrac1{x_0^{\,2}}=-\dfrac{(x-x_0)(x+x_0)}{x^2x_0^{\,2}}\) なので、\((x-x_0)\) でくくれます。

$$\cfic{F}=(x-x_0)\Bigl\{k-\frac{\varepsilon_0SV^2(x+x_0)}{2x_0^{\,2}x^2}\Bigr\}$$
式の立て方：同じ物体の2つの状態でつり合いの式を立て、引き算して「共通で変わらない力」（ここでは \(mg\) と \(kL\)）を消します。\(x=x_0\) で \(F=0\) になるはずなので、\((x-x_0)\) でくくれることが検算になります。
アニメーションで確かめよう：P₂ をゆっくり上下させています。紫の矢印（手の力）の向きと長さが、右上のグラフの点の高さ（\(F\) の値）と対応しています。
⒟　F = 0 となるもう1つの位置 x₁答 (イ) \(\dfrac{\varepsilon_0SV^2}{4kx_0^{\,2}}\)　(ウ) \(1+\dfrac{8kx_0^{\,3}}{\varepsilon_0SV^2}\)

⒞ の { } の中が 0 になる位置を探します。両辺に \(2x_0^{\,2}x^2\) をかけて整理すると、2次方程式になります。

F = 0 の条件（{ } の中 = 0）

$$2kx_0^{\,2}x^2-\varepsilon_0SV^2x-\varepsilon_0SV^2x_0=0$$

解の公式（x > 0 の解）

$$\cfic{x_1}=\frac{\varepsilon_0SV^2}{4kx_0^{\,2}}\Bigl(1+\sqrt{1+\frac{8kx_0^{\,3}}{\varepsilon_0SV^2}}\Bigr)$$

定数項が負なので2つの解は異符号で、正の解は1つだけです。

補足：x₁ < x₀ となる条件

静電気力の強さを \(a=\dfrac{\varepsilon_0SV^2}{2kx_0^{\,3}}\) とおくと \(\dfrac{x_1}{x_0}=\dfrac a2\bigl(1+\sqrt{1+\frac4a}\bigr)\) で、\(x_1\lt x_0\) となるのは \(a\lt \frac12\) のときです。設定のスライダーはこの \(a\) です。

式の立て方：分数を含む式が 0 になる条件は、分母を払って多項式にしてから考えます。答えの形 \(\square\times(1+\sqrt{\square})\) に合わせて、解の公式の分子分母を整理します。
アニメーションで確かめよう：グラフの \(F=0\) の点が2つ（\(x_1\) と \(x_0\)）あります。\(a\) を大きくすると \(x_1\) が \(x_0\) に近づき、\(a=0.5\) で重なります。
⒠　F のグラフの形答 ⑦

\(F=(x-x_0)\times\dfrac{g(x)}{2x_0^{\,2}x^2}\)、\(g(x)=2kx_0^{\,2}x^2-\varepsilon_0SV^2x-\varepsilon_0SV^2x_0\) と書くと、\(g(x)\) は \(x_1\) より左で負、右で正です。符号を表にすると

符号の表

$$\begin{array}{c|ccc}&0\lt x\lt x_1&x_1\lt x\lt x_0&x_0\lt x\\\hline x-x_0&-&-&+\\g(x)&-&+&+\\F&+&-&+\end{array}$$

さらに、\(x\to0\) では静電気力が \(\frac1{x^2}\) で大きくなるので \(F\to+\infty\)、\(x\) が大きいと静電気力が効かなくなり \(F\) は直線 \(k(x-x_0)\) に近づきます。この4つの特徴をすべて満たすのは ⑦ です。

式の立て方：グラフを選ぶ問題では、(1) 0 になる点、(2) 区間ごとの符号、(3) 端（\(x\to0\)、\(x\to\infty\)）でのふるまい、の3つを調べれば形が決まります。
アニメーションで確かめよう：右上のグラフで、点線の直線が \(x\) の大きいところでの近づき先です。\(x_1\) と \(x_0\) の間だけ \(F\) が負（グラフが横軸の下）になっています。
⒡　x₁ < x < x₀ で手を放した直後のふるまい答 ①（x₀ に向かって動き始める）

この範囲では、止めておくのに必要な手の力が \(F\lt 0\)、つまり下向きです。手を放すと、残りの3つの力の合力は \(-F>0\)（上向き）になります。

手を放した直後の運動方程式

$$m\,a=-\cfic{F}>0$$

P₂ は上向き、つまり \(x_0\) に向かって動き始めます。

着眼点：x₀ は安定、x₁ は不安定

\(x_0\) より少し上では \(F>0\)（手で上に支える必要がある）なので、放すと下に戻されます。少し下では上に戻されます。どちらにずれても戻されるので \(x_0\) は安定なつり合いです。逆に \(x_1\) のまわりでは、ずれた向きにさらに押されるので不安定です。\(x_1\) より下で放すと、静電気力に負けて P₁ に引き寄せられてしまいます。

式の立て方：「つり合いに必要な外力 \(F\)」がわかれば、外力を取り去ったときの合力は \(-F\) です。\(F\) のグラフが右上がりに横軸を横切る点が安定なつり合いの位置です。
アニメーションで確かめよう：設定の「手を放す位置」を変えてみましょう。\(x_1\) と \(x_0\) の間や \(x_0\) の少し上で放すと \(x_0\) のまわりで振動し、\(x_1\) より下で放すと P₁ に引き寄せられます。\(x_0\) よりずっと上で放すと、勢いがつきすぎて \(x_1\) を越え、やはり引き寄せられます。
⒢　操作1で R₁ に発生するジュール熱答 \(\dfrac12CV^2\)

S₂ が開いているので、電流は「電池 → R₁ → C」の道だけを流れ、十分に時間がたつと C の電圧は \(V\)、電気量は \(Q=CV\) になります。

電池がした仕事（電気量 × 起電力）

$$W=QV=CV^2$$

静電エネルギー

$$U_0=\frac12CV^2$$

エネルギー保存則（電池の仕事 ＝ 静電エネルギー ＋ ジュール熱）

$$\cfr{J_1}=W-U_0=\frac12CV^2$$

電池がした仕事のちょうど半分が熱になります。\(R_1\) の値によらず、\(R_1\) が小さいと大きな電流が短い時間流れ、大きいと小さな電流が長く流れて、熱の合計は同じです。

式の立て方：抵抗の熱は \(\int RI^2\,dt\) を計算せず、「電池の仕事 − 静電エネルギーの増加」で求めます。電池の仕事は「通した電気量 × 起電力」です。
アニメーションで確かめよう：右下の棒グラフで、電池の仕事（灰）が C の静電エネルギー（青）と R₁ の熱（オレンジ）に半分ずつ分かれていきます。\(R_1\) を変えても最後の高さは変わりません。
⒣　操作2の後のコンデンサーの静電エネルギー答 \(\dfrac12C\Bigl(\dfrac{R_2}{R_1+R_2}V\Bigr)^2\)

十分に時間がたつと C には電流が流れず、電流は R₁ と R₂ を直列に流れます。C は R₂ と並列なので、C の電圧は R₂ の電圧に等しくなります。

キルヒホッフの第2法則（電池 → R₁ → R₂）

$$V=(R_1+R_2)I\qquad\therefore\ I=\frac{V}{R_1+R_2}$$

並列の電圧と静電エネルギー

$$V_\mathrm C=R_2I=\frac{R_2}{R_1+R_2}V,\qquad\cacc{U}=\frac12CV_\mathrm C^{\,2}=\frac12C\Bigl(\frac{R_2}{R_1+R_2}V\Bigr)^2$$
式の立て方：「十分に時間がたった後」のコンデンサーは電流 0 の断線として扱い、残った抵抗だけの回路で電流と電圧を求めます。コンデンサーの電圧は、並列につながった部分の電圧と同じです。
アニメーションで確かめよう：S₂ を閉じると C の電圧（青い線）が \(V\) から \(\frac{R_2}{R_1+R_2}V\)（点線）まで下がります。\(R_2\) を小さくすると下がり方が大きくなります。
⒤　操作1〜4での R₂ の電流 I の変化と最大値答 ⑧，最大値 \(\dfrac{V}{R_2}\)

どの操作でも、切りかえた瞬間のコンデンサーの電圧は直前の値のままです（電気量は瞬間的には変われないため）。これを使って、各操作の直後と十分に時間がたった後を調べます。

操作1（S₂ 開）

R₂ には電流が流れず \(I=0\)。C は \(V\) まで充電されます。

操作2（S₂ を閉じる）

$$\text{直後：}\ \cacc{I}=\frac{V}{R_2},\qquad\text{十分後：}\ \cacc{I}=\frac{V}{R_1+R_2}$$

閉じた瞬間、R₂ には C の電圧 \(V\) がかかるので大きな電流が流れ、C が放電して減っていきます。

操作3（S₁ を開く）

$$\text{直後：}\ \cacc{I}=\frac{V_\mathrm C}{R_2}=\frac{V}{R_1+R_2},\qquad\text{十分後：}\ \cacc{I}=0$$

C だけが R₂ を通して放電します。電流の向きは同じ（正）で、連続的に 0 まで減ります。

操作4（S₁ を閉じる）

$$\text{直後：}\ \cacc{I}=0,\qquad\text{十分後：}\ \cacc{I}=\frac{V}{R_1+R_2}$$

C の電圧は 0 なので、並列の R₂ の電圧も 0 から始まり、C の充電とともに増えます。

「0 → 跳び上がって減る → なめらかに 0 へ → なめらかに増える」の形は ⑧ で、最大値は操作2の直後の \(\dfrac V{R_2}\) です。

式の立て方：スイッチの切りかえでは、(1) 直後はコンデンサーを「直前と同じ電圧の電池」、(2) 十分後は「断線」として扱い、それぞれキルヒホッフの法則を立てます。電流が跳ぶのは抵抗の電圧が跳ぶところだけです。
アニメーションで確かめよう：右上のグラフに \(I\) が描かれます。操作2の直後だけ電流が跳び上がり、操作3と4では跳ばずになめらかに変化します。\(R_1\)、\(R_2\) を変えると高さと減り方（時定数）が変わっても、形は ⑧ のままです。
