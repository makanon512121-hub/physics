半透膜で仕切られた混合気体（東京大学 2022年 第3問）

気体 X は通し、気体 Y は通さない膜でシリンダーを2つに仕切ります。分子の運動から圧力を導くと、X は膜がないかのように全体に広がり、Y は下の領域だけに閉じこめられていることが、圧力の式にそのまま表れます。後半は、ピストンを押し下げる断熱変化と、おもりを載せて温める定圧変化で、熱力学第1法則の立て方を確かめます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。気体 X・Y はどちらも 1 mol の単原子分子理想気体、断面積 \(S\)、アボガドロ定数 \(N_A\)、気体定数 \(R\)、ボルツマン定数 \(k = R/N_A\) です。

I(1)　ピストンが気体 X から受ける力 F₁答 \(F_1 = \dfrac{N_ASm_X\overline{v_z^{\,2}}}{V_1+V_2}\)

X にとって膜は「ないのと同じ」

X の分子は膜を素通りするので、底面からピストンまでの高さ \(h = \dfrac{V_1+V_2}{S}\) を往復します。

1分子の力積 → 平均の力

速度の \(z\) 成分 \(v_z\) の分子がピストンで弾性衝突すると、ピストンに与える力積は \(2m_Xv_z\)。次にピストンに当たるまでの時間は \(\dfrac{2h}{v_z}\) なので、1分子がピストンに及ぼす平均の力は

$$\frac{2m_Xv_z}{2h/v_z} = \frac{m_Xv_z^{\,2}}{h} = \frac{Sm_Xv_z^{\,2}}{V_1+V_2}$$

\(N_A\) 個について足し合わせ、\(v_z^{\,2}\) を平均 \(\overline{v_z^{\,2}}\) に置きかえると

$$F_1 = \frac{N_ASm_X\overline{v_z^{\,2}}}{V_1+V_2}$$
式の立て方：気体分子運動論は、①1回の衝突で壁が受ける力積（\(2mv\)）、②次の衝突までの時間（往復距離 ÷ 速さ）、③平均の力 ＝ ①÷②、④分子数倍、の4段階です。「往復距離」はその分子が実際に動ける範囲で決まるので、膜を通れる X は全体の高さ、通れない Y は領域2の高さを使います。
アニメーションで確かめよう：小さい点が X、大きい点が Y です。X は膜を通り抜けて全体を飛びまわり、ピストンに当たるのは X だけです（当たった瞬間に光ります）。
I(2)　底面が X と Y から受ける力 F₂答 \(F_2 = \dfrac{N_ASm_X\overline{v_z^{\,2}}}{V_1+V_2} + \dfrac{N_ASm_Y\overline{w_z^{\,2}}}{V_2}\)

X は (1) と同じ高さ \(\dfrac{V_1+V_2}{S}\) を往復するので、底面が X から受ける力は \(F_1\) と同じです。

Y は膜で跳ね返されるので、底面と膜の間の高さ \(\dfrac{V_2}{S}\) を往復します。同じ手順で

$$\frac{2m_Yw_z}{2(V_2/S)/w_z}\times N_A = \frac{N_ASm_Y\overline{w_z^{\,2}}}{V_2}$$

合計して答えになります。

考え方：混合気体では、それぞれの気体が「自分だけがその空間にいるとき」の圧力（分圧）を及ぼし、全圧はその和になります（ドルトンの分圧の法則）。分子どうしが衝突しないほど希薄なら、各気体の分子は互いを気にせず壁と衝突するからです。
アニメーションで確かめよう：底面には X と Y の両方が当たります。Y は膜に当たると跳ね返り、膜を上向きに押しています。
I(3)　圧力 p₁ と p₂答 \(p_1 = \dfrac{RT}{V_1+V_2}\)、\(p_2 = \dfrac{RT}{V_1+V_2} + \dfrac{RT}{V_2}\)

1方向あたりの運動エネルギーが \(\dfrac12kT\) なので \(m_X\overline{v_z^{\,2}} = m_Y\overline{w_z^{\,2}} = kT = \dfrac{R}{N_A}T\)。これを (1)(2) に入れて \(S\) で割ります。

$$p_1 = \frac{F_1}{S} = \frac{N_A}{V_1+V_2}\cdot\frac{R}{N_A}T = \frac{RT}{V_1+V_2}$$ $$p_2 = \frac{F_2}{S} = \frac{RT}{V_1+V_2} + \frac{RT}{V_2}$$

X の分圧は「1 mol が体積 \(V_1+V_2\) を占める」ときの、Y の分圧は「1 mol が体積 \(V_2\) を占める」ときの状態方程式そのものです。\(p_2 > p_1\) で、その差 \(\dfrac{RT}{V_2}\) は Y が膜を押し上げる圧力です（膜が固定されているので支えられています）。

式の立て方：分子運動論で求めた力の式は、最後に \(\dfrac12m\overline{v_z^{\,2}} = \dfrac12kT\) を使って温度で書き直すと、状態方程式 \(pV = nRT\) と一致することを確かめられます。逆に、状態方程式を使うときは「その気体が動ける体積」を \(V\) に入れます。
アニメーションで確かめよう：下の棒グラフは p₁ と p₂ の内訳です。\(V_2\) を小さくすると Y の分圧だけが大きくなり、\(V_1\) を変えると X の分圧が両方の領域で同じだけ変わります。
I(4)　内部エネルギーの合計答 \(3RT\)

単原子分子の内部エネルギーは分子の運動エネルギーの和です。1分子あたり3方向で \(\dfrac32kT\)、1 mol で \(\dfrac32RT\)。X と Y が 1 mol ずつなので

$$U = \frac32RT\times2 = 3RT$$

内部エネルギーは温度と物質量だけで決まり、体積や膜の位置にはよりません。

式の立て方：単原子分子理想気体は \(U = \dfrac32nRT\)（定積モル比熱 \(\dfrac32R\)）。混合気体では物質量を足して \(n = 2\) とします。
II(1)(2)　断熱圧縮での温度変化と圧力変化答 (1) \(\Delta T = \dfrac{p_1\Delta V_1}{3R}\)　(2) ア \(\dfrac43\)

(1) 熱力学第1法則

ピストンに接しているのは領域1（圧力 \(p_1\)）だけなので、気体がピストンからされる仕事は \(p_1\Delta V_1\)。熱のやりとりはないので、これがそのまま内部エネルギー \(3RT\) の増加になります。

$$3R\Delta T = p_1\Delta V_1\qquad\therefore\quad \Delta T = \frac{p_1\Delta V_1}{3R}$$

(2) X の状態方程式を微小変化させる

\(p_1(V_1+V_2) = RT\) の変化前と変化後を比べ、微小量どうしの積を無視すると

$$(p_1+\Delta p_1)(V_1+V_2-\Delta V_1) - p_1(V_1+V_2) \fallingdotseq (V_1+V_2)\Delta p_1 - p_1\Delta V_1 = R\Delta T$$

(1) の \(R\Delta T = \dfrac{p_1\Delta V_1}{3}\) を入れると

$$(V_1+V_2)\Delta p_1 = \frac43p_1\Delta V_1\qquad\therefore\quad \frac{\Delta p_1}{p_1} = \frac43\cdot\frac{\Delta V_1}{V_1+V_2}$$

4/3 の意味

1種類の単原子分子だけなら、断熱変化は \(pV^{5/3} = \)一定、つまり \(\dfrac{\Delta p}{p} = \dfrac53\dfrac{\Delta V}{V}\) です。ここでは仕事を受けるのは X の圧力ですが、受けたエネルギーは Y にも分けられる（熱容量が2倍の \(3R\)）ので温度が上がりにくく、圧力の上がり方は \(\dfrac53\) より小さい \(\dfrac43\) になります。等温変化（\(1\)）と単原子分子の断熱変化（\(\dfrac53\)）の間の値です。

式の立て方：断熱変化は「\(Q = 0\) の第1法則 \(\Delta U = W_{\text{された}}\)」と「状態方程式の微小変化」の2式を連立します。\(pV^\gamma =\)一定 を覚えていなくても、この2式から導けます。仕事は実際に動く面（ここではピストン）にはたらく圧力で計算します。
アニメーションで確かめよう：押し下げる量を大きくすると、下のグラフで、この気体の断熱曲線（\(p_1 \propto (V_1+V_2)^{-4/3}\)）が等温曲線と単原子分子の断熱曲線の間にあることが分かります。いまの値の欄では、近似式と正確な値を比べられます。
III(1)(2)　おもりを載せて温めたときの温度と熱量答 (1) \(\dfrac{2V_1+V_2}{V_1+V_2}\,T\)　(2) \(\dfrac{4V_1}{V_1+V_2}\,RT\)

(1) 領域1の圧力は一定

外は真空なので、ピストンのつり合いは「\(p_1S\) ＝ ピストンとおもりの重さ」です。ゆっくり押し上がる間このつり合いが続くので、\(p_1\) は一定です。X の状態方程式 \(p_1(V_1+V_2) = RT\) で、体積が \(2V_1+V_2\) になったときの温度を \(T'\) とすると

$$p_1(2V_1+V_2) = RT'\qquad\therefore\quad T' = \frac{2V_1+V_2}{V_1+V_2}\,T$$

(2) 熱力学第1法則

内部エネルギーの増加は \(3R(T'-T) = \dfrac{3RTV_1}{V_1+V_2}\)。気体がした仕事はピストンを押し上げた分で \(p_1\times V_1 = \dfrac{RTV_1}{V_1+V_2}\)。吸収した熱量は

$$Q = \Delta U + W = \frac{3RTV_1}{V_1+V_2} + \frac{RTV_1}{V_1+V_2} = \frac{4V_1}{V_1+V_2}\,RT$$

Y は体積 \(V_2\) のまま温度だけが上がり（定積変化）、仕事をしません。Y の圧力 \(\dfrac{RT}{V_2}\) は温度とともに上がりますが、固定された膜が支えています。

式の立て方：①ピストンの力のつり合いで「どの圧力が一定か」を決める → ②その圧力の気体の状態方程式で温度を求める → ③第1法則 \(Q = \Delta U + W\) で、\(\Delta U\) は全部の気体、\(W\) は動いた面の分だけ、と分けて計算します。
アニメーションで確かめよう：ヒーターで温めると、ピストンが上がって領域1の体積が \(2V_1\) まで増えます。下の棒グラフは吸収した熱量の行き先（X と Y の内部エネルギー、ピストンにした仕事）です。
