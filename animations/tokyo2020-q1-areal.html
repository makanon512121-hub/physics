面積速度と中心力：ケプラーの第2法則から暗黒物質まで（東京大学 2020年 第1問）

平面内を運動する小球について、面積速度が一定になる条件（中心力）を式で確かめ、速度を「動径方向」と「回転方向」に分けて有効ポテンシャルで運動を読み解きます。最後はボーアの量子条件を使って、暗黒物質の粒子の質量の下限を見積もります。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。アニメーションでは \(GM=1\)、\(m=1\)、はじめの距離 \(r=1\) の単位で計算しています。色は図と式で共通です：速度（青）、力・加速度（赤）、面積（紫）、動径方向（緑）、回転方向（オレンジ）。

I(1)　微小時間後の位置・速度と面積速度の変化答 ア \(v_x\)　イ \(v_y\)　ウ \(a_x\)　エ \(a_y\)　オ \(a_y\)　カ \(a_x\)

微小時間の変化は「変化率 × Δt」

位置の変化率が速度、速度の変化率が加速度です。\(\Delta t\) が十分小さければ、その間の速度・加速度は一定とみなせるので

$${\vec r}' = \vec r + \cacc{\vec v}\,\Delta t = (x + v_x\Delta t,\ y + v_y\Delta t),\qquad {\vec v}' = \vec v + \cfrc{\vec a}\,\Delta t = (v_x + a_x\Delta t,\ v_y + a_y\Delta t)$$

よって ア \(v_x\)、イ \(v_y\)、ウ \(a_x\)、エ \(a_y\) です。

新しい位置と速度で面積速度を作り直す

\(\Delta t\) 後の面積速度は、同じ式の \(x,y,v_x,v_y\) を新しい値に置きかえたものです。

$$A_v' = \frac12\Big\{(x+v_x\Delta t)(v_y+a_y\Delta t) - (y+v_y\Delta t)(v_x+a_x\Delta t)\Big\}$$

展開すると、\(\Delta t\) を含まない部分はもとの \(A_v\)、\(\Delta t\) の1次の部分のうち \(v_xv_y\Delta t\) は打ち消し合い、\((\Delta t)^2\) の項は無視できます。

$$\cfic{\Delta A_v} = A_v' - A_v = \frac12\big(x\,\cfrc{a_y} - y\,\cfrc{a_x}\big)\Delta t$$

よって オ \(a_y\)、カ \(a_x\) です。

別の立て方：時間で微分する

\(A_v=\frac12(xv_y-yv_x)\) を積の微分で \(t\) について微分すると、\(\dot x=v_x,\ \dot v_y=a_y\) などから \(\dfrac{dA_v}{dt} = \dfrac12\{(v_xv_y + xa_y) - (v_yv_x + ya_x)\} = \dfrac12(xa_y - ya_x)\) と一気に出ます。「\(\Delta t\) の1次まで残して展開する」ことと「微分する」ことは同じ操作です。

そもそも \(A_v\) はなぜ面積か

\(\Delta t\) の間に動径が掃く部分は、O・\((x,y)\)・\((x+v_x\Delta t,\,y+v_y\Delta t)\) を頂点とする細い三角形です。2つのベクトル \((p_1,p_2)\)、\((q_1,q_2)\) が張る三角形の面積は \(\frac12(p_1q_2-p_2q_1)\) なので、面積は \(\frac12(xv_y - yv_x)\Delta t\)、単位時間あたりにすると \(A_v\) です。反時計回りに回っているときに正になります。

式の立て方：「微小時間後の量」を問われたら、①位置・速度を「もとの値＋変化率×\(\Delta t\)」で書く ②目的の量の式に代入して展開する ③\(\Delta t\) の1次の項だけを残す、の順に進めます。この手順は運動量・エネルギー・電気量など、どの量の変化率を求めるときにも使えます。
アニメーションで確かめよう：紫の細い三角形が \(\Delta t\) の間に掃く面積です。φ = 0（力が原点を向く）のときは \(xa_y-ya_x=0\) で、下のグラフの \(A_v\) は水平な直線になります。φ を 0 からずらすと、力に回転方向の成分ができて \(A_v\) が増えたり減ったりします。
I(2)　面積速度が一定になる力の条件答 \(F_x : F_y = x : y\)（力が原点と小球を結ぶ直線の方向を向く）

\(\Delta A_v = 0\) を力の条件に言いかえる

I(1) より、面積速度が変化しない条件は

$$x\,a_y - y\,a_x = 0\qquad\Longleftrightarrow\qquad a_x : a_y = x : y$$

運動方程式 \(m\vec a = \vec F\) より \(\vec F\) と \(\vec a\) は同じ向きなので

$$\cfrc{F_x : F_y} = x : y$$

つまり力 \(\vec F\) が位置ベクトル \(\vec r\) と平行です。原点に向かう引力でも、原点から遠ざかる斥力でもかまいません。このような力を中心力といいます。

着眼点：回転方向の成分が面積速度を変える

\(x a_y - y a_x\) は「\(\vec r\) と \(\vec a\) の張る平行四辺形の面積」で、\(r\times(\)加速度の \(\vec r\) に垂直な成分\()\) に等しくなります。面積速度を変えられるのは回転方向の力だけで、動径方向の力はいくら強くても面積速度を変えません。惑星（太陽からの万有引力）、クーロン力で回る電子、糸につながれて回る物体など、力が1点を向く運動では必ず面積速度が保存します。

式の立て方：面積速度（角運動量 \(L = 2mA_v\)）が保存するかどうかは、「力が回転の中心を向いているか」だけで判定できます。保存すると分かったら、2つの位置で \(\frac12 r_1v_1\sin\theta_1 = \frac12 r_2v_2\sin\theta_2\) と立てます。近日点・遠日点では \(\sin\theta = 1\) なので \(r_1v_1 = r_2v_2\) です。
アニメーションで確かめよう：一定時間ごとに掃いた扇形を色分けしています。φ = 0 では、近いところで速く・遠いところでゆっくり動いても、扇形の面積（下のグラフの棒）がすべて等しくなります（ケプラーの第2法則）。φ をずらすと棒の高さがそろわなくなります。
I(3)　A→B と A→C の仕事の大小答 どちらも 0 で等しい（円周上では移動の向きと力がつねに垂直だから）

仕事は「力の移動方向の成分 × 移動距離」

原点を中心とする円周上を動くとき、移動の向き（接線方向）はつねに動径と垂直です。I(2) の力は動径方向を向くので、移動の向きと力はつねに垂直です。

$$\Delta W = \cfrc{\vec F}\cdot\Delta\vec s = |\vec F||\Delta\vec s|\cos 90^\circ = 0$$

どの部分でも仕事は 0 なので、A→B も A→C も仕事は 0 で、両者は等しくなります。

一歩進んだ見方：中心力は保存力

力の大きさが距離 \(r\) だけで決まる中心力なら、どんな経路でも、仕事は「動径方向に動いた部分」だけで決まります。円周に沿った部分は 0、外に出て戻ってくる部分は行きと帰りで打ち消し合います。そのため仕事は始点と終点の距離だけで決まり、位置エネルギー \(U(r)\) が定義できます。II(2) で万有引力の位置エネルギーを使えるのはこのためです。

式の立て方：仕事を問われたら、まず「力と移動の向きのなす角」を見ます。垂直なら計算せずに 0 と言えます。斜めのときは、力を移動方向に分解した成分だけが仕事をします。
アニメーションで確かめよう：「寄り道の半径」を 1 にすると円周上を進み、下のグラフの仕事はずっと 0 です。半径を大きくして外側を回ると、外へ出る間は仕事が負、戻る間は正になり、C に着いたときの合計はやはり 0 になります。
II(1)　運動エネルギーと動径方向の運動エネルギーの差答 \(K - K_r = \dfrac{2mA_v^{\,2}}{r^2}\)

速度を「動径方向」と「回転方向」に分ける

\(\vec r\) と \(\vec v\) のなす角を \(\theta\) とすると、速度は動径方向の成分 \(\cgrav{v_r = v\cos\theta}\) と、それに垂直な回転方向の成分 \(\cfr{v_\perp = v\sin\theta}\) に分かれます。2つは直交するので

$$K = \frac12mv^2 = \cgrav{\frac12mv_r^{\,2}} + \cfr{\frac12mv_\perp^{\,2}}$$

一方、面積速度は「底辺 \(r\) × 高さ \(v\sin\theta\)」の三角形の面積なので

$$\cfic{A_v} = \frac12 r\,v_\perp\qquad\Longrightarrow\qquad v_\perp = \frac{2A_v}{r}$$

したがって

$$K - K_r = \frac12mv_\perp^{\,2} = \frac12m\left(\frac{2A_v}{r}\right)^2 = \frac{2mA_v^{\,2}}{r^2}$$

成分のまま計算する方法

\(K - K_r = \dfrac{m}{2r^2}\{(x^2+y^2)(v_x^2+v_y^2) - (xv_x+yv_y)^2\}\) と通分すると、中かっこの中は \((xv_y - yv_x)^2 = (2A_v)^2\) にまとまります。ベクトルの図が描ければ、上の分解の方が見通しよく計算できます。

式の立て方：回転運動を含む問題では、速度を「中心に近づく・遠ざかる成分」と「回る成分」に分けます。回る成分は面積速度（角運動量）で \(r\) の関数として書けるので、運動エネルギーのうち回転の部分を「距離だけの関数」に変えられます。
アニメーションで確かめよう：小球の速度（青）を緑（動径方向）とオレンジ（回転方向）に分けて描いています。近日点・遠日点では緑が 0 になり、運動エネルギーはすべて回転の部分です。下のグラフで、オレンジの曲線 \(2mA_v^2/r^2\) は \(r\) が小さいところで大きくなります。
II(2)　力学的エネルギーが最小となる運動答 半径 \(\dfrac{4A_0^{\,2}}{GM}\) の等速円運動。最小値 \(-\dfrac{G^2M^2m}{8A_0^{\,2}}\)

エネルギーを \(v_r\) と \(r\) だけの式にする

II(1) を使うと、力学的エネルギーは

$$E = \cgrav{\frac12mv_r^{\,2}} + \cfr{\frac{2mA_0^{\,2}}{r^2}} - \cfrc{\frac{GMm}{r}}$$

\(A_0\) は定数なので、\(E\) は \(v_r\) と \(r\) の2変数だけで決まります。第1項は \(v_r=0\) で最小です。残りの2項は \(\frac1r\) の2次式なので平方完成します。

$$\frac{2mA_0^{\,2}}{r^2} - \frac{GMm}{r} = 2mA_0^{\,2}\left(\frac1r - \frac{GM}{4A_0^{\,2}}\right)^2 - \frac{G^2M^2m}{8A_0^{\,2}}$$

最小になるのは \(v_r = 0\) かつ \(r = \dfrac{4A_0^{\,2}}{GM}\) のときです。\(r\) が変わらず、面積速度一定なので速さ \(v = \dfrac{2A_0}{r}\) も一定、つまり半径 \(\dfrac{4A_0^{\,2}}{GM}\) の等速円運動で、最小値は

$$E_{\min} = -\frac{G^2M^2m}{8A_0^{\,2}}$$

確かめ：円運動の式 \(m\dfrac{v^2}{r} = \dfrac{GMm}{r^2}\) に \(v = \dfrac{2A_0}{r}\) を入れると \(r = \dfrac{4A_0^{\,2}}{GM}\) となり、一致します。

着眼点：有効ポテンシャル

\(U_{\rm eff}(r) = \dfrac{2mA_0^{\,2}}{r^2} - \dfrac{GMm}{r}\) を有効ポテンシャルといいます。\(E = \frac12mv_r^2 + U_{\rm eff}(r)\) は「直線上を動く質点の力学的エネルギー」と同じ形なので、\(r\) の動きは谷の中を往復する玉のように読めます。

  • \(E = E_{\min}\)（谷底）：\(r\) が動けない → 円軌道
  • \(E_{\min} < E < 0\)：\(r\) は2つの転回点の間を往復 → 楕円軌道
  • \(E \ge 0\)：遠くへ行ったきり戻らない

第1項 \(\frac{2mA_0^2}{r^2}\) は近づくほど大きくなる「回転の壁」で、面積速度が 0 でない限り小球は原点に落ちません。

式の立て方：中心力の問題で「最も近づく距離・最も遠い距離」や「円運動になる条件」を問われたら、①面積速度保存で回転方向の速さを \(r\) で表す ②エネルギー保存に代入して \(v_r\) と \(r\) の式にする ③転回点では \(v_r = 0\) とおく。円運動は「谷底（\(dU_{\rm eff}/dr = 0\)）」で、これは向心方向の運動方程式と同じ条件です。
アニメーションで確かめよう：下のグラフが有効ポテンシャル、水平な線が力学的エネルギー \(E\) です。緑の棒（\(E - U_{\rm eff} = \frac12mv_r^2\)）が 0 になる点で \(r\) が折り返します。「はじめの動径方向の速さ」を 0 にすると \(E\) が谷底に一致し、軌道は円になります。
III(1)　量子条件を満たす円軌道の半径答 \(r_n = \dfrac{n^2h^2}{4\pi^2GMm^2}\)

運動方程式と量子条件を連立する

円運動の向心方向の運動方程式と、量子条件（\(\lambda = h/mv\) を代入したもの）は

$$m\frac{v^2}{r_n} = \cfrc{\frac{GMm}{r_n^{\,2}}},\qquad 2\pi r_n = n\,\frac{h}{mv}$$

2本目から \(v = \dfrac{nh}{2\pi m r_n}\) として1本目に代入すると

$$\frac{m}{r_n}\left(\frac{nh}{2\pi m r_n}\right)^2 = \frac{GMm}{r_n^{\,2}}\qquad\therefore\ r_n = \frac{n^2h^2}{4\pi^2GMm^2}$$

水素原子のボーア模型で、クーロン力 \(\dfrac{ke^2}{r^2}\) を万有引力 \(\dfrac{GMm}{r^2}\) に置きかえただけの式です。半径は \(n^2\) に比例し、\(m^2\) に反比例します。

量子条件の意味

\(2\pi r = n\lambda\) は「円周にちょうど \(n\) 個の波が入り、1周して元の波とつながる」という条件です。つながらない半径では波が自分自身と打ち消し合い、安定に存在できません。量子条件は面積速度で書くと \(2mA_v = mvr = n\dfrac{h}{2\pi}\) で、面積速度（角運動量）がとびとびになる、という意味もあります。

式の立て方：ボーア模型型の問題は、どの力でも「向心方向の運動方程式」＋「\(2\pi r = n\lambda\)」の2本で決まります。未知数は \(v\) と \(r\) の2つなので、まず \(v\) を消去します。
アニメーションで確かめよう：円周に沿った波の数が \(n\) です。\(n\) を整数以外（例：2.5）にすると、1周したところで波の山と谷がずれて（赤い印）つながりません。下のグラフは \(r_n\) と \(n\) の関係で、整数の点だけが許される軌道です。
III(2)　暗黒物質の粒子の質量の下限答 \(m \fallingdotseq 10^{-61}\ \mathrm{kg}\)

III(1) を \(m\) について解き、指数で計算する

\(n = 1\) で \(r_1 = R\) とおき、\(m\) について解くと

$$m = \frac{h}{2\pi}\cdot\frac{1}{\sqrt{GMR}}$$

指数だけを足し引きします。

$$GMR = 10^{-10}\times10^{42}\times10^{22} = 10^{54},\qquad \sqrt{GMR} = 10^{27}$$ $$m = \frac{10^{-34}}{10^{27}} = 10^{-61}\ \mathrm{kg}$$

なぜ「下限」になるのか

\(r_1 \propto \dfrac{1}{m^2}\) なので、粒子が軽いほど、許される最小の軌道が大きくなります。\(m\) が \(10^{-61}\ \mathrm{kg}\) より小さいと、いちばん内側の軌道でさえ \(R\) より外になり、銀河の大きさの中にとどまれません。暗黒物質が半径 \(R\) の中に集まっていることから、粒子の質量はこの値以上と言えます。電子（約 \(10^{-30}\ \mathrm{kg}\)）と比べても、\(10^{30}\) 倍以上軽い値です。

式の立て方：桁の見積もりは、文字式のまま目的の量について解いてから、最後に \(10^{n}\) を代入して指数だけを計算します。平方根は指数を半分にする操作です。
アニメーションで確かめよう：\(R\) や \(M\) を変えると、下の対数目盛りの上で質量の下限が動きます。\(R\) を 10 倍にすると \(m\) は \(1/\sqrt{10}\) 倍（指数が 0.5 減る）です。
