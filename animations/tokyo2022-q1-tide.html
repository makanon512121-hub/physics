潮汐力：月と太陽が海を引きのばすしくみ（東京大学 2022年 第1問）

自転による遠心力から始めて、地球と月が共通重心のまわりを回るときに地球上の物体が受ける力を調べます。地球は自転しなくても月のまわりを「公転」していて、その遠心力は地球上のどこでも同じ大きさ・同じ向きです。月の引力は場所によって違うので、その差が潮の満ち干を起こす潮汐力になります。最後に、太陽の潮汐力が月の何倍かを見積もります。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。万有引力定数 \(G\)、地球の質量 \(M_1\)・半径 \(R\)、月の質量 \(M_2\)、地球の中心と月の距離 \(a\) を使います。

I(1)　赤道上と北緯45°での遠心力答 \(f_0 = \dfrac{4\pi^2 mR}{T_1^{\,2}}\)、\(f_1 = \dfrac{2\sqrt2\,\pi^2 mR}{T_1^{\,2}}\)

遠心力は「回転の中心からの距離」で決まる

地球といっしょに回る立場（回転座標系）で見ると、物体には回転軸から外向きに遠心力 \(mr\omega^2\) がはたらきます。ここで \(r\) は回転軸からの距離で、地球の中心からの距離ではありません。自転の角速度は

$$\omega_1 = \frac{2\pi}{T_1}$$

赤道上の点 E は回転軸から \(R\) 離れているので

$$f_0 = mR\omega_1^{\,2} = \frac{4\pi^2 mR}{T_1^{\,2}}$$

緯度 \(\lambda\) の点は、軸から \(R\cos\lambda\) の円を回ります。北緯45°では \(r = \dfrac{R}{\sqrt2}\) なので

$$f_1 = m\frac{R}{\sqrt2}\,\omega_1^{\,2} = \frac{2\sqrt2\,\pi^2 mR}{T_1^{\,2}}$$
式の立て方：円運動の問題では、まず「何を中心に、半径いくつの円を回っているか」を図に描きます。半径が決まれば、遠心力（または向心力）は \(mr\omega^2 = m\dfrac{v^2}{r}\) で書けます。緯度 \(\lambda\) なら半径は \(R\cos\lambda\)、向きは軸に垂直で、地球の中心向きではありません。
アニメーションで確かめよう：緯度を変えると、回る円が小さくなり、遠心力も \(\cos\lambda\) 倍になります。北極（90°）では遠心力はゼロです。下のグラフは \(f/f_0 = \cos\lambda\) です。
I(2)　遠心力を含めた赤道上の重力加速度答 \(g_0 = \dfrac{GM_1}{R^2} - \dfrac{4\pi^2R}{T_1^{\,2}}\)

地上で「重力」と呼んでいるのは、万有引力と遠心力の合力です。赤道上では、万有引力（中心向き）と遠心力（外向き）がちょうど反対向きなので、大きさを引き算できます。

$$mg_0 = G\frac{M_1 m}{R^2} - mR\omega_1^{\,2}\qquad\therefore\quad g_0 = \frac{GM_1}{R^2} - \frac{4\pi^2R}{T_1^{\,2}}$$

表の数値を入れると、万有引力の項は約 \(9.8\ \mathrm{m/s^2}\)、遠心力の項は約 \(0.034\ \mathrm{m/s^2}\) です。遠心力の効果は 0.3 % ほどで、赤道で体重がわずかに軽くなる原因になっています。

式の立て方：回転している物体の上で静止している物体は、回転座標系で「万有引力 ＋ 遠心力 ＋ 垂直抗力 ＝ 0」とつり合いの式を立てます。この「万有引力 ＋ 遠心力」が見かけの重力 \(mg\) です。赤道以外では2つの力が一直線上にないので、ベクトルとして足します（重力の向きも中心から少しずれます）。
アニメーションで確かめよう：自転周期 \(T_1\) を短くしていくと遠心力の矢印が伸び、約 1.4 時間で \(g_0 = 0\)（赤道上の物体が浮く）になります。下のグラフで \(g_0\) と \(T_1\) の関係を確かめられます。
II(1)　地球の中心と月の速さ答 \(v_1 = \sqrt{\dfrac{GM_2^{\,2}}{a(M_1+M_2)}}\)、\(v_2 = \sqrt{\dfrac{GM_1^{\,2}}{a(M_1+M_2)}}\)

① 重心の位置で半径を決める

地球と月は重心 O を中心に同じ周期で回ります。重心の定義 \(M_1a_1 = M_2a_2\)、\(a_1 + a_2 = a\) より

$$a_1 = \frac{M_2}{M_1+M_2}\,a,\qquad a_2 = \frac{M_1}{M_1+M_2}\,a$$

② 地球の運動方程式（向心力 ＝ 月の引力）

共通の角速度を \(\omega_2\) とすると、地球は半径 \(a_1\) の円運動をしていて、その向心力は月の万有引力です。

$$M_1a_1\omega_2^{\,2} = G\frac{M_1M_2}{a^2}\qquad\therefore\quad \omega_2 = \sqrt{\frac{G(M_1+M_2)}{a^3}}$$

速さは \(v = (\text{半径})\times\omega_2\) なので

$$v_1 = a_1\omega_2 = \sqrt{\frac{GM_2^{\,2}}{a(M_1+M_2)}},\qquad v_2 = a_2\omega_2 = \sqrt{\frac{GM_1^{\,2}}{a(M_1+M_2)}}$$
式の立て方：2体が互いの引力で回る問題（連星）は、①「重心は動かない」から各半径を決め、②どちらか一方の運動方程式「質量 × 半径 × \(\omega^2\) ＝ 万有引力」を立てる、の2段階です。引力の式の距離は2体間の距離 \(a\)、円運動の半径は重心からの距離 \(a_1\) と、2つの長さを区別するのがポイントです。
アニメーションで確かめよう：質量比 \(M_2/M_1\) を大きくすると重心 O が月側へ移り、地球の回る円が大きくなります。実際の値 0.0123 では \(a_1\) は約 4700 km で、O は地球の内部にあります。
II(2)　時刻 t における点 X の座標答 \(\left(-R - a_1\cos\dfrac{2\pi t}{T_2},\ -a_1\sin\dfrac{2\pi t}{T_2}\right)\)

自転しない ＝ 平行移動しながら回る

地球の中心は O のまわりを半径 \(a_1\) で回ります。時刻 0 に \((-a_1,\,0)\) にあり、月と反対側を同じ角速度 \(\dfrac{2\pi}{T_2}\) で回るので

$$\text{中心}:\ \left(-a_1\cos\frac{2\pi t}{T_2},\ -a_1\sin\frac{2\pi t}{T_2}\right)$$

地球は自転しないので、地球の向きは変わりません（観覧車のゴンドラと同じ）。点 X は常に中心から \(x\) 方向に \(-R\) ずれた位置にあり、座標は中心の座標に \((-R,\,0)\) を足したものになります。

つまり点 X は、点 \((-R,\,0)\) を中心とする半径 \(a_1\) の円を回ります。X に限らず、地球上のすべての点が同じ半径 \(a_1\)・同じ周期の円運動をしています（円の中心がずれているだけです）。

式の立て方：剛体の運動は「中心（重心）の運動」＋「中心のまわりの回転」に分けて書きます。ここでは回転がないので、どの点の位置も「中心の位置 ＋ 一定のベクトル」です。
アニメーションで確かめよう：地球に描いた矢印は常に同じ向きを向いたままです。X・中心・反対側の点の軌跡が、同じ大きさの円になっていることを確かめましょう。下のグラフは X の \(x\) 座標と \(y\) 座標の時間変化です。
II(3)　地球の公転で生じる遠心力答 \(f_C = \dfrac{GM_2m}{a^2}\)

II(2) で見たように、点 X は半径 \(a_1\)、角速度 \(\omega_2\) の円運動をしています。地球とともに動く立場では、遠心力の大きさは

$$f_C = ma_1\omega_2^{\,2} = m\cdot\frac{M_2a}{M_1+M_2}\cdot\frac{G(M_1+M_2)}{a^3} = \frac{GM_2m}{a^2}$$

これは「地球の中心に置いた質量 \(m\) が月から受ける引力」と同じ大きさです。向きは、すべての点で月から遠ざかる向き（O から地球の中心へ向かう向きと平行）です。

なぜ場所によらないか：遠心力は「その点が描く円の半径と角速度」で決まります。地球が自転していないとき、地球上のどの点も半径 \(a_1\)、角速度 \(\omega_2\) の円を描くので、遠心力は全地点で共通になります。I の自転の遠心力（軸からの距離で変わる）との違いに注意しましょう。
式の立て方：加速度 \(\vec{A}\) で動く座標系では、すべての物体に慣性力 \(-m\vec{A}\) がはたらきます。地球の中心の加速度は「月の引力 ÷ \(M_1\)」なので、慣性力は \(-m\times\dfrac{GM_2}{a^2}\)（月と反対向き）と、計算せずにすぐ書けます。
アニメーションで確かめよう：紫の矢印（遠心力）はどこでも同じ長さ・同じ向きです。緑の矢印（月の引力）は月に近い側ほど長くなります。
II(4)　点 P・点 Q での合力答 \(f_P = \dfrac{GM_2m}{a^2} - \dfrac{GM_2m}{(a+R)^2}\)（月から遠ざかる向き）、\(f_Q = \dfrac{GM_2m}{(a-R)^2} - \dfrac{GM_2m}{a^2}\)（月に近づく向き）

P は月から \(a+R\)、Q は月から \(a-R\) の距離にあります。遠心力はどちらも月から遠ざかる向きに \(\dfrac{GM_2m}{a^2}\) です。

・P：月の引力 \(\dfrac{GM_2m}{(a+R)^2}\) は遠心力より小さい → 合力は月から遠ざかる向き

・Q：月の引力 \(\dfrac{GM_2m}{(a-R)^2}\) は遠心力より大きい → 合力は月に近づく向き

どちらも地球の中心から外向きなので、海水は月の側と反対側の2か所で盛り上がります。地球が自転すると、1日に2回満潮が来る理由がこれです。

近似すると見通しがよくなる

\(R \ll a\) のとき \((1+x)^n \fallingdotseq 1+nx\) を使うと

$$f_P \fallingdotseq f_Q \fallingdotseq \frac{2GM_2mR}{a^3}$$

潮汐力は距離の3乗に反比例します。引力そのもの（2乗に反比例）を距離で微分した「引力の場所による差」だからです。

式の立て方：潮汐力 ＝「その点での引力」−「中心での引力」です（慣性力の考え方）。中心から月の方向に \(x\) ずれた点では \(\dfrac{GM_2m}{(a-x)^2} - \dfrac{GM_2m}{a^2} \fallingdotseq \dfrac{2GM_2m}{a^3}x\) となり、ずれ \(x\) に比例して外向きに引きのばす力になります。
アニメーションで確かめよう：赤い矢印が合力（潮汐力）です。地球の大きさ \(R/a\) を大きくする（誇張する）と、Q の方が P より少し大きいことが分かります。下のグラフは月の方向の位置 \(x\) と潮汐力の関係で、実線が正確な値、点線が近似の直線です。
III　太陽の潮汐力と月の潮汐力の比答 ア 4（\(f_S/f_P \fallingdotseq 0.44\)）

II と同じ考え方で、太陽について S（太陽から最も遠い点）での合力は

$$f_S = \frac{GM_3m}{b^2} - \frac{GM_3m}{(b+R)^2}$$

\(R \ll b\) より \(\dfrac{1}{(b+R)^2} = \dfrac{1}{b^2}\left(1+\dfrac{R}{b}\right)^{-2} \fallingdotseq \dfrac{1}{b^2}\left(1-\dfrac{2R}{b}\right)\) と近似すると

$$f_S \fallingdotseq \frac{2GM_3mR}{b^3},\qquad f_P \fallingdotseq \frac{2GM_2mR}{a^3}$$ $$\frac{f_S}{f_P} \fallingdotseq \frac{M_3}{M_2}\left(\frac{a}{b}\right)^3 = \frac{2.0\times10^{30}}{7.3\times10^{22}}\times\left(\frac{3.8\times10^{8}}{1.5\times10^{11}}\right)^3 \fallingdotseq 0.44$$

よって ア は 4（イ は 5）です。

引力と潮汐力の違い：地球が受ける引力そのものは、太陽の方が月の約 180 倍です。ところが潮汐力は距離の3乗に反比例するので、遠い太陽は不利になり、月の半分ほどになります。
式の立て方：数値の比を求める問題は、まず文字式で比をつくり、共通の因子（\(G, m, R\)）を消してから数値を入れます。\(\left(\dfrac{a}{b}\right)^3\) のように比を先に計算すると、桁の扱いが楽になります。
アニメーションで確かめよう：月が太陽と同じ方向・反対方向にあるとき（新月・満月）は2つの潮汐力が重なって大潮、90°ずれたとき（半月）は打ち消し合って小潮になります。距離 \(a\)、\(b\) を変えると、比が距離の3乗で変わることが確かめられます。
