床の上の3つのおもりと棒（東京大学 2025年 第1問）

3つのおもり A・B・C（どれも質量 m）を棒でつないだ直角三角形の物体を、C につけた糸で水平に引きます。「浮く・倒れる・すべる」の境目を、力の矢印・力のモーメント・グラフで確かめましょう。

設定

見る立場

力の大きさは mg を単位にして表示しています（d = 0.5 m、g = 9.8 m/s² で動かしています）。μ を 1/3 より大きくすると、すべる前に倒れ始める様子も見られます。

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。A の位置を原点、右向き・上向きを正とします。

I(1)　おもり B が床から離れるときの F答 \(F = mg\)

「離れる」＝垂直抗力が 0

物体が床から離れる瞬間を式にするときは、いつでもその点の垂直抗力 \(N_{\mathrm B} = 0\) とおきます。離れる直前まではつり合いが成り立っているので、つり合いの式に \(N_{\mathrm B}=0\) を入れれば境目の値が出ます。

どこのまわりのモーメントを考えるか

A は床に固定されているので、A には「固定するための力」（向きも大きさも分からない）がはたらきます。分からない力が集まっている点を回転軸に選ぶと、その力はモーメントの式から消えます。A のまわりで考えると

  • 糸の力 \(F\)：作用線は高さ \(d\) の水平線 → 腕の長さ \(d\)（B を持ち上げる向き）
  • B の重力 \(mg\)：A から水平に \(d\) 離れている → 腕の長さ \(d\)（B を押し下げる向き）
  • C の重力：C は A の真上なので作用線が A を通る → 0
  • B の垂直抗力 \(N_{\mathrm B}\)：腕の長さ \(d\)（B を持ち上げる向き）
$$F\cdot d + N_{\mathrm B}\cdot d = mg\cdot d$$

\(N_{\mathrm B} = 0\) とおいて

$$F = mg$$
アニメーションで確かめよう：「再生」で \(F\) をゆっくり大きくします。グラフの \(N_{\mathrm B}\) が 1 次関数で減って、\(F = mg\) でちょうど 0 になります。点線は「腕の長さ」です。
I(2)　倒れるまでに必要な仕事 W₀答 \(W_0 = (\sqrt{2}-1)mgd\)

仕事＝エネルギーの増加

糸でゆっくり（運動エネルギーをほぼ 0 のまま）傾けるとき、糸がした仕事はそのまま位置エネルギーの増加になります。力が角度とともに変わっても、エネルギーで考えれば積分しなくてすみます。

どこまで傾ければ倒れるか＝重心が支点の真上

3つのおもりの重心 G は

$$\mathrm G = \left(\frac{0+(-d)+0}{3},\ \frac{0+0+d}{3}\right) = \left(-\frac{d}{3},\ \frac{d}{3}\right),\qquad \mathrm{AG} = \frac{\sqrt2}{3}d$$

A のまわりに傾けると G は A を中心とする半径 \(\mathrm{AG}\) の円の上を動きます。G が A の真上を越えると、重力のモーメントが倒す向きに変わるので、あとは糸を引かなくても倒れます。その瞬間の G の高さは \(\dfrac{\sqrt2}{3}d\)（このとき B と C は同じ高さ）。

$$W_0 = 3mg\left(\frac{\sqrt2}{3}d - \frac{d}{3}\right) = (\sqrt2-1)mgd$$

力で確かめる（別の見方）

角度 \(\theta\) だけ傾けたとき、A のまわりのモーメントのつり合いから \(F = mg(1-\tan\theta)\)。\(\theta = 45^\circ\) で \(F=0\) になり、それ以降は引かなくても倒れます。C の水平移動 \(x = d\sin\theta\) に対する \(F\) のグラフの面積が仕事で、計算すると上と同じ値になります。

アニメーションで確かめよう：重心 G（紫の点）と A を通る鉛直線に注目。G が鉛直線を越えると \(F=0\) でも倒れていきます。左のグラフの塗った面積（仕事）と、右のグラフの位置エネルギーの増加が同じになっています。
II(1)(2)　A を固定しないときの垂直抗力答 \(N_{\mathrm B} = mg - F,\ \ N_{\mathrm A} = 2mg + F\)

(1) A のまわりのモーメント

A が固定されていなくても、A にはたらく力（垂直抗力 \(N_{\mathrm A}\)、静止摩擦力 \(f\)）はどれも A を通るので、A のまわりのモーメントの式は I(1) と同じ形です。

$$F d + N_{\mathrm B} d = mg d \qquad\therefore\quad N_{\mathrm B} = mg - F$$

(2) 物体全体の鉛直方向のつり合い

$$N_{\mathrm A} + N_{\mathrm B} = 3mg \qquad\therefore\quad N_{\mathrm A} = 2mg + F$$

水平に引いたのに垂直抗力が変わる理由

糸は水平なのに、\(N_{\mathrm A}\) は \(F\) だけ増え、\(N_{\mathrm B}\) は \(F\) だけ減ります。高い所（C）を引くと物体を回そうとするモーメントが生じ、それを床が「A を強く・B を弱く」押すことで打ち消しているからです。力の作用点の高さが、垂直抗力の分かれ方を変えます。

アニメーションで確かめよう：\(F\) のスライダーを動かすと、A の上向きの矢印が伸び、B の矢印が縮みます。下のグラフで2本の直線の和がいつも \(3mg\) です。
II(3)　すべり始めるときの F答 \(F = \dfrac{2\mu}{1-\mu}mg\)

必要な摩擦力と最大摩擦力を比べる

B と床の間には摩擦がないので、水平方向のつり合いから A の静止摩擦力は \(f = F\)。静止していられるのは \(f \le \mu N_{\mathrm A}\) の間です。すべり出す境目は

$$F = \mu N_{\mathrm A} = \mu(2mg + F) \qquad\therefore\quad F = \frac{2\mu}{1-\mu}mg$$

ここで大事なのは、\(F\) を大きくすると最大摩擦力 \(\mu N_{\mathrm A}\) も大きくなることです（II(2) より）。だから \(\mu\cdot 3mg\) のような単純な値にはなりません。

すべるのが先か、倒れるのが先か

倒れ始めの条件は I(1) と同じ \(N_{\mathrm B} = 0\)、つまり \(F = mg\)。すべりが先に起こるのは

$$\frac{2\mu}{1-\mu}mg < mg \iff \mu < \frac{1}{3}$$

問題の条件 \(\mu < \dfrac13\) は「倒れる前にすべる」ことを保証していたわけです。「すべる」「倒れる」の両方がありうる問題では、2つの境目の値を比べて小さい方が先に起こると考えます。

アニメーションで確かめよう：「再生」で \(F\) をゆっくり増やします。グラフの「必要な摩擦力 \(f=F\)」と「最大摩擦力 \(\mu N_{\mathrm A}\)」が交わる所ですべり出します。μ を 1/3 より大きくすると、先に \(N_{\mathrm B} = 0\) になって B が浮きます。
III(1)　等速直線運動させる F答 \(F = \dfrac{2\mu'}{1-\mu'}mg\)

等速直線運動＝力のつり合い。静止しているときと同じ式が使えます。違うのは摩擦力が動摩擦力 \(\mu' N_{\mathrm A}\)（向きは運動と逆向き）になることだけです。

$$N_{\mathrm B} = mg - F,\qquad N_{\mathrm A} = 2mg + F,\qquad F = \mu' N_{\mathrm A}$$ $$\therefore\quad F = \frac{2\mu'}{1-\mu'}mg$$

II(3) の式の \(\mu\) を \(\mu'\) に置きかえた形です。「すべり出す直前（最大摩擦力）」と「すべっている間（動摩擦力）」は、どちらも摩擦力が \(\mu N\) の形で決まるので、同じ式の構造になります。

アニメーションで確かめよう：物体は一定の速さで右へ動きます（画面は物体を追いかけ、床の目盛りが流れます）。\(\mu'\) を変えると必要な \(F\) が変わります。
III(2)(3)　糸を離した後の減速答 \(N_{\mathrm B} = m(g-a),\ \ a = \dfrac{2\mu'}{3-\mu'}g\)

(2) 物体といっしょに動く立場で考える

物体は左向きの加速度 \(a\) で減速しているので、物体といっしょに動く立場では、各おもりに右向きの慣性力 \(ma\) がはたらき、物体は静止して見えます。こうすると静止しているときと同じモーメントのつり合いが使えます。

A のまわりのモーメント：C の慣性力は高さ \(d\) にあるので腕の長さ \(d\)。A・B の慣性力は床の高さなので腕は 0。

$$ma\cdot d + N_{\mathrm B}\cdot d = mg\cdot d \qquad\therefore\quad N_{\mathrm B} = m(g-a)$$

I・II の式の \(F\) が \(ma\) に置きかわっています。C にはたらく慣性力が、糸で引く力と同じ役割をしているのです。急ブレーキで背の高い物が前に倒れやすいのも同じ理由です。

(3) 力のつり合いの残り2本

$$\text{鉛直：}\ N_{\mathrm A} + N_{\mathrm B} = 3mg \quad\Rightarrow\quad N_{\mathrm A} = 2mg + ma$$ $$\text{水平：}\ \mu' N_{\mathrm A} = 3ma$$ $$\mu'(2mg + ma) = 3ma \qquad\therefore\quad a = \frac{2\mu'}{3-\mu'}g$$

もし B にも同じ摩擦があれば \(a = \mu' g\) ですが、ここでは摩擦がはたらくのは A だけ。その代わり減速中は A が強く押しつけられる（\(N_{\mathrm A} > 2mg\)）ので、単純に「A の分だけ」\(\dfrac{2\mu'}{3}g\) より少し大きくなります。

アニメーションで確かめよう：「物体といっしょに動く」にすると紫の慣性力の矢印が出ます。C の慣性力が III(1) の糸の力と同じ位置にはたらいていることを見比べてください。グラフの直線の傾きが \(-a\) です。
