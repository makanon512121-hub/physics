ばねでつながった板とおもり：床から浮き上がる条件と重心の運動（名古屋大学 2019年 第1問）

床に置いた板 A の上にばねを立て、おもり B をのせて単振動させます。振幅 d を大きくしていくと、ばねが板を引き上げる力が重力に勝ち、板が床から浮き上がります。「おもりの単振動」「板のつり合い（垂直抗力 N）」「重心の運動」の3つの見方で、浮き上がる条件と浮いた後の運動を確かめます。

問題文は 名古屋大学の公式ページ（試験問題・解答例等） で確認してください。図と解説はこのサイトのオリジナルです。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。上向きを正とします。図の色：おもり B（青）、板 A（紫）、重心（黒）、ばねの力（オレンジ）、床からの垂直抗力（赤）、重力（緑）。

⑴　つり合いでのばねの縮み x₀答 \(x_0=\dfrac{mg}{k}\)

おもり B にはたらく力は、下向きの重力 \(mg\) と、縮んだばねが押し上げる力 \(kx_0\) の2つです。

力のつり合い（おもり B）

$$\cfr{kx_0}=\cgrav{mg}\qquad\therefore\ x_0=\frac{mg}{k}$$
式の立て方：止まっている物体では「上向きの力の和 ＝ 下向きの力の和」です。ばねの力の大きさは「ばね定数 × 自然長からの伸び（縮み）」で、伸び縮みは必ず自然長から測ります。
アニメーションで確かめよう：おもり B の上向きのオレンジの矢印と、下向きの緑の矢印が同じ長さです。\(m\) を大きく、\(k\) を小さくすると縮み \(x_0\) が大きくなります。
⑵　おもり B の角振動数 ω答 \(\omega=\sqrt{\dfrac km}\)

板 A は床の上で止まっているので、ばねの下端は動きません。おもり B だけが、ばねと重力を受けて動きます。つり合いの位置からの変位を \(X=x-(L-x_0)\) とします。

運動方程式（おもり B）

$$m\,a=\cfr{-k(x-L)}\cgrav{-mg}\nobreak=-k\bigl(x-(L-x_0)\bigr)=-k\cacc{X}$$

加速度が「変位に比例し、逆向き」なので単振動です。\(a=-\omega^2X\) と比べて

$$\omega=\sqrt{\frac km}$$

重力はつり合いの位置（振動の中心）を \(x_0\) だけ下げるだけで、角振動数は変えません。鉛直ばね振り子の周期が水平ばね振り子と同じ \(2\pi\sqrt{m/k}\) になるのはこのためです。

式の立て方：単振動では、(1) つり合いの位置を求め、(2) そこからの変位 \(X\) で運動方程式を書き、(3) \(ma=-KX\) の形にして \(\omega=\sqrt{K/m}\) を読み取ります。
アニメーションで確かめよう：\(M\) や \(g\) に関係する量を変えても、下の x–t グラフの周期は変わりません。\(k\) を4倍にすると周期が半分になります。
⑶　時刻 t のおもり B の位置 x答 (え)　\(x=L-x_0-d\cos\omega t\)

単振動の位置は「中心 ＋ 振幅 × (sin または cos)」で表せます。中心・振幅・\(t=0\) の位置の3つを順に決めます。

  • 中心：つり合いの位置 \(x=L-x_0\)（⑴）
  • 振幅：つり合いの位置から押し下げた距離 \(d\)（静かに放したので、そこが折り返し点）
  • \(t=0\)：最も低い点 \(x=L-x_0-d\) から動き始める

単振動の式

$$\cacc{x}=(L-x_0)-\cacc{d}\cos\omega t$$

\(t=0\) を代入すると \(x=L-x_0-d\) になるのは (え) だけです。(お)〜(く) は中心が自然長の位置 \(L\) になっていて、重力で中心が下がることが入っていません。

式の立て方：選択肢の式は、\(t=0\) を代入して出発点と比べると速く絞れます。さらに \(\omega t=\pi/2\) で中心を通ること、\(\omega t=\pi\) で最高点になることを確かめると確実です。
アニメーションで確かめよう：x–t グラフは最低点から始まる \(-\cos\) の形です。点線（中心 \(L-x_0\)）を上下に \(d\) ずつはさんで振動します。
⑷　板 A がばねから受ける力 F答 \(F=-mg-kd\cos\omega t\)

ばねの質量は無視できるので、ばねは両端に大きさの等しい力をおよぼします。縮んでいれば両端を外向きに押し（板 A は下向き）、伸びていれば両端を内向きに引きます（板 A は上向き）。

フックの法則（ばねの伸び \(x-L\)）

$$\cfr{F}=k(x-L)=k(-x_0-d\cos\omega t)\nobreak=-mg-kd\cos\omega t$$

伸び \(x-L\) が正なら \(F>0\)（上向き）、負なら \(F<0\)（下向き）なので、符号まで含めて1つの式で表せます。

別解：おもり B の運動方程式から

B の加速度は \(a=\dfrac{d^2x}{dt^2}=d\omega^2\cos\omega t\) です。B がばねから受ける力を \(f\) とすると \(ma=f-mg\) なので \(f=mg+kd\cos\omega t\)。ばねは A にこれと逆向きの力をおよぼすので \(F=-f\) になります。

式の立て方：ばねの力は「自然長からの伸び」をそのまま符号つきで使うと、向きの場合分けがいりません。軽いばね・軽い糸は、両端に同じ大きさの力を伝える「力の通り道」です。
アニメーションで確かめよう：下のグラフのオレンジの線が \(F\) です。B が最も低いとき（ばねが最も縮むとき）に最も大きく下向きになり、B が自然長の位置より上に来ると \(F\) が正（上向き）に変わります。
⑸　板 A が床から受ける垂直抗力 N答 \(N=(M+m)g+kd\cos\omega t\)

板 A は動かないので、A にはたらく3つの力（重力・ばねの力・垂直抗力）がつり合っています。

力のつり合い（板 A）

$$\cfrc{N}+\cfr{F}-\cgrav{Mg}=0\qquad\therefore\ N=Mg-F\nobreak=(M+m)g+kd\cos\omega t$$

別解：A と B をまとめて見る

A と B をひとまとめにすると、外から受ける力は垂直抗力 \(N\) と重力 \((M+m)g\) だけで、ばねの力は内力として消えます。動いているのは B だけなので

$$m\cdot d\omega^2\cos\omega t=N-(M+m)g$$

からも同じ結果が出ます。B が下で上向きに加速しているときは、床は全体の重さより強く押し返します。

式の立て方：知りたい力が「外力」になるように物体を選びます。\(N\) は A だけを見ても、A＋B 全体を見ても外力です。全体で見るとばねの力を考えなくてよいので計算が短くなります。
アニメーションで確かめよう：赤い線 \(N\) は、平均値 \((M+m)g\)（点線）を中心に \(kd\) の幅で振動します。B が最も高いときに \(N\) が最も小さくなります。
⑹　板 A が浮き上がり始める振幅 d₀答 \(d_0=\dfrac{(M+m)g}{k}\)

板 A が床に接している間は \(N\ge 0\) です。\(N\) が最も小さくなるのは \(\cos\omega t=-1\)（B が最高点）のときなので、その最小値が 0 以上なら A は浮きません。

浮き上がらない条件（\(N\) の最小値 \(\ge 0\)）

$$\cfrc{N_{\min}}=(M+m)g-kd\ \ge\ 0\qquad\therefore\ d\le\frac{(M+m)g}{k}=d_0$$

着眼点：ばねが板を引き上げる力で考える

B が最高点にあるとき、ばねは自然長より \(d-x_0\) だけ伸びて、A を上向きに \(k(d-x_0)\) で引きます。これが A の重さ \(Mg\) を超えると A は浮きます。\(k(d-x_0)=Mg\) より \(d=x_0+\dfrac{Mg}k=\dfrac{(M+m)g}k\) と同じ結果になります。

式の立て方：「床から離れる」は「垂直抗力が 0 になる」と言いかえます。離れるまでの \(N\) を時刻の式で表し、その最小値を調べます。
アニメーションで確かめよう：\(d=d_0\) では、赤い線 \(N\) が最高点でちょうど 0 に触れ、A はぎりぎり浮きません。設定の \(d/d_0\) を 1 より少し大きくすると A が浮きます。
⑺　A が床を離れる時刻 t₁ の cos ωt₁答 \(\cos\omega t_1=-\dfrac{d_0}{d}\)

\(d>d_0\) のとき、⑸の \(N\) が 0 になる最初の時刻が \(t_1\) です。それまで A は止まっているので、⑸の式がそのまま使えます。

床を離れる条件（\(N=0\)）

$$(M+m)g+kd\cos\omega t_1=0\qquad\therefore\ \cos\omega t_1=-\frac{(M+m)g}{kd}=-\frac{d_0}{d}$$

\(-1<\cos\omega t_1<0\) なので \(\dfrac\pi2<\omega t_1<\pi\) です。このとき B はつり合いの位置より上にいて、まだ上向きに動いています。

式の立て方：「〜になった瞬間」は、その瞬間まで成り立っていた式（ここでは⑸）に条件（\(N=0\)）を入れて求めます。
アニメーションで確かめよう：赤い線 \(N\) が 0 に下がった時刻に、縦の点線 \(t_1\) が引かれ、そこから紫の線（A の高さ \(y\)）が持ち上がります。
⑻　時刻 t₁ のおもり B の位置 x₁答 \(x_1=L+\dfrac{Mg}{k}\)

浮き上がる瞬間の A は、垂直抗力 0 のまま、重力 \(Mg\) とばねの引く力がつり合っています。

力のつり合い（板 A、\(N=0\)）

$$\cfr{k(x_1-L)}=\cgrav{Mg}\qquad\therefore\ x_1=L+\frac{Mg}{k}$$

⑶の式に⑺を入れても \(x_1=L-x_0-d\cos\omega t_1=L-x_0+d_0=L+\dfrac{Mg}k\) となり、一致します。\(x_1\) は \(d\) によらず、「ばねが \(Mg/k\) だけ伸びた位置」と決まります。

式の立て方：位置を問われても、まず「その瞬間に何がつり合っているか」を考えると近道になることがあります。
アニメーションで確かめよう：\(d/d_0\) をいろいろ変えても、A が浮き上がるのは B が点線「\(x_1=L+Mg/k\)」に来たときです。
⑼　時刻 t₁ のおもり B の速度 v₁答 \(v_1=\omega\sqrt{d^2-{d_0}^2}\)

⑶の式を時間で微分すると、\(t\le t_1\) の速度は \(v=d\omega\sin\omega t\) です。

単振動の速度

$$\cacc{v_1}=d\omega\sin\omega t_1=d\omega\sqrt{1-\Bigl(\frac{d_0}{d}\Bigr)^2}\nobreak=\omega\sqrt{d^2-{d_0}^2}$$

\(0<\omega t_1<\pi\) なので \(\sin\omega t_1>0\) です（B は上向きに動いている）。

別解：単振動のエネルギー

中心からの変位を \(X\) とすると、単振動では \(\dfrac12mv^2+\dfrac12kX^2=\dfrac12kd^2\) が一定です。\(t_1\) では \(X=x_1-(L-x_0)=d_0\) なので、\(v_1=\sqrt{\dfrac km}\sqrt{d^2-{d_0}^2}\) とすぐに求まります。

式の立て方：単振動の速さは、時刻を経由するより「中心からの変位 \(X\)」と振幅から \(v=\omega\sqrt{A^2-X^2}\) で求めるほうが速いことが多いです。
アニメーションで確かめよう：「いまの値」の \(v_1\)（測定）と式の値を比べてください。\(d\) を \(d_0\) に近づけると \(v_1\) は 0 に近づきます（最高点でぎりぎり浮くため）。
⑽　0 ≦ t ≦ t₂ の重心の高さ z のグラフ答 (b)

重心の運動は、外力（重力と垂直抗力）だけで決まります。ばねの力は内力なので入りません。

重心の運動方程式（A＋B）

$$(M+m)\,a_G=\cfrc{N}-\cgrav{(M+m)g}$$

① \(0：A は床にあり \(y=0\) なので \(z=\dfrac{m x}{m+M}\) です。B は最低点から \(t_1\) まで上がり続ける（⑺より \(\omega t_1<\pi\)）ので、\(z\) は増え続けます。途中で減る (c)(d)(e)(f) は誤りです。

② \(t_1：\(N=0\) なので \(a_G=-g\)。重心は投げ上げた物体と同じ放物線をえがきます。\(t_1\) では \(N\) が連続的に 0 になるので、グラフは折れずになめらかにつながります。

③ \(t=t_2\) の高さ：A が床にあるとき、重心の高さは B の高さ \(x\) で決まります。\(0\le t\le t_2\) では垂直抗力が仕事をしない（A が動かないときだけはたらく）ので、力学的エネルギーが保存します。

力学的エネルギー保存則（A が床にある時刻 \(0\) と \(t_2\) を比べる）

$$mgx+\frac12k(L-x)^2+K=\text{一定}$$

\(mgx+\dfrac12k(L-x)^2=\dfrac12k\bigl(x-(L-x_0)\bigr)^2+(\text{定数})\) と書けるので、運動エネルギー \(K\) が残る \(t_2\) では \(|x-(L-x_0)|x(0)\) です。着地のとき重心は出発点より高く、(a) は誤りで、(b) が正解です。

補足：浮いている間の2物体の動き

浮いている間は、重心が放物運動をしながら、ばねの伸び \(e=x-y-L\) が単振動します。2つの運動方程式を引き算すると \(\ddot e=-k\Bigl(\dfrac1m+\dfrac1M\Bigr)e\) となり、角振動数は \(\omega'=\sqrt{\dfrac{k(M+m)}{mM}}\) です（重力は打ち消し合う）。A の高さ \(y\) は、この2つを組み合わせて求まります。

式の立て方：2物体の運動をグラフで選ぶ問題では、(1) 重心の運動方程式で外力から加速度を決め、(2) 区間の境目で速度がつながるか、(3) 端点の値をエネルギーで比べる、の順に確かめます。
アニメーションで確かめよう：黒い太線が重心の高さ \(z\) です。\(t_1\) から先は放物線になり、\(t_2\) での高さが出発点（灰色の点線）より上にあることを、\(d/d_0\) や \(M/m\) を変えて確かめてください。
