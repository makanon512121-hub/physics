エレクトレット発電：動く電極と多層コンデンサー（東京大学 2024年 第2問）

誘電体の中に電荷を閉じこめた「エレクトレット」の上で、ばねにつるした電極を上下させると、回路に電流が流れて発電できます。極板の電荷と電場・電位の関係、スイッチを開くと電荷一定・閉じると電位一定、そして力学的エネルギーが電気（ジュール熱）に変わる流れを、電位のグラフとエネルギーの棒グラフで確かめましょう。

設定

II の条件

電極は 1 辺 L = 20 cm の正方形、ε0 = 8.85×10⁻¹² F/m。a = ε0d/ε は「誘電体 1 層（厚さ d）が、真空なら何 mm 分にあたるか」を表します。誘電体の厚さは見やすさのため一定の幅で描いています。

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。上電極の電荷を \(q\)、下電極の電荷を \(Q-q\)（2つは導線でつながり、合計 \(Q\) が保存）、金属板の電荷は \(-Q\) のままです。

I(1)　金属板の電位答 \(-\dfrac{Qd}{\varepsilon L^2}\)

平行な極板がつくる電場は「下にある電荷の合計」で決まる

広い平行板が何枚も重なっているとき、全体の電荷の合計が 0 なら外側の電場は 0。そしてある隙間の電場は、それより下にある電荷の合計 \(q_{\text{下}}\) だけで

$$E = \frac{q_{\text{下}}}{\varepsilon L^2}\quad(\text{上向きを正})$$

と書けます（ガウスの法則）。いま下電極 \(+Q\)、金属板 \(-Q\)、上電極 0 なので

  • 下電極〜金属板：\(E = \dfrac{Q}{\varepsilon L^2}\)（上向き）
  • 金属板より上：下の電荷の合計 \(Q-Q=0\) → 電場 0

電場の向きに進むと電位は下がるので、下電極（電位 0）から \(d\) 上の金属板は

$$V_{\text{金属板}} = 0 - Ed = -\frac{Qd}{\varepsilon L^2}$$
アニメーションで確かめよう：右の電位グラフで、下電極から金属板までだけ電位が下がり、その上は平らです。上電極（電荷 0）は金属板と同じ電位になっています。
I(2)　スイッチを閉じた後の上電極の電荷答 \(\dfrac Q2\)

スイッチを閉じる＝上電極と下電極が同じ電位

上電極の電荷を \(q\) とすると下電極は \(Q-q\)。I(1) と同じ考え方で

  • 下の誘電体（下電極〜金属板）：下の電荷 \(Q-q\) → 電位は \(\dfrac{(Q-q)d}{\varepsilon L^2}\) 下がる
  • 上の誘電体（金属板〜上電極）：下の電荷 \((Q-q)-Q = -q\) → 電位は \(\dfrac{qd}{\varepsilon L^2}\) 上がる

上電極が \(z=0\)（真空のすき間なし）で、上下の電極が同じ電位になるには、下がる量と上がる量が等しく

$$\frac{(Q-q)d}{\varepsilon L^2} = \frac{qd}{\varepsilon L^2}\qquad\therefore\quad q = \frac Q2$$

金属板の \(-Q\) が、上下同じ形のコンデンサーに半分ずつ相手の電荷を引きよせた、とも見られます。

一般の高さ z では

真空のすき間 \(z\) でも電位が \(\dfrac{qz}{\varepsilon_0L^2}\) 上がるので、\(\dfrac{(Q-q)d}{\varepsilon} = \dfrac{qd}{\varepsilon} + \dfrac{qz}{\varepsilon_0}\) より

$$q = Q\cdot\frac{d/\varepsilon}{2d/\varepsilon + z/\varepsilon_0} = Q\cdot\frac{a}{2a+z}\qquad\left(a = \frac{\varepsilon_0 d}{\varepsilon}\right)$$

電極が離れるほど引きよせられる電荷は減ります。これが発電のしくみの核心です（下の q–z グラフの点線）。

アニメーションで確かめよう：スイッチを閉じると抵抗に電流が流れ、上電極の電荷が 0 から \(Q/2\) に増えます。電位グラフで上電極の電位が 0 になるまで電荷が移ります。
I(3)　スイッチを開いて静止する位置答 \(z_0 = h_0 - \dfrac{Q^2}{8k\varepsilon_0L^2}\)

極板が受ける力は「自分以外がつくる電場」× 電荷

上電極のすぐ下の電場は \(E = \dfrac{q}{\varepsilon_0L^2}\)（下向き）。でもこれは上電極自身の電荷もつくった電場で、自分の電場で自分は押されません。自分以外がつくる電場はその半分なので、引力の大きさは

$$F = q\cdot\frac E2 = \frac{q^2}{2\varepsilon_0L^2}$$

スイッチを開くと \(q = Q/2\) のまま変わらないので \(F = \dfrac{Q^2}{8\varepsilon_0L^2}\)、高さによらず一定です。

ばね＋重力は「h₀ からのずれ」に比例

電荷がないときのつり合いが \(z = h_0\) なので、ばねの力と重力の合力は上向きに \(k(h_0-z)\)。つり合いは

$$k(h_0-z_0) = \frac{Q^2}{8\varepsilon_0L^2}\qquad\therefore\quad z_0 = h_0 - \frac{Q^2}{8k\varepsilon_0L^2}$$
アニメーションで確かめよう：下の右のグラフで、上向きの力 \(k(h_0-z)\)（直線）と一定の静電気力が交わる高さが \(z_0\) です。外力で電極をゆっくり持ち上げ、交点で手を離すと止まったままになります。
I(4)　上電極の電位答 \(\dfrac{Q}{2\varepsilon_0L^2}\left(h_0 - \dfrac{Q^2}{8k\varepsilon_0L^2}\right)\)

電荷 \(q = Q/2\) のまま、下から電位を足していきます。

$$V = \underbrace{-\frac{(Q/2)d}{\varepsilon L^2}}_{\text{下の誘電体}} + \underbrace{\frac{(Q/2)d}{\varepsilon L^2}}_{\text{上の誘電体}} + \underbrace{\frac{(Q/2)z_0}{\varepsilon_0L^2}}_{\text{真空のすき間}} = \frac{Qz_0}{2\varepsilon_0L^2}$$

誘電体の部分は打ち消し合い（\(z=0\) の電位は 0 のまま）、すき間の電場 × すき間の長さだけが残ります。スイッチが開いているので、上電極は下電極と違う電位になれます。

アニメーションで確かめよう：電位グラフで、\(z=0\) の電位が 0 のまま、すき間だけ電位が直線的に上がります。電極が上がるほど電位が高くなる＝電荷を押し出す力が強くなる、これが (II) で電流が流れる理由です。
II(1)　スイッチを開いて手を離したときの最高点答 \(h_1 = 2h_0 - \dfrac{Q^2}{4k\varepsilon_0L^2}\)

一定の力＋ばね ＝ 中心がずれた単振動

スイッチを開くと電荷は \(Q/2\) のまま → 静電気力は一定。ばね＋一定の力は、つり合いの位置 \(z_0\)（I(3)）を中心とする単振動になります（ばねにおもりをつるしても単振動の周期が変わらないのと同じ）。

\(z=0\) で静かに離すので、そこが振動の下の端。上の端はつり合いの位置について対称な \(2z_0\)：

$$h_1 = 2z_0 = 2h_0 - \frac{Q^2}{4k\varepsilon_0L^2}$$
アニメーションで確かめよう：（ア）→（イ）→（ウ）で、電極が \(z_0\) を中心に上がり \(h_1\) で止まります。下の q–z グラフでは電荷一定なので水平に右へ進みます。
II(2)　h₁ でスイッチを閉じたときの発熱答 \(\dfrac{Q^2h_1}{10\varepsilon_0L^2}\)

まず Q/10 になる条件から d/ε を求める

I(2) の一般式で \(z = h_1\)、\(q = Q/10\) とおくと

$$\frac{a}{2a+h_1} = \frac1{10}\qquad\therefore\quad a = \frac{\varepsilon_0 d}{\varepsilon} = \frac{h_1}{8}$$

発熱＝静電エネルギーの減少

電極を固定してスイッチを閉じるとき、電池も外力の仕事もないので、抵抗の発熱はコンデンサーにたくわえられたエネルギーの減少分です。3つの層のエネルギーの和は

$$U(z,q) = \frac{(Q-q)^2}{2C_1} + \frac{q^2}{2C_1} + \frac{q^2}{2C_z},\qquad C_1 = \frac{\varepsilon L^2}{d},\ C_z = \frac{\varepsilon_0L^2}{z}$$

\(q: \dfrac Q2 \to \dfrac Q{10}\) での減少を、\(\dfrac{d}{\varepsilon} = \dfrac{h_1}{8\varepsilon_0}\) を使って計算すると

$$U\!\left(h_1,\tfrac Q2\right)-U\!\left(h_1,\tfrac Q{10}\right) = \frac{Q^2}{\varepsilon_0L^2}\left(\frac{6h_1}{25}-\frac{8}{25}\cdot\frac{h_1}{8}\right) = \frac{Q^2h_1}{10\varepsilon_0L^2}$$

電極が離れると「引きよせておける電荷」が減り（\(Q/2 \to Q/10\)）、余った電荷が抵抗を通って下電極へ戻る＝電流が流れて発電します。

アニメーションで確かめよう：（エ）で抵抗を電流が下向きに流れ、発熱の棒が伸びます。q–z グラフでは点線（スイッチを閉じたときの電荷）まで真下に下がります。
II(3)　おもりの質量答 \(M = \dfrac{3Q^2}{25\varepsilon_0L^2g}\)

スイッチを開くと電荷は \(Q/10\) で一定、静電気力は \(\dfrac{(Q/10)^2}{2\varepsilon_0L^2} = \dfrac{Q^2}{200\varepsilon_0L^2}\) で一定。おもりの重力も一定なので、また単振動です。

\(h_1\) で静かに離して最低点が \(0\) → 振動の中心は \(\dfrac{h_1}{2} = z_0\)。中心はつり合いの位置なので

$$Mg + \frac{Q^2}{200\varepsilon_0L^2} = k(h_0-z_0) = \frac{Q^2}{8\varepsilon_0L^2}\qquad\therefore\quad M = \frac{3Q^2}{25\varepsilon_0L^2g}$$

II(1) と同じ「端の2点の真ん中がつり合いの位置」という単振動の性質を使っています。

アニメーションで確かめよう：（オ）→（カ）で、おもりをのせた電極が \(h_1/2\) を中心に下がり、\(z=0\) でちょうど止まります。
II(4)　1サイクルの発熱答 \(\dfrac{3Q^2h_1}{25\varepsilon_0L^2}\)

（キ）の発熱

\(z=0\) でスイッチを閉じ、\(q: \dfrac Q{10}\to\dfrac Q2\)。真空のすき間がないので

$$U\!\left(0,\tfrac Q{10}\right)-U\!\left(0,\tfrac Q2\right) = \frac{(9Q/10)^2+(Q/10)^2-2(Q/2)^2}{2C_1} = \frac{4Q^2d}{25\varepsilon L^2} = \frac{Q^2h_1}{50\varepsilon_0L^2}$$

合計と、その意味

$$\frac{Q^2h_1}{10\varepsilon_0L^2} + \frac{Q^2h_1}{50\varepsilon_0L^2} = \frac{3Q^2h_1}{25\varepsilon_0L^2}$$

これは II(3) の \(M\) を使うと、ちょうど \(Mgh_1\)。1 サイクルで電極・ばね・電荷はすべて元にもどり、変わったのは「おもりが \(h_1\) から 0 まで下がった」ことだけ。おもりが失った位置エネルギーが、そのままジュール熱になったのです。エレクトレット発電は、振動などの力学的エネルギーを電気エネルギーに変える装置だと分かります。

こうした「1 サイクルで元にもどる」問題では、エネルギー保存を全体に使うと検算になります（\(a\) の値によらず、発熱の合計はいつも \(Mgh_1\)）。

アニメーションで確かめよう：q–z グラフでは長方形をひと回りします。エネルギーの棒グラフで、1サイクル後の発熱の合計が \(Mgh_1\)（点線）にぴったり一致します。「II の条件」のチェックを外して \(a\) を変えても一致します。
