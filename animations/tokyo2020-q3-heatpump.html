おもりと断熱変化で熱を運ぶ：気体のヒートポンプ（東京大学 2020年 第3問）

ピストンつきの容器 X を、冷たい物体 Z と温かい容器 Y の間で行き来させながら、おもりを減らす・増やすことで気体に仕事をします。断熱変化と定圧変化を組み合わせると、低温の物体から高温の物体へ熱を運べることを、p–V 図とエネルギーの収支で確かめます。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。気体はどれも 1 mol の単原子分子理想気体で、定積モル比熱 \(\frac32R\)、定圧モル比熱 \(\frac52R\) です。「された仕事」は気体が外からされた仕事（圧縮で正）です。色は図と式で共通です：仕事（青）、熱（赤）、内部エネルギー（紫）、容器 X の温度（オレンジ）、容器 Y の温度（緑）。

I　操作①（A→B）で気体がされた仕事 W₁答 \(W_1 = \dfrac{3}{2a^2}RT_{\rm A}(1-a^2)\)

まず「どんな変化か」を見抜く

操作①では X はどこにも触れていないので熱の出入りがなく、おもりを徐々に減らすので断熱変化です。表の値でも \(pV^{5/3}\) が A と B で等しくなっていて、ポアソンの式を満たしています。

断熱変化の仕事は内部エネルギーの変化から

熱力学第一法則 \(\Delta U = Q + W\) で \(Q = 0\) なので、された仕事は内部エネルギーの変化に等しくなります。

$$\cacc{W_1} = \cfic{\Delta U} = \frac32R\left(\frac{T_{\rm A}}{a^2} - T_{\rm A}\right) = \frac{3}{2a^2}RT_{\rm A}(1-a^2)$$

\(a>1\) なので \(W_1<0\)：気体は膨張して外に仕事をし、その分だけ温度が下がります。

式の立て方：断熱変化の仕事は \(\int p\,dV\) を計算せずに、「\(W = \Delta U = \frac32nR\Delta T\)」で求めます。断熱変化かどうかは「熱を通す相手に触れているか」「ゆっくりか」で判断し、ポアソンの式 \(pV^\gamma = \)一定（単原子で \(\gamma = \frac53\)）で確かめられます。
アニメーションで確かめよう：おもりが \(a^5m\) から \(m\) まで小さくなると、ピストンが上がり、気体の色が青く（温度が低く）なります。下の p–V 図で、断熱線の下の面積が \(|W_1|\) です。
I　操作②（B→C）で気体がされた仕事 W₂答 \(W_2 = RT_{\rm A}\left(\dfrac{1}{a^2} - \dfrac45\right)\)

定圧変化の仕事は「−圧力 × 体積変化」

おもりは \(m\) のままなので、圧力は \(\dfrac{p_{\rm A}}{a^5}\) で一定です。気体がされた仕事は

$$\cacc{W_2} = -p\,\Delta V = -\frac{p_{\rm A}}{a^5}\left(\frac45a^5\frac{RT_{\rm A}}{p_{\rm A}} - a^3\frac{RT_{\rm A}}{p_{\rm A}}\right) = RT_{\rm A}\left(\frac{1}{a^2} - \frac45\right)$$

状態方程式を使えば \(-p\Delta V = -R\Delta T\) なので、温度差 \(\frac45T_{\rm A} - \frac{T_{\rm A}}{a^2}\) から直接 \(-R\Delta T\) としても同じです。

着眼点：定圧変化は 5 : 3 : (−2)

単原子分子の定圧変化では、もらう熱 \(Q\)、内部エネルギーの変化 \(\Delta U\)、された仕事 \(W\) が

$$Q : \Delta U : W = \frac52R\Delta T : \frac32R\Delta T : (-R\Delta T) = 5 : 3 : (-2)$$

どれか1つが分かれば、残りは比で求まります。操作②で Z からもらう熱は \(\cfrc{Q_2} = \frac52R\left(\frac45T_{\rm A} - \frac{T_{\rm A}}{a^2}\right)\) です。

式の立て方：定圧変化では「\(W = -p\Delta V = -nR\Delta T\)」「\(Q = nC_p\Delta T\)」「\(\Delta U = nC_v\Delta T\)」の3つが温度差 \(\Delta T\) だけで書けます。圧力が一定かどうかは、ピストンの上のおもりが変わらないか（力のつり合い）で判断します。
アニメーションで確かめよう：X が Z に触れると、Z（\(\frac45T_{\rm A}\)）の方が温かいので熱が流れこみ、気体が膨張します（\(a>\frac{\sqrt5}{2}\) のとき）。p–V 図では水平な線で、その下の長方形の面積が \(|W_2|\) です。上の式の下に 5 : 3 : (−2) の数値が表示されます。
I　操作③（C→D）で気体がされた仕事 W₃答 \(W_3 = \dfrac65RT_{\rm A}(a^2-1)\)

ふたたび断熱変化

X をどこにも触れない位置に戻して、おもりを徐々に増やすので断熱圧縮です。

$$\cacc{W_3} = \cfic{\Delta U} = \frac32R\left(\frac45a^2T_{\rm A} - \frac45T_{\rm A}\right) = \frac65RT_{\rm A}(a^2-1)$$

\(W_3>0\)：圧縮されて仕事をされ、温度が \(\frac45T_{\rm A}\) から \(\frac45a^2T_{\rm A}\) に上がります。断熱変化では温度が圧力の \(\frac25\) 乗に比例する（\(T\propto p^{2/5}\)）ので、圧力が \(a^5\) 倍になると温度は \(a^2\) 倍です。

式の立て方：断熱変化での温度の変わり方は、状態方程式 \(pV = nRT\) とポアソンの式 \(pV^{5/3} = \)一定 から \(V\) を消して \(T \propto p^{2/5}\) と覚えておくと速く求まります。この問題のおもりが \(a^5m\) という中途半端な値なのは、温度がちょうど \(a^2\) 倍になるようにするためです。
アニメーションで確かめよう：おもりが増えるにつれてピストンが下がり、気体の色が赤く（温度が高く）なります。p–V 図で、操作①より右側（高温側）の断熱線を上っていきます。
II(1)(2)　操作④の ΔU₄ と W₄答 \(\Delta U_4 = \dfrac32R(T_{\rm E}-T_{\rm D})\)，\(W_4 = -R(T_{\rm E}-T_{\rm D})\)

内部エネルギーは温度だけで決まる

$$\cfic{\Delta U_4} = \frac32R(T_{\rm E} - T_{\rm D})$$

おもりは \(a^5m\) のまま → 定圧変化

圧力は \(p_{\rm A}\) で一定です。状態方程式 \(p_{\rm A}V_{\rm D} = RT_{\rm D}\)、\(p_{\rm A}V_{\rm E} = RT_{\rm E}\) を使うと

$$\cacc{W_4} = -p_{\rm A}(V_{\rm E} - V_{\rm D}) = -R(T_{\rm E} - T_{\rm D})$$

別の立て方：定圧なので X がもらう熱は \(\cfrc{Q_4} = \frac52R(T_{\rm E}-T_{\rm D})\)、第一法則 \(W_4 = \Delta U_4 - Q_4\) からも同じ式が出ます（5 : 3 : (−2) の比）。\(T_{\rm E}<T_{\rm D}\) なら \(W_4>0\) で、X は冷えて縮みます。

式の立て方：熱を受けるのが「おもりつきピストン」なら定圧、「体積一定の容器」なら定積です。同じ温度変化でも、定圧の気体は仕事の分だけ多くの熱をやりとりします。
アニメーションで確かめよう：X が Y に触れると、X は温度が下がって縮み（ピストンが下がる）、Y は温度が上がります。下の棒グラフで、X の \(Q_4 : \Delta U_4 : W_4\) が 5 : 3 : (−2) になっています。
II(3)　状態 E の温度 TE答 \(T_{\rm E} = \dfrac{3T_{\rm A} + 5T_{\rm D}}{8}\)

X が出した熱 ＝ Y がもらった熱

X と Y の外とは熱のやりとりがないので、X が出した熱はすべて Y に入ります。X は定圧変化（\(C_p = \frac52R\)）、Y は定積変化（\(C_v = \frac32R\)）です。

$$\cfrc{\frac52R(T_{\rm D} - T_{\rm E})} = \cfrc{\frac32R(T_{\rm E} - T_{\rm A})}\qquad\Longrightarrow\qquad T_{\rm E} = \frac{3T_{\rm A} + 5T_{\rm D}}{8}$$

重みが \(5:3\) の平均になり、定圧の X の方が「熱容量が大きい」ので、\(T_{\rm E}\) は \(T_{\rm D}\) の側に寄ります。

別の立て方：X と Y をまとめた系

X と Y をひとまとめにすると、外からされた仕事は \(W_4\) だけ（Y は体積一定）、熱の出入りはありません。

$$\cfic{\Delta U_4 + \Delta U_{\rm Y}} = \cacc{W_4}\quad\Longrightarrow\quad \frac32R(T_{\rm E}-T_{\rm D}) + \frac32R(T_{\rm E}-T_{\rm A}) = -R(T_{\rm E}-T_{\rm D})$$

整理すると同じ \(T_{\rm E}\) です。「どこまでを1つの系とみるか」を変えると、立てる式が変わります。

式の立て方：熱平衡の問題は「出た熱 ＝ 入った熱」（熱量保存）で立てます。このとき、それぞれの気体が定圧か定積かで比熱が変わることに注意します。迷ったら、全体の系で「\(\Delta U_{\rm 合計} = \)外からされた仕事 ＋ 外からもらった熱」を立てると確実です。
アニメーションで確かめよう：下のグラフは X（オレンジ）と Y（緑）の温度で、両者は \(T_{\rm E}\)（点線）で一致します。X の温度の下がり幅と Y の上がり幅の比はつねに \(3:5\) です。
III(1)　ΔUY > 0 のときの p–V 図答 オ

4つの過程の形を決める

  • ①・③：断熱変化。①は膨張（右下へ）、③は圧縮（左上へ）。
  • ②：圧力 \(\dfrac{p_{\rm A}}{a^5}\) の定圧変化（低い水平線）。
  • ④：圧力 \(p_{\rm A}\) の定圧変化（A と同じ高さの水平線）。

ΔUY > 0 から向きを決める

Y の内部エネルギーが増えるのは、X から Y に熱が流れるとき、つまり接触前に \(T_{\rm D} > T_{\rm A}\) のときです。すると \(T_{\rm A} < T_{\rm E} < T_{\rm D}\) で、圧力 \(p_{\rm A}\) の水平線上で E は A と D の間にあります。④は D から E へ左向き（冷えて縮む）です。

また D は A より高温なので、同じ圧力の D は A より右にあります。③の断熱線は①の断熱線より右（高温側）を通るので、C は B より右、②は右向き（膨張）です。この条件をすべて満たすのがオです。

式の立て方：p–V 図を選ぶ問題では、①各過程が等温・断熱・定圧・定積のどれか ②同じ圧力（同じ体積）の2状態の温度の大小 → 左右（上下）の位置関係、の順に絞ります。理想気体では、同じ圧力なら温度が高い方が右です。
アニメーションで確かめよう：1サイクル全体を再生します。\(a\) を \(\frac{\sqrt5}{2} \approx 1.118\) より小さくすると、D が A より左になり、④の矢印の向きが逆（X が Y から熱をもらう）になります。
III(2)　ΔUY > 0 となる a の条件答 \(a > \dfrac{\sqrt5}{2}\)

熱は高温から低温へ

Y の温度が上がるには、接触する直前の X が Y より高温であればよいので

$$\cfr{T_{\rm D}} > \cgrav{T_{\rm A}}\quad\Longleftrightarrow\quad \frac45a^2T_{\rm A} > T_{\rm A}\quad\Longleftrightarrow\quad a > \frac{\sqrt5}{2}$$

II(3) の \(T_{\rm E} = \dfrac{3T_{\rm A}+5T_{\rm D}}{8} > T_{\rm A}\) から出発しても同じ条件になります。

着眼点：同じ条件の言いかえ

\(a > \frac{\sqrt5}{2}\) は、操作②の直前の温度 \(T_{\rm B} = \dfrac{T_{\rm A}}{a^2}\) が Z の温度 \(\frac45T_{\rm A}\) より低い、という条件とも同じです。つまり「断熱膨張で Z より冷たくなるまで冷やせれば、Z から熱を吸える」→「断熱圧縮で Y より熱くできる」→「Y に熱を渡せる」がつながっています。冷蔵庫やエアコン（ヒートポンプ）は、冷媒を膨張させて冷やし、圧縮して温めることで、同じしくみで熱を低温から高温へ運んでいます。

式の立て方：「熱が流れる向き」の条件は、接触する2つの物体の温度の大小に言いかえます。温度は表や状態方程式から \(a\) の式で書けるので、不等式を解くだけです。
アニメーションで確かめよう：下のグラフは \(T_{\rm D}/T_{\rm A} = \frac45a^2\) と \(a\) の関係です。\(a\) を動かして、1 を超える境目が \(\frac{\sqrt5}{2}\) であることを確かめてください。境目では \(T_{\rm B}\) と Z の温度も一致します。
III(3)　ΔUY を W と Q₂ で表す答 \(\Delta U_{\rm Y} = \dfrac{Q_2 + W}{2}\)

X と Y をまとめた系のエネルギー収支

操作①〜④の間に、X と Y をまとめた系が外から受け取ったエネルギーは、Z からの熱 \(Q_2\) と、X がされた仕事の合計 \(W\) だけです（④の X→Y の熱は系の内部のやりとり）。

X ははじめ \(T_{\rm A}\)、最後に \(T_{\rm E}\)。Y も \(T_{\rm A}\) から \(T_{\rm E}\)。どちらも 1 mol の単原子分子なので、内部エネルギーの変化はどちらも \(\Delta U_{\rm Y}\) で、合計 \(2\Delta U_{\rm Y}\) です。

$$\cfrc{Q_2} + \cacc{W} = \cfic{2\Delta U_{\rm Y}}\qquad\Longrightarrow\qquad \Delta U_{\rm Y} = \frac{Q_2 + W}{2}$$

別の立て方：X だけに第一法則

X がもらった正味の熱は \(Q_2 - \Delta U_{\rm Y}\)（Y に渡した熱は Y の内部エネルギーの増加に等しい）で、X の内部エネルギーの変化も \(\Delta U_{\rm Y}\) です。\(\Delta U_{\rm Y} = (Q_2 - \Delta U_{\rm Y}) + W\) を解いても同じ式になります。

式の立て方：複数の物体が熱をやりとりする問題では、「系の境界」を決めて、境界を横切る熱と仕事だけを数えます。内部どうしのやりとり（ここでは④の熱）は打ち消し合うので、細かく追わなくてよくなります。
アニメーションで確かめよう：下の棒グラフは1サイクル分の \(W_1\)〜\(W_4\)、その和 \(W\)、\(Q_2\)、\(2\Delta U_{\rm Y}\) です。\(Q_2 + W\) の棒と \(2\Delta U_{\rm Y}\) の棒が同じ高さになります。\(a\) を変えても成り立ちます。
III(4)　くり返したときの Y の温度 TF答 \(T_{\rm F} = \dfrac45a^2T_{\rm A}\)

着眼点：状態 C は毎回同じ

2回目以降、X は状態 E（圧力 \(p_{\rm A}\)、温度は Y と同じ）から出発するので、状態 B は1回目と違います。しかし操作②で Z に触れると、温度は必ず \(\frac45T_{\rm A}\)、圧力は \(\frac{p_{\rm A}}{a^5}\) になり、状態 C は毎回同じです。そこから③の断熱圧縮で、状態 D も毎回同じ \(T_{\rm D} = \frac45a^2T_{\rm A}\) になります。

漸化式で追う

\(n\) 回目の後の Y の温度を \(T_n\) とすると、II(3) と同じ熱量保存から

$$\cgrav{T_{n+1}} = \frac{3T_n + 5T_{\rm D}}{8}\qquad\Longrightarrow\qquad T_n - T_{\rm D} = \left(\frac38\right)^n(T_{\rm A} - T_{\rm D})$$

差が毎回 \(\frac38\) 倍に縮むので、\(T_n\) は \(T_{\rm D}\) に近づきます。

$$T_{\rm F} = T_{\rm D} = \frac45a^2T_{\rm A}$$

Y が \(T_{\rm D}\) まで温まると、X と接触しても温度差がなくなり、それ以上熱を運べません。もっと高温にしたければ \(a\)（おもりの比）を大きくして \(T_{\rm D}\) を上げる必要があります。

式の立て方：「何度もくり返すと近づく値」は、①毎回変わらない状態（ここでは C と D）を探す ②1回分の変化を漸化式にする ③「変化しなくなる値」（\(T_{n+1} = T_n\) とおく）を求める、の順に考えます。③だけなら漸化式を解かなくても答えが出ます。
アニメーションで確かめよう：サイクルを何度も回すと、Y の温度（緑）が階段状に上がり、\(T_{\rm D}\)（点線）に近づきます。1回ごとの上がり幅が前の回の \(\frac38\) 倍になっていることを、下のグラフの点で確かめてください。

発展：閉じたサイクルにしたときの「仕事と熱の比」

④で Y を使わずに状態 A まで戻すと、断熱2本と定圧2本の閉じたサイクルになります。このとき外からした仕事 \(W\) と、低温側（操作②）で吸った熱 \(Q\) の比は、表の温度を使うと

$$\frac{\cacc{W}}{\cfrc{Q}} = \frac{T_{\rm A}-T_{\rm D}}{T_{\rm B}-T_{\rm C}} - 1 = a^2 - 1 = \frac{T_{\rm A}}{T_{\rm B}} - 1$$

となります。断熱線どうしでは温度の比が同じ（\(T_{\rm D}/T_{\rm A} = T_{\rm C}/T_{\rm B}\)）ことがポイントです。\(a\) が 1 に近い（温度差が小さい）ほど、少ない仕事で多くの熱を運べます。
