ドップラー効果とうなりで距離と速さを測る（東京大学 2024年 第3問）

動く音源の波面が詰まる様子と、反射音とのうなりを、波面のアニメーションとx–t 図（時空図）で確かめます。後半は振動数が時間とともに変わる音を使い、うなりから反射板までの距離と速さを測る方法（レーダーと同じ原理）を調べます。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。音速は \(V\)、音の速さは音源や反射板の動きに関係なく空気に対して \(V\) です。

I(1)　時刻 t₁ に出た音が P に届く時刻答 \(\left(2-\dfrac{v_s}{V}\right)\dfrac LV\)

\(t=0\) に原点で出た音が P に届く時刻は \(t_1 = \dfrac LV\)。その瞬間、音源は \(x = v_st_1\) にいて、そこで出た音が残り \(L - v_st_1\) を速さ \(V\) で進みます。

$$t_1 + \frac{L-v_st_1}{V} = \frac LV + \frac LV - \frac{v_s}{V}\cdot\frac LV = \left(2-\frac{v_s}{V}\right)\frac LV$$

一般化：出た時刻 → 届く時刻の対応

時刻 \(t_e\) に出た音が P に届く時刻は

$$t_{\text{着}} = t_e + \frac{L - v_st_e}{V} = \frac LV + \left(1-\frac{v_s}{V}\right)t_e$$

この1本の式から、ドップラー効果の公式がすぐに出てきます（次の (2)）。

アニメーションで確かめよう：下の x–t 図で、音の波面は傾きが一定の直線（速さ \(V\)）、音源は傾きのゆるい直線です。赤い波面（\(t=0\) に出た音）と青い波面（\(t_1\) に出た音）が P に届く時刻の差が \(\left(1-\dfrac{v_s}{V}\right)t_1\) に縮んでいます。
I(2)　点 P で位相が 2π 変化する時間答 \(\dfrac{V-v_s}{V}\cdot\dfrac1{f_0}\)

音源は 1 周期 \(\dfrac1{f_0}\) ごとに波の山を出します。(1) の式で \(t_e\) が \(\dfrac1{f_0}\) 増えると、届く時刻は \(\left(1-\dfrac{v_s}{V}\right)\dfrac1{f_0}\) 増えるので、P での周期は

$$T_P = \frac{V-v_s}{V}\cdot\frac1{f_0}\qquad\left(f_P = \frac{V}{V-v_s}f_0\right)$$

次の山を出すまでに音源が \(\dfrac{v_s}{f_0}\) だけ前に進むので、波長が \(\dfrac{V-v_s}{f_0}\) に縮むと考えても同じです。公式を覚えるより「出た時刻と届く時刻の対応」を作れば、どんな状況でもドップラー効果が計算できます。

アニメーションで確かめよう：音源の前（右）では波面の間隔が詰まり、後ろ（左）では広がります。\(v_s\) を大きくすると差がはっきりします。
I(3)　音源と一緒に動く観測者が聞くうなり答 \(\dfrac{2v_s}{V-v_s}f_0\)

反射板＝「受けた音をそのまま出し直す音源」

静止した反射板は、受けた振動数 \(f_P = \dfrac{V}{V-v_s}f_0\) の音をそのまま送り返します。観測者はその反射音に速さ \(v_s\) で近づいているので、1 秒間に出会う波の数が増えて

$$f_{\text{反}} = \frac{V+v_s}{V}f_P = \frac{V+v_s}{V-v_s}f_0$$

一方、直接音は音源と観測者が一緒に動いているので（相対的に止まっている）\(f_0\) のまま。うなりの振動数は振動数の差です：

$$\left|\frac{V+v_s}{V-v_s}f_0 - f_0\right| = \frac{2v_s}{V-v_s}f_0$$

「反射した音とのうなりで自分の速さが分かる」——これはスピード測定器（ドップラーレーダー）の原理です。

アニメーションで確かめよう：上段が直接音、下段が反射音の波面です。右下の波形は観測者が聞く音（2つの音の和）で、大きさがゆっくりふくらんだりしぼんだりする周期が、うなりの周期です。
I(4)　点 Q で聞くうなりが始まる時刻と振動数答 時刻 \(\dfrac{L}{2v_s}\)、振動数 \(\dfrac{2v_sV}{V^2-v_s^{\,2}}f_0\)

音源が Q を通りすぎるまでは、うなりがない

音源が Q の手前にいる間、Q に届く直接音は近づく音源からの音で \(\dfrac{V}{V-v_s}f_0\)。反射音は反射板が受けた \(\dfrac{V}{V-v_s}f_0\) がそのまま届きます（反射板も Q も静止）。2つの振動数が等しいので、うなりは聞こえません。

通りすぎると、直接音が下がる

音源が Q を通りすぎる時刻 \(\dfrac{L/2}{v_s} = \dfrac{L}{2v_s}\) から、直接音は遠ざかる音源からの音 \(\dfrac{V}{V+v_s}f_0\) に変わり、うなりが始まります：

$$\frac{V}{V-v_s}f_0 - \frac{V}{V+v_s}f_0 = \frac{2v_sV}{V^2-v_s^{\,2}}f_0$$

（音源が原点を通るときに反射音がすでに届いている、という条件は「反射音はずっと前から Q に来ている」ことを保証するためのものです。）

アニメーションで確かめよう：音源が Q を通りすぎる前は、右下の波形の大きさが一定（うなりなし）。通りすぎた瞬間から大きさがふくらんだりしぼんだりし始めます。
II(1)　うなりから距離 L₀ を求める答 \(L_0 = \dfrac{f_hVT}{2f_1}\)

反射音は「少し前の音」

反射板が静止していれば、いま原点に届いた反射音は、往復の時間 \(\dfrac{2L_0}{V}\) だけ前に出た音です。振動数は一定の割合 \(\dfrac{f_1}{T}\) で下がり続けているので、直接音（いまの音）と反射音（少し前の音）には差ができます：

$$f_h = \frac{f_1}{T}\cdot\frac{2L_0}{V}\qquad\therefore\quad L_0 = \frac{f_hVT}{2f_1}$$

振動数の変化の傾き × 遅れの時間 ＝ 振動数の差。遅れの時間は距離に比例するので、うなりの振動数から距離が分かります（FMCW レーダーという実際の距離計の原理）。

アニメーションで確かめよう：下の振動数–時刻のグラフで、反射音の線（点線）は直接音の線を右に \(\dfrac{2L_0}{V}\) ずらしたもの。縦の差がうなりの振動数 \(f_h\) です。\(L_0\) を大きくすると差が広がります。
II(2)　近づく反射板と (A) の音答 \(\dfrac{4v_r}{V-v_r}f_1 + \dfrac{2L_A}{VT}f_1\)

近づく反射板で振動数は 2 回上がる

反射板は (i) 音に向かって動く観測者として \(\dfrac{V+v_r}{V}\) 倍で受け、(ii) 近づく音源として \(\dfrac{V}{V-v_r}\) 倍で出し直します。合わせて

$$f_{\text{反}} = \frac{V+v_r}{V-v_r}f_A(0) = \frac{V+v_r}{V-v_r}\cdot 2f_1$$

遅れの効果と合わせる

反射した位置が \(L_A\) なので、往復で \(t_{A0} = \dfrac{2L_A}{V}\)。この間に直接音は \(f_A(t_{A0}) = 2f_1 - \dfrac{f_1}{T}\cdot\dfrac{2L_A}{V}\) まで下がっています。差をとると

$$f_{\text{反}} - f_A(t_{A0}) = \underbrace{\frac{4v_r}{V-v_r}f_1}_{\text{ドップラー効果}} + \underbrace{\frac{2L_A}{VT}f_1}_{\text{遅れ（距離）}}$$

(A) では、反射音が「上がる（ドップラー）」と直接音が「下がる（遅れ）」が同じ向きに差を広げます。

アニメーションで確かめよう：振動数–時刻のグラフで、反射音の点線は直接音の線を右にずらすだけでなく、上にも持ち上がっています。\(v_r\) を 0 にすると (1) と同じになります。
II(3)　近づく反射板と (B) の音答 \(\dfrac{2L_B}{VT}f_1 - \dfrac{2v_r}{V-v_r}\left(1+\dfrac{t_s}{T}\right)f_1\)

考え方は (2) と同じです。\(t_s\) に出た音 \((1+\tfrac{t_s}{T})f_1\) は、反射で \(\dfrac{V+v_r}{V-v_r}\) 倍に。届く時刻 \(t_B = t_s + \dfrac{2L_B}{V}\) には、直接音は \(\left(1+\dfrac{t_s}{T}+\dfrac{2L_B}{VT}\right)f_1\) まで上がっています。

$$f_B(t_B) - f_{\text{反}} = \frac{2L_B}{VT}f_1 - \frac{2v_r}{V-v_r}\left(1+\frac{t_s}{T}\right)f_1$$

(B) では遅れの効果で直接音が上がり、ドップラー効果で反射音も上がるので、2つの効果が打ち消し合います。\(v_r < \dfrac{L_0}{4T}\) という条件は、遅れの効果の方が大きい（差が正）ことを保証しています。

アニメーションで確かめよう：(B) のグラフでは、反射音の点線が右にずれて下がる分を、ドップラー効果が少し持ち上げて差を縮めています。
II(4)(5)　うなりの差 Δfₕ から速さを求める答 \(\Delta f_h = \dfrac{6v_r}{V-v_r}f_1\)、\(v_r = 9.4\times10^{-1}\ \text{m/s}\)

同時に出した A と B は、同じ道すじで戻ってくる

同じ時刻 \(t'\) に出た A と B の音は、同じ位置 \(L'\) で反射し、同じ時刻に戻ります。(2)(3) の式で \(t_s = t'\)、\(L_A = L_B = L'\) とすると（A は \(f_A(t') = (2-\tfrac{t'}{T})f_1\)）

$$f_h^{A} = \frac{2L'}{VT}f_1 + \frac{2v_r}{V-v_r}\left(2-\frac{t'}{T}\right)f_1,\qquad f_h^{B} = \frac{2L'}{VT}f_1 - \frac{2v_r}{V-v_r}\left(1+\frac{t'}{T}\right)f_1$$ $$\Delta f_h = f_h^A - f_h^B = \frac{2v_r}{V-v_r}\cdot 3f_1 = \frac{6v_r}{V-v_r}f_1$$

距離の効果（\(\tfrac{2L'}{VT}f_1\)）は差をとると消え、速さの効果だけが残ります。下がる音と上がる音を組み合わせると、距離と速さを分けて測れる——実際の自動車用レーダーでも使われる工夫です（和をとれば距離が分かります）。

(5) 数値を入れる

$$v_r = \frac{V\Delta f_h}{6f_1 + \Delta f_h} = \frac{340\times 500}{1.8\times10^5 + 500}\ \text{m/s} \approx 9.4\times10^{-1}\ \text{m/s}$$

\(\Delta f_h \ll 6f_1\) なので \(v_r \approx \dfrac{V\Delta f_h}{6f_1}\) と近似してもほぼ同じ値です。

アニメーションで確かめよう：右下のグラフで、\(f_h^A\) と \(f_h^B\) は時間とともに変わりますが、その差はずっと一定です。\(v_r\) を変えると差だけが変わり、\(L_0\) を変えても差は変わりません。
