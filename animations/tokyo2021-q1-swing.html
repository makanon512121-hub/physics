ブランコの力学：飛び降り・立ち上がり・こぎ方（東京大学 2021年 第1問）

ブランコに乗った人を質点とみなし、力学的エネルギー保存・運動量保存・面積速度一定の3つの法則でブランコの運動を追いかけます。最低点で立ち上がると振れ幅が大きくなる理由と、何回こげば振れ幅が2倍になるかまで、アニメーションで確かめられます。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。支点を O、ブランコの長さを \(\ell\)、振れ角を \(\theta\)（鉛直下向きから反時計回りが正）、重力加速度を \(g\) とします。式の色は、アニメーションの矢印や寸法線の色とそろえています。

I　ア〜ウ　力学的エネルギーと速さ答 ア \(-mg\ell\cos\theta_0\)　イ \(\dfrac12mu^2 - mg\ell\cos\theta\)　ウ \(\sqrt{2g\ell(\cos\theta-\cos\theta_0)}\)

位置エネルギーは「基準からの高さ」で決まる

基準は支点 O の高さです。角度 \(\theta\) のとき、質点 P は O より \(\ell\cos\theta\) だけ下にあるので、位置エネルギーは \(\cgrav{-mg\ell\cos\theta}\) と負になります。高さが基準より下なら位置エネルギーは負、という符号の扱いに注意します。

\(\theta=\theta_0\) で静かに放した瞬間は運動エネルギーが 0 なので

$$\text{ア}:\quad E_0 = -mg\ell\cos\theta_0$$

角度 \(\theta\) で速さ \(u\) のときは

$$\text{イ}:\quad E = \cfrc{\frac12mu^2} + \cgrav{\left(-mg\ell\cos\theta\right)}$$

保存則で速さを求める

糸の張力はつねに速度と垂直なので仕事をしません。仕事をするのは重力だけなので、力学的エネルギーが保存します。ア＝イ とおいて

$$\frac12mu^2 = mg\ell(\cos\theta - \cos\theta_0)\qquad\therefore\ u = \sqrt{2g\ell(\cos\theta-\cos\theta_0)}$$

右辺の \(\ell(\cos\theta-\cos\theta_0)\) は「放した位置から何 m 下がったか」です。基準をどこに選んでも、この高さの差だけが速さを決めます。

式の立て方：①張力・垂直抗力など、速度と垂直な力は仕事をしないことを確認する ②基準の高さを1つ決め、各位置の高さを \(\ell\cos\theta\) のように図から読む ③「はじめ＝あと」の形に並べる。円運動の問題では、高さは「支点からの鉛直距離 \(\ell\cos\theta\)」で表すのが定番です。
アニメーションで確かめよう：上の式の \(\frac12mu^2\)（赤）と \(-mg\ell\cos\theta\)（緑）に触れると、速度の矢印と高さの寸法線が強調されます。下のグラフでは、赤と緑の和（黒線）がどの角度でも一定です。\(\theta_0\) を大きくしても式はそのまま成り立ちます（近似を使っていないため）。
II(1)　A が飛び降りた直後の速さ \(v_{\rm A}\)答 \(v_{\rm A} = \dfrac{m_{\rm A}+m_{\rm B}}{m_{\rm A}}\,v_0\)

短い時間の出来事には運動量保存

A が飛び降りる動作は一瞬で終わります。この間に A と B の間には大きな力がはたらきますが、それは内力なので、2人の運動量の和を変えません。外力のうち重力と張力は鉛直方向で、\(\theta=0\) では水平成分をもちません。したがって水平方向の運動量の和が保存します。

$$\cacc{(m_{\rm A}+m_{\rm B})v_0} = \cfrc{m_{\rm A}v_{\rm A}} + m_{\rm B}\cdot 0$$

飛び降りた後、B を乗せたブランコは静止するので B の運動量は 0 です。よって

$$v_{\rm A} = \frac{m_{\rm A}+m_{\rm B}}{m_{\rm A}}\,v_0$$

A は軽いほど速く飛び出します。B が止まった分の運動量を A が全部受け取るためです。

式の立て方：分裂・衝突・飛び乗りのように「一瞬で起こる」ものは、まず運動量保存を考えます。①どの物体をまとめて1つの系とみるか決める ②その系にはたらく外力を書き出し、外力の成分が 0 の方向を探す ③その方向の「前の運動量の和＝後の運動量の和」を立てる。エネルギーは人が仕事をするので保存しません。
アニメーションで確かめよう：左上の2本の矢印は運動量です。分裂の前後で長さが同じになります。下のグラフでは、直前の運動量のうち B が持っていた分（紫）が、直後には A の分（赤）にまとめて移っています。\(m_{\rm B}\) を大きくすると \(v_{\rm A}\) が大きくなり、遠くまで飛びます。
II(2)　着地点までの距離 GG′答 \({\rm GG'} = \dfrac{2(m_{\rm A}+m_{\rm B})}{m_{\rm A}}\sqrt{\ell h(1-\cos\theta_0)}\)，数値は \(1.2\ \rm m\)

最低点での速さ \(v_0\)：エネルギー保存

I と同じ考え方で、\(\theta_0\) から \(\theta=0\) まで \(\ell(1-\cos\theta_0)\) だけ下がるので

$$\frac12(m_{\rm A}+m_{\rm B})v_0^{\,2} = (m_{\rm A}+m_{\rm B})g\ell(1-\cos\theta_0)\qquad\therefore\ v_0=\sqrt{2g\ell(1-\cos\theta_0)}$$

水平投射：水平と鉛直に分けて考える

最低点の高さは \(h\) です。A は水平に速さ \(v_{\rm A}\) で飛び出すので、鉛直方向は初速度 0 の自由落下、水平方向は等速直線運動です。着地までの時間 \(t_{\rm A}\) は鉛直方向だけで決まります。

$$\cgrav{h = \frac12 g\,t_{\rm A}^{\,2}}\qquad\therefore\ \cfic{t_{\rm A}} = \sqrt{\frac{2h}{g}}$$ $$\cacc{{\rm GG'}} = \cfrc{v_{\rm A}}\,\cfic{t_{\rm A}} = \frac{m_{\rm A}+m_{\rm B}}{m_{\rm A}}\sqrt{2g\ell(1-\cos\theta_0)}\cdot\sqrt{\frac{2h}{g}} = \frac{2(m_{\rm A}+m_{\rm B})}{m_{\rm A}}\sqrt{\ell h(1-\cos\theta_0)}$$

\(g\) が消えるのがポイントです。数値 \(\ell=2.0\ \rm m\)，\(h=0.30\ \rm m\)，\(\cos\theta_0=0.85\)，\(m_{\rm A}=m_{\rm B}\) を代入すると

$${\rm GG'} = 2\cdot2\cdot\sqrt{2.0\times0.30\times0.15} = 4\times0.30 = 1.2\ \rm m$$
式の立て方：放物運動は「鉛直方向で時間を決め、その時間を水平方向に使う」の順で立てます。飛び出す速さは別の法則（ここではエネルギー保存＋運動量保存）で先に求めておき、最後につなげます。
アニメーションで確かめよう：下のグラフは、水平に進んだ距離（青、直線）と高さ（緑、放物線）を時間に対して描いたものです。緑が 0 になる時刻が \(t_{\rm A}\)（紫）で、そのときの青の値が GG′ です。初期設定は問題の数値（\(\cos\theta_0 = 0.85\) は \(\theta_0\approx31.8^\circ\)）です。
III(1)　立ち上がった後に止まる角度 \(\theta''\)答 \((\theta'')^2 = (\theta')^2 + \dfrac{v'^2}{g(\ell-\Delta\ell)}\)

立ち上がった後は「長さ \(\ell-\Delta\ell\) の振り子」

立ち上がった直後から \(\theta=-\theta''\) で止まるまでは、長さ \(\ell-\Delta\ell\) の円運動で、人は仕事をしていません。力学的エネルギー保存が使えます。\(\theta'\) の位置から \(-\theta''\) の位置まで、\((\ell-\Delta\ell)(\cos\theta'-\cos\theta'')\) だけ上がるので

$$\frac12m\cfrc{v'^2} = mg\,\cgrav{(\ell-\Delta\ell)(\cos\theta'-\cos\theta'')}$$

小さい角度の近似

\(\cos\theta\fallingdotseq 1-\dfrac{\theta^2}{2}\) を使うと \(\cos\theta'-\cos\theta''\fallingdotseq\dfrac{(\theta'')^2-(\theta')^2}{2}\) なので

$$\frac12 v'^2 = g(\ell-\Delta\ell)\,\frac{(\theta'')^2-(\theta')^2}{2}\qquad\therefore\ (\theta'')^2 = (\theta')^2 + \frac{v'^2}{g(\ell-\Delta\ell)}$$
式の立て方：途中で条件（長さ）が変わる運動は、変わる瞬間で区切り、区間ごとに保存則を立てます。各区間で「誰も仕事をしていないか」を確認してから力学的エネルギー保存を使います。
アニメーションで確かめよう：立ち上がる瞬間に一時停止し、直前の速度 \(v\)（青）と直後の速度 \(v'\)（赤）が表示されます。緑の寸法線が \((\ell-\Delta\ell)(\cos\theta'-\cos\theta'')\) です。「いまの値」で、近似式から求めた \(\theta''\) と数値計算の \(\theta''\) を比べられます。
III(2)　\(\theta''\) を \(\ell,\Delta\ell,\theta_0,\theta'\) で表す答 \((\theta'')^2 = \left(\dfrac{\ell}{\ell-\Delta\ell}\right)^3\theta_0^{\,2} - \left\{\left(\dfrac{\ell}{\ell-\Delta\ell}\right)^3-1\right\}(\theta')^2\)

立ち上がる前：エネルギー保存で \(v\)

\(\theta_0\) から \(\theta'\) まで長さ \(\ell\) のまま \(\ell(\cos\theta'-\cos\theta_0)\) 下がるので、近似を使って

$$\frac12m\cacc{v^2} = mg\,\cgrav{\ell(\cos\theta'-\cos\theta_0)}\qquad\therefore\ v^2\fallingdotseq g\ell\{\theta_0^{\,2}-(\theta')^2\}$$

立ち上がる瞬間：面積速度一定で \(v'\)

立ち上がるとき、人は糸の方向（O に向かう方向）に強く引かれます。O を中心とする中心力なので、O のまわりの面積速度が変わりません。

$$\cfic{\frac12(\ell-\Delta\ell)v' = \frac12\ell v}\qquad\therefore\ v' = \frac{\ell}{\ell-\Delta\ell}\,v$$

半径が縮むと速さが上がります。フィギュアスケートで腕を縮めると回転が速くなるのと同じしくみです。

III(1) に代入

$$(\theta'')^2 = (\theta')^2 + \frac{1}{g(\ell-\Delta\ell)}\left(\frac{\ell}{\ell-\Delta\ell}\right)^2 g\ell\{\theta_0^{\,2}-(\theta')^2\} = \left(\frac{\ell}{\ell-\Delta\ell}\right)^3\theta_0^{\,2} - \left\{\left(\frac{\ell}{\ell-\Delta\ell}\right)^3-1\right\}(\theta')^2$$

エネルギーはどこから来たか

立ち上がる瞬間は面積速度が保存するだけで、力学的エネルギーは保存しません。人が張力にさからって体を引き上げる仕事が、運動エネルギーの増加分になります。張力は速いほど（遠心力の分だけ）大きいので、速い所で立つほど大きな仕事ができます。

式の立て方：「中心に向かう力だけが一瞬はたらく」ときは面積速度 \(\frac12rv_\perp\) が保存します（中心のまわりの角運動量保存）。\(v_\perp\) は半径に垂直な速度成分で、ここでは速度がもともと半径に垂直なので \(v\) そのものです。
アニメーションで確かめよう：紫の2つの三角形は、O と速度ベクトルでつくる三角形で、面積が \(\frac12\ell v\) と \(\frac12(\ell-\Delta\ell)v'\) に比例します。底辺が短くなった分、高さ（速さ）が伸びて面積が同じになります。
III(3)　\(\theta''\) を最大にする \(\theta'\)答 \(\theta'=0\)，そのとき \(\theta''=\left(\dfrac{\ell}{\ell-\Delta\ell}\right)^{3/2}\theta_0\)

III(2) の結果で \(\left(\dfrac{\ell}{\ell-\Delta\ell}\right)^3 - 1 > 0\) なので、\((\theta')^2\) の係数は負です。\((\theta'')^2\) は \(\theta'\) の下に凸ではなく上に凸の放物線になり、\(\theta'=0\) で最大です。

$$\theta'' = \left(\frac{\ell}{\ell-\Delta\ell}\right)^{3/2}\theta_0$$

物理的には「最低点で立ち上がるのが一番効率がよい」ことを表しています。最低点は速さが最大で、張力も最大なので、同じ \(\Delta\ell\) だけ体を引き上げる仕事が最も大きくなります。

式の立て方：最大・最小を聞かれたら、まず式を「変数の2乗」でまとめ、係数の符号を調べます。微分しなくても、平方完成や係数の符号で決まることが多いです。
アニメーションで確かめよう：\(\theta'\) のスライダーを動かすと、下のグラフの点が放物線上を動きます。\(\theta'=0\) の頂点で \(\theta''\) が最大です。\(\theta'\) を負にする（最低点を通り過ぎてから立つ）と、正のときと同じだけ効果が下がります。
III(4)(5)　こぎ続けたときの振れ幅答 (4) \(\theta_n = \left(\dfrac{\ell}{\ell-\Delta\ell}\right)^{\frac32n}\theta_0\)　(5) \(N=5\)

1サイクルで振れ幅が何倍になるか

1サイクルは「\(\theta_{n-1}\) から出発 → 最低点で立つ → \(-\theta_n\) で止まる → 戻って \(\theta_n\) で止まる → しゃがむ」です。最低点で立つので III(3) の結果がそのまま使え、\(-\theta_n\) から \(\theta_n\) へ戻る間は長さ一定なので振れ幅は変わりません。しゃがむのは静止しているときなので、速さも角度も変わりません。

$$\theta_n = \cfr{\left(\frac{\ell}{\ell-\Delta\ell}\right)^{3/2}}\theta_{n-1}\qquad\Longrightarrow\qquad\theta_n = \left(\frac{\ell}{\ell-\Delta\ell}\right)^{\frac32n}\theta_0$$

毎回同じ倍率がかかるので、振れ幅は等比数列で増えます。

2倍になる回数

\(\dfrac{\Delta\ell}{\ell}=0.1\) なら \(\dfrac{\ell}{\ell-\Delta\ell} = \dfrac{1}{0.9}\) です。\(\theta_N\geqq2\theta_0\) は

$$0.9^{-\frac32N}\geqq2\quad\Longleftrightarrow\quad -\frac32N\log_{10}0.9\geqq\log_{10}2\quad\Longleftrightarrow\quad N\geqq\frac{0.30}{1.5\times0.046}=4.3\cdots$$

これを満たす最小の整数は \(N=5\) です。

式の立て方：くり返しの問題は、まず1回分の変化を「\(x_n = r\,x_{n-1}\)」や「\(x_n = x_{n-1}+d\)」の形で書きます。それから一般項を出し、不等式は対数で解きます。
アニメーションで確かめよう：人が最低点で立ち（ひもが短くなる）、端でしゃがむ様子をくり返します。下のグラフは各サイクル後の振れ幅で、棒が公式、点が数値計算です。\(\Delta\ell/\ell\) を変えると \(N\) が変わります。
