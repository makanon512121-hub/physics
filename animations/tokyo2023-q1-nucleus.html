原子核の分裂と電場中の転回軌道（東京大学 2023年 第1問）

磁場で特定の運動エネルギーの原子核だけを選び出すしくみ、静止した原子核の分裂（運動量保存とエネルギー保存）、そして一様な電場の中を進みながら分裂した原子核のかけらが折り返して検出器に届く条件を、軌道のアニメーションとグラフで確かめます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。X は質量 \(4m\)・電気量 \(2q\)、A は質量 \(m\)・電気量 \(q\)、B は質量 \(3m\)・電気量 \(q\) です。

I(1)　小窓から集められる X の運動エネルギー答 \(\dfrac{q^2a^2B^2}{8m}\)

「壁に垂直に小窓へ入る」＝ 直径 a の半円

磁場の中の荷電粒子は、速さを変えずに円運動します。原点を出て x 軸上の小窓に垂直に入るには、円の中心が x 軸上にあり、原点と小窓が円の直径の両端になっていなければなりません。つまり X は原点から \(+y\) 向きに飛び出し、半径 \(\dfrac a2\) の半円を描きます。

円運動の運動方程式を立てる

向心方向の運動方程式「質量 × \(\dfrac{v^2}{r}\) ＝ 中心向きの力」に、ローレンツ力 \(2qvB\) を入れます。

$$4m\frac{v^2}{a/2} = 2qvB\qquad\therefore\quad v = \frac{qaB}{4m}$$ $$K = \frac12\cdot4m\,v^2 = \frac{q^2a^2B^2}{8m}$$
式の立て方：磁場中の円運動は \(\dfrac{Mv^2}{r} = QvB\)、つまり \(r = \dfrac{Mv}{QB}\)（半径は運動量に比例）の1本で決まります。半径が装置の形（ここでは小窓までの距離）で決まれば、速さ・運動エネルギーが逆算できます。質量分析器や速度選別器も同じ考え方です。
アニメーションで確かめよう：いろいろな速さ・向きの X が飛び出しますが、小窓を抜ける（緑）のは \(+y\) 向きに出て半径 \(a/2\) の半円を描いたものだけです。\(B\) を大きくすると、通り抜ける X の速さ（運動エネルギー）が大きくなります。
I(2)　分裂前に小窓を通る割合を f 以上にする B の下限答 \(B \geqq \dfrac{2\pi m}{qT\log_{\frac12}f}\)

小窓までにかかる時間は速さによらない

半円を進む時間は周期の半分です。半径 \(r=\dfrac{Mv}{QB}\) と速さ \(v\) から

$$\tau = \frac{\pi r}{v} = \frac{\pi\cdot 4m}{2qB} = \frac{2\pi m}{qB}$$

速さが消えて、\(B\) だけで決まります（周期 \(\dfrac{2\pi M}{QB}\) は速さによらない）。

半減期の式で「残る割合」を書く

時間 \(t\) の間に分裂しないで残る割合は \(\left(\dfrac12\right)^{t/T}\)。これが \(f\) 以上なので

$$\left(\frac12\right)^{\tau/T} \geqq f\quad\Longleftrightarrow\quad \frac{\tau}{T} \leqq \log_{\frac12}f\quad\Longleftrightarrow\quad B \geqq \frac{2\pi m}{qT\log_{\frac12}f}$$

\(0<f<1\) なので \(\log_{\frac12}f > 0\) です。底が \(\dfrac12\)（1より小さい）の対数をとると不等号の向きが変わる点に注意します。

式の立て方：「割合」が出てきたら \(\left(\frac12\right)^{t/T}\)、時間は運動の方程式から出す、の2段階です。磁場を強くすると軌道が小さくなって早く着くので、分裂する前に集められます。
アニメーションで確かめよう：飛んでいる途中で分裂した X は赤い印で止まります。下のグラフは「残る割合」と \(B\) の関係で、横線 \(f\) を上回る \(B\) の範囲が答えです。\(T\) を短くすると必要な \(B\) が大きくなります。
I(3)　静止した X が分裂したときの vA, vB答 \(v_A = \sqrt{\dfrac{3\Delta m}{2m}}\,c,\quad v_B = \sqrt{\dfrac{\Delta m}{6m}}\,c\)

運動量保存とエネルギー保存の2本

はじめ静止しているので運動量の和は 0。質量欠損のエネルギー \(\Delta m\,c^2\) がすべて運動エネルギーになります。

$$m v_A - 3m v_B = 0,\qquad \frac12 m v_A^{\,2} + \frac12\cdot 3m\,v_B^{\,2} = \Delta m\,c^2$$

1本目から \(v_B = \dfrac{v_A}{3}\)。2本目に入れると \(\dfrac12 mv_A^{\,2}\cdot\dfrac43 = \Delta mc^2\) より

$$v_A = \sqrt{\frac{3\Delta m}{2m}}\,c,\qquad v_B = \frac{v_A}{3} = \sqrt{\frac{\Delta m}{6m}}\,c$$
式の立て方：静止した物体が2つに分かれるとき、運動量の大きさは等しく \(p\)。運動エネルギーは \(\dfrac{p^2}{2M}\) なので質量の逆比（ここでは A : B ＝ 3 : 1）に分かれます。原子核の崩壊でも、ばねで押し合う2物体でも同じです。
アニメーションで確かめよう：運動量の矢印は同じ長さ、速さは 3 : 1。下の棒グラフで \(\Delta mc^2\) が 3 : 1 に配分されることが確かめられます。
II(1)　転回軌道に入って検出器に届く条件（ア〜カ）答 ア \(\sqrt{\dfrac{2x_0}{L}}\)　イ \(\dfrac{\alpha L}{v_A}\)　ウ \(-\alpha\)　エ \(\dfrac L2\)　オ \(-(1+\sqrt2)\alpha\)　カ \(\dfrac{3-2\sqrt2}{2}L\)

ア・イ：X の等加速度運動

X の加速度は \(\dfrac{2qE}{4m} = \dfrac{v_A^{\,2}}{L}\)（\(E = \dfrac{2mv_A^{\,2}}{qL}\) を代入）。エネルギーで速さを、運動量の変化（または \(v = at\)）で時間を出します。

$$\frac12\cdot4m(\alpha v_A)^2 = 2qE\,x_0\ \Rightarrow\ \alpha = \sqrt{\frac{2x_0}{L}},\qquad t_0 = \frac{\alpha v_A}{v_A^{\,2}/L} = \frac{\alpha L}{v_A}$$

ウ・エ：速度の合成で「後ろ向き」かどうかを判定

X 静止系での A の速度に、X の速度 \(\alpha v_A\) を足したものが床（検出器）から見た速度です。x 成分は

$$u = v_A\cos\theta_0 + \alpha v_A$$

転回するには \(u<0\)、つまり \(\cos\theta_0 < -\alpha\)（ウ）。\(\cos\theta_0 \geqq -1\) なので、\(\alpha\geqq1\)、すなわち \(x_0 \geqq \dfrac L2\) では転回する向きがありません（エ）。

オ・カ：戻れる距離と x₀ を比べる

A の加速度は \(\dfrac{qE}{m} = \dfrac{2v_A^{\,2}}{L}\)（\(+x\) 向き）。初速度 \(u<0\) で後ろに進める距離は \(\dfrac{u^2}{2\cdot 2v_A^{\,2}/L}\) で、これが \(x_0 = \dfrac{\alpha^2L}{2}\) より小さければ \(x<0\) に入りません：

$$\frac{u^2L}{4v_A^{\,2}} < \frac{\alpha^2 L}{2}\ \Leftrightarrow\ |u| < \sqrt2\,\alpha v_A\ \Leftrightarrow\ \cos\theta_0 > -(1+\sqrt2)\alpha$$

どの \(\theta_0\) でも満たすには \(-(1+\sqrt2)\alpha < -1\)、つまり \(\alpha > \sqrt2-1\)。\(x_0 = \dfrac{\alpha^2L}{2}\) に直して \(x_0 > \dfrac{(\sqrt2-1)^2}{2}L = \dfrac{3-2\sqrt2}{2}L\)（カ）。

式の立て方：①乗りかえた系の速度に、その系の速度を足す（速度の合成）。②一様な力の中の運動は、その力の向きだけ等加速度、垂直な向きは等速。③「届くか届かないか」は \(v^2 = 2ax\)（またはエネルギー）で、進める距離と実際の距離を比べる。
アニメーションで確かめよう：上の図の細い線は、いろいろな \(\theta_0\) で出た A の軌道です（青：そのまま前へ、緑：転回して検出器へ、赤：\(x<0\) へ逃げる）。下のグラフは \((x_0,\ \cos\theta_0)\) 平面での条件で、境界線が \(\cos\theta_0 = -\alpha\) と \(\cos\theta_0 = -(1+\sqrt2)\alpha\) です。
II(2)　x 軸上で検出される A の運動エネルギーの範囲答 \(\dfrac{3-2\sqrt2}{2}mv_A^{\,2} < K \leqq 2mv_A^{\,2}\)、\(\dfrac52 mv_A^{\,2} \leqq K \leqq 3mv_A^{\,2}\)

x 軸上に届くのは θ₀ = 0 か π だけ

電場は x 向きなので y 方向は等速です。x 軸上に届くには y 方向の速度が 0、つまり \(\theta_0 = 0\)（前向き）か \(\pi\)（後ろ向き）です。

エネルギー保存：はじめの運動エネルギー ＋ 電場がした仕事

電場が A にする仕事は \(qE(L - x_0) = mv_A^{\,2}(2-\alpha^2)\)。分裂直後の速さは \((\alpha\pm1)v_A\) なので

$$K_\pm = \frac12m(\alpha\pm1)^2v_A^{\,2} + mv_A^{\,2}(2-\alpha^2) = \frac12mv_A^{\,2}\left\{6-(\alpha\mp1)^2\right\}$$

\(K_+\)（前向き）は \(0\leqq\alpha<\sqrt2\) で \(\dfrac52mv_A^{\,2}\leqq K_+\leqq 3mv_A^{\,2}\)（\(\alpha=1\) で最大）。\(K_-\)（後ろ向き）は \(x<0\) に入らない \(\sqrt2-1\leqq\alpha<\sqrt2\) で \(\dfrac{3-2\sqrt2}{2}mv_A^{\,2} < K_- \leqq 2mv_A^{\,2}\)。

式の立て方：途中の軌道が複雑でも、一様な電場がする仕事は「電気量 × 電場 × x 方向の移動距離」だけで決まります。最後の運動エネルギーは「最初 ＋ 仕事」。あとは文字 \(\alpha\) の2次関数の値域の問題です（\(\alpha\) の範囲に注意）。
アニメーションで確かめよう：\(x_0\) を動かすと、前向き（青）と後ろ向き（赤）の A のエネルギーが下のグラフ上を動きます。\(x_0\) が小さいと後ろ向きの A は \(x<0\) に逃げてしまいます。
II(3)　運動エネルギーが mvA² より小さい A が多いのは？答 半減期 \(T\) が \(\dfrac{L}{v_A}\) よりはるかに長い場合

どこで分裂すると K が小さくなるか

任意の向き \(\theta_0\) で出た A の検出器での運動エネルギーは、(2) と同じく「はじめ ＋ 仕事」で

$$K = \frac12 m v_A^{\,2}(1+\alpha^2+2\alpha\cos\theta_0) + mv_A^{\,2}(2-\alpha^2) = mv_A^{\,2}\left(\frac52 - \frac{\alpha^2}{2} + \alpha\cos\theta_0\right)$$

\(K < mv_A^{\,2}\) になるのは \(\cos\theta_0 < \dfrac{\alpha^2-3}{2\alpha}\) のときで、右辺が \(-1\) より大きいこと、つまり \(\alpha>1\)（\(x_0 > \dfrac L2\)）が必要です。後半で、後ろ向きに出た A だけがこうなります。

半減期が短いと、ほとんど原点の近くで分裂する

\(T \ll \dfrac{L}{v_A}\) だと X は動き出してすぐに分裂し、\(x_0 > \dfrac L2\) まで進むものはほとんどありません。\(T \gg \dfrac{L}{v_A}\) だと分裂の時刻は飛行中ほぼ一様にばらつき、\(x_0 > \dfrac L2\) で分裂するものが一定の割合で出てきます。よって半減期が長い場合の方が多くなります。

式の立て方：「割合を比べる」問題は、まず「条件を満たすのはどの場合か」を式で絞り込みます（ここでは \(\alpha>1\)）。そのあとで「その場合がどれくらい起こるか」を半減期で考えると、計算せずに結論が出せます。
アニメーションで確かめよう：X を次々と入れて、検出された A のエネルギーの分布（ヒストグラム）をためていきます。赤い部分が \(K<mv_A^{\,2}\)。\(T\) を変えると右のグラフ上の点が動き、\(T\) が長いほど割合が大きくなることが分かります。
