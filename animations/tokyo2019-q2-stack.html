積み重ねた RC 素子：放電・交流・ブリッジで ε と ρ を測る（東京大学 2019年 第2問）

誘電率 ε・抵抗率 ρ の円柱を電極ではさむと、抵抗とコンデンサーの並列とみなせます。これを N 個積み重ねた素子 X に、直流電源・抵抗・交流電源をつなぎかえて、電流・電気量・ジュール熱・交流電流を調べます。最後は交流ブリッジをつりあわせて、ε と ρ を同時に求めます。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。色は図と式で共通です：コンデンサー・電気量（青）、抵抗・電流（赤）、電源の電圧（オレンジ）、抵抗 R₀ やブリッジの抵抗（緑）、交流でコンデンサーに流れる電流（紫）。

I　1組の電極と円柱の R と C答 \(R = \rho\dfrac dS\)，\(C = \varepsilon\dfrac Sd\)

同じ円柱が「コンデンサー」と「抵抗」を兼ねる

電極間に電圧 \(V\) をかけると、円柱は誘電体として電荷をため、同時に導体として電流も流します。どちらにも同じ電圧 \(V\) がかかるので、等価回路は抵抗とコンデンサーの並列です。

平行板コンデンサーの電気容量

$$\cacc{C} = \varepsilon\frac Sd$$

抵抗率と抵抗値の関係

$$\cfrc{R} = \rho\frac dS$$

着眼点：RC は形によらない

2式をかけると \(RC = \varepsilon\rho\) で、\(S\) と \(d\) が消えます。この組み合わせの時定数は物質だけで決まります。III では R と C の両方を測ることで、ε と ρ を別々に求めます。

式の立て方：1つの物体が2つの性質を持つときは、「同じ電圧がかかる → 並列」「同じ電流が流れる → 直列」で等価回路を決めます。\(C\) は面積に比例・間隔に反比例、\(R\) は長さに比例・断面積に反比例と、向きが逆になることも確認しておきます。
アニメーションで確かめよう：S や d を変えると R と C は逆向きに変わりますが、下のグラフで積 RC は一定です。ε や ρ を変えたときだけ RC が変わります。
II(1)　直流電圧 V₀ を加えて十分時間後答 電流 \(\dfrac{V_0}{NR}\)，電気量 \(\dfrac{CV_0}{N}\)

電圧は N 個に等分される

N 組はすべて同じで直列なので、それぞれに \(V_0/N\) の電圧がかかります。十分時間がたつとコンデンサーには電流が流れず、電流は抵抗だけを通ります。

キルヒホッフの第2法則

$$\cfr{V_0} = N\cdot\cfrc{RI_1}\;\Longrightarrow\;I_1 = \frac{V_0}{NR}$$

コンデンサーの電気量 Q = CV

$$\cacc{Q_1} = C\cdot\frac{V_0}{N} = \frac{CV_0}{N}$$

着眼点：電荷が残るのは両端の電極だけ

中間の電極は、上の円柱の下面（\(-Q_1\)）と下の円柱の上面（\(+Q_1\)）を兼ねるので、電極としての電気量は 0 です。電極 E には \(+Q_1\) だけが残ります。

式の立て方：直流で十分時間がたったら「コンデンサーの電流 0」とおき、まず抵抗だけの回路で電流と電圧を決めます。そのあと、コンデンサーには並列な抵抗と同じ電圧がかかるとして \(Q = CV\) を使います。
アニメーションで確かめよう：下の左のグラフは高さと電位の関係で、各組で \(V_0/N\) ずつ一様に下がります。N を増やすと1組あたりの電圧が減り、\(I_1\) と \(Q_1\) はどちらも \(1/N\) に比例して小さくなります。
II(2)　抵抗 R₀ につなぎかえたときのジュール熱答 \(\dfrac12\cdot\dfrac{R}{R_0+NR}CV_0^{\,2}\)，②（単調に減少）

各瞬間の発熱の比は一定

放電中も、素子 X の各組の電圧はすべて等しく \(v\)、\(R_0\) の電圧は \(Nv\) です（\(R_0\) と X は並列）。

ジュール熱の発生率 V²/R

$$\cfrc{\frac{(Nv)^2}{R_0}} : \cfr{N\cdot\frac{v^2}{R}} = NR : R_0$$

この比は \(v\) によらないので、放電が終わるまでの合計 \(P_0\)（\(R_0\)）と \(P\)（X の内部）も \(P_0 : P = NR : R_0\) です。

エネルギー保存（静電エネルギー → ジュール熱）

$$P_0 + P = N\cdot\frac{Q_1^{\,2}}{2C} = \frac{CV_0^{\,2}}{2N}$$ $$P_0 = \frac{NR}{R_0+NR}\cdot\frac{CV_0^{\,2}}{2N} = \frac12\cdot\frac{R}{R_0+NR}\,CV_0^{\,2}$$

分母に \(NR\) があるので、\(N\) を増やすと \(P_0\) は単調に減少します（②）。蓄えられたエネルギー \(\frac{CV_0^2}{2N}\) 自体が減り、さらに内部の抵抗 \(NR\) で失われる割合も増えるためです。

参考：放電の時定数は \(\tau = \dfrac{CRR_0}{R_0+NR}\) で、\(v = \dfrac{V_0}{N}e^{-t/\tau}\) と減っていきます。

式の立て方：放電の発熱は、電流の時間変化を求めなくても ①エネルギー保存で合計を出す ②各瞬間の発熱の比が一定なら、合計もその比で分ける、の2段で求まります。並列なら電圧共通なので \(V^2/R\)、直列なら電流共通なので \(RI^2\) で比をとります。
アニメーションで確かめよう：左のグラフで、青（残っている静電エネルギー）が赤（\(R_0\) の熱）とオレンジ（X 内部の熱）に変わっていきます。赤とオレンジの比はいつも \(NR : R_0\) です。右のグラフは \(P_0\) と N の関係で、N を動かすと点が単調に下がる曲線の上を動きます。
II(3)　交流電圧 V₁ sin ωt を加えたときの電流答 \(\dfrac{V_1}{N}\left(\dfrac1R\sin\omega t + \omega C\cos\omega t\right)\)

並列なので、抵抗とコンデンサーの電流を別々に求めて足す

各組の電圧は \(\dfrac{V_1}{N}\sin\omega t\) です。

オームの法則（抵抗）

$$\cfrc{I_R} = \frac{V_1}{NR}\sin\omega t$$

コンデンサーの電流 I = dq/dt（q = Cv）

$$\cfic{I_C} = \frac{d}{dt}\left(C\frac{V_1}{N}\sin\omega t\right) = \frac{\omega CV_1}{N}\cos\omega t$$

キルヒホッフの第1法則

$$I = \cfrc{I_R} + \cfic{I_C} = \frac{V_1}{N}\left(\frac1R\sin\omega t + \omega C\cos\omega t\right)$$

抵抗の電流は電圧と同じ位相、コンデンサーの電流は電圧より \(\frac\pi2\) 進みます。合成すると振幅 \(\dfrac{V_1}{N}\sqrt{\dfrac1{R^2}+\omega^2C^2}\)、位相の進み \(\varphi\)（\(\tan\varphi = \omega RC\)）の正弦波です。

式の立て方：交流回路では「並列 → 電圧共通 → 各素子の電流を求めて足す」「直列 → 電流共通 → 各素子の電圧を求めて足す」。コンデンサーは \(q = Cv\) を時間で微分（またはリアクタンス \(1/\omega C\) と位相 \(\frac\pi2\) 進み）、抵抗は同位相です。
アニメーションで確かめよう：右の図は電流の回転ベクトルで、赤 \(I_R\) は電圧と同じ向き、紫 \(I_C\) は 90° 先を回ります。ω を大きくすると紫が長くなり、合成電流の位相の進みが大きくなります。
III　交流ブリッジで ε と ρ を求める答 ア \(\dfrac{2V_1}{3}\sin\omega t\)　イ・ウ \(\dfrac{V_1}{3R_2}\)　エ \(\dfrac{V_1}{3}\sin\omega t\)　オ \(\dfrac{V_1}{3NR}\)　カ \(\dfrac{\omega CV_1}{3N}\)　キ \(\varepsilon = \dfrac{Nd}{\omega R_2S}\)　ク \(\rho = \dfrac{R_2S}{Nd}\)

つりあい ⇔ L と K が同電位（ア・エ）

交流電流計に電流が流れないので、\(R_1\) と \(2R_1\) には同じ電流が流れ、電圧は \(1:2\) に分かれます。

キルヒホッフの第2法則（J→K→M）

$$V_{\mathrm{JK}} = \frac{V_1}{3}\sin\omega t,\qquad V_{\mathrm{KM}} = \frac{2V_1}{3}\sin\omega t$$

L と K は同電位なので、\(V_{\mathrm{LM}} = \frac{2V_1}{3}\sin\omega t\)、素子 X の電圧 \(V_{\mathrm{JL}} = \frac{V_1}{3}\sin\omega t\) です。

L–M を流れる電流（イ・ウ）

\(I_{\mathrm{LM}} = \alpha\sin\omega t + \beta\cos\omega t\) とおきます。\(C_0\) の電気量は \(I\) を時間で積分して \(\frac1\omega(-\alpha\cos\omega t + \beta\sin\omega t)\)、\(\frac{1}{\omega C_0} = R_2\) を使うと

キルヒホッフの第2法則（L→M）

$$\cgrav{R_2(\alpha\sin\omega t+\beta\cos\omega t)} + \cacc{R_2(\beta\sin\omega t-\alpha\cos\omega t)} = \frac{2V_1}{3}\sin\omega t$$

どの時刻でも成り立つので、sin と cos の係数をそれぞれ比べて \(\alpha+\beta = \frac{2V_1}{3R_2}\)、\(\beta-\alpha = 0\)。よって \(\alpha = \beta = \dfrac{V_1}{3R_2}\) です。

J–L を流れる電流（オ・カ）

X には \(\frac{V_1}{3}\sin\omega t\) がかかるので、II(3) の \(V_1\) を \(\frac{V_1}{3}\) にかえて

$$I_{\mathrm{JL}} = \cfrc{\frac{V_1}{3NR}\sin\omega t} + \cfic{\frac{\omega CV_1}{3N}\cos\omega t}$$

2つの電流を等しいとおく（キ・ク）

キルヒホッフの第1法則（点 L）

$$I_{\mathrm{JL}} = I_{\mathrm{LM}}\;\Longrightarrow\;\frac{1}{3NR} = \frac{1}{3R_2},\quad \frac{\omega C}{3N} = \frac{1}{3R_2}$$

\(R = \dfrac{R_2}{N}\)、\(C = \dfrac{N}{\omega R_2}\) に I の式を使うと

$$\varepsilon = \frac{Cd}{S} = \frac{Nd}{\omega R_2S},\qquad \rho = \frac{RS}{d} = \frac{R_2S}{Nd}$$

着眼点

交流ブリッジのつりあいは「sin の係数」と「cos の係数」の2つの条件を与えます。未知数 ε と ρ が2つあっても1回のつりあいで決まるのはこのためです。また、この問題で \(C_0 = \dfrac1{\omega R_2}\) になったのは \(\omega RC = 1\)、つまり \(\omega = \dfrac1{\varepsilon\rho}\) で測った場合にあたります。ほかの ω でも \(R_2, C_0\) の値が変わるだけで、同じ手順で求められます。

別解：回転ベクトルで見ると、\(R_2\) と \(C_0\) の電圧は大きさが等しく位相が 90° ずれるので、合成は \(\sqrt2\) 倍で 45° ずれます。これが \(\frac{2V_1}{3}\sin\omega t\) と一致するので、電流は振幅 \(\frac{\sqrt2V_1}{3R_2}\)、位相 \(+\frac\pi4\)、すなわち \(\frac{V_1}{3R_2}(\sin\omega t+\cos\omega t)\) です。

式の立て方：ブリッジは「検流計の両端が同電位」→「向かい合う枝で電圧の比が等しい」→「各枝の電流を同じ形（sin と cos の組）で書いて係数を比べる」の順に立てます。コイルを含むブリッジでも同じ手順です。
アニメーションで確かめよう：\(R_2\) や \(C_0\) をずらすと、検流計の針が振れ、下のグラフで L と K の電位の波形（検流計を外したときの値）がずれます。「つりあわせる」を押すと2つの波形が重なり、針が止まります。ω を変えると、つりあう \(C_0\) が \(1/(\omega R_2)\) からずれることも確かめられます。
