多極板コンデンサーとコイルの電気振動（東京大学 2021年 第2問）

平行な金属板を差し込んだり導線でつないだりしながら、電荷・電位・エネルギーがどう決まるかを追いかけます。後半はコイルにつなぎかえて電気振動を起こします。電位のグラフを極板の位置にそろえて描いているので、キルヒホッフの法則（電位の足し算）と電気量保存の式が図のどこに対応するかが見えます。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。極板の面積 \(S\)、AB 間の距離 \(d\)、誘電率 \(\varepsilon\)、\(C_0=\varepsilon S/d\) です。アニメーションの電荷は \(C_0V\)、エネルギーは \(C_0V^2\) を単位にして表示しています。

I(1)　平行板コンデンサーの電気容量答 \(C_0 = \dfrac{\varepsilon S}{d}\)

ガウスの法則 → 電場 → 電位差

板 A の電荷 \(Q\) から出る電気力線は、すべて極板の間を通って B に入ります。電気力線の本数は \(Q/\varepsilon\) で、それが面積 \(S\) を一様に貫くので、電場の強さは

$$E = \frac{Q}{\varepsilon S}$$

一様な電場なので、電位差は「電場 × 距離」です。

$$V = Ed = \frac{Qd}{\varepsilon S}\qquad\Longrightarrow\qquad \cfrc{Q} = \cacc{\frac{\varepsilon S}{d}}\,\cgrav{V}$$

\(Q = C_0V\) と比べて \(C_0 = \dfrac{\varepsilon S}{d}\) です。

式の立て方：電気容量は「電荷 → 電場（ガウスの法則）→ 電位差（\(V=Ed\)）」の順に求めて、\(Q\) と \(V\) の比をとります。極板が何枚あっても、隣り合う2枚の間を1つのコンデンサーとみて、この関係を区間ごとに使います。
アニメーションで確かめよう：\(d\) を半分にすると、同じ電圧でも電場が2倍になり、電荷（＋の数）も2倍になります。下のグラフは \(Q\)–\(V\) グラフで、傾きが \(C_0\)、三角形の面積が静電エネルギー \(\frac12QV\) です。
I(2)　板 C を入れて A とつないだときの静電エネルギー答 \(\dfrac12\cdot\dfrac{\varepsilon S}{d-x}V^2\)

導線でつながった板は同じ電位

A と C を導線 a でつなぐと、A と C は同じ電位になります。AC 間には電位差がないので電場がなく、電荷もたまりません。電圧 \(V\) がかかるのは CB 間（距離 \(d-x\)）だけです。

$$C_{\rm CB} = \frac{\varepsilon S}{d-x},\qquad U_1 = \frac12C_{\rm CB}V^2 = \frac12\cdot\frac{\varepsilon S}{d-x}V^2$$

電荷は A が 0、C が \(+\dfrac{\varepsilon S}{d-x}V\)、B が \(-\dfrac{\varepsilon S}{d-x}V\) です。

式の立て方：板が増えたら、まず「導線でつながっている板のグループ」を見つけ、グループごとに電位を1つ決めます。電位差が 0 の区間には電荷がたまらないので、その区間は無視できます。
アニメーションで確かめよう：右側の電位のグラフで、A と C の間が平ら（電位差 0）になっています。\(x\) を大きくして C を B に近づけると、CB 間の電場が強くなり、電荷とエネルギーが増えます。
I(3)　板 C をゆっくり動かす外力の仕事答 \(W = \dfrac{(4x-d)\varepsilon S}{6d(d-x)}V^2\)，\(W\) は \(W_0\) の \(-\dfrac12\) 倍

電源につながったままのコンデンサーのエネルギー収支

C を A に近づけると CB 間が \(d-x\) から \(\frac34d\) に広がり、電気容量が減ります。

$$\Delta C = \frac{\varepsilon S}{\frac34d} - \frac{\varepsilon S}{d-x} = -\frac{(4x-d)\varepsilon S}{3d(d-x)}\ (<0)$$

電圧 \(V\) は一定なので、電荷の変化は \(\Delta Q = V\Delta C\)、静電エネルギーの変化は \(\Delta U = \frac12V^2\Delta C\) です。電源は電荷 \(\Delta Q\) を電位差 \(V\) で運ぶので、電源がした仕事は

$$\cfr{W_0} = V\Delta Q = V^2\Delta C$$

エネルギー保存は「外からされた仕事の合計 ＝ 静電エネルギーの増加」です。

$$\cgrav{W} + \cfr{W_0} = \cacc{\Delta U}\qquad\Longrightarrow\qquad W = \frac12V^2\Delta C - V^2\Delta C = -\frac12V^2\Delta C = \frac{(4x-d)\varepsilon S}{6d(d-x)}V^2$$

\(W/W_0 = -\frac12\) です。\(\Delta C<0\) なので \(W_0<0\)：電荷が電源に押し戻され、電源はエネルギーを受け取っています。外力の仕事 \(W\) と静電エネルギーの減少分 \(|\Delta U|\) がどちらも電源に流れ込んでいます。

別の立て方：極板間の引力から直接

C の電荷 \(Q\) は CB 間の電場の半分 \(\frac{E}{2}\) から力を受けるので、引力は \(\frac12QE = \frac12\cdot\frac{\varepsilon SV^2}{(d-y)^2}\)（\(y\) は AC 間の距離）です。ゆっくり動かすので外力は引力とつり合い、\(y\) を \(x\) から \(\frac d4\) まで積分すると同じ \(W\) になります。

式の立て方：電池につないだまま極板を動かすときは「\(W_{\rm 外力} + W_{\rm 電池} = \Delta U\)」を立てます。電池の仕事は \(V\Delta Q\)（電圧一定）です。電池を切り離して動かすときは \(W_{\rm 電池}=0\) で、電荷一定になります。
アニメーションで確かめよう：C が上に動くにつれて、下のグラフの3本の棒が伸びます。緑（外力の仕事、正）とオレンジ（電源の仕事、負）の和が青（静電エネルギーの変化）に一致し、緑の長さはつねにオレンジの半分です。図の緑の矢印が外力、赤が C にはたらく静電気力です。
II(1)　板 D を入れ、a を外した後の電荷答 ア \(0\)　イ \(2\)

a を外す前に電荷を決める

D を入れて C と導線 b でつなぐと、A・C・D が導線でつながった1つのグループになり、すべて電源の正極と同じ電位です。電位差があるのは DB 間（距離 \(\frac d2\)）だけです。

$$C_{\rm DB} = \frac{\varepsilon S}{d/2} = 2C_0,\qquad Q_2 = 2C_0V$$

A・C は相手との電位差が 0 なので電荷は 0 です。

a を外しても電荷は変わらない

導線を外すのは電荷を動かす操作ではないので、外した瞬間の電荷がそのまま残ります。よって \(Q_1 = 0\)（ア＝0）、B の電荷は \(-2C_0V\)（イ＝2）です。

a を外すと、C と D は他のどこともつながらない孤立した導体になります。C と D の電荷の和 \(0 + 2C_0V = 2C_0V\) は、これ以降ずっと変わりません。この保存量が II(2) と III の鍵になります。

式の立て方：スイッチや導線を切りかえる問題では、切りかえるたびに「孤立した導体のかたまり」を探し、そのかたまりの電荷の和を記録しておきます。それが次の状況での電気量保存の式の右辺になります。
アニメーションで確かめよう：D を入れる → b でつなぐ → a を外す、の順に進みます。b をつないだ瞬間に C の電荷が D に移り、DB 間に集まります。紫の枠が孤立した部分で、下のグラフでその電荷の和が一定であることが確認できます。
II(2)　電圧を \(\alpha V\) にしたときの電位差 \(V_1,V_2\)答 \(V_1 = \dfrac{\alpha-1}{3}V\)，\(V_2 = \dfrac{2\alpha+1}{3}V\)

未知数2つ → 式2つ

AC 間の電気容量は \(\frac{\varepsilon S}{d/4} = 4C_0\)、DB 間は \(2C_0\) です（CD 間は導線 b で同電位）。未知数は \(V_1\)（A の C に対する電位）と \(V_2\)（D の B に対する電位）の2つです。

① キルヒホッフの第2法則（電位の足し算）：A から B まで電位を下っていくと、合計は電源の電圧になります。

$$\cacc{V_1} + \cfrc{V_2} = \alpha V$$

② 孤立部分（C と D）の電気量保存：C の電荷は \(-4C_0V_1\)、D の電荷は \(+2C_0V_2\) です。和は II(1) のときの \(2C_0V\) のままです。

$$\cfic{-4C_0V_1 + 2C_0V_2 = 2C_0V}$$

①を \(V_2 = \alpha V - V_1\) として②に代入すると \(-6V_1 + 2\alpha V = 2V\) なので

$$V_1 = \frac{\alpha-1}{3}V,\qquad V_2 = \frac{2\alpha+1}{3}V$$

\(\alpha=1\)（電圧を変えない）なら \(V_1=0,\ V_2=V\) で II(1) の状態に戻ります。\(\alpha<1\) では \(V_1<0\) となり、A の方が C より電位が低くなります。

式の立て方：コンデンサーを含む回路は「キルヒホッフの第2法則（閉回路1周で電位の和）」と「孤立部分の電気量保存」で立てます。式の数が未知数の数と同じになるまで、孤立部分を探します。符号は「極板の電荷＝その極板の電位 − 向かい合う極板の電位、に電気容量をかけたもの」で統一すると迷いません。
アニメーションで確かめよう：\(\alpha\) を動かすと、右の電位のグラフで青の段差 \(V_1\) と赤の段差 \(V_2\) が変わり、その和がつねに \(\alpha V\) になります。下のグラフで、C と D の電荷の和（紫）は \(\alpha\) によらず \(2C_0V\) です。
III(1)　電気振動の周期 \(T\)答 \(T = 4\pi\sqrt{\dfrac{LC_0}{3}}\)

回路の式を1つの変数にまとめる

A の電荷を \(Q_3\)、B の電荷を \(-Q_4\) とします。キルヒホッフの第2法則（コンデンサー2つの電圧の和＝コイルの電圧）と、孤立部分 C・D の電気量保存は

$$\cacc{\frac{Q_3}{4C_0}} + \cfrc{\frac{Q_4}{2C_0}} = \cfr{L\frac{dI}{dt}},\qquad \cfic{-Q_3 + Q_4 = 2C_0V}$$

図の矢印の向き（A から出てコイルへ）に流れる電流は A の電荷を減らすので \(I = -\dfrac{dQ_3}{dt}\) です。\(Q_4 = Q_3 + 2C_0V\) を代入して整理すると

$$\frac{d^2Q_3}{dt^2} = -\frac{3}{4LC_0}\left(Q_3 + \frac43C_0V\right)$$

これは \(Q_3 = -\frac43C_0V\) を中心とする単振動の式で、角振動数は \(\omega = \sqrt{\dfrac{3}{4LC_0}}\) です。

$$T = \frac{2\pi}{\omega} = 4\pi\sqrt{\frac{LC_0}{3}}$$

2つのコンデンサー \(4C_0\) と \(2C_0\) の直列合成 \(\frac43C_0\) を使って \(T = 2\pi\sqrt{L\cdot\frac43C_0}\) としても同じです。孤立部分の電荷は振動の中心をずらすだけで、周期には影響しません。

式の立て方：電気振動は「\(\dfrac{d^2Q}{dt^2} = -\omega^2(Q - Q_{\rm 中心})\)」の形にできれば、周期と振動の中心が読めます。ばねにつるしたおもり（つり合いの位置が中心）と同じ構造です。電流の符号 \(I = \pm\dfrac{dQ}{dt}\) は、電流の正の向きに流れるとその極板の電荷が増えるか減るかで決めます。
アニメーションで確かめよう：コイルにつなぐと電流（緑の点）が往復します。右の電位のグラフで、A と B の電位差（オレンジ）がコイルの電圧 \(L\frac{dI}{dt}\) です。下のグラフで \(Q_3\) が \(-\frac43C_0V\) を中心に振動しています。
III(2)　\(t=0\) のコイルの電圧と \(I_0\)答 \(2V\)，\(I_0 = \dfrac{VT}{\pi L}\)

\(t=0\) の直前まで電源（電圧 \(2V\)）が A と B の間につながっていたので、A と B の電位差は \(2V\) です。スイッチを切りかえた瞬間、コンデンサーの電荷はまだ変わらないので、コイルにも \(2V\) がかかります。

\(I = I_0\sin\dfrac{2\pi t}{T}\) より、\(t=0\) での電流の変化の割合は \(\dfrac{dI}{dt} = \dfrac{2\pi I_0}{T}\) です。コイルの電圧は \(L\dfrac{dI}{dt}\) なので

$$\cfr{L\cdot\frac{2\pi I_0}{T}} = 2V\qquad\therefore\ I_0 = \frac{VT}{\pi L}$$
式の立て方：スイッチを切りかえた瞬間は「コンデンサーの電荷（電圧）は連続」「コイルの電流は連続」の2つを使います。ここでは電荷が連続なので電圧 \(2V\) が保たれ、電流は 0 から始まります。
アニメーションで確かめよう：下のグラフの電流（緑）は \(t=0\) で 0 ですが、傾きが最大です。その傾きを決めているのが、右の電位のグラフの A–B 間の電位差 \(2V\) です。
III(3)　\(Q_3=-2Q_4\) となる時刻と \(Q_3=0\) の時刻答 ウ \(-2\)，\(t' = \dfrac T6,\ \dfrac56T\)

初期値から \(Q_3(t)\) を決める

\(t=0\) の電荷は、II(2) で \(\alpha=2\) とおいた \(V_1 = \frac13V\) から \(Q_3 = 4C_0V_1 = \frac43C_0V\) です。\(t=0\) で電流 0 なので、\(Q_3\) は振動の端から出発します（cos 型）。振動の中心は \(-\frac43C_0V\) なので

$$\cacc{Q_3} = -\frac43C_0V + \frac83C_0V\cos\frac{2\pi t}{T}$$

\(t = T/4\) のとき

\(\cos\frac{\pi}{2}=0\) なので \(Q_3 = -\frac43C_0V\)、電気量保存から \(Q_4 = Q_3 + 2C_0V = \frac23C_0V\)。よって \(Q_3 = -2Q_4\)（ウ＝\(-2\)）です。この瞬間はコイルの電圧が 0（振動の中心）で、電流が最大です。

\(Q_3 = 0\) となる時刻

$$\cos\frac{2\pi t'}{T} = \frac12\qquad\therefore\ \frac{2\pi t'}{T} = \frac\pi3,\ \frac53\pi\qquad t' = \frac T6,\ \frac56T$$
式の立て方：単振動の式は「中心 ＋ 振幅 × cos（または sin）」で書きます。中心は運動方程式（回路の式）から、振幅と cos/sin の区別は初期条件（\(t=0\) の位置と速度＝電荷と電流）から決めます。
アニメーションで確かめよう：下のグラフに \(T/6,\ T/4,\ 5T/6\) の目盛りがあります。再生を止めて縦線を合わせ、\(Q_3\) が 0 になる時刻や \(Q_3=-2Q_4\) を確かめられます。
III(4)　静電エネルギーとコイルのエネルギー答 \(E_1 = 3C_0V^2\)，\(E_2 = \dfrac13C_0V^2\)，\(\Delta E = -\dfrac12LI_0^{\,2}\)

各区間のコンデンサーのエネルギー \(\frac{Q^2}{2C}\) を足します。

$$E_1 = \frac{(\frac43C_0V)^2}{2\cdot4C_0} + \frac{(\frac{10}{3}C_0V)^2}{2\cdot2C_0} = \frac29C_0V^2 + \frac{25}{9}C_0V^2 = 3C_0V^2$$ $$E_2 = \frac{(\frac43C_0V)^2}{2\cdot4C_0} + \frac{(\frac23C_0V)^2}{2\cdot2C_0} = \frac29C_0V^2 + \frac19C_0V^2 = \frac13C_0V^2$$

\(t=T/4\) では電流が最大値 \(I_0\) です。抵抗がないので、静電エネルギーの減少分がコイルのエネルギーになります。

$$\cacc{E_1} = \cacc{E_2} + \cfrc{\frac12LI_0^{\,2}}\qquad\therefore\ \Delta E = E_2 - E_1 = -\frac12LI_0^{\,2}$$

（確認：\(I_0 = \frac{VT}{\pi L}\) と \(T^2 = \frac{16\pi^2LC_0}{3}\) から \(\frac12LI_0^{\,2} = \frac83C_0V^2 = E_1 - E_2\)。）

静電エネルギーは 0 まで下がりません。孤立部分の電荷 \(2C_0V\) が残す電場のエネルギーは、振動では取り出せないためです。

式の立て方：LC 回路では「静電エネルギーの和 ＋ \(\frac12LI^2\) ＝ 一定」が成り立ちます。電流最大の瞬間は振動の中心で、静電エネルギーが最小です。
アニメーションで確かめよう：下のグラフの右の棒は、静電エネルギー（青）とコイルのエネルギー（赤）の積み上げです。合計の高さはつねに \(3C_0V^2\) で、青は \(\frac13C_0V^2\) より下がりません。
III(5)　\(Q_3\) と \(-Q_4\) のグラフを選ぶ答 ④

電圧が \(\alpha V\) のとき、\(t=0\) の電荷は II(2) から \(Q_3 = \frac43(\alpha-1)C_0V\)、振動の中心は III(1) と同じ \(-\frac43C_0V\) です（中心は孤立部分の電荷で決まり、\(\alpha\) によらない）。

$$Q_3 = -\frac43C_0V + \frac43\alpha C_0V\cos\frac{2\pi t}{T},\qquad -Q_4 = -Q_3 - 2C_0V$$

選択肢を絞るポイントは3つです。

① 周期：\(0\sim T\) でちょうど1往復 → 2往復している図は除外。
② \(t=0\) で電流 0：\(Q_3\) のグラフは \(t=0\) で傾き 0（山か谷）→ \(Q_3\) が \(t=0\) で最大の図に限られる。
③ 電気量保存：\(Q_3 + (-Q_4) = -2C_0V\) なので、2つのグラフは高さ \(-C_0V\) の線について上下対称で、一方が山のとき他方は谷。

これらをすべて満たすのは④です。

式の立て方：グラフ選択問題は、式を全部計算する前に「周期」「初期条件（値と傾き）」「保存量（和や差が一定）」の3点で絞り込みます。
アニメーションで確かめよう：\(\alpha\) を動かしても、2つのグラフはつねに灰色の線（\(-C_0V\)）について対称です。\(\alpha\) を大きくすると振幅が増えて \(-Q_4\) が正になる時間ができ、④の形になります。
