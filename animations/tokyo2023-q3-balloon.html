風船の膜張力と2つの風船（東京大学 2023年 第3問）

ゴム膜の膜張力が風船の内圧を外気圧より高くするしくみを、仕事のつり合いから導きます。2つの風船をつなぐと小さい方がしぼむのはなぜか、実際の風船（膜張力が半径で変わる）では大きさがどう分かれるか、温度を変えると何が起こるかを、圧力–半径のグラフで確かめます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。膜を面積 \(\Delta S\) 広げるのに必要な仕事は \(\Delta W = \sigma\Delta S\)、外気圧は \(p_0\) です。

I(1)(2)(3)　ピストンの仕事・膜の仕事・内圧 p答 (1) \(4\pi(p-p_0)r^2\Delta r\)　(2) \(8\pi\sigma r\Delta r\)　(3) \(p = p_0 + \dfrac{2\sigma}{r}\)

(1) 圧力がする仕事 ＝ 圧力差 × 体積変化

液体の体積は一定なので、ピストンが押しのけた体積がそのまま風船の体積の増加 \(\Delta V\) になります。ピストンには内側から \(p\)、外側から \(p_0\) がはたらくので、ゆっくり押すのに必要な力は \((p-p_0)\times\)（ピストンの面積）。仕事は

$$W_1 = (p-p_0)\Delta V,\qquad \Delta V = \frac43\pi(r+\Delta r)^3 - \frac43\pi r^3 \fallingdotseq 4\pi r^2\Delta r$$ $$W_1 = 4\pi(p-p_0)r^2\Delta r$$

(2) 膜を広げる仕事

$$\Delta S = 4\pi(r+\Delta r)^2 - 4\pi r^2 \fallingdotseq 8\pi r\Delta r,\qquad W_2 = \sigma\Delta S = 8\pi\sigma r\Delta r$$

(3) 2つの仕事が等しい

$$4\pi(p-p_0)r^2\Delta r = 8\pi\sigma r\Delta r\qquad\therefore\quad p = p_0 + \frac{2\sigma}{r}$$

別の見方：半分に切って力のつり合い

風船を半球に切って、半分にはたらく力を考えます。圧力差が押し広げる力は \((p-p_0)\times\pi r^2\)（切り口の円の面積）、切り口の縁で膜が引き戻す力は \(\sigma\times2\pi r\)（\(\sigma\) は単位長さあたりの力）。等しいとおくと同じ式が出ます。

式の立て方：「少しだけ変化させたときの仕事のつり合い」（仮想仕事）か「半分に切った部分の力のつり合い」のどちらでも立てられます。\(\Delta r\) の2次以上を捨てる近似は、球の体積・表面積を \(r\) で微分したもの（\(4\pi r^2\)、\(8\pi r\)）を使うのと同じです。
アニメーションで確かめよう：下のグラフは \(p - p_0 = \dfrac{2\sigma}{r}\)。小さい風船ほど内圧が高いことが分かります。右の棒グラフで、ピストンの仕事と膜の仕事が等しいことも確かめられます。
II(1)　小さい風船と大きい風船をつなぐと答 ア ②（小さい）　イ ④（他方はしぼみきっている）　理由：\(p = p_0 + \dfrac{2\sigma}{r}\) より、半径の小さい風船の方が内圧が高いから

弁を開くと、気体は圧力の高い方から低い方へ移ります。(3) より半径が小さいほど内圧が高いので、小さい風船 A から大きい風船 B へ気体が移ります。

A はしぼむとさらに内圧が上がり、B はふくらむとさらに内圧が下がります。圧力差は広がる一方なので、途中で止まることはなく、A がしぼみきるまで続きます。

考え方：「ずれが生じたとき、そのずれを戻す向きに変化するか（安定）、さらに広げる向きに変化するか（不安定）」を調べます。ここでは半径が小さくなるほど圧力が上がる（\(p\) が \(r\) の減少関数）ので不安定です。シャボン玉を2つつないでも同じことが起こります。
アニメーションで確かめよう：下のグラフの曲線上で、A（赤）は左上へ、B（青）は右下へ動いていきます。\(r_A\) と \(r_B\) を入れかえても、必ず小さい方がしぼみます。
II(2)　σ を p₀, rA, rB, rC で表す答 \(\sigma = \dfrac{p_0\left(r_C^{\,3} - r_A^{\,3} - r_B^{\,3}\right)}{2\left(r_A^{\,2} + r_B^{\,2} - r_C^{\,2}\right)}\)

温度一定・物質量一定 → pV の和が変わらない

理想気体の状態方程式 \(pV = nRT\) で、\(T\) が一定で気体の出入りがない（2つの風船の合計）ので、\(pV\) の和が保存されます：

$$\left(p_0 + \frac{2\sigma}{r_A}\right)\frac43\pi r_A^{\,3} + \left(p_0 + \frac{2\sigma}{r_B}\right)\frac43\pi r_B^{\,3} = \left(p_0 + \frac{2\sigma}{r_C}\right)\frac43\pi r_C^{\,3}$$

\(\dfrac43\pi\) で割ると \(p_0(r_A^{\,3}+r_B^{\,3}) + 2\sigma(r_A^{\,2}+r_B^{\,2}) = p_0r_C^{\,3} + 2\sigma r_C^{\,2}\)。σ について解いて答えになります。

式の立て方：気体がつながった容器の間を移動する問題では、まず「全体で何が保存されるか」を探します。温度が一定なら \(\sum pV\)（物質量の和）、断熱ならエネルギー、と決めてから、各容器の \(p\) と \(V\) を半径で書きます。
アニメーションで確かめよう：弁を開く前と後で \(\sum pV\) が同じになっていることを、下の棒グラフで確かめられます。最後の半径 \(r_C\) から計算した σ は、設定した σ と一致します。
III(1)　半径 rD が満たすべき条件答 \(r_D > \dfrac32 r_0\)

内圧を半径の関数として書く

(3) の \(\sigma\) に \(\sigma(r) = a\dfrac{r-r_0}{r^2}\) を入れると

$$p(r) = p_0 + \frac{2\sigma(r)}{r} = p_0 + 2a\,\frac{r-r_0}{r^3},\qquad p'(r) = 2a\,\frac{3r_0 - 2r}{r^4}$$

\(p(r)\) は \(r = \dfrac32r_0\) で最大になる山形のグラフです。

安定か不安定かは、グラフの傾きで決まる

片方を少ししぼませると、気体はもう一方へ移ります。

・\(p'(r_D) > 0\)（山の左側）：しぼんだ方は内圧が下がり、ふくらんだ方は上がるので、気体は押し戻され、元の同じ大きさに戻ります。

・\(p'(r_D) < 0\)（山の右側）：しぼんだ方は内圧が上がり、さらに気体を送り出すので、差が広がります（II と同じ）。

大きさが異なる2つになったので \(p'(r_D) < 0\)、つまり \(r_D > \dfrac32r_0\)。

式の立て方：つり合いの安定性は「少しずらしたとき、元に戻す向きの変化が起こるか」を、ずれに対する圧力（力）の変化の符号で判定します。ばねのつり合いや浮力のつり合いの安定性と同じ考え方です。
アニメーションで確かめよう：\(r_D\) を \(1.5r_0\) より小さくすると、しぼませても元に戻ります。大きくすると、一方は山の左側、もう一方は右側の同じ高さ（同じ圧力）の点に分かれて止まります。
III(2)　温度をわずかに上げると内圧は？答 低くなる

III(1) のあと、2つの風船の圧力は等しく、小さい方は山の左側（\(r < \dfrac32r_0\)）、大きい方は右側（\(r > \dfrac32r_0\)）にあります。

いったん弁を閉じたまま温度を上げると、どちらの気体も膨張して半径が大きくなります。すると山の左側の小さい風船は内圧が上がり、右側の大きい風船は内圧が下がります。弁を開けると小さい方から大きい方へ気体が移り、大きい風船はさらにふくらんで内圧がさらに下がります。小さい方も気体を失ってしぼむので、左側の坂を下って内圧が下がります。結局、両方の内圧ははじめより低い同じ値にそろいます。

考え方：「弁を閉じて変化させる → 弁を開いて圧力をそろえる」と2段階に分けると、つながった容器の変化を追いやすくなります。
アニメーションで確かめよう：温度を上げると、下のグラフの2点は同じ高さを保ったまま山の両側を下がっていきます（大きい方は右へ、小さい方は \(r_0\) の方へ）。
III(3)　温度をゆっくり下げたときの半径の変化答 ⑥（温度を下げると2つの半径が近づいて \(\tfrac32r_0\) で一致し、その後は同じ半径のまま \(r_0\) に近づくグラフ）

III(2) の逆に、温度を下げると2点は山の両側を上がっていき、大きい風船は小さく、小さい風船は大きくなって、山の頂上 \(r = \dfrac32r_0\) で一致します。

そこからさらに温度を下げると、両方とも山の左側（安定な側）にあるので、同じ半径を保ったまましぼみ、\(r_0\) に近づいていきます。

温度を横軸にして描き直すと、高温側では2本（大きい方は温度とともに大きくなり、小さい方は \(r_0\) に近づく）、ある温度より低温側では1本にまとまった、枝分かれのグラフになります。

式の立て方：状態は「圧力が等しい」「\(\sum pV = nRT\)」の2つの式で決まります。下の右のグラフは、この2式を数値で解いて、温度ごとの2つの半径を描いたものです（点線は不安定なつり合い）。
アニメーションで確かめよう：温度のスライダーを左右に動かすと、2つの風船と、右のグラフ上の点が動きます。
