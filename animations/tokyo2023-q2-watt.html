ワット天秤：電磁誘導で質量を測る（東京大学 2023年 第2問）

磁場の中を動くコイルの誘導起電力と、電流を流したコイルが受ける力を組み合わせると、コイルの形や磁場の強さを知らなくても質量が測れます（キログラムの定義に使われるワット天秤の原理）。後半はホール素子とソレノイドの磁場の打ち消しを使って抵抗値を精密に決める方法を調べます。

解答解説

II(1) では増幅器を切りはなし、I₁ と I₃ を手で動かせるようにしています。見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。z 軸は鉛直下向き、磁場は円盤の半径方向外向きに大きさ \(B_0\) です。

I(1)　一定の速さで動かしたときの J₂ の電位 V₁答 \(V_1 = 2\pi rNv_0B_0\)

大きさ：導線が磁場を横切る長さ × v × B

導線はどの部分も速度（下向き）と磁場（水平・半径方向）が垂直です。長さ \(l\) の導線が速さ \(v\) で磁場 \(B\) を横切るときの起電力は \(vBl\)。巻かれた導線の全長は \(l = 2\pi r\times N\) なので

$$V_1 = v_0B_0\cdot 2\pi rN$$

向き：正電荷が受けるローレンツ力の向き

上から見ると z 軸（下向き）は紙面の裏向き、磁場は外向きです。導線中の正電荷が受ける力 \(q\vec v\times\vec B\) は円周に沿って時計回り。導線は J₁ から時計回りに巻かれているので、正電荷は J₁ 側から J₂ 側へ押されます。電池でいえば J₂ が＋極なので、J₂ の電位は J₁ より \(V_1\) だけ高くなります。

式の立て方：誘導起電力は「\(V = vBl\)（向きは \(q\vec v\times\vec B\)）」または「単位時間に横切る磁束」のどちらでも出せます。放射状の磁場は、円形の導線のどこでも \(v\) と \(B\) が垂直になるように作られているので、直線の導体棒と同じ式がそのまま使えます。
アニメーションで確かめよう：右の上から見た図で、赤い矢印が正電荷の受ける力（時計回り）。\(v_0\)・\(N\)・\(B_0\)・\(r\) のどれを2倍にしても \(V_1\) は2倍になります。
I(2)　干渉計の信号 V(z) の k答 \(k = \dfrac{4\pi f}{c}\)

鏡 M₁ が \(z\) だけ動くと、M₁ へ行って戻る光の道のりは \(2z\) 変わります。2つの光の道のりの差が波長 \(\lambda = \dfrac cf\) だけ変わるたびに、明るさは同じ状態に戻ります。つまり \(V(z)\) の周期は \(\Delta z = \dfrac{\lambda}{2}\)：

$$k\cdot\frac{\lambda}{2} = 2\pi\qquad\therefore\quad k = \frac{4\pi}{\lambda} = \frac{4\pi f}{c}$$
式の立て方：干渉は「経路差 ＝ 波長の整数倍で強め合う」。反射鏡が動く問題では、往復するので経路差は移動距離の2倍になる点を必ず確認します。
アニメーションで確かめよう：円盤がゆっくり動くと、光検出器の明るさと \(V(z)\) が \(\lambda/2\) ごとにくり返します。下のグラフで2つの光の波の重なり方（位相差 \(kz\)）も見られます。
I(3)(4)　物体をのせたときの合力と、静止位置 z₁・電圧 V₂答 (3) \((M+m)g - T - \dfrac{2\pi rNB_0\left\{AV_L\sin(kz) + 2\pi rNB_0v\right\}}{R}\)　(4) \(z_1 = \dfrac{mgR}{2\pi rNB_0AV_Lk}\)、\(V_2 = \dfrac{mgR}{2\pi rNB_0}\)

回路の式（キルヒホッフの第2法則）

回路には可変電源の電圧 \(V_A = AV_L\sin(kz)\) と、コイルの誘導起電力 \(2\pi rNB_0v\)（(1) と同じ）が同じ向きに入り、抵抗 \(R\) で電圧が下がります：

$$AV_L\sin(kz) + 2\pi rNB_0v - RI = 0\qquad\therefore\quad I = \frac{AV_L\sin(kz) + 2\pi rNB_0v}{R}$$

力の式：電流が磁場から受ける力 IBl

コイルを流れる電流は、磁場から上向きに \(IB_0\cdot2\pi rN\) の力を受けます（下向きに動くと誘導電流がその動きを妨げる向き、というレンツの法則とも合います）。重力・張力と合わせて、下向きを正として

$$F = (M+m)g - T - 2\pi rNB_0\cdot\frac{AV_L\sin(kz) + 2\pi rNB_0v}{R}$$

(4) 静止したとき：v = 0, F = 0, T = Mg

おもりも静止するので \(T=Mg\)。\(\sin(kz_1)\fallingdotseq kz_1\) として

$$mg = 2\pi rNB_0\cdot\frac{AV_Lkz_1}{R}\quad\Rightarrow\quad z_1 = \frac{mgR}{2\pi rNB_0AV_Lk}$$ $$V_2 = RI = AV_Lkz_1 = \frac{mgR}{2\pi rNB_0}$$
式の立て方：電磁誘導と運動が組み合わさった問題は、回路の式（電圧のつり合い）と運動方程式（力）の2本を、共通の電流 \(I\) でつなぎます。ここで \(AV_L\sin(kz)\) の項は「ずれ \(z\) に比例して押し戻す」ばね、\(v\) の項は「速さに比例する」ブレーキ（電磁制動）としてはたらくので、円盤は減衰振動して \(z_1\) に落ち着きます。
アニメーションで確かめよう：増幅率 \(A\) を大きくするほど「ばね」が硬くなり、\(z_1\) は小さくなります。それでも電圧 \(V_2\) は変わりません（\(V_2\) は \(mg\) を支えるのに必要な電流で決まるから）。
I(5)　物体の質量 m答 \(m = \dfrac{V_1V_2}{v_0gR}\)

(1) と (4) にはどちらも、正確に測るのが難しい \(2\pi rNB_0\)（コイルの形と磁場の強さ）が入っています。これを \(\kappa\) とおくと

$$V_1 = \kappa v_0,\qquad V_2 = \frac{mgR}{\kappa}$$

掛け合わせると \(\kappa\) が消えます：

$$V_1V_2 = mgRv_0\qquad\therefore\quad m = \frac{V_1V_2}{v_0gR}$$

書き直すと \(V_1\cdot\dfrac{V_2}{R} = mg\,v_0\)。「電気の仕事率（電圧 × 電流）」と「力学の仕事率（力 × 速さ）」を等しくおいた形なのでワット天秤と呼ばれます。

式の立て方：測りにくい量が2つの実験に共通して出てくるときは、2つの式を割ったり掛けたりして消去します。誘導起電力 \(V=\kappa v\) と力 \(F=\kappa I\) に同じ係数 κ が出てくるのは、どちらも同じ導線と磁場で決まるからです。
アニメーションで確かめよう：\(B_0\) を変えると \(V_1\) と \(V_2\) は逆向きに変わりますが、計算した \(m\) は変わりません。
II(1)　電圧計の値 V と、ソレノイド内の磁場 H答 \(V = R_HI_1 - RI_2\)、\(H = \left|n_1I_1 - n_2I_2 - n_3I_3\right|\)

電位は基準点からたどって足し引きする

P₅ から出発し、抵抗 \(R\)（電流 \(I_2\)）を通って P₃ へ、ホール素子の中で P₃ から P₄ へとたどります。\(R\) を電流の向きにたどると電位は \(RI_2\) 下がり、ホール素子では P₃ に対して P₄ が \(R_HI_1\) 高いので

$$V = -RI_2 + R_HI_1$$

磁場は巻き方の向きで足し引きする

長いソレノイドの内部の磁場は \(H = nI\)。ソレノイド2と3は同じ向き、1は逆向きに巻かれているので

$$H = \left|n_1I_1 - n_2I_2 - n_3I_3\right|$$
式の立て方：回路が複雑なときは、測りたい2点の間を1本の道でたどり、素子ごとに「上がる／下がる」を足していきます。磁場の重ね合わせも同じで、向きを決めてから符号つきで足します。
アニメーションで確かめよう：\(I_1\) を動かすと、下の棒グラフで3つのソレノイドの磁場の和が変わります。\(H = 0\) になる \(I_1\) を探してみましょう。
II(2)　H = 0 のときの式（ア・イ）答 ア \(\dfrac{n_1I_1 - n_3I_3}{n_2I_1}\)　イ \(\dfrac{R'I_3}{RI_1}\)

使える式は3本です。

$$V = R_HI_1 - RI_2,\qquad AV = R'I_3,\qquad n_1I_1 - n_2I_2 - n_3I_3 = 0$$

答えに使える文字に \(I_2\) と \(V\) がないので、この2つを消去します。1本目と2本目から \(\dfrac{R'I_3}{A} = R_HI_1 - RI_2\)。両辺を \(RI_1\) で割って

$$\frac{R_H}{R} = \frac{I_2}{I_1} + \frac1A\cdot\frac{R'I_3}{RI_1}$$

3本目から \(I_2 = \dfrac{n_1I_1 - n_3I_3}{n_2}\) を代入すると、ア \(=\dfrac{n_1I_1-n_3I_3}{n_2I_1}\)、イ \(=\dfrac{R'I_3}{RI_1}\)。\(A\) が大きいとイの項は無視できて

$$R \fallingdotseq R_H\cdot\frac{n_2I_1}{n_1I_1 - n_3I_3}$$
式の立て方：未知数（電流・電圧）の数だけ式を集め、答えに使ってはいけない文字から順に消去します。「増幅率 \(A\) が大きい」は「入力電圧 \(V\) がほぼ 0」と同じ意味で、ホール電圧 \(R_HI_1\) と \(RI_2\) が等しくなるように自動調整されています。
アニメーションで確かめよう：\(A\) を小さくすると、イの項が効いて近似式の値が真の値からずれます。\(A\) を大きくすると一致します。
II(3)　測定値から求めた R と相対誤差答 \(R = 108\ \Omega\)、相対誤差 2 %
$$R \fallingdotseq 12.9\times10^3\times\frac{10\times540}{1290\times540 - 129\times400}\ \Omega = 108\ \Omega,\qquad \frac{108-106}{106}\fallingdotseq 0.02$$

電流の誤差が 10 % でも、R の誤差が 2 % で済む理由

近似式を変形すると

$$R \fallingdotseq R_H\frac{n_2}{n_1}\cdot\frac{1}{1 - \dfrac{n_3}{n_1}\cdot\dfrac{I_3}{I_1}}$$

大きな部分 \(R_H\dfrac{n_2}{n_1} = 100\ \Omega\) は、正確な \(R_H\) と巻数の比だけで決まります。電流の測定値は、6 % ほどの小さな補正項 \(\dfrac{n_3I_3}{n_1I_1}\) の中にしか入らないので、電流の誤差は小さく薄められます。巻数比を \(\dfrac{n_2}{n_1}\fallingdotseq\dfrac{R}{R_H}\)、\(\dfrac{n_3}{n_1}\) を小さく選んだのはこのためです。

式の立て方：誤差の問題では、結果を「正確に分かる大きな部分 ×（1 ＋ 小さな補正）」の形に直すと、どの測定値の誤差がどれだけ効くかが見えます。
アニメーションで確かめよう：\(I_1\)、\(I_3\) の測定誤差を ±20 % の範囲で動かすと、\(R\) の誤差は数 % にとどまります。下のグラフの点線は「誤差がそのまま R に効いた場合」です。
