動く台車の上の単振動：ばね振り子と倒立振子を止める（東京大学 2019年 第1問）

台車を強制的に動かすと、台車の上では物体に慣性力がはたらき、ばね振り子の振動の中心がずれます。加速度を切りかえるタイミングをうまく選ぶと、台車が止まったときに振動も止められます。後半は手のひらに棒を立てる遊びを倒立振子で考え、棒を倒さずに台車を止める加速度の変え方を求めます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。色は図と式で共通です：台車の加速度・速度（青）、ばねの力・棒に垂直な力 f（赤）、慣性力（紫）、重力（緑）、振動の中心（オレンジ）。

I(1)　台車の速度と移動距離答 速度 \(a_1t_1\)，移動距離 \(a_1t_1t_2\)

v–t グラフを描く

加速度が区間ごとに一定なので、台車の速度は直線をつないだグラフになります。加速区間の終わりの速度は

等加速度直線運動の式

$$v = \cacc{a_1}t_1$$

減速区間の長さは \((t_1+t_2)-t_2 = t_1\) で、加速区間と同じです。同じ大きさの加速度で同じ時間だけ減速するので、時刻 \(t_1+t_2\) でちょうど止まります。グラフは左右対称な台形です。

移動距離 ＝ v–t グラフの面積

$$x = \frac{(t_2-t_1)+(t_1+t_2)}{2}\times a_1t_1 = a_1t_1t_2$$

発展：台車を動かした仕事はどこへ行くか

台車は最後に止まるので、台車を動かす外力がした仕事は、最後に物体に残る振動のエネルギー \(\frac12kA^2\)（\(A\) は残った振幅）に等しくなります。\(d = \dfrac{ma_1}{k}\) とおくと、\(t_1, t_2\) の選び方で \(A\) は 0 から \(4d\) まで変わり、仕事は最小 0、最大 \(\dfrac12k(4d)^2 = \dfrac{8m^2a_1^{\,2}}{k}\) です。最小になる例が I(2) です。

式の立て方：加速度が区間ごとに一定の運動は、まず v–t グラフを描きます。速度は「加速度 × 時間」の積み重ね（傾き）、移動距離はグラフの面積です。式を区間ごとに書くより、面積で一度に求める方が速く確実です。
アニメーションで確かめよう：\(t_1, t_2\) を変えると台形の形が変わり、塗った面積が \(a_1t_1t_2\) と一致します。下の y–t グラフを見ると、台車が止まったあとも物体の振動が残ることが多く、「いまの値」の「残った振動のエネルギー」が外力のした仕事です。\(t_1 = 0.5T\)、\(t_2\) を \(T\) の整数倍にすると 0 になります。
I(2)　t₁ = T/2，t₂ = nT のときの物体答 \(y = 0\)，相対速度 0

台車から見ると「中心がずれたばね振り子」

加速度 \(a\) の台車から見ると、物体にはばねの力 \(-ky\) に加えて慣性力 \(-ma\) がはたらきます。

運動方程式（台車から見た物体）

$$m\frac{d^2y}{dt^2} = \cfrc{-ky}\cfic{\,-\,ma} = -k\left(y - \cfr{\left(-\frac{ma}{k}\right)}\right)$$

右辺は「\(y = -\dfrac{ma}{k}\) からのずれに比例する復元力」なので、物体は周期 \(T = 2\pi\sqrt{m/k}\)、中心 \(\cfr{y_c = -\dfrac{ma}{k}}\) の単振動をします。\(a\) が変わると中心だけが移り、周期は変わりません。\(d = \dfrac{ma_1}{k}\) とおくと、中心は加速区間 \(-d\)、等速区間 0、減速区間 \(+d\) です。

区間ごとに端点をつなぐ

単振動では、速度 0 の点（端点）どうしは中心について対称で、端から端までちょうど半周期かかります。

① 加速区間（長さ \(T/2\)）：\(y = 0\) で静止 → 端点。中心 \(-d\) の反対側の端 \(y = -2d\) に、半周期後の \(t = T/2\) でちょうど着きます（速度 0）。

② 等速区間（長さ \(nT - \frac T2\)）：中心 0、振幅 \(2d\)。\(n-\frac12\) 周期後には反対側の端 \(y = +2d\) で速度 0 です。

③ 減速区間（長さ \(T/2\)）：中心 \(+d\)。端 \(+2d\) から半周期で反対側の端 \(y = 0\) に着き、速度 0 です。

その後は \(a = 0\)（中心 0）で、\(y = 0\) に静止したままです。よって \(y = 0\)、相対速度 0 です。

式の立て方：加速する座標系では運動方程式に慣性力 \(-ma\) を加えます。「ばねの力 ＋ 一定の力」は中心がずれた単振動になります。区間ごとに中心・振幅・端点を求め、境目で位置と速度をつなぎます。境目がちょうど端点（速度 0）になるように時間が選ばれていると、計算がほとんどいりません。
アニメーションで確かめよう：オレンジの破線が振動の中心です。区間が変わるたびに中心が跳び、物体はちょうど端で折り返します。y–t グラフでは、各区間の曲線が中心の線について上下対称になっています。\(n\) を変えても最後は止まります。
I(3)　y₀ から放して t = T で止める答 \(a_2 = -\dfrac{ky_0}{4m}\)，\(y = -\dfrac12y_0\)

着眼点：t = 0, T/2, T の3つの時刻はすべて端点

\(t = 0\) で静かに放すので速度 0、\(t = T\) でも相対速度 0 です。各区間はちょうど半周期なので、\(t = T/2\) も端点になります。\(t = T/2\) の位置を \(y_1\) とします。

単振動の端点と中心の関係（中心は両端の中点）

$$\frac{y_0 + y_1}{2} = \cfr{-\frac{ma_2}{k}},\qquad \frac{y_1 + 0}{2} = \cfr{+\frac{ma_2}{k}}$$

2式を足すと \(y_0 + 2y_1 = 0\) なので

$$y_1 = -\frac12y_0,\qquad a_2 = \frac{k y_1}{2m} = -\frac{ky_0}{4m}$$

\(y_0 < 0\) なので \(a_2 > 0\) です。参考に、y–t グラフを式で書くと \(0

式の立て方：「止まる」「放す」「折り返す」は速度 0、つまり単振動の端点です。端点が分かっている区間では「中心 ＝ 両端の中点」の1本で式が立ちます。三角関数で \(y(t)\) を書くより、端点と中心の位置関係で考える方が速く、間違いも減ります。
アニメーションで確かめよう：「a₂ を理論値の何倍にするか」を 1 からずらすと、\(t = T\) で \(y \neq 0\) になったり速度が残ったりして、振動が止まりません。グラフの3つの黒点（端点）と2本のオレンジの線（中心）で、中点の関係を確かめられます。
II(1)　質点にはたらく力の棒に垂直な成分答 \(f = mg\theta - ma\)

台車から見て、棒に垂直な方向に分ける

台車から見ると、質点には重力 \(mg\)（下向き）と慣性力 \(ma\)（台車の加速度と逆向き）がはたらきます。棒が質点を押す（引く）力は棒に沿った向きなので、棒に垂直な成分を持ちません。

力の分解（θ が増える向きを正）

$$f = \cgrav{mg\sin\theta} - \cfic{ma\cos\theta} \;\approx\; mg\theta - ma$$

着眼点：倒れないための加速度

\(f = 0\) となるのは \(a = g\theta\) のときです。棒が傾いている向きに、傾きに比例した加速度で手を動かすと、棒は傾いたまま倒れません。手のひらに棒を立てる遊びで「倒れる向きに手を動かす」のはこのためです。

式の立て方：棒や糸の先の質点は、運動を「棒に垂直（接線方向）」と「棒の方向」に分けます。棒の力は棒の方向だけなので、接線方向の運動方程式には重力と慣性力の成分だけが入ります。小さい角では \(\sin\theta \approx \theta\)、\(\cos\theta \approx 1\) とします。
アニメーションで確かめよう：θ と a を変えると、赤い矢印 f の大きさと向きが変わります。下のグラフは θ を固定したときの f と a の関係で、\(a = g\theta\) で f が 0 になります。矢印の分解（点線）は見やすいように拡大しています。
II(2)　倒立振子を倒さずに台車を止める答 ア②　イ①　ウ⑩　エ④　オ①　i \(\dfrac{\theta_0+\theta_1}{2}\pi\sqrt{g\ell}\)　ii \(\dfrac{\theta_1}{2}\pi\sqrt{g\ell}\)　iii \(-\dfrac12\)

θ(t) をグラフから読む（ア・イ）

\(0 $$\theta = \frac{\theta_0-\theta_1}{2}\cos\sqrt{\frac g\ell}\,t + \cfr{\frac{\theta_0+\theta_1}{2}}$$

この運動に必要な力（ウ）

質点の棒に垂直な方向の加速度は \(\ell\dfrac{d^2\theta}{dt^2}\) です（半径一定の円運動の接線加速度）。θ の式を2回微分すると \(\dfrac{d^2\theta}{dt^2} = -\dfrac g\ell\left(\theta - \dfrac{\theta_0+\theta_1}{2}\right)\) なので

運動方程式（棒に垂直な方向・台車から見る）

$$F = m\ell\frac{d^2\theta}{dt^2} = -mg\left(\theta - \frac{\theta_0+\theta_1}{2}\right)$$

f = F から台車の加速度（エ・オ）

実際にはたらく力 \(f = mg\theta - ma\) が、必要な力 \(F\) と等しくなるように \(a\) を選びます。

$$\cgrav{mg\theta}-\cfic{ma} = -mg\left(\theta - \frac{\theta_0+\theta_1}{2}\right)\;\Longrightarrow\; \cacc{a} = \left\{(\theta_0-\theta_1)\cos\sqrt{\frac g\ell}\,t + \frac{\theta_0+\theta_1}{2}\right\}g$$

台車の速度の変化（i・ii・iii）

第1項は単振動の加速度と同じ形です。単振動は端から端までの半周期で速度 0 → 0 なので、この項による速度の変化は 0 です。残るのは定数項だけで、\(g\cdot\frac T2 = \pi\sqrt{g\ell}\) を使って

速度の変化 ＝ a–t グラフの面積

$$v_1 = \frac{\theta_0+\theta_1}{2}\,g\cdot\frac T2 = \frac{\theta_0+\theta_1}{2}\pi\sqrt{g\ell}$$

後半も同じ考え方で、θ の中心は \(\frac{\theta_1}{2}\) なので \(v_2 = \dfrac{\theta_1}{2}\pi\sqrt{g\ell}\) です。台車ははじめと終わりで静止しているので

$$v_1 + v_2 = 0\;\Longrightarrow\;\theta_0 + 2\theta_1 = 0\;\Longrightarrow\;\theta_1 = -\frac12\theta_0$$

着眼点

台車の加速度を時間平均すると「g × 振動の中心の角度」になります。台車を止めるには、前半と後半の中心の角度を打ち消し合わせればよい、ということです。はじめ前に傾いた棒を立て直すには、まず前へ加速して棒を反対側へ少し倒し、その後で減速して戻します。

式の立て方：「望みの運動をさせる力を求める」問題は ①望みの運動を式にする ②運動方程式から必要な力を逆算する ③実際の力の式と等しいとおく、の順です。選択肢から選ぶときは単位（次元）をそろえるだけでも候補が大きく減ります（角度は単位なし、\(F\) は力の単位）。
アニメーションで確かめよう：「θ₁ / θ₀」を −0.5 以外にすると、θ は同じように 0 に戻りますが、台車が止まらずに走り続けます。右のグラフで \(v\) が \(t = T\) で 0 に戻るのは −0.5 のときだけです。
