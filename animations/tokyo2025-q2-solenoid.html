ソレノイドの端を通過するコイル（東京大学 2025年 第2問）

長いソレノイドの端では磁場が「半分」になり、外側へ広がります。そこへ小さな円形コイル B を一定の速さで通すと、どこで電流が流れ、どちら向きの力を受けるのでしょうか。磁束 Φ・電流 I・力 F のグラフを同時に描いて確かめます。

設定

表示
つなぐ素子

D↓ は X→Y（図の下向き）にだけ、D↑ は Y→X にだけ電流を通すダイオードです。II(4) ではソレノイドの電流を逆向きにしています。

ソレノイドの直径 a = 10 cm、内部の磁束密度 BO = 1 T として計算しています。コイル B は小さいとして、中心軸上の磁場で磁束を求めています。

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。

I(1)　長いソレノイドの中の磁場答 \(B_{\mathrm O} = \dfrac{\mu_0NI}{\ell}\)

十分に長いソレノイドの内部の磁場は、軸に平行で一様、外側はほぼ 0 です。大きさを決めるのは「単位長さあたりの巻数」\(n = \dfrac{N}{\ell}\) だけで

$$B_{\mathrm O} = \mu_0 nI = \frac{\mu_0NI}{\ell}$$

直径 \(a\) によらないことに注意しましょう。向きは右ねじの法則で決まり、この問題の電流の向きでは左向き（\(-x\) 向き）です。

アニメーションで確かめよう：内部の磁力線はまっすぐで等間隔（一様）です。グラフは軸上の磁束密度で、端から十分離れた所ではどこでも \(B_{\mathrm O}\) です。
I(2)　半分にしたときの端の磁場答 \(B_1 = \dfrac{1}{2}B_{\mathrm O}\)

重ね合わせ＋対称性

長いソレノイドを「左半分」と「右半分」に分けて考えます。O にできる磁場は

$$B_{\mathrm O} = (\text{左半分がつくる磁場}) + (\text{右半分がつくる磁場})$$

O から見ると、左半分と右半分はちょうど鏡に映した形です。どちらも O に同じ向き（\(-x\)）・同じ大きさの磁場をつくるので、それぞれ \(\dfrac12B_{\mathrm O}\)。左半分を取り除けば

$$B_1 = \frac{1}{2}B_{\mathrm O}$$

このように「全体の場＝部分の場の和」と「部分どうしの対称性」を組み合わせると、直接計算が難しい場を求められます。半無限の直線電流の端の磁場（無限長の半分）、一様に帯電した平面の一部がつくる電場なども同じ考え方で求まります。

磁力線が広がる理由

端では磁束密度が半分になるのに、磁力線は途中で消えません。だから磁力線は外へ広がって、間隔が広がります（図の磁力線）。この「広がり」＝軸に垂直な成分 \(B_\perp\) が、II で力を生む主役です。

アニメーションで確かめよう：「右半分だけ／左半分だけ／両方」を切りかえて、軸上の磁場のグラフ（右半分・左半分・合計）を見比べてください。O ではどちらの半分も \(\dfrac12B_{\mathrm O}\) です。
II(1)(2)　端を通過するコイル B の電流と力答 (1) \(I_{\mathrm B} = \dfrac{1}{R}\left|\dfrac{\Delta\Phi}{\Delta t}\right|\)　(2) O 付近だけで負（左向き）の山が1つ（く）

(1) ファラデーの法則とオームの法則

コイル B の自己インダクタンスと抵抗は無視できるので、起電力 \(\left|\dfrac{\Delta\Phi}{\Delta t}\right|\) がそのまま抵抗 \(R\) にかかります。

$$I_{\mathrm B} = \frac{1}{R}\left|\frac{\Delta\Phi}{\Delta t}\right|$$

(2) 電流が流れるのは磁場が変わる場所だけ

一定の速さ \(v_0\) で動くので \(\dfrac{\Delta\Phi}{\Delta t} = v_0\dfrac{\Delta\Phi}{\Delta x}\)。

  • ソレノイドから遠い所（\(x\approx -x_0\)）：磁場ほぼ 0 → 磁束が変わらない → 電流 0、力 0
  • ソレノイドの奥（\(x\approx x_0\)）：磁場は一様 → 磁束が変わらない → 電流 0、力 0
  • 端（O）の付近：磁束が急に増える → 電流が流れ、力がはたらく

力の向きは「いつも運動を妨げる向き」

レンツの法則より、誘導電流は磁束の増加を妨げます。エネルギーで見ると、抵抗でジュール熱 \(RI^2\) が出ている分、コイルを動かす外力が仕事をしなければなりません。つまり磁場からの力は進む向きと逆（\(-x\) 向き）で、O の手前でも奥でも負です。式にすると

$$F\,v_0 = -RI_{\mathrm B}^{\,2} \quad\Longrightarrow\quad F = -\frac{v_0}{R}\left(\frac{\Delta\Phi}{\Delta x}\right)^2$$

\(\dfrac{\Delta\Phi}{\Delta x}\) が最大になるのは磁場の変化が最も急な O の位置なので、グラフは O を中心とする負の山が1つ（く）になります。

力を生むのは広がった磁場

軸方向の磁場 \(B_x\) と円電流から生じる力はコイルの面内（半径方向）で打ち消し合います。軸方向の力を生むのは、端で磁力線が広がってできた軸に垂直な成分 \(B_\perp\) です。アニメーションの青い小矢印がそれです。

アニメーションで確かめよう：コイルが O に近づくと電流（オレンジ）が流れ、赤い力の矢印が左向きに出ます。グラフの \(F\) はずっと 0 以下です。\(v_0\) を2倍にすると \(F\) は2倍、\(b\) を大きくすると急に大きくなります（\(\Phi\propto b^2\) なので \(F\propto b^4\)）。
II(3)　抵抗を R から 2R にすると答 \(\dfrac12\) 倍

考え方を3段に分けます。

  1. 起電力 \(v_0\dfrac{\Delta\Phi}{\Delta x}\) はコイルの動きと磁場だけで決まる → 抵抗を変えても同じ
  2. 電流 \(=\) 起電力 \(\div\) 抵抗 → \(\dfrac12\) 倍
  3. 力 \(=\) 電流 \(\times\) その場所の磁場（\(B_\perp\)）。磁場はソレノイドがつくるもので変わらない → 力も \(\dfrac12\) 倍

式 \(F = -\dfrac{v_0}{R}\left(\dfrac{\Delta\Phi}{\Delta x}\right)^2\) からも、\(F \propto \dfrac{1}{R}\) がすぐ分かります。電磁ブレーキは抵抗が小さいほど強く効くということです（抵抗 0 の超伝導リングなら非常に強い反発になります）。

アニメーションで確かめよう：点線は抵抗 \(R\)（1 Ω）のときのグラフ、実線がいまの抵抗です。\(R\) を 2 Ω にすると、山の深さがちょうど半分になります。
II(4)　ソレノイドの電流を逆にしたとき、同じ力になる素子答 1, 5, 7

磁場を逆にすると何が逆になるか

ソレノイドの電流を逆にすると、磁場が逆 → 磁束の変化が逆 → 起電力が逆。力は「電流 × 磁場」なので、磁場が逆でも電流も逆で大きさが同じなら、力は元と全く同じになります。

II(2) では素子に X→Y の向きに電流が流れていました。逆にすると起電力は Y→X 向き。したがって、Y→X 向きの電流に対して、ただの抵抗 \(R\) と同じにふるまう素子を選べばよいのです。

ダイオード＝向きで決まるスイッチ

理想的なダイオードは、順方向なら導線、逆方向なら切れた導線と同じです。電流の向きを決めてから、各素子の「生きている枝」だけを残して考えます（Y→X 向きの電流）。

  • 1 R：そのまま抵抗 → 同じ
  • 2 R とコンデンサーの直列：電荷がたまると電流が減る → ちがう
  • 3 R∥C：コンデンサーにも充電電流が流れる → ちがう
  • 4 R＋D↓：Y→X は通さない → 電流 0 → ちがう
  • 5 R＋D↑：Y→X を通す → 抵抗だけと同じ
  • 6 R∥(C＋D↑)：C の枝も通る → ちがう
  • 7 R∥(C＋D↓)：C の枝は切れている → 抵抗だけと同じ
  • 8, 9：C が X–Y に直接つながっている → ちがう

答は 1, 5, 7。回路の問題でダイオードが出てきたら、まず電流（電位）の向きを決め、オン／オフを決めてから回路を描き直すのが定石です。

アニメーションで確かめよう：素子を切りかえると、F のグラフ（実線）と II(2) の結果（点線）が重なるかどうかと「同じ／ちがう」の判定が出ます。C を大きくすると、コンデンサーの影響がよりはっきり見えます。
III　円形コイル C を通過するとき答 O の手前と奥に負の山が2つ（O では 0）

磁束は「増えてから減る」

円形コイル C の軸上の磁場は O で最大、離れると両側で小さくなります（軸上では \(B\propto \dfrac{1}{(r^2+x^2)^{3/2}}\)、\(r\) は C の半径）。コイル B を貫く磁束 \(\Phi\) も O で最大の山形です。

  • O の手前：磁束が増える → 電流が流れる → 近づくのを妨げる＝反発（左向き）
  • O の位置：磁束が最大で一瞬変化しない → 電流 0、力 0
  • O の奥：磁束が減る → 電流が逆向き → 離れるのを妨げる＝引きもどす（左向き）

どちらも左向きなので、グラフは O で 0 になる負の山が2つ。電流の向きは O の前後で逆になりますが、\(B_\perp\) の向きも O の前後で逆（O の手前では外向き、奥では内向き）なので、力の向きは同じになります。

II との違いを一般化すると

どちらも \(F = -\dfrac{v_0}{R}\left(\dfrac{\Delta\Phi}{\Delta x}\right)^2\) で、力は磁束の傾きの2乗で決まります。

  • ソレノイド：\(\Phi\) は単調に増える（坂が1つ）→ 負の山1つ
  • 円形コイル：\(\Phi\) は山形（上り坂と下り坂）→ 負の山2つ、頂上で 0

磁石がリングを通り抜ける問題、磁石をアルミ管に落とす問題なども、この「\(\Phi(x)\) のグラフの傾き」で同じように考えられます。

アニメーションで確かめよう：\(\Phi\) のグラフの頂上で \(I\) と \(F\) が 0 になることを確認しましょう。青い \(B_\perp\) の矢印が O の前後で外向き→内向きに変わります。
