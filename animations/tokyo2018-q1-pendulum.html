台の上の振り子：動かない点 Q と見かけの重力（東京大学 2018年 第1問）

なめらかな床の上の台に振り子をつるすと、小球と台は互いに引き合いながら振動します。水平方向に外力がないので重心は左右に動かず、糸の上に「左右に動かない点 Q」ができます。後半は台を一定の加速度で引き、台から見た見かけの重力で小球の最高点や台を引く力を調べます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。色は図と式で共通です：台（点 P）の速度・加速度（青）、小球の速度・台を引く力 F（赤）、点 Q・重心（オレンジ）、重力（緑）、慣性力（紫）。

I(1)　最下点を通るときの小球の速度答 \(\sqrt{\dfrac{2MgL(1-\cos\theta_0)}{m+M}}\)（右向き）

使える保存則を2つそろえる

台と小球をひとまとめにすると、はたらく外力は重力と床の垂直抗力だけで、どちらも鉛直です。よって水平方向の運動量が保存します。張力は小球と台に逆向きにはたらき、糸は伸び縮みしないので、張力が2物体にする仕事の和は 0 です。よって力学的エネルギーも保存します。

最下点での小球と台の速度の x 成分を \(v_1, V_1\) とします。

運動量保存則（水平方向）

$$m\cfrc{v_1}+M\cacc{V_1}=0$$

力学的エネルギー保存則

$$mgL(1-\cos\theta_0)=\frac12m\cfrc{v_1}^{\,2}+\frac12M\cacc{V_1}^{\,2}$$

1式目の \(V_1=-\dfrac mMv_1\) を2式目に入れると \(\dfrac12mv_1^{\,2}\cdot\dfrac{m+M}{M}=mgL(1-\cos\theta_0)\)。小球は左から右へ動くので \(v_1>0\) です。

$$v_1=\sqrt{\frac{2MgL(1-\cos\theta_0)}{m+M}}$$

別解：相対速度で考える

重心が静止している2物体の運動エネルギーの和は、相対速度 \(v_{\rm r}=v_1-V_1\) を使って \(\dfrac12\cdot\dfrac{mM}{m+M}v_{\rm r}^{\,2}\) と書けます。また重心から見ると、2物体の速さの比は質量の逆比なので \(v_1=\dfrac{M}{m+M}v_{\rm r}\) です。

力学的エネルギー保存則（相対運動の形）

$$mgL(1-\cos\theta_0)=\frac12\cdot\frac{mM}{m+M}\,v_{\rm r}^{\,2}$$

ここから \(v_{\rm r}\) を求めて \(\dfrac{M}{m+M}\) 倍すると、同じ答えになります。2物体の問題で何度も使える形です。

着眼点：M が大きい極限

\(M\to\infty\) で \(v_1\to\sqrt{2gL(1-\cos\theta_0)}\) となり、台を固定した振り子と一致します。台が動けると、位置エネルギーの一部を台の運動エネルギーが受け取るので、小球は遅くなります。

式の立て方：2物体が押し合う問題では、まず「外力がない向き → 運動量保存」「仕事をする力の和が 0 → エネルギー保存」を確かめます。未知数（ここでは \(v_1, V_1\)）の数だけ式を集めれば解けます。
アニメーションで確かめよう：赤（小球）と青（台）の速度の矢印はいつも逆向きで、長さの比は \(M:m\) です。\(M\) を大きくすると台はほとんど動かず、\(v_1\) は台を固定したときの値に近づきます。「いまの値」で、最下点で測った速度と式の値が一致します。
I(2)　糸上の点の速度答 \(\dfrac{\ell v+(L-\ell)V}{L}\)

位置の内分を時間で微分する

糸はまっすぐ張っているので、P から \(\ell\) の点は線分 P–小球を \(\ell:(L-\ell)\) に内分します。x 座標で書くと次のとおりです。

内分点の位置

$$x_\ell=\frac{(L-\ell)\,x_{\rm P}+\ell\,x_{\rm m}}{L}$$

\(\ell\) と \(L\) は時間によらない定数なので、両辺を時間で微分すると、速度も同じ比で内分されます。点 P は台に固定されているので、P の速度は台の速度 \(V\) です。

内分点の速度（位置の式を時間で微分）

$$\cfr{u}=\frac{\ell\,\cfrc{v}+(L-\ell)\,\cacc{V}}{L}$$

別解：P から見た回転

P とともに動く人から見ると、糸の上の点はすべて P のまわりを同じ角速度で回ります。速度の x 成分は P からの距離に比例するので \(u-V=\dfrac{\ell}{L}(v-V)\)。整理すると同じ式です。

式の立て方：伸び縮みしない棒や糸の上の点の速度は、両端の速度を距離の比で内分すれば求まります。「位置の関係式を書いて時間で微分する」と、速度・加速度の関係が機械的に出せます。
アニメーションで確かめよう：ℓ/L を動かすと、オレンジの矢印 \(u\) の先端は、青（P）と赤（小球）の矢印の先端を結ぶ直線の上を動きます。左のグラフは各瞬間の \(u\) を \(\ell\) の関数として描いたもので、いつも直線です。
I(3)　x 方向に動かない点 Q答 \(\ell_0=\dfrac{m}{m+M}L\)

u = 0 と運動量保存を連立する

I(2) の結果で u = 0

$$\ell_0\,\cfrc{v}+(L-\ell_0)\,\cacc{V}=0$$

運動量保存則（水平方向）

$$m\cfrc{v}+M\cacc{V}=0$$

2式目の \(V=-\dfrac mMv\) を1式目に入れ、\(v\) で割ると \(\ell_0-\dfrac mM(L-\ell_0)=0\) です。

$$\ell_0=\frac{m}{m+M}L$$

この値は \(v, V\) によらないので、どの瞬間も同じ点 Q が x 方向に止まっています。

着眼点：Q は「台の質量を P に集めたときの重心」

台の質量 \(M\) が P にあると考えると、P と小球の重心は P から \(\dfrac{m}{m+M}L\) の点で、ちょうど Q です。台は傾かずに水平に動くだけなので、台の本当の重心と P の x 座標の差は一定です。よって x 方向については P に質量を集めて考えてかまいません。水平方向に外力がないので、重心の x 座標は変わりません。

式の立て方：「外力の x 成分が 0 ⇒ 重心の x 座標は一定（はじめ静止なら）」は運動量保存と同じ内容です。動かない点を探す問題では、まず重心を疑います。
アニメーションで確かめよう：Q（オレンジ）を通る鉛直の破線から、Q が左右に動かないことが分かります。Q の軌跡は上下に動くだけで、θ₀ を小さくすると上下の動きもほとんどなくなります。左のグラフの直線は、いつも同じ \(\ell_0\) で 0 を横切ります。
I(4)　θ₀ が小さいときの周期 T₁答 \(T_1=2\pi\sqrt{\dfrac{ML}{(m+M)g}}\)

Q から見ると、長さ L − ℓ₀ の単振り子

θ₀ が小さいと Q は上下にもほとんど動かないので、Q を静止した支点とみなせます。小球は Q からの糸で引かれているので、Q から見た小球は長さ \(L-\ell_0=\dfrac{M}{m+M}L\) の単振り子です。

単振り子の周期

$$T_1=2\pi\sqrt{\frac{\cfr{L-\ell_0}}{g}}=2\pi\sqrt{\frac{ML}{(m+M)g}}$$

別解：運動方程式から直接

台の加速度を \(A\)、糸の傾きを θ（小さい）とします。鉛直方向のつりあいから張力は \(mg\) とみなせます。小球の台に対する水平位置を \(x'=L\theta\) とします。

運動方程式（台・水平方向）

$$M\cacc{A}=mg\theta$$

運動方程式（台から見た小球・水平方向）

$$m\ddot{x}'=-mg\theta\cfic{\,-\,mA}$$

\(A=\dfrac{mg}{M}\theta\)、\(\theta=\dfrac{x'}{L}\) を入れると

$$\ddot{x}'=-\frac{(m+M)g}{ML}\,x'$$

角振動数 \(\omega=\sqrt{\dfrac{(m+M)g}{ML}}\) の単振動なので、同じ \(T_1\) が得られます。

着眼点

\(M\to\infty\) では \(2\pi\sqrt{L/g}\) に戻ります。台が動けると、振り子は短くなったように速く振れます。なお、振幅が大きいと Q は上下に動き、Q から見た小球は正確な円運動ではありません。張力を求めるときに「Q を中心とする円運動の向心方向の式」を使うと誤りになるので注意します。

式の立て方：支点が動く振り子は「動かない点（重心）から見た振り子」に置きかえると、単振り子の公式がそのまま使えます。置きかえが使えないときは、台と小球それぞれの運動方程式を立てて連立します。
アニメーションで確かめよう：Q から小球までの糸（オレンジの太線）が「本当の振り子」です。θ₀ を小さくすると測った周期が \(T_1\) に一致し、θ₀ を大きくすると少し長くなります（大きく振れる振り子と同じ性質）。
II(1)　時刻 t₀ での小球の高さ答 \(h+\dfrac{2a^2L}{a^2+g^2}\)

台から見ると「傾いた重力」の世界

加速度 \(a\) で動く台から見ると、小球には重力 \(mg\)（下向き）に加えて慣性力 \(ma\)（後ろ向き）がはたらきます。どちらも一定なので、合力は一定の大きさ・向きの「見かけの重力」です。

慣性力と重力の合成（見かけの重力）

$$mg'=m\sqrt{g^2+a^2},\qquad \tan\alpha=\frac{\cfic{ma}}{\cgrav{mg}}=\frac ag$$

見かけの重力の向き（鉛直から後ろへ α）が、振り子の見かけの最下点です。

振り子は見かけの最下点について対称に振れる

t = 0 で小球は台に対して静止し、糸は真下を向いています。見かけの最下点から α ずれた位置で止まっているので、ここが振動の一方の端です。反対側の端は見かけの最下点から逆に α、つまり鉛直から \(2\alpha\) の位置です。高さがはじめて最大になる \(t_0\) は、この端に着いた瞬間です。

幾何（長さ L の糸が鉛直から 2α 傾く）

$$H=h+L(1-\cos2\alpha)=h+2L\sin^2\alpha=h+\frac{2a^2L}{a^2+g^2}$$

\(\sin\alpha=\dfrac{a}{\sqrt{a^2+g^2}}\) を使いました。

着眼点：極端な場合で確かめる

\(a\to0\) なら \(H\to h\)（振れない）。逆に \(a\) を非常に大きくすると \(\alpha\to\dfrac\pi2\) で \(H\to h+2L\)（真上まで上がる）となり、どちらも直感と合います。

式の立て方：加速する物体の上の運動は、その物体から見て慣性力 \(-m\vec a\) を加え、重力と合わせた「見かけの重力」で考えます。見かけの重力が一定なら、振り子や放物運動の結果を「傾けて」そのまま使えます。
アニメーションで確かめよう：\(a\) を大きくすると、見かけの鉛直（オレンジの破線）が後ろに倒れ、小球はその反対側の 2α まで振れます。右のグラフで、振れ角が −α の線について対称に動くことが分かります。
II(2)　0 から t₀ までに F がした仕事答 \(\dfrac12(M+m)(at_0)^2+mgL\cdot\dfrac{2a^2}{a^2+g^2}\)

F(t) が分からなくても仕事は求まる

F(t) は (3) で問われるほど複雑なので、\(\int F\,dx\) を直接計算するのは大変です。かわりに床から見た系全体のエネルギーを使います。床はなめらかで、張力の仕事は台と小球で打ち消し合うので、F の仕事がそのまま系の力学的エネルギーの増加になります。

仕事と力学的エネルギーの関係（系全体・床から見る）

$$\cfrc{W}=\cacc{\Delta K}+\cgrav{\Delta U}$$

t₀ では小球は台に対して静止しているので、台も小球も同じ速度 \(at_0\) です（台は等加速度運動）。小球は最下点より \(L(1-\cos2\alpha)\) 高い位置にいます。

運動エネルギーと重力による位置エネルギー

$$\cacc{\Delta K}=\frac12(M+m)(at_0)^2,\qquad \cgrav{\Delta U}=mgL(1-\cos2\alpha)=mgL\cdot\frac{2a^2}{a^2+g^2}$$ $$W=\frac12(M+m)(at_0)^2+mgL\cdot\frac{2a^2}{a^2+g^2}$$
式の立て方：力が時間とともに変わって積分しにくいときは、「仕事 ＝ エネルギーの変化」で始めと終わりの状態だけを見ます。終わりの速度が分かる瞬間（ここでは相対速度 0）を選ぶのがコツです。
アニメーションで確かめよう：グラフの赤い線は ∫F dx を数値計算で積み上げたもので、t₀ で ΔK + ΔU（黒の破線）と一致します。途中では、F の仕事が運動エネルギーと位置エネルギーに分かれていく様子が見えます。

II(4)　力を止めたあとの Q の速度と周期 T₂答 Q の速度 \(at_0\)，\(T_2=2\pi\sqrt{\dfrac{ML}{(m+M)g}}\)

重心は等速直線運動

t ≥ t₀ では水平方向の外力がないので、系の水平方向の運動量が保存し、重心 Q は一定の速度で動きます。t₀ では台も小球も速度 \(at_0\) なので

運動量保存則（水平方向）

$$(M+m)\,\cfr{v_{\rm Q}}=(M+m)\,at_0\qquad\therefore\ v_{\rm Q}=at_0$$

Q とともに動く人から見ると I と同じ

Q の加速度は 0 なので、Q とともに動く座標系には慣性力がはたらきません。この座標系から見た運動は I と同じです。\(a\ll g\) なら振幅 2α も小さく、

単振り子の周期（I(4) と同じ）

$$T_2=T_1=2\pi\sqrt{\frac{ML}{(m+M)g}}$$
式の立て方：外力が消えた瞬間からは「重心は等速」「重心から見ると外力なしの運動」に分けます。等速で動く座標系に乗りかえても運動方程式は変わらないので、前に解いた結果がそのまま使えます。
アニメーションで確かめよう：左のグラフで Q の x–t は t₀ まで放物線、そのあと傾き \(at_0\) の直線です。\(a\) を大きくすると振幅 2α が大きくなり、測った周期が \(T_2\) より長くなります（「a ≪ g」の条件の意味）。
