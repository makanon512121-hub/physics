一輪車の加速と円運動（東京大学 2026年 第1問）

電動一輪車と乗る人を「下端に車輪のついた一様な棒（長さ L、質量 m）」とみなし、路面との静止摩擦力だけで加速したり曲がったりする様子を調べます。上のボタンで設問を選ぶと、その状況になり、下の解説が開きます。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

見る立場

質量は m = 60 kg、g = 9.8 m/s² として数値を出しています（答えの式には m は残りません）。

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。

I　直線で加速できる最大の加速度答 \(\mu g\)

考え方

車輪のモーターが車輪を回すと、車輪は路面を後ろ向きにけります。その反作用として、路面は車輪を前向きに押し返します。これが静止摩擦力 \(f\) で、一輪車を前に加速させる力はこの摩擦力だけです（モーターの力は内力なので、全体を加速させることはできません）。

式

鉛直方向はつり合っているので、垂直抗力は \(N = mg\)。水平方向の運動方程式は

$$ma = f$$

すべらない条件は「静止摩擦力 ≦ 最大静止摩擦力」なので \(f \le \mu N = \mu mg\)。よって

$$a \le \mu g \qquad \therefore\ \text{最大値は } \mu g$$
アニメーションで確かめよう：加速度 \(a\) を大きくしていくと、左上のゲージ（必要な摩擦力 ÷ 最大静止摩擦力）が 100% に近づきます。\(a > \mu g\) にすると車輪が空回りして、その加速度は出せません。\(\mu\) を変えると限界の位置が動くことも確認しましょう。

参考：加速中は前に傾かないと倒れる

「棒といっしょに」見ると、重心に後ろ向きの慣性力 \(ma\) がはたらきます。重力と慣性力の合力が車輪の接点を通らないと棒は回転してしまうので、棒は水平面から \(\tan\theta = \dfrac{g}{a}\) となる角 \(\theta\) だけ前に傾きます。この考え方が II で活躍します。

II(1)　水平面で円運動するときの傾き答 \(\tan\theta = \dfrac{gR}{v_0^2}\)

なぜ「棒といっしょに」見るのか

棒が傾いたまま一定の姿勢を保っているので、棒から見れば棒は静止しています。静止して見える立場なら、力のつり合いと力のモーメントのつり合いがそのまま使えます。その代わり、重心に慣性力（遠心力） \(m\dfrac{v_0^2}{R}\) を外向きに加えます。

力のモーメントのつり合い

棒にはたらく力は ① 重力 \(mg\)（重心）② 慣性力（重心）③ 垂直抗力 \(N\)（接点）④ 静止摩擦力 \(f\)（接点）です。接点のまわりで考えると ③④ のモーメントは 0 なので、① と ② の合力が接点を通ること、つまり合力の向きが棒の向きと一致することが条件になります。

$$\tan\theta = \frac{mg}{m\dfrac{v_0^2}{R}} = \frac{gR}{v_0^2}$$

接点まわりのモーメントを直接書いても同じ結果です。

$$mg\cdot\frac{L}{2}\cos\theta = m\frac{v_0^2}{R}\cdot\frac{L}{2}\sin\theta$$
アニメーションで確かめよう：右の図の点線（重力と慣性力の合力）が、いつも棒に沿って接点に向かっています。\(v_0\) を大きくすると慣性力が増え、棒はより深く内側に傾きます（\(\theta\) が小さくなる）。\(L\) や \(m\) には関係しません。
II(2)　すべらずに回れる最大の速さ答 \(v_1 = \sqrt{\mu g R}\)

考え方

水平面上の円運動で、中心向きの力（向心力）になれる水平な力は静止摩擦力だけです。したがって

$$f = m\frac{v_0^2}{R}, \qquad N = mg$$

すべらない条件 \(f \le \mu N\) より \(v_0^2 \le \mu g R\)。よって最大値は

$$v_1 = \sqrt{\mu g R}$$
アニメーションで確かめよう：接点の摩擦力の矢印と、点線の目盛り（最大静止摩擦力 \(\mu N\)）を比べてください。\(v_0\) を \(v_1\) より大きくすると、上から見た図で一輪車が外側へすべり出ていきます。半径 \(R\) を大きくすると \(v_1\) も大きくなります。
II(3)　円運動しながら加速するときの摩擦力答 \(m\sqrt{a^2 + \dfrac{v_0^4}{R^2}}\)

加速度を2つの向きに分ける

速さを変えながら円運動するとき、加速度は接線方向（速さを変える）の \(a\) と、中心方向（向きを変える）の \(\dfrac{v_0^2}{R}\) の2つに分けられます。この2つの向きは直交しています。

どちらも摩擦力がまかなう

水平な力は静止摩擦力だけなので、摩擦力の接線成分 \(f_1\) と中心向き成分 \(f_2\) は

$$f_1 = ma, \qquad f_2 = m\frac{v_0^2}{R}$$

大きさは三平方の定理で

$$f = \sqrt{f_1^2 + f_2^2} = m\sqrt{a^2 + \frac{v_0^4}{R^2}}$$
アニメーションで確かめよう：上から見た図の右下に「摩擦円」を出しています。円の半径が最大静止摩擦力 \(\mu mg\)、矢印が実際の摩擦力です。\(a\) を増やすと矢印が横（接線方向）に伸びます。
II(4)　すべらずに加速できる \(a\) の最大値答 \(\sqrt{\mu^2 g^2 - \dfrac{v_0^4}{R^2}}\)

(3) の摩擦力が最大静止摩擦力 \(\mu mg\) に達するときが限界です。

$$m\sqrt{a^2 + \frac{v_0^4}{R^2}} \le \mu mg$$ $$\therefore\quad a \le \sqrt{\mu^2 g^2 - \frac{v_0^4}{R^2}}$$

意味（摩擦円）

摩擦力のベクトルの先端は、半径 \(\mu mg\) の円の内側にしか置けません。曲がるために中心向きの成分をすでに使っているので、加速（またはブレーキ）に使える余裕は直線のとき（I の \(\mu g\)）より小さくなります。\(v_0 \to v_1\) では余裕が 0 になり、少しも加速できません。「カーブの途中で急加速・急ブレーキをするとすべりやすい」理由です。

アニメーションで確かめよう：\(a\) を少しずつ上げ、摩擦円の矢印が円からはみ出す所が限界です。\(v_0\) を大きくしてから同じことをすると、限界の \(a\) が小さくなります。
III(1)　すりばち状の路面での傾き答 \(\tan\theta = \dfrac{gR}{v_0^2}\)（\(\varphi\) によらない）

棒といっしょに見ると、重心にはたらく重力 \(mg\) と慣性力 \(m\dfrac{v_0^2}{R}\) は、路面が傾いていても II とまったく同じです。垂直抗力と摩擦力は接点にはたらくので、接点まわりのモーメントは 0。したがって条件も II(1) と同じで

$$\tan\theta = \frac{gR}{v_0^2}$$

ポイントは、棒の傾きは路面に対してではなく水平面に対して決まるということです。

アニメーションで確かめよう：傾斜角 \(\varphi\) を変えても、棒と水平面のなす角 \(\theta\) は変わりません。
III(2)　すりばちで回れる最大の速さ答 \(v_2 = \sqrt{\dfrac{\mu + \tan\varphi}{1 - \mu\tan\varphi}\,gR}\)

力の向き

垂直抗力 \(N\) は路面に垂直（斜め上、中心寄り）、摩擦力 \(f\) は路面に沿う向きです。速いときは外へすべり出そうとするので、摩擦力は斜面に沿って下向き（中心寄り）になります。

水平・鉛直に分けてつり合いを書く（棒といっしょに見る）

$$\begin{aligned}\text{水平：}\ & N\sin\varphi + f\cos\varphi = m\frac{v^2}{R}\\ \text{鉛直：}\ & N\cos\varphi - f\sin\varphi = mg\end{aligned}$$

限界では \(f = \mu N\)。2式の比をとると \(N\) が消えて

$$\frac{v_2^2}{gR} = \frac{\sin\varphi + \mu\cos\varphi}{\cos\varphi - \mu\sin\varphi} = \frac{\tan\varphi + \mu}{1 - \mu\tan\varphi}$$ $$\therefore\quad v_2 = \sqrt{\frac{\mu + \tan\varphi}{1 - \mu\tan\varphi}\,gR}$$

（解答例のように斜面に垂直・平行に分けても同じ結果になります。）条件 \(\tan\varphi < \dfrac{1}{\mu}\) は分母を正にするためのもので、これを超える急な傾斜だと理論上どんなに速くてもすべりません。

アニメーションで確かめよう：接点の摩擦力の矢印と点線の目盛り（\(\mu N\)）を比べます。\(v\) が \(v_2\) を超えると外にすべり出します。逆に、傾斜が急で \(v\) が小さすぎると摩擦力は斜面上向きになり、内側（下）にすべり落ちることもあります（最小の速さも表示しています）。
III(3)　外側を高くする理由答 同じ半径でも \(v_2 > v_1\)

II(2) と III(2) を同じ \(R,\ \mu\) で比べると、\(\varphi > 0\) のとき分子は大きく、分母は小さくなるので \(v_2 > v_1\) です。つまり外側を高くした路面のほうが、同じ半径のカーブをすべらずにより速く回れる。これが高速道路のカーブや競輪のバンクに傾斜がある理由です。

なぜ速く回れるのか

① 垂直抗力が斜めに傾くので、その水平成分が向心力の一部を受けもつ。② 垂直抗力そのものが大きくなり、最大静止摩擦力 \(\mu N\) も大きくなる。この2つの効果です。

とくに \(v = \sqrt{gR\tan\varphi}\) のときは摩擦力が 0 でも回れます（道路の「設計速度」の考え方）。

アニメーションで確かめよう：このボタンでは、上の図の下に \(v_1\)（水平）と \(v_2\)（傾斜）の棒グラフを並べています。\(\varphi\) を 0 にすると2つが一致し、\(\varphi\) を大きくすると \(v_2\) が伸びます。
