一輪車の加速と円運動（東京大学 2026年 第1問）

電動一輪車と乗る人を「下端に車輪のついた一様な棒（長さ L、質量 m）」とみなし、路面との静止摩擦力だけで加速したり曲がったりする様子を調べます。上のボタンで設問を選ぶと、その状況になり、下の解説が開きます。

設定

見る立場

質量は m = 60 kg、g = 9.8 m/s² として数値を出しています（答えの式には m は残りません）。

いまの値

解答解説

見出しを押すと開きます。「方針」と「解答」で式の流れをつかみ、くわしい説明は下の「式の立て方」「補足」で確かめてください。「この状況にする」で上のアニメーションがその設問の設定になります。

I　直線で加速できる最大の加速度答 \(\mu g\)

方針一輪車を前に押す外力は路面からの静止摩擦力だけ。運動方程式と「摩擦力 ≦ 最大静止摩擦力」を組み合わせる。

解答

運動方程式（水平）・力のつり合い（鉛直）

$$ma = f, \qquad N = mg$$

すべらない条件

$$f \le \mu N \qquad\therefore\quad a \le \mu g$$

よって最大の加速度は \(\mu g\)。

式の立て方：運動方程式の右辺には外から一輪車にはたらく力だけを書きます。モーターが車輪を回す力は一輪車の内部どうしの力（内力）なので、全体の加速には直接入りません。車輪が路面を後ろへけると、その反作用で路面が車輪を前向きに押します。これが静止摩擦力 \(f\) で、加速の原因になる水平な外力はこれしかありません。だから \(ma = f\) と書けます。あとは「静止摩擦力は \(\mu N\) を超えられない」という条件を、鉛直のつり合いから出した \(N = mg\) と組み合わせるだけです。
補足：加速中は棒が前に傾かないと倒れてしまいます。棒といっしょに加速する立場で見ると、重心に後ろ向きの慣性力 \(ma\) がはたらきます。重力 \(mg\) と慣性力 \(ma\) の合力が接点を通らないと、接点のまわりに回転してしまうので、棒は水平面から $$\tan\theta = \frac{g}{a}$$ となる角 \(\theta\) だけ前に傾きます。「重心にはたらく力の合力が接点を通る」というこの見方が、II・III の傾きの問題でそのまま使えます。
アニメーションで確かめよう：加速度 \(a\) を大きくしていくと、左上のゲージ（必要な摩擦力 ÷ 最大静止摩擦力）が 100% に近づきます。\(a > \mu g\) にすると車輪が空回りして、その加速度は出せません。\(\mu\) を変えると限界の位置が動くことも確認しましょう。
II(1)　水平面で円運動するときの傾き答 \(\tan\theta = \dfrac{gR}{v_0^2}\)

方針棒といっしょに回る立場で見ると棒は静止している。重心に遠心力を加え、接点のまわりの力のモーメントのつり合いを書く。

解答

力のモーメントのつり合い（接点のまわり、棒といっしょに回る立場）

$$mg\cdot\frac{L}{2}\cos\theta = m\frac{v_0^2}{R}\cdot\frac{L}{2}\sin\theta \qquad\therefore\quad \tan\theta = \frac{gR}{v_0^2}$$
式の立て方：棒は傾いたまま一定の姿勢で回っているので、棒から見れば棒は止まって見えます。止まって見える立場なら、力のつり合いと力のモーメントのつり合いがそのまま使えます。そのかわり重心に慣性力（遠心力）\(m\dfrac{v_0^2}{R}\) を外向きに加えます。
棒にはたらく力は ① 重力 \(mg\)（重心）② 遠心力（重心）③ 垂直抗力 \(N\)（接点）④ 静止摩擦力 \(f\)（接点）の4つです。未知の力 ③④ が集まる接点をモーメントの中心に選ぶと、③④ の腕の長さが 0 になって式から消え、①② だけの式になります。腕の長さは、重力（鉛直）に対しては重心の水平距離 \(\dfrac{L}{2}\cos\theta\)、遠心力（水平）に対しては重心の高さ \(\dfrac{L}{2}\sin\theta\) です。
補足：この式は「① と ② の合力が接点を通る」、つまり合力の向きが棒の向きと一致することと同じ意味です。合力の水平成分と鉛直成分の比が棒の傾きになるので $$\tan\theta = \frac{mg}{m\dfrac{v_0^2}{R}}$$ と一気に書くこともできます。結果に \(L\) や \(m\) は入りません。速く回るほど遠心力が大きくなり、棒はより深く内側に傾きます（\(\theta\) が小さくなる）。自転車でカーブを曲がるときに体を内側に倒すのも同じ理由です。
アニメーションで確かめよう：右の図の点線（重力と慣性力の合力）が、いつも棒に沿って接点に向かっています。\(v_0\) を大きくすると慣性力が増え、棒はより深く内側に傾きます（\(\theta\) が小さくなる）。\(L\) や \(m\) には関係しません。
II(2)　すべらずに回れる最大の速さ答 \(v_1 = \sqrt{\mu g R}\)

方針向心力をまかなう水平な外力は静止摩擦力だけ。円運動の運動方程式に「摩擦力 ≦ 最大静止摩擦力」を合わせる。

解答

円運動の運動方程式（中心方向）・力のつり合い（鉛直）

$$m\frac{v_0^2}{R} = f, \qquad N = mg$$

すべらない条件

$$f \le \mu N \quad\Rightarrow\quad v_0^2 \le \mu gR \qquad\therefore\quad v_1 = \sqrt{\mu gR}$$
式の立て方：円運動の運動方程式は「質量 × 向心加速度 \(\dfrac{v^2}{R}\) ＝ 中心向きの外力の合計」です。水平面の上では、重力も垂直抗力も鉛直なので中心向きの成分をもちません。中心向きの外力になれるのは接点の静止摩擦力だけなので、右辺は \(f\) だけになります。（II(1) の「棒といっしょに回る立場」で遠心力とのつり合いとして書いても同じ式です。）
補足：結果は \(m\) にも \(L\) にもよらず、\(\mu\) と \(R\) だけで決まります。半径が大きいゆるいカーブほど速く回れ、路面がぬれて \(\mu\) が小さいと限界の速さが下がります。\(v_0\) が \(v_1\) を超えると摩擦力が向心力をまかないきれず、一輪車は円の外側へすべり出します。
アニメーションで確かめよう：接点の摩擦力の矢印と、点線の目盛り（最大静止摩擦力 \(\mu N\)）を比べてください。\(v_0\) を \(v_1\) より大きくすると、上から見た図で一輪車が外側へすべり出ていきます。半径 \(R\) を大きくすると \(v_1\) も大きくなります。
II(3)　円運動しながら加速するときの摩擦力答 \(m\sqrt{a^2 + \dfrac{v_0^4}{R^2}}\)

方針加速度を接線方向 \(a\) と中心方向 \(\dfrac{v_0^2}{R}\) に分け、それぞれを摩擦力の成分がまかなう。

解答

運動方程式（接線方向・中心方向）

$$f_1 = ma, \qquad f_2 = m\frac{v_0^2}{R}$$

直交する成分の合成（三平方の定理）

$$f = \sqrt{f_1^{\,2} + f_2^{\,2}} \qquad\therefore\quad f = m\sqrt{a^2 + \frac{v_0^4}{R^2}}$$
式の立て方：速さを変えながら円運動するときの加速度は、接線方向（速さを変える）の \(a\) と、中心方向（向きを変える）の \(\dfrac{v_0^2}{R}\) の2つに分けられ、この2つは直交しています。運動方程式は方向ごとに立てられるので、接線方向・中心方向それぞれに「質量 × 加速度 ＝ その方向の外力」を書きます。どちらの方向も、水平な外力は静止摩擦力しかないので、右辺は摩擦力の成分 \(f_1,\ f_2\) になります。
補足：\(f_1\) と \(f_2\) は直交しているので、摩擦力の大きさは単純な和 \(f_1 + f_2\) ではなく三平方の定理で求めます。摩擦力の向きは進行方向より少し内側を向いていて、\(a\) を大きくするほど前向きに、\(v_0\) を大きくするほど内向きに傾きます。
アニメーションで確かめよう：上から見た図の右下に「摩擦円」を出しています。円の半径が最大静止摩擦力 \(\mu mg\)、矢印が実際の摩擦力です。\(a\) を増やすと矢印が横（接線方向）に伸びます。
II(4)　すべらずに加速できる \(a\) の最大値答 \(\sqrt{\mu^2 g^2 - \dfrac{v_0^4}{R^2}}\)

方針(3) の摩擦力が最大静止摩擦力 \(\mu mg\) を超えない条件を書く。

解答

すべらない条件（\(N = mg\)）

$$m\sqrt{a^2 + \frac{v_0^4}{R^2}} \le \mu mg \qquad\therefore\quad a \le \sqrt{\mu^2 g^2 - \frac{v_0^4}{R^2}}$$
式の立て方：静止摩擦力の条件 \(f \le \mu N\) の \(f\) は、成分ではなく摩擦力ベクトル全体の大きさです。接線方向だけ、中心方向だけで別々に \(\mu N\) と比べるのではなく、(3) で合成した大きさを \(\mu mg\) と比べます。両辺を2乗して \(a^2\) について解けば答えが出ます。
補足：摩擦力ベクトルの先端は、半径 \(\mu mg\) の円（摩擦円）の内側にしか置けません。カーブでは向心力のために中心向きの成分をすでに使っているので、加速（やブレーキ）に回せる余裕は、直線のとき（I の \(\mu g\)）より小さくなります。\(v_0 = 0\) とおくと I の答え \(\mu g\) に戻り、\(v_0 \to v_1 = \sqrt{\mu gR}\) では根号の中が 0 になって少しも加速できません。「カーブの途中で急加速・急ブレーキをするとすべりやすい」理由がこの式に表れています。
アニメーションで確かめよう：\(a\) を少しずつ上げ、摩擦円の矢印が円からはみ出す所が限界です。\(v_0\) を大きくしてから同じことをすると、限界の \(a\) が小さくなります。
III(1)　すりばち状の路面での傾き答 \(\tan\theta = \dfrac{gR}{v_0^2}\)（\(\varphi\) によらない）

方針II(1) と同じく接点のまわりのモーメントを考える。路面からの力はすべて接点にはたらくので、路面の傾きは式に入らない。

解答

力のモーメントのつり合い（接点のまわり、棒といっしょに回る立場）

$$mg\cdot\frac{L}{2}\cos\theta = m\frac{v_0^2}{R}\cdot\frac{L}{2}\sin\theta \qquad\therefore\quad \tan\theta = \frac{gR}{v_0^2}$$
式の立て方：路面が傾いても変わるのは垂直抗力と摩擦力の向きだけで、どちらも接点にはたらくことは同じです。接点のまわりではこの2力のモーメントは 0 なので、残るのは重心にはたらく重力 \(mg\) と遠心力 \(m\dfrac{v_0^2}{R}\) だけ。これは II(1) とまったく同じ2力なので、同じ式になります。
補足：棒の傾き \(\theta\) は路面に対してではなく水平面に対して決まります。決めているのは重心にはたらく「重力＋遠心力」の向きで、路面の形には関係しないからです。路面の傾き \(\varphi\) が効いてくるのは、次の (2) のように「すべるかどうか」を考えるときです。
アニメーションで確かめよう：傾斜角 \(\varphi\) を変えても、棒と水平面のなす角 \(\theta\) は変わりません。
III(2)　すりばちで回れる最大の速さ答 \(v_2 = \sqrt{\dfrac{\mu + \tan\varphi}{1 - \mu\tan\varphi}\,gR}\)

方針限界の速さでは外へすべり出そうとするので、摩擦力は斜面に沿って下向き（中心寄り）で \(f = \mu N\)。水平・鉛直の2式から \(N\) を消す。

解答

円運動の運動方程式（水平）・力のつり合い（鉛直）

$$\begin{aligned}N\sin\varphi + f\cos\varphi &= m\frac{v^2}{R}\\ N\cos\varphi - f\sin\varphi &= mg\end{aligned}$$

すべり出す直前（\(f = \mu N\)）、2式の比をとる

$$\frac{v_2^{\,2}}{gR} = \frac{\sin\varphi + \mu\cos\varphi}{\cos\varphi - \mu\sin\varphi} = \frac{\mu + \tan\varphi}{1 - \mu\tan\varphi} \qquad\therefore\quad v_2 = \sqrt{\frac{\mu + \tan\varphi}{1 - \mu\tan\varphi}\,gR}$$
式の立て方：まず力の向きを決めます。垂直抗力 \(N\) は路面に垂直（斜め上、中心寄り）、摩擦力 \(f\) は路面に沿う向きです。速すぎると外へすべり出そうとするので、摩擦力はそれを止める向き、つまり斜面に沿って下向き（中心寄り）になります。
次に分ける方向を選びます。加速度は水平に中心を向く \(\dfrac{v^2}{R}\) だけで、鉛直方向の加速度は 0 です。そこで水平・鉛直に分けると、水平は円運動の運動方程式、鉛直はつり合いと、それぞれすっきり書けます。\(N\) と \(f\) は斜めなので、\(\sin\varphi,\ \cos\varphi\) で成分に分けます。最後に \(f = \mu N\) を入れて比をとると \(N\) が消えます。
補足：斜面に平行・垂直に分けても同じ結果になります。その場合は加速度 \(\dfrac{v^2}{R}\) のほうを斜面方向と垂直方向に分けることになり、式が少しだけ複雑になります。
条件 \(\tan\varphi \lt \dfrac{1}{\mu}\) は分母を正にするためのものです。これより急な傾斜では、理論上どんなに速くても外へはすべり出しません。また \(\varphi = 0\) とおくと II(2) の \(v_1 = \sqrt{\mu gR}\) に戻ることも確かめておきましょう。
逆に、傾斜が急で速さが小さすぎると内側（下）へすべり落ちそうになり、摩擦力は斜面に沿って上向きになります。このときの限界は上の式で \(\mu\) を \(-\mu\) に置きかえた \(\sqrt{\dfrac{\tan\varphi - \mu}{1 + \mu\tan\varphi}\,gR}\) です。
アニメーションで確かめよう：接点の摩擦力の矢印と点線の目盛り（\(\mu N\)）を比べます。\(v\) が \(v_2\) を超えると外にすべり出します。逆に、傾斜が急で \(v\) が小さすぎると摩擦力は斜面上向きになり、内側（下）にすべり落ちることもあります（最小の速さも表示しています）。
III(3)　外側を高くする理由答 同じ半径でも \(v_2 > v_1\)

方針II(2) と III(2) の答えを同じ \(R,\ \mu\) で比べる。

解答

II(2)・III(2) の結果の比較（\(\varphi > 0\)）

$$\frac{v_2^{\,2}}{v_1^{\,2}} = \frac{\mu + \tan\varphi}{\mu\,(1 - \mu\tan\varphi)} > 1 \qquad\therefore\quad v_2 > v_1$$

外側を高くした路面のほうが、同じ半径のカーブをすべらずに速く回れる。

式の立て方：\(\varphi > 0\) なら分子 \(\mu + \tan\varphi\) は \(\mu\) より大きく、分母 \(1 - \mu\tan\varphi\) は 1 より小さいので、比は 1 より大きくなります。式を比べるときは、このように「分子は増え、分母は減る」と一つずつ見ていくと確実です。
補足：速く回れる理由は2つあります。① 垂直抗力が中心側に傾くので、その水平成分が向心力の一部を受けもつ。② 鉛直のつり合いを保つために垂直抗力そのものが大きくなり、最大静止摩擦力 \(\mu N\) も大きくなる。
とくに \(v = \sqrt{gR\tan\varphi}\) のときは、垂直抗力の水平成分だけで向心力がまかなえるので、摩擦力が 0 でも回れます（III(2) の式で \(f = 0\) とおくと得られます）。高速道路のカーブや競輪場のバンクに傾斜がつけてあるのはこのためで、道路の「設計速度」もこの考え方で決められています。
アニメーションで確かめよう：このボタンでは、上の図の下に \(v_1\)（水平）と \(v_2\)（傾斜）の棒グラフを並べています。\(\varphi\) を 0 にすると2つが一致し、\(\varphi\) を大きくすると \(v_2\) が伸びます。
