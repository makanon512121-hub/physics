3つの容器と気体：液面の高さで圧力とエネルギーを読む（東京大学 2018年 第3問）

管でつながった3つの容器のうち、A の上は真空、B の上には気体、C の上は大気です。液体の圧力は液面の高さの差だけで決まるので、液面を見れば気体の圧力が分かります。B の気体を温めると液体が押し上げられますが、気体がした仕事は液体の位置エネルギーだけでなく大気を押し上げる仕事にも使われます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。色は図と式で共通です：容器 A・液面の移動（青）、容器 B の気体（紫）、大気・外気圧 p₀（オレンジ）、液体の圧力 ρg×高さ・位置エネルギー（緑）、熱・気体がした仕事（赤）。

I　はじめの気体の圧力 p₁答 \(p_1=\dfrac35p_0\)

同じ液体でつながっていれば、同じ高さは同じ圧力

3つの容器の液体は管でつながっています。静止した液体の中では、同じ高さの点の圧力は等しくなります。そこで、いちばん低い容器 C の液面の高さで、3つの容器の圧力を比べます。

液体中の圧力（液面の上の圧力 ＋ ρg × 深さ）

$$\underbrace{0+\cgrav{\rho g\cdot5h}}_{\text{A（上は真空）}}=\underbrace{\cfic{p_1}+\cgrav{\rho g\cdot2h}}_{\text{B}}=\underbrace{\cfr{p_0}}_{\text{C（大気）}}$$

1つ目と3つ目から \(\rho gh=\dfrac{p_0}{5}\)。これを2つ目に入れると

$$p_1=p_0-2\rho gh=\frac35p_0$$

着眼点：容器 A は気圧計

A の上は真空なので、A と C の液面の差 \(5h\) は「大気圧を支える液柱の高さ」です（トリチェリの実験と同じ）。\(\rho gh=\dfrac{p_0}{5}\) は、このあとのすべての計算で使う「ものさし」になります。

式の立て方：液体の圧力は、基準の高さを1つ決め、各容器でその高さの圧力を「液面の上の圧力 ＋ ρg × 深さ」で書いて等しいとおきます。基準をいちばん低い液面にすると、どの容器も足し算だけで書けます。
アニメーションで確かめよう：下のグラフは各容器の圧力を高さごとに描いたものです。液体の部分では3本の線が同じ直線に重なり、液面より上では A は 0、B は \(p_1\)、C は \(p_0\) の一定値です。
II(1)　B の液面が x 下がったときの A・C の液面答 A・C とも上向きに \(\dfrac x2\)

A と C の液面の上昇をそれぞれ \(a,\ c\) とします。液体の体積は変わらず、断面積はすべて \(S\) なので

液体の体積保存

$$\cacc{a}+\cacc{c}=x$$

A の上は真空、C の上は大気圧 \(p_0\) のままです。I と同じく C の液面の高さで A と C の圧力を比べると、A と C の液面の差は \(\dfrac{p_0}{\rho g}=5h\) から変わりません。

液体中の圧力（A と C）

$$\rho g\,(5h+\cacc{a}-\cacc{c})=\cfr{p_0}=\rho g\cdot5h\qquad\therefore\ a=c$$ $$a=c=\frac x2$$

着眼点

A と C だけを見ると「大気圧を測る気圧計」なので、差 \(5h\) は B の状態によりません。B の気体は、A と C の液面を同じだけ押し上げることしかできません。この関係は \(x\) が小さくなくても成り立つので、III でも使えます。

式の立て方：連結した容器の液面の動きは「体積保存（移動量の和）」と「圧力の関係（液面の差）」の2本で決まります。
アニメーションで確かめよう：B の液面が \(x\) 下がる間、A と C の液面は同じ速さで \(x/2\) ずつ上がり、A と C の差はいつも \(5h\) です。
II(2)　体積と圧力の変化率答 \(\dfrac{\Delta V}{V_1}=\dfrac{x}{4h}\)，\(\dfrac{\Delta p}{p_1}=\dfrac{x}{2h}\)

体積 ＝ 断面積 × 長さ

$$\frac{\Delta V}{V_1}=\frac{Sx}{S\cdot4h}=\frac{x}{4h}$$

B の気体の圧力は、真空の A との液面の差で読むのが簡単です。A の液面は \(x/2\) 上がり、B の液面は \(x\) 下がるので、差は \(3h\) から \(3h+\dfrac32x\) になります。

液体中の圧力（A と B：A の上は真空）

$$\cfic{p}=\cgrav{\rho g\times(\text{A と B の液面の差})}$$ $$p_1=\rho g\cdot3h,\qquad p_1+\Delta p=\rho g\Bigl(3h+\frac32x\Bigr)\qquad\therefore\ \frac{\Delta p}{p_1}=\frac{x}{2h}$$

どちらも \(x\) に比例する式で、近似をしていない正確な値です。圧力は体積の1次関数なので、p–V 図は直線になります。

式の立て方：真空の容器があるときは、気体の圧力を「真空側の液面との高さの差 × ρg」で読みます。大気側（C）から読んでも同じ結果ですが、項が1つ増えます。
アニメーションで確かめよう：右のグラフで、圧力の変化率は体積の変化率のちょうど2倍です。左の p–V 図は直線になっています。
II(3)　B の気体がした仕事 W答 \(W=\dfrac35p_0Sx\)

気体がする仕事（圧力一定とみなす）

$$\cfrc{W}=p_1\,\Delta V=p_1Sx=\frac35p_0Sx$$

参考：正確に計算すると

圧力は \(p_1\) から \(p_1+\Delta p\) まで体積とともに直線的に増えるので、仕事は p–V 図の台形の面積です。

仕事 ＝ p–V 図の面積

$$W=\Bigl(p_1+\frac{\Delta p}2\Bigr)Sx=\frac35p_0Sx+\frac{3}{20}\,\frac{x}{h}\,p_0Sx$$

2項目が「\(x^2\) に比例する項」で、\(x\ll h\) なら無視できます。

式の立て方：気体の仕事はいつでも「p–V 図の面積」です。圧力がほとんど変わらないときは長方形 \(p\Delta V\)、直線的に変わるときは台形で求めます。
アニメーションで確かめよう：\(x/h\) を大きくすると、台形（正確な値）と長方形（近似）の差が \(x^2\) に比例して広がります。
II(4)　液体の位置エネルギーの変化 ΔE答 \(\Delta E=\dfrac1{10}p_0Sx\)

「どこからどこへ移ったか」だけを見る

液体全体の動きを追うかわりに、B の液面のすぐ下にあった厚さ \(x\) の層が、半分ずつ A と C の液面の上に移ったと考えます。ほかの部分は前と同じ形なので、位置エネルギーの差に効きません。高さは C の液面を基準にします（A の液面は \(5h\)、B は \(2h\)、C は 0）。

重力による位置エネルギー（質量 × g × 高さ）

$$\cgrav{\Delta E}=\frac{\rho Sx}{2}g\cdot5h+\frac{\rho Sx}{2}g\cdot0-\rho Sx\,g\cdot2h=\frac12\rho Sgxh=\frac1{10}p_0Sx$$

最後に \(\rho gh=\dfrac{p_0}5\) を使いました。

参考：重心まで考えると

移る層の重心まで正確に考えると \(\Delta E=\dfrac12\rho Sgxh+\dfrac34\rho Sgx^2\) となり、2項目が無視した \(x^2\) の項です。

式の立て方：液体の位置エネルギーの変化は「抜けた部分」と「増えた部分」だけで計算します。重さ \(\rho S\times\)厚さ\(\times g\) と、移る前後の高さの差をかけるだけです。
アニメーションで確かめよう：図の赤い層（B から抜けた部分）が、青い層（A と C に増えた部分）に移ります。高さ \(2h\) の層が、半分は \(5h\)、半分は 0 に移るので、平均すると \(\dfrac{5h+0}2-2h=\dfrac h2\) だけ持ち上がったことになります。
II(5)　W と ΔE は等しいか答 等しくない（W のうち \(p_0S\cdot\dfrac x2\) は、容器 C の液面が大気を押し上げる仕事に使われる）

液体に仕事をするのは、B の気体（\(+W\)）と、C の液面に接する大気です。A の上は真空なので仕事をしません。C の液面は \(x/2\) 上がり、大気は液面を \(p_0S\) で押し続けるので、大気が液体にする仕事は \(-p_0S\cdot\dfrac x2\) です（液体が大気を押し上げる）。

仕事とエネルギーの関係（液体）

$$\cfrc{W}+\Bigl(\cfr{-p_0S\cdot\frac x2}\Bigr)=\cgrav{\Delta E}$$

確かめると \(\dfrac35p_0Sx-\dfrac12p_0Sx=\dfrac1{10}p_0Sx\) で、(3)(4) の結果と一致します。

着眼点

「気体の仕事 ＝ 液体の位置エネルギーの増加」と思い込まないことが大切です。液面が大気に触れているところでは、大気とのあいだで仕事をやりとりします。なお \(x^2\) の項まで含めて正確に計算しても、\(W-\Delta E=\dfrac12p_0Sx\) はちょうど成り立ちます（2つの \(x^2\) の項が打ち消し合う）。

式の立て方：エネルギー収支は「どの物体について書くか」を先に決め、その物体に仕事をする相手（ここでは気体・大気・真空）をすべて並べます。
アニメーションで確かめよう：右の棒グラフで、気体の仕事 W（赤）＝ 位置エネルギー ΔE（緑）＋ 大気を押した仕事（オレンジ）になっています。\(x/h\) を変えても成り立ちます。
III(1)　A の真空がなくなった時点の V₂, p₂, T₂答 \(V_2=\dfrac32V_1\)，\(p_2=2p_1\)，\(T_2=3T_1\)

A の液面が \(h\) 上がると、II(1) の関係（A の上昇 ＝ B の下降 ÷ 2）から B の液面は \(2h\) 下がります。この関係は体積保存と「A と C の差 5h」だけから出ているので、変化が大きくても使えます。

体積 ＝ 断面積 × 長さ

$$V_2=S(4h+2h)=6Sh\qquad\therefore\ \frac{V_2}{V_1}=\frac{6h}{4h}=\frac32$$

液体中の圧力（A と B の液面の差）

$$p_2=\rho g\cdot6h,\quad p_1=\rho g\cdot3h\qquad\therefore\ \frac{p_2}{p_1}=2$$

理想気体の状態方程式

$$\frac{T_2}{T_1}=\frac{p_2V_2}{p_1V_1}=2\times\frac32=3$$
式の立て方：変化が大きいときも、「体積保存」と「液面の差 → 圧力」はそのまま使えます。使えなくなるのは「x² を無視する」近似の部分だけです。
アニメーションで確かめよう：加熱が進むと、B の液面は C の最初の液面の高さまで下がり、A の液面は上端に届きます。右のグラフで V/V₁, p/p₁, T/T₁ がそれぞれ 1.5, 2, 3 に近づきます。
III(2)　熱量と温度変化の比 C答 \(C=\dfrac{15}{8}nR\)

仕事：p–V 図の台形

II(2) で見たとおり、圧力は体積の1次関数なので p–V 図は直線です。

気体がする仕事 ＝ p–V 図の面積

$$\cfrc{W'}=\frac12(p_1+p_2)(V_2-V_1)=\frac12\cdot3p_1\cdot\frac12V_1=\frac34p_1V_1=\frac34nRT_1$$

単原子分子理想気体の内部エネルギー

$$\cfic{\Delta U}=\frac32nR(T_2-T_1)=\frac32nR\cdot2T_1=3nRT_1$$

熱力学第1法則

$$Q=\cfic{\Delta U}+\cfrc{W'}=\frac{15}4nRT_1$$ $$C=\frac{Q}{T_2-T_1}=\frac{15nRT_1/4}{2T_1}=\frac{15}8nR$$

別解：液体のエネルギー収支から W′ を出す

II(5) と同じく \(W'=\Delta E'+p_0S\cdot h\)（C の液面は \(h\) 上がる）です。ただし変化が大きいので、II(4) の答えで \(x\to2h\) とするのは誤りで、層の重心まで考えます。B の高さ 0〜2h の層（重心 h）のうち、半分が A の 5h〜6h（重心 5.5h）、半分が C の 0〜h（重心 0.5h）に移るので \(\Delta E'=\rho Shg(5.5h+0.5h)-2\rho Shg\cdot h=4\rho Sgh^2=\dfrac45p_0Sh\)。よって \(W'=\dfrac95p_0Sh\)。\(nRT_1=p_1V_1=\dfrac{12}5p_0Sh\) なので \(W'=\dfrac34nRT_1\) で一致します。

着眼点：C の意味

C はこの過程での「熱容量」で、1 mol あたりにすると \(\dfrac{15}8R\fallingdotseq1.88R\) です。定積モル比熱 \(\dfrac32R\) と定圧モル比熱 \(\dfrac52R\) の間に入ります。仕事の分 \(\dfrac{W'}{T_2-T_1}=\dfrac38nR\) が上乗せされているので、気体の種類によらず \(C=nC_V+\dfrac38nR\) です。

式の立て方：熱量は直接求めにくいので「第1法則 \(Q=\Delta U+W\)」で、\(\Delta U\)（温度だけで決まる）と \(W\)（p–V 図の面積）から出します。
アニメーションで確かめよう：右のグラフは、加熱の途中でのモル比熱（その瞬間の \(\dfrac{dQ}{n\,dT}\)）です。始めは \(\dfrac{11}6R\)、終わりは \(\dfrac{19}{10}R\) と少し変わり、全体の平均が \(\dfrac{15}8R\) です。設定で \(C_V\) を \(\dfrac52R\)（2原子分子）にすると、C も \(R\) だけ大きくなります。
