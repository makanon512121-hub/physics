← 物理のHPに戻る

断熱膨張で比熱比を測る：クレマン・デゾルムの実験（東京科学大学（旧 東京工業大学） 2019年 第3問）

少し加圧した容器のコックを一瞬開けて空気を逃がし（断熱膨張）、閉じてから温度が戻るのを待つと、圧力が少しだけ上がります。差圧計の2つの読み h₁、h₂ だけで比熱比 γ が求まるしくみを、容器に残る空気だけに注目した「見えない仕切り」と P–V 図で確かめます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。図の色：容器に残る空気（青い分子）、灰色の分子は外へ出ていく空気、断熱変化（赤）、等温線（緑）、定積変化・流入する熱（オレンジ）。

⒜　状態 A，B でのモル数 n₁，n₂答 \(n_1=\dfrac{P_1V_1}{RT_0},\ \ n_2=\dfrac{P_0V_1}{RT_1}\)

どちらの状態も、容器の体積 \(V_1\) いっぱいに空気が入っています。A は圧力 \(P_1\)・温度 \(T_0\)、B は圧力 \(P_0\)・温度 \(T_1\) です。

理想気体の状態方程式（A と B）

$$P_1V_1=\cacc{n_1}RT_0,\qquad P_0V_1=\cacc{n_2}RT_1$$ $$\cacc{n_1}=\frac{P_1V_1}{RT_0},\qquad\cacc{n_2}=\frac{P_0V_1}{RT_1}$$

コック C₂ を開けている間に空気が出ていくので \(n_2\lt n_1\) です。

式の立て方：状態方程式は「ある瞬間に容器の中にある気体」について、その瞬間の \(P,\ V,\ T\) で立てます。出入りがある問題では、どの瞬間のどの気体かを決めてから書きます。
アニメーションで確かめよう：はじめ（A）の分子は青と灰色を合わせた数、コックを閉じた後（B）は青だけです。「いまの値」で \(n_2/n_1\) を確かめられます。
⒝　状態 C の圧力 P₂答 \(P_2=\dfrac{n_2}{n_1}P_1\)

B から C の間はコックが閉じているので、モル数は \(n_2\) のまま、体積も \(V_1\) のままで、温度だけ \(T_0\) に戻ります。

理想気体の状態方程式（C）

$$\cacc{P_2}V_1=n_2RT_0$$

A の式 \(P_1V_1=n_1RT_0\) と割り算すると、\(V_1\) も \(RT_0\) も消えます。

$$\cacc{P_2}=\frac{n_2}{n_1}P_1$$
式の立て方：同じ体積・同じ温度の2つの状態は、圧力がモル数に比例します。共通な量が多い2つの状態を選んで比をとると、式が短くなります。
アニメーションで確かめよう：C で止まります。容器の大きさも温度も A と同じなので、圧力の比は分子の数の比（青 ÷ 全部）に等しくなっています。
⒞　P₁(n₂/n₁)γ = P₀ を示す答 容器に残る n₂ の部分だけに断熱変化の式を使う

\(PV^\gamma=\text{一定}\) は、決まった量の気体が断熱変化するときの式です。容器から出ていく空気があるので、容器全体には使えません。そこで、最後まで容器に残る \(n_2\) モルの部分だけに注目します。

状態 A でこの部分が占める体積を \(V_\mathrm A\) とします。A では容器内の圧力も温度も一様なので、体積はモル数に比例します。

状態方程式（同じ P₁，T₀ ならモル数に比例）

$$\cacc{V_\mathrm A}=\frac{n_2}{n_1}V_1$$

この部分は、圧力 \(P_1\)・体積 \(V_\mathrm A\) から、圧力 \(P_0\)・体積 \(V_1\) まで断熱膨張します。

ポアソンの法則（断熱変化）

$$P_1\Bigl(\frac{n_2}{n_1}V_1\Bigr)^\gamma=P_0V_1^{\,\gamma}\qquad\therefore\ P_1\Bigl(\frac{n_2}{n_1}\Bigr)^\gamma=P_0$$

着眼点：見えない仕切りを考える

残る空気と出ていく空気の間に、熱を通さない軽い仕切りがあると考えます。仕切りの外側の空気がコックから押し出される間に、内側の \(n_2\) モルは仕切りを押して広がり、容器全体を満たします。出ていく空気は、このピストンの役目をしているだけです。

式の立て方：気体が出入りする断熱変化では、(1) 最後まで残る気体を決め、(2) その気体が最初に占めていた体積を求め、(3) その気体だけに \(PV^\gamma=\text{一定}\) を使います。
アニメーションで確かめよう：A では青い分子が下の \(V_\mathrm A\) の部分に、灰色の分子が上の部分にいます。C₂ を開くと灰色の分子が外へ出て、点線の仕切りが上がり、青い部分が容器いっぱいに広がります。P–V 図では赤い断熱曲線に沿って A → B と進みます。
⒟　h₁，h₂ で表した比熱比 γ答 \(\gamma=\dfrac{h_1}{h_1-h_2}\)

⒝ の \(\dfrac{n_2}{n_1}=\dfrac{P_2}{P_1}\) を ⒞ に入れて、モル数を消します。

$$\frac{P_1}{P_0}\Bigl(\frac{P_2}{P_1}\Bigr)^\gamma=1$$

\(P_1=P_0+h_1,\ P_2=P_0+h_2\) を入れ、両辺の対数をとります。

対数をとる

$$\log\Bigl(1+\frac{h_1}{P_0}\Bigr)+\gamma\log\frac{1+h_2/P_0}{1+h_1/P_0}=0$$

近似式（\(\frac{1+x}{1+y}\fallingdotseq1+x-y\)，\(\log(1+x)\fallingdotseq x\)）

$$\frac{h_1}{P_0}+\gamma\Bigl(\frac{h_2}{P_0}-\frac{h_1}{P_0}\Bigr)=0\qquad\therefore\ \gamma=\frac{h_1}{h_1-h_2}$$

対数を使わずに \(\bigl(\frac{P_0+h_2}{P_0+h_1}\bigr)^\gamma\fallingdotseq1+\gamma\bigl(\frac{h_2}{P_0}-\frac{h_1}{P_0}\bigr)\) と近似しても同じ結果になります。

着眼点：P–V 図の傾きの比として読む

A と C はどちらも温度 \(T_0\) なので、\(n_2\) モルの空気について見ると、同じ等温線の上にあります（\(P_1V_\mathrm A=P_2V_1\)）。A から体積が \(V_1\) まで増える間に、断熱曲線では圧力が \(h_1\) 下がり、等温線では \(h_1-h_2\) 下がります。断熱曲線の傾きは等温線の傾きの \(\gamma\) 倍なので、その比が \(\gamma\) です。断熱変化で下がった温度が、定積変化で同じだけ上がって元に戻る、と言いかえることもできます。

式の立て方：小さな量の近似では、まず式を「1 + 小さい量」の形にそろえ、小さい量の1次の項だけを残します。最後に答えが \(P_0\) によらない形になるのが目安です。
アニメーションで確かめよう：「いまの値」に、正確な \(\gamma\) と、測った \(h_1,\ h_2\) から近似式で出した値が並びます。\(h_1/P_0\) を小さくするほど2つが一致し、大きくするとずれます。P–V 図の赤（断熱）と緑（等温）の傾きの違いも見比べましょう。
⒠　2原子分子の空気で得られるべき γ答 \(\gamma=\dfrac75=1.4\)

マイヤーの関係

$$C_P=C_V+R=\frac52R+R=\frac72R$$

比熱比の定義

$$\gamma=\frac{C_P}{C_V}=\frac{\frac72R}{\frac52R}=\frac75$$

単原子分子（\(C_V=\frac32R\)）なら \(\gamma=\frac53\) です。一般に、分子が自由に動ける向き（自由度）が \(f\) なら \(C_V=\frac f2R\)、\(\gamma=\frac{f+2}{f}\) で、自由度が大きいほど \(\gamma\) は 1 に近づきます。

式の立て方：\(C_P\) は \(C_V\) より、定圧で膨張するときに外にする仕事のぶん（1 モルあたり \(R\)）だけ大きくなります。\(C_V\) がわかれば \(C_P\) と \(\gamma\) はすぐ求まります。
アニメーションで確かめよう：設定の「分子の自由度」を 3（単原子）、5（2原子）、6（多原子）と変えると、同じ \(h_1\) でも \(h_2\) が変わります。\(\gamma\) が大きいほど断熱膨張での温度の下がり方が大きく、\(h_2\) も大きくなります。
⒡　温度差 T₀ − T₁答 \(T_0-T_1=\dfrac{h_2}{P_0+h_2}T_0\)

B から C は、モル数 \(n_2\)・体積 \(V_1\) が変わらない定積変化です。

ボイル・シャルルの法則（B と C）

$$\frac{P_0V_1}{\cfrc{T_1}}=\frac{P_2V_1}{T_0}\qquad\therefore\ \cfrc{T_1}=\frac{P_0}{P_0+h_2}T_0$$ $$T_0-\cfrc{T_1}=\Bigl(1-\frac{P_0}{P_0+h_2}\Bigr)T_0\nobreak=\frac{h_2}{P_0+h_2}T_0$$

温度センサーで \(T_1\) を直接読めなくても、温度が戻った後の差圧 \(h_2\) から、断熱膨張でどれだけ冷えたかがわかります。

式の立て方：同じ量の気体の2つの状態は、ボイル・シャルルの法則 \(\frac{PV}{T}=\text{一定}\) で結びます。体積が同じなら圧力は絶対温度に比例します。
アニメーションで確かめよう：B で止まります。温度表示器が \(T_0\) より低い \(T_1\) を示し、分子の動きも少し遅くなっています。その後、壁から熱が入って温度と圧力が一緒に上がります。
⒢　B から C の間に流入する熱量答 \(Q=\dfrac52h_2V_1\)

体積が変わらないので、気体は仕事をしません。流入した熱はすべて内部エネルギーの増加になります。

定積変化の熱量（熱力学第1法則で W = 0）

$$\cfr{Q}=n_2C_V(T_0-T_1)\nobreak=n_2\cdot\frac52R\cdot\frac{h_2}{P_0+h_2}T_0$$

状態方程式（C：\(P_2V_1=n_2RT_0\)）

$$n_2RT_0=(P_0+h_2)V_1\qquad\therefore\ \cfr{Q}=\frac52h_2V_1$$

補足：定積変化の熱は「圧力の増え方 × 体積」

一般に、体積 \(V\) のまま圧力が \(\Delta P\) 増える定積変化では \(Q=\dfrac{C_V}{R}V\,\Delta P\) です。状態方程式 \(PV=nRT\) より \(nR\,\Delta T=V\,\Delta P\) となるからです。モル数や温度を経由しなくても、差圧計の読み \(h_2\) と容器の体積だけで熱量が決まります。

式の立て方：熱量は (1) どの変化か（定積・定圧・断熱）を確かめ、(2) 定積なら \(nC_V\Delta T\)、(3) \(nR\Delta T\) を状態方程式で \(P\)・\(V\) の量に書きかえる、の順に進めます。
アニメーションで確かめよう：オレンジの矢印が壁から入る熱です。「いまの値」の熱量が、差圧の増加とともに増えて \(\frac52h_2V_1\) に達します（容器の体積 \(V_1=10\) L として J で表示）。
