電池につないだ導体棒：電磁誘導とコンデンサーの類似（東京大学 2020年 第2問）

磁場中のレールに置いた導体棒を電池で動かします。棒が速くなるほど誘導起電力が電池に逆らい、電流が減って「到達速さ」に落ち着きます。この流れがコンデンサーの充電とそっくりであることを、グラフとエネルギーの収支で確かめます。後半はレールの間隔が変わる場合と、2本の棒を直列につないだ場合です。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。磁場は鉛直下向き（上から見た図では紙面の奥向き ⊗）です。色は図と式で共通です：電池（オレンジ）、誘導起電力（紫）、抵抗の電圧（緑）、電磁力（赤）、速さ・電気量（青）。グラフの時間は時定数 \(\tau = \dfrac{mR}{B^2d^2}\) を単位にしています。

I(1)　電磁力・磁場の向き・誘導起電力・到達速さ答 ア \(IBd\)　イ 下　ウ X　エ \(V_0 = V\)　オ \(\dfrac{V_0}{Bd}\)

電流が受ける力と磁場の向き

長さ \(d\) の棒を流れる電流 \(I\) が磁場から受ける力の大きさは \(\cfrc{IBd}\)（ア）です。電池の向きから、棒には X → Y の向きに電流が流れます。この電流が右向きの力を受けるので、フレミングの左手の法則（中指＝電流 X→Y、人差し指＝磁場、親指＝力 右）から、磁場は鉛直下向き（イ）です。

誘導起電力の向きと大きさ

棒が右に速さ \(s\) で動くと、棒の中の正電荷はローレンツ力 \(qsB\) を受けます。右手の法則で向きを調べると X 側に押されるので、X 側が正（ウ）の誘導起電力 \(\cfic{V = sBd}\) が生じます。これは電池が電流を流そうとする向きと逆向きです。

キルヒホッフの第2法則で電流を決める

回路を1周すると、電池で \(V_0\) 上がり、棒で \(V\) 下がり、抵抗で \(RI\) 下がります。

$$\cfr{V_0} - \cfic{sBd} - \cgrav{RI} = 0\qquad\Longrightarrow\qquad I = \frac{V_0 - sBd}{R}$$

\(s\) が増えるほど \(I\) が減り、\(V_0 = V\)（エ）になると \(I = 0\)、電磁力も 0 になって速さが一定になります。到達速さは

$$s_0 = \frac{V_0}{Bd}\quad\text{（オ）}$$

抵抗値 \(R\) と質量 \(m\) は、到達速さには関係せず、そこに達するまでの時間だけを決めます。

式の立て方：磁場中を動く導体棒は「電池 \(sBd\)」に置きかえて回路図を描き、①キルヒホッフの第2法則で電流を決める ②その電流で電磁力 \(IBd\) を求め、運動方程式を立てる、の2本を組にします。「一定の速さになる」は「加速度 0 ⇔ 電磁力 0（他に力がなければ電流 0）」と読みかえます。
アニメーションで確かめよう：スイッチが入ると、紫の誘導起電力 \(sBd\) が速さとともに大きくなり、緑の \(RI\) が小さくなります。式の下の数値で、オレンジ ＝ 紫 ＋ 緑 がつねに成り立っています。\(R\) や \(m\) を変えると、近づき方の速さだけが変わり、到達速さは変わりません。
I(2)　微小時間 Δt での速さと起電力の変化答 \(\Delta s = \dfrac{IBd}{m}\Delta t\)，\(\Delta V = \dfrac{IB^2d^2}{m}\Delta t\)

運動方程式を「Δ」の形で書く

棒の運動方程式は、加速度を \(\dfrac{\Delta s}{\Delta t}\) と書いて

$$m\frac{\Delta s}{\Delta t} = \cfrc{IBd}\qquad\Longrightarrow\qquad \cacc{\Delta s} = \frac{IBd}{m}\Delta t$$

起電力は \(V = sBd\) で、\(B,d\) は一定なので、変化するのは \(s\) だけです。

$$\cfic{\Delta V} = Bd\,\Delta s = \frac{IB^2d^2}{m}\Delta t$$

この式の意味

\(I\Delta t\) は \(\Delta t\) の間に棒を通った電気量です。式を \(I\Delta t = \dfrac{m}{B^2d^2}\Delta V\) と書きかえると、「通った電気量に比例して起電力が上がる」という関係になります。これはコンデンサーの \(\Delta q = C\,\Delta V\) と同じ形で、比例定数 \(\dfrac{m}{B^2d^2}\) が電気容量の役割をします。

式の立て方：時間変化する量どうしの関係は、運動方程式やキルヒホッフの法則を「Δ」の形で書き、共通の \(\Delta t\) や \(I\Delta t\) をはさんでつなぎます。積分が必要な設問（I(3)、I(4)）はこの微小関係を足し合わせるだけです。
アニメーションで確かめよう：下のグラフは起電力 \(V\) の時間変化で、いまの時刻の接線（傾き \(\Delta V/\Delta t\)）を描いています。傾きは電流 \(I\) に比例するので、電流が大きいはじめほど急で、到達速さに近づくと平らになります。
I(3)　到達速さまでに棒を流れる電気量答 \(Q = \dfrac{mV_0}{B^2d^2}\)

微小な電気量を足し合わせる

I(2) より、\(\Delta t\) の間に流れる電気量は起電力の増加 \(\Delta V\) に比例します。

$$\cacc{I\Delta t} = \frac{m}{B^2d^2}\,\cfic{\Delta V}$$

起電力は 0 から \(V_0\) まで増えるので、両辺を足し合わせて

$$Q = \frac{m}{B^2d^2}\,V_0 = \frac{mV_0}{B^2d^2}$$

別の立て方：運動量の変化から

運動方程式を \(I\Delta t = \dfrac{m}{Bd}\Delta s\) と変形すると、「電磁力の力積 \(Bd\cdot I\Delta t\) ＝ 運動量の変化 \(m\Delta s\)」です。速さが 0 から \(s_0\) まで変わるので \(Q = \dfrac{m s_0}{Bd} = \dfrac{mV_0}{B^2d^2}\) と一致します。電流が時間とともにどう変わるかを知らなくても、始めと終わりの速さだけで電気量が決まります。

参考：電流の時間変化

キルヒホッフの式を時間で微分して運動方程式に入れると \(\dfrac{dI}{dt} = -\dfrac{B^2d^2}{mR}I\) となり、\(I = \dfrac{V_0}{R}e^{-t/\tau}\)（\(\tau = \frac{mR}{B^2d^2}\)）です。\(I\)–\(t\) グラフの面積を求めても同じ \(Q\) になります。

式の立て方：「流れた電気量」は ①\(I\)–\(t\) グラフの面積 ②微小関係 \(I\Delta t = (\text{定数})\times\Delta(\text{何か})\) を見つけて足す ③力積と運動量の関係 \(Bd\cdot Q = m\Delta s\)、のどれかで求めます。電流が一定でないときは②③が強力です。
アニメーションで確かめよう：左のグラフは \(I\)–\(t\) グラフで、塗った面積がこれまでに流れた電気量です。右のグラフは電気量と起電力の関係で、傾き \(\dfrac{B^2d^2}{m}\) の直線上を進みます（コンデンサーの \(V = q/C\) と同じ形）。
I(4)　起電力に逆らって電荷を運ぶ仕事答 \(\dfrac12ms_0^{\,2}\)

微小な仕事を運動エネルギーの変化にする

電荷 \(I\Delta t\) を起電力 \(V\) に逆らって運ぶ仕事は「電荷 × 電位差」です。\(V = sBd\) と I(2) の \(\Delta s\) を使うと

$$\Delta W = \cfic{V}\cdot\cacc{I\Delta t} = sBd\cdot I\Delta t = ms\cdot\frac{IBd}{m}\Delta t = ms\,\Delta s$$

\(ms\Delta s\) は \(\frac12ms^2\) の微小変化です。速さ 0 から \(s_0\) まで足し合わせて

$$W = \frac12ms_0^{\,2}$$

コンデンサーとの対応で見る

I(3) で \(Q = \dfrac{m}{B^2d^2}V_0\) だったので、棒は電気容量 \(C = \dfrac{m}{B^2d^2}\) のコンデンサーのようにふるまいます。コンデンサーを電圧 \(V_0\) まで充電する仕事は \(\frac12CV_0^{\,2}\) で、

$$\frac12CV_0^{\,2} = \frac12\cdot\frac{m}{B^2d^2}\cdot V_0^{\,2} = \frac12m\left(\frac{V_0}{Bd}\right)^2 = \frac12ms_0^{\,2}$$

と同じ答えです。「コンデンサーの電荷」にあたるのは \(q = \dfrac{ms}{Bd}\)（運動量に比例する量）、「静電エネルギー」にあたるのは運動エネルギーです。

式の立て方：電荷を運ぶ仕事は \(\Delta W = V\,\Delta q\)、つまり \(V\)–\(q\) グラフの面積です。\(V\) と \(q\) が比例するなら三角形の面積 \(\frac12qV\) になります。比例関係を見つけたら、すぐに「コンデンサーと同じ」と言いかえられます。
アニメーションで確かめよう：下のグラフは \(V\)–\(q\) グラフで、塗った三角形の面積が起電力に逆らってした仕事です。最後は \(\frac12QV_0\) になり、「いまの値」の運動エネルギー \(\frac12ms^2\) とつねに等しくなっています。
I(5)　電池がした仕事の行き先答 導体棒の運動エネルギー \(\dfrac12QV_0\) と、抵抗のジュール熱 \(\dfrac12QV_0\)

エネルギー保存を立てる

電池がした仕事 \(QV_0\) は、棒の運動エネルギーと抵抗で発生するジュール熱 \(J\) に分かれます。

$$\cfr{QV_0} = \cacc{\frac12ms_0^{\,2}} + \cfrc{J}$$

\(Q = \dfrac{mV_0}{B^2d^2}\) と \(s_0 = \dfrac{V_0}{Bd}\) から \(QV_0 = m s_0^{\,2}\) なので、\(\frac12ms_0^{\,2} = \frac12QV_0\)、残りの \(J = \frac12QV_0\) がジュール熱です。ちょうど半分ずつで、これは抵抗の大きさによりません。コンデンサーを電池で充電するとき、静電エネルギーとジュール熱が半分ずつになるのと同じです。

着眼点：瞬間ごとのエネルギーの流れ

キルヒホッフの式 \(V_0 - sBd - RI = 0\) に \(I\) をかけると

$$IV_0 = RI^2 + IsBd = RI^2 + \frac{d}{dt}\left(\frac12ms^2\right)$$

（2つ目の等号は運動方程式 \(m\frac{ds}{dt} = IBd\) から）。電池の仕事率が、ジュール熱の発生率と運動エネルギーの増加率に分かれます。電磁力が棒にする仕事率 \(IBd\cdot s\) と、誘導起電力に逆らう仕事率 \(I\cdot sBd\) は同じ大きさで、磁場は電気のエネルギーを力学的エネルギーに「橋渡し」するだけで、自分ではエネルギーを持ち込みません。

式の立て方：回路と運動が組み合わさった問題のエネルギー収支は「電池の仕事 ＝ ジュール熱 ＋ 力学的エネルギーの増加（＋ 静電エネルギーなど）」と立てます。どれか2つが分かれば残りが求まります。電池の仕事は「電池を通った電気量 × 起電力」です。
アニメーションで確かめよう：下のグラフは電池の仕事（オレンジ）が運動エネルギー（青）とジュール熱（赤）に分かれる様子です。はじめは電流が大きく、ほとんどが熱になります。後半は運動エネルギーに回る割合が増え、最後にちょうど半分ずつになります。\(R\) を変えても最終的な配分は変わりません。
II　スイッチを閉じたまま間隔 2d のレールへ答 カ \(\dfrac12\)　キ \(1\)

到達速さは「起電力＝電池の電圧」で決まる

スイッチが閉じていれば、到達速さでは電流が 0 なので、起電力は電池の電圧と等しくなります。間隔 \(2d\) のレールでは

$$\cfr{V_0} - \cfic{s_0'B\cdot2d} = 0\qquad\Longrightarrow\qquad s_0' = \frac{V_0}{2Bd} = \frac12s_0$$

到達速さは \(\frac12\) 倍（カ）、そのときの起電力は \(V_0\) のままで 1 倍（キ）です。

移り変わりの間に何が起こるか

棒が \(2d\) の部分に入った直後は、速さがまだ \(s_0\) なので起電力は \(s_0B\cdot2d = 2V_0\) です。電池より大きいので、電流は逆向き（Y→X）に流れ、電磁力は左向きになって棒を減速させます。電流は電池を逆向きに通るので、電池は充電され、エネルギーを受け取ります。

発展：減速の間の力積は \(m\left(\frac{s_0}{2}-s_0\right) = B\cdot2d\cdot q\) なので、逆向きに流れた電気量は \(\frac{ms_0}{4Bd} = \frac Q4\) です。運動エネルギーの減少 \(\frac38QV_0\) のうち、\(\frac14QV_0\) が電池に戻り、残りの \(\frac18QV_0\) がジュール熱になります。

式の立て方：レールの間隔や磁場が途中で変わっても、到達状態は「電流 0 ⇔ 起電力の和 ＝ 電池の電圧」の1本で決まります。途中の様子は I と同じ「キルヒホッフ＋運動方程式」で、起電力の大きさが変わるだけです。
アニメーションで確かめよう：棒が広いレールに入った瞬間、紫の起電力がオレンジの電池の電圧を超え、電流（緑の点の流れ）が逆向きになります。赤い電磁力が左向きになり、速さが半分まで下がると電流は止まります。下のグラフで、起電力が \(2V_0\) まで跳ね上がってから \(V_0\) に戻る様子が見えます。
II　スイッチを切ったまま間隔 2d のレールへ答 ク \(1\)　ケ \(2\)

電流が流れなければ力もはたらかない

スイッチを切ると回路が開いているので電流は流れず、電磁力もはたらきません。摩擦もないので、速さは \(s_0\) のまま変わりません（ク＝1）。起電力は棒の長さ（レールの間隔）に比例するので

$$\cfic{V''} = s_0B\cdot2d = 2V_0\qquad\text{（ケ＝2）}$$

起電力は「電荷を押す力」の大きさであって、電流が流れていなくても X, Y 間には電位差として現れます。

式の立て方：誘導起電力 \(vBl\) の \(l\) は「回路の一部として電流が流れうる部分の長さ」、つまり接点どうしの間隔です。棒そのものの長さではありません。スイッチが開いているときは、起電力はそのまま端子間の電圧になります。
アニメーションで確かめよう：電流の点が止まったまま、棒は同じ速さで進みます。広い部分に入ると接点 X, Y の間隔が 2 倍になり、紫の起電力も 2 倍になります。
III　2本の導体棒を直列につないだときの速さ答 導体棒1 \(\dfrac{V_0}{5Bd}\)，導体棒2 \(\dfrac{2V_0}{5Bd}\)

着眼点：同じ電流、長さ2倍 → 力も2倍

2本の棒は直列なので、同じ電流 \(I\) が流れます。電磁力は棒1が \(IBd\)、棒2が \(IB\cdot2d\) で、いつでも \(1:2\) です。質量は同じなので加速度も \(1:2\)、どちらも静止から動き出すので、速さもつねに \(s_2 = 2s_1\) です。

到達状態のキルヒホッフの式

十分時間がたつと速さが一定、つまり電磁力 0、電流 0 です。2本の起電力の和が電池の電圧に等しくなります。

$$\cfr{V_0} - \cfic{s_1Bd} - \cfic{s_2B\cdot2d} = 0$$

\(s_2 = 2s_1\) を入れて \(V_0 = 5s_1Bd\) なので

$$s_1 = \frac{V_0}{5Bd},\qquad s_2 = \frac{2V_0}{5Bd}$$

別の立て方：コンデンサー2個の直列

I(4) の対応で、棒1は電気容量 \(C_1 = \dfrac{m}{B^2d^2}\)、棒2は \(C_2 = \dfrac{m}{B^2(2d)^2} = \dfrac{C_1}{4}\) のコンデンサーです。直列なので電荷が等しく、電圧（起電力）は容量に反比例して \(1:4\) に分かれます。よって \(s_1Bd = \frac15V_0\) で同じ結果です。

式の立て方：複数の棒があるときは、①電流の関係（直列なら同じ、並列ならキルヒホッフの第1法則）②各棒の運動方程式 ③到達状態の条件、を順に立てます。静止から同時に動き出すなら「力の比 ＝ 速さの比」が使えます。
アニメーションで確かめよう：下のグラフで、棒2の速さ（赤）はつねに棒1（青）のちょうど2倍です。上の式の数値で、2本の起電力の比がいつも \(1:4\) になっていることも確認できます。
