台車とピストン：気体をばねにした跳ね返り（東京大学 2025年 第3問）

断熱容器の中の単原子分子理想気体（1 mol）を、走ってきた台車がピストンごと押し込みます。気体は「ばね」のように台車を押し返しますが、そのエネルギーは内部エネルギーとしてたくわえられます。後半は容器を2室に分け、熱が移ると跳ね返りがどう弱まるかを調べます。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

気体は 1 mol、V0 = 25 L、ピストンの断面積 0.05 m²、気体定数 R = 8.31 J/(mol·K)。ピストンが動いている時間はとても短い（0.1 秒程度）ので、スローで再生しています。

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。\(K_0 = \dfrac12 mv_0^{\,2}\)、\(U_0 = \dfrac32RT_0\) です。

I(1)(2)　エネルギー保存で温度を求める答 \(K_0 = \dfrac12mv_0^{\,2},\ U_0 = \dfrac32RT_0,\ \ \dfrac{T_1}{T_0} = \dfrac{U_0+K_0}{U_0}\)

(1) 単原子分子理想気体の内部エネルギー

単原子分子理想気体の内部エネルギーは、物質量 \(n\) と温度 \(T\) だけで決まり \(U = \dfrac32nRT\)。ここでは 1 mol なので \(U_0 = \dfrac32RT_0\)。体積や圧力にはよらないことが、この問題の計算を簡単にしてくれます。

(2) 台車 → ピストン → 気体 とエネルギーが移る

熱力学第1法則 \(\Delta U = Q + W_{\text{された}}\) で、断熱なので \(Q = 0\)。ピストンは質量 0・摩擦なしなので、台車がピストンにした仕事は、そのままピストンが気体にした仕事になります（ピストンは途中でエネルギーをためられない）。台車の運動エネルギーの減少 \(K_0\) が気体の仕事 \(W\) になり、

$$U_1 = U_0 + K_0$$

\(U\propto T\) なので

$$\frac{T_1}{T_0} = \frac{U_1}{U_0} = \frac{U_0+K_0}{U_0}$$

「断熱・質量0のピストン・摩擦なし」がそろうと、力学的エネルギー＋内部エネルギーが保存します。気体は、エネルギーを内部エネルギーとしてたくわえる「ばね」なのです。

アニメーションで確かめよう：エネルギーの棒グラフで、台車の運動エネルギーが減った分だけ気体の内部エネルギーが増え、合計は一定です。\(m\) や \(v_0\) を変えて \(K_0\) を大きくすると \(T_1\) が上がります。
I(3)　体積の比答 \(\dfrac{V_1}{V_0} = \left(\dfrac{U_0}{U_0+K_0}\right)^{3/2}\)

ポアソンの法則を温度と体積の式に直す

\(pV^{5/3} = \text{一定}\) に \(p = \dfrac{RT}{V}\) を代入すると

$$TV^{2/3} = \text{一定}$$

温度の比が分かっているので、この形が便利です。

$$T_0V_0^{\,2/3} = T_1V_1^{\,2/3} \qquad\therefore\quad \frac{V_1}{V_0} = \left(\frac{T_0}{T_1}\right)^{3/2} = \left(\frac{U_0}{U_0+K_0}\right)^{3/2}$$

ポアソンの法則は \(pV^\gamma\)、\(TV^{\gamma-1}\)、\(T^\gamma p^{1-\gamma}\) のどの形でも使えます。与えられた量・求めたい量に合わせて形を選ぶのがコツです（単原子分子なら \(\gamma = \dfrac53\)）。

アニメーションで確かめよう：右の \(p\)–\(V\) 図に断熱線が描かれます。圧縮と膨張が同じ線の上を往復していることに注目しましょう。
I(4)　台車の v–t グラフ答 ③（\(t_1\) で傾きが最も急、\(t_2\) 以降は \(-v_0\)、\(t_1\) について点対称）

傾き＝加速度＝気体の圧力に比例

接触中の台車の運動方程式は（\(S\) はピストンの断面積）

$$m\frac{\Delta v}{\Delta t} = -pS$$

\(v\)–\(t\) グラフの傾きは \(-\dfrac{pS}{m}\)。圧力は体積が小さいほど大きいので、最も押しこまれた \(t_1\)（\(v=0\)）で傾きが最も急になります。ばねの単振動と同じで、「最も縮んだ所で力が最大」です。

行きと帰りは対称

断熱変化の圧力は体積だけで決まり（\(p\propto V^{-5/3}\)）、行きと帰りで同じ体積なら同じ力。だから運動は時間を逆回しにしても同じになり、グラフは \((t_1, 0)\) について点対称。離れるときの速さは \(v_0\)（向きは逆）で、エネルギー保存とも合います。

\(t_0\) と \(t_2\) で折れ曲がる

はじめから気体には圧力 \(p_0\) があり、ピストンはストッパーに押しつけられています。接触した瞬間に台車は力 \(p_0S\) を受け始めるので、加速度が 0 から急に \(-\dfrac{p_0S}{m}\) にとぶ＝グラフが折れ曲がります。なめらかに減速し始めるグラフは選べません。

アニメーションで確かめよう：点線は実際のグラフを \((t_1,0)\) のまわりに 180° 回したもので、帰りのグラフとぴったり重なります。右のグラフは加速度で、\(t_0\) で 0 から急にとび、\(t_1\) で最大になります。
II(1)　2室にしたときの運動エネルギー K₄答 \(K_4 = \dfrac32R(T_3-T_4)\)

\(t_3\) から \(t_4\) の間は時間が短く、仕切り壁を通る熱の移動は無視できます。

  • 右の気体：体積も変わらず熱も来ない → 内部エネルギーは変わらない（温度 \(T_3\) のまま）
  • 左の気体：断熱膨張して台車に仕事をする → 内部エネルギーが \(\dfrac32R(T_3-T_4)\) 減る

台車ははじめ静止しているので、左の気体が失った内部エネルギーがそのまま台車の運動エネルギーになります。

$$K_4 = \frac32RT_3 - \frac32RT_4 = \frac32R(T_3-T_4)$$

エネルギーの流れを「どこからどこへ」と追いかけるのが、熱と力学がまざった問題の基本です。

アニメーションで確かめよう：エネルギーの棒グラフで、\(t_1\) から \(t_3\) の間に左から右へ内部エネルギーが移り（合計は一定）、そのあと左の気体の分だけが台車に戻ります。
II(2)　温度の大小関係答 \(T_4 < T_0 < T_3 < T_1\)

\(T_3\)：同じ熱容量の物体を接触させると平均の温度

台車を固定している間、全体のエネルギーは保存。左右とも 1 mol の単原子分子なので熱容量が等しく

$$\frac32RT_1 + \frac32RT_0 = 2\cdot\frac32RT_3 \qquad\therefore\quad T_3 = \frac{T_1+T_0}{2}$$

よって \(T_0 < T_3 < T_1\)。

\(T_4\)：同じ体積比の断熱変化は温度比も同じ

左の気体は \(V_0 \to V_1\)（圧縮）と \(V_1 \to V_0\)（膨張）で、同じ体積比を行き来します。\(TV^{2/3} = \text{一定}\) より

$$\frac{T_1}{T_0} = \left(\frac{V_0}{V_1}\right)^{2/3} = \frac{T_3}{T_4} \qquad\therefore\quad T_4 = T_0\cdot\frac{T_3}{T_1} < T_0$$

熱を逃がした後で同じだけ膨張するので、出発時より冷えてしまうのです。

アニメーションで確かめよう：温度の棒グラフで、点線の \(T_0\) と比べてください。\(K_0\) を大きくすると、\(T_1\) と \(T_4\) の差が広がります。
II(3)　速さの比 e答 \(e = \sqrt{\dfrac{2U_0+K_0}{2(U_0+K_0)}}\)

内部エネルギーで計算する

\(t_3\) での左の気体の内部エネルギーは、全体の半分：

$$U_3 = \frac{(U_0+K_0) + U_0}{2} = U_0 + \frac{K_0}{2}$$

II(2) より \(T_4 = T_3\cdot\dfrac{T_0}{T_1}\) なので \(U_4 = U_3\cdot\dfrac{U_0}{U_0+K_0}\)。台車がもらうのはその差：

$$K_4 = U_3 - U_4 = \left(U_0+\frac{K_0}{2}\right)\frac{K_0}{U_0+K_0}$$ $$e = \left|\frac{v_4}{v_0}\right| = \sqrt{\frac{K_4}{K_0}} = \sqrt{\frac{2U_0+K_0}{2(U_0+K_0)}}$$

pV 図で見ると

\(t_1\) と \(t_3\) は体積が同じで温度だけが下がっているので、膨張の断熱線は圧縮の断熱線より下を通ります。台車がされた仕事（帰りの面積）は、した仕事（行きの面積）より小さくなります。その比が \(e^2\) です。

極端な場合で確かめる

  • \(K_0 \ll U_0\)：ほとんど温度が上がらず熱も移らない → \(e\to 1\)
  • \(K_0 \gg U_0\)：受け取ったエネルギーの約半分が右へ逃げる → \(e\to \dfrac{1}{\sqrt2}\)

答えの式は、極端な場合を考えると意味が分かり、検算にもなります。

アニメーションで確かめよう：pV 図の行き（上の線）と帰り（下の線）の間の面積が、台車に戻らなかったエネルギー \(K_0-K_4\) です。\(v_0\) を大きくすると \(e\) が \(\dfrac{1}{\sqrt2}\approx 0.71\) に近づきます。
