傾いたベルトコンベア上の物体と摩擦（東京大学 2024年 第1問）

傾いたベルトコンベアの上で物体がすべったり、ベルトに乗って運ばれたりします。カギは「摩擦力の向きは、ベルトに対する相対速度で決まる」こと。後半はばねでつないだ2物体を重心の運動＋相対運動（単振動）に分けて考えます。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

重力加速度 g = 9.8 m/s²。物体の大きさは見やすさのため実際より大きく描いています。

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。斜面に沿って上向きを正とし、垂直抗力は \(N = mg\cos\theta\) です。

I(1)　最高点の x 座標答 \(x_1 = \dfrac{v_0^{\,2}}{2g(\sin\theta_1 + \mu'\cos\theta_1)}\)

まず「摩擦力の向き」を決める

動摩擦力は接している面に対する相対速度と逆向きにはたらきます。ベルトは止まっているので、上りの間は物体の速度そのものが上向き → 摩擦力は下向き。重力の斜面成分 \(mg\sin\theta_1\) も下向きなので、どちらも減速させます。

$$ma = -mg\sin\theta_1 - \mu' mg\cos\theta_1 \qquad\therefore\quad a = -g(\sin\theta_1+\mu'\cos\theta_1)$$

等加速度運動の公式（または仕事とエネルギー）

\(v^2 - v_0^{\,2} = 2ax\) で \(v = 0\) とおけば

$$x_1 = \frac{v_0^{\,2}}{2g(\sin\theta_1+\mu'\cos\theta_1)}$$

「運動エネルギーの変化＝した仕事の和」で考えても同じ式です：\(0-\dfrac12mv_0^{\,2} = -(mg\sin\theta_1 + \mu'mg\cos\theta_1)\,x_1\)。一定の力なら、どちらの方法でも1行で解けます。

アニメーションで確かめよう：v–t グラフは直線（傾き＝加速度）。\(\mu'\) を大きくすると傾きが急になり、最高点が下がります。
I(2)　x = 0 に戻ったときの速度答 \(v_1 = -v_0\sqrt{\dfrac{\sin\theta_1-\mu'\cos\theta_1}{\sin\theta_1+\mu'\cos\theta_1}}\)

下りでは摩擦力の向きが逆になる

最高点で向きが変わると相対速度も下向きになり、摩擦力は上向きに変わります。下りの加速度の大きさは

$$|a'| = g(\sin\theta_1 - \mu'\cos\theta_1)$$

上りと下りで同じ距離 \(x_1\) を進むので、\(v_1^{\,2} = 2|a'|x_1\)、\(v_0^{\,2} = 2|a|x_1\) の比をとって

$$\frac{v_1^{\,2}}{v_0^{\,2}} = \frac{\sin\theta_1-\mu'\cos\theta_1}{\sin\theta_1+\mu'\cos\theta_1} \qquad\therefore\quad v_1 = -v_0\sqrt{\frac{\sin\theta_1-\mu'\cos\theta_1}{\sin\theta_1+\mu'\cos\theta_1}}$$

（下向きなので負）。エネルギーで見れば、往復で摩擦力がした仕事 \(-2\mu'mg\cos\theta_1\cdot x_1\) の分だけ運動エネルギーが減っています。

そもそも戻ってくる条件

最高点で一瞬止まったとき、静止摩擦力で支えきれなければすべり出します：\(mg\sin\theta_1 > \mu mg\cos\theta_1\)、つまり \(\tan\theta_1 > \mu\)。この問題は戻ってくると書いてあるので、この条件が成り立っています。

アニメーションで確かめよう：v–t グラフが最高点で折れ曲がり、下りは傾きがゆるくなります。\(\mu\) を \(\tan\theta_1\) より大きくすると最高点で止まったままになります。
II(1)　動いているベルトに置いた物体の速度答 \(v = g(\mu'\cos\theta_2-\sin\theta_2)\,t\ \ \left(t < \dfrac{V}{g(\mu'\cos\theta_2-\sin\theta_2)}\right),\quad v = V\ \ (\text{それ以降})\)

ベルトから見ると物体は「下へすべっている」

物体の速度 0、ベルトの速度 \(V\)（上向き）なので、ベルトに対する物体の相対速度は \(0 - V < 0\)（下向き）。摩擦力はその逆、上向きです。物体自身は止まっていても、摩擦力の向きは決まります。

$$ma = \mu'mg\cos\theta_2 - mg\sin\theta_2 \qquad\therefore\quad a = g(\mu'\cos\theta_2-\sin\theta_2)$$

物体が上り始めるので \(\mu'\cos\theta_2 > \sin\theta_2\) です。速度は \(v = at\) で増え、ベルトと同じ \(V\) になった瞬間に相対速度が 0 になります。

追いついた後は静止摩擦力

相対速度 0 のまま一緒に動くには、静止摩擦力が \(mg\sin\theta_2\) を支えればよく、\(\mu \ge \mu' > \tan\theta_2\) なので大丈夫。以後は速度 \(V\) の等速運動です。

$$v = \begin{cases} g(\mu'\cos\theta_2-\sin\theta_2)\,t & \left(0\le t<\dfrac{V}{g(\mu'\cos\theta_2-\sin\theta_2)}\right)\\[2mm] V & \left(t \ge \dfrac{V}{g(\mu'\cos\theta_2-\sin\theta_2)}\right)\end{cases}$$
アニメーションで確かめよう：摩擦力のグラフで、すべっている間は大きさ \(\mu'N\)（動摩擦）、追いついた後は \(mg\sin\theta_2\)（静止摩擦、\(\mu N\) 以下）に切りかわります。
II(2)　下向きに打ち出したときの戻りの速度答 \(v_0\)（上向き）

摩擦力はずっと上向き

物体が下っているときも上っているときも、速度は \(V\) より小さいので相対速度はずっと下向き → 摩擦力はずっと上向きで大きさ \(\mu'mg\cos\theta_2\)。I(2) と違い、物体の向きが変わっても摩擦力の向きは変わりません。

力が一定 → 加速度 \(a = g(\mu'\cos\theta_2-\sin\theta_2)\) の等加速度運動。これは「鉛直に投げ上げた物体」と同じ形で、行きと帰りが対称になります。

$$v^2 - (-v_0)^2 = 2a\cdot 0 \qquad\therefore\quad v = v_0$$

\(v_0 < V\) なので、\(x = 0\) に戻るまでにベルトの速さに達することはありません（もし \(v_0 > V\) なら途中で \(V\) に追いつき、戻ったときの速さは \(V\) になります）。

アニメーションで確かめよう：v–t グラフは 1 本の直線です。\(v_0\) を \(V\) より大きくすると、直線が \(V\) で頭打ちになるのが見られます。
III(1)(2)　つり合いの d₀ と μ′答 \(d_0 = \dfrac{mg\sin\theta_3}{k},\quad \mu' = 2\tan\theta_3\)

(1) B だけを見る

B とベルトの間には摩擦がないので、B にはたらく斜面方向の力は重力の成分とばねの力だけ。B が静止し続けるには

$$kd_0 = mg\sin\theta_3 \qquad\therefore\quad d_0 = \frac{mg\sin\theta_3}{k}$$

(2) A と B をまとめて見る

ベルトは動いていて A は静止しているので、A はベルトに対して下へすべっています → A には上向きの動摩擦力 \(\mu'mg\cos\theta_3\)。ばねの力は A と B の間の内力なので、全体で見ると打ち消し合います。全体のつり合いは

$$\mu'mg\cos\theta_3 = 2mg\sin\theta_3 \qquad\therefore\quad \mu' = 2\tan\theta_3$$

「内力を消したいときは全体を1つの物体として見る」は、連結物体の基本テクニックです。

アニメーションで確かめよう：物体は止まっていて、ベルトの模様だけが流れています。A の摩擦力（上向き）が、2物体分の重力の成分とつり合っています。
III(3)(4)　重心の速度と B の速度、時刻 t₁答 \(v_G = \dfrac V2,\quad v_B = \dfrac V2\left(1+\cos\sqrt{\dfrac{2k}{m}}\,t\right),\quad t_1 = \pi\sqrt{\dfrac{m}{2k}}\)

(3) 外力の和が 0 なら重心は等速

\(0 $$2mg\sin\theta_3\ (\text{摩擦}) - 2mg\sin\theta_3\ (\text{重力}) = 0$$

なので重心 G は等速運動。\(t = 0\) で \(v_A = 0,\ v_B = V\) だから

$$v_G = \frac{mv_A + mv_B}{2m} = \frac V2$$

(4) 重心から見ると単振動

A、B それぞれの運動方程式を立て、ばねの伸びを \(s\)（\(s = d_0\) がつり合い）とすると、引き算で

$$m\frac{d^2(x_B - x_A)}{dt^2} = -2k\,(\text{つり合いからのずれ})$$

となり、相対運動は角振動数 \(\omega_1 = \sqrt{\dfrac{2k}{m}}\) の単振動です（質量 \(m\) の物体が重心とのあいだの「半分の長さのばね」＝ばね定数 \(2k\) につながれていると考えてもよい）。

重心から見ると、B は \(t=0\) につり合いの位置で速度 \(V - \dfrac V2 = \dfrac V2\) をもつので

$$v_B - v_G = \frac V2\cos\omega_1 t \qquad\therefore\quad v_B = \frac V2\left(1+\cos\sqrt{\frac{2k}{m}}\,t\right)$$

同様に \(v_A = \dfrac V2(1-\cos\omega_1 t)\)。A がはじめて \(V\) になるのは \(\cos\omega_1 t = -1\)、つまり半周期後：

$$t_1 = \frac{\pi}{\omega_1} = \pi\sqrt{\frac{m}{2k}}$$

2物体の問題 ＝ 重心の運動 ＋ 相対運動。外力が一定なら重心は簡単に分かり、ばねでつながれた相対運動は単振動になります。

アニメーションで確かめよう：v–t グラフで \(v_A\) と \(v_B\) が \(v_G = V/2\)（点線）について上下対称に振動します。\(k\) を大きくすると \(t_1\) が短くなります。
III(5)　t ≧ t₁ での B の速度答 \(v_B = V\left\{1-\cos\left(\sqrt{\dfrac km}\,t - \dfrac{\pi}{\sqrt2}\right)\right\}\)

A はベルトに乗って等速 V

\(t_1\) で A はベルトに追いつき、以後は静止摩擦力で一緒に動きます（条件は (6)）。A は速度 \(V\) で動く「壁」になったと考えられます。

A から見た B は、ばね定数 k の単振動

等速で動く A から見ても慣性力ははたらかないので、B は片方が固定されたばね（ばね定数 \(k\)）につながれた単振動をします：\(\omega_2 = \sqrt{\dfrac km}\)。

\(t = t_1\) では、相対運動がちょうど半周期進んでいるのでばねはつり合いの長さ、B の速度は \(v_B = 0\)、A から見た B の速度は \(0 - V = -V\)。よって

$$v_B - V = -V\cos\omega_2(t-t_1)$$

\(\omega_2 t_1 = \sqrt{\dfrac km}\cdot\pi\sqrt{\dfrac m{2k}} = \dfrac{\pi}{\sqrt2}\) なので

$$v_B = V\left\{1-\cos\left(\sqrt{\frac km}\,t-\frac{\pi}{\sqrt2}\right)\right\}$$

前半（\(\omega_1=\sqrt{2k/m}\)）と後半（\(\omega_2=\sqrt{k/m}\)）で振動の速さが変わるのは、相手が動けるか（重心まわり）、固定されているかの違いです。

アニメーションで確かめよう：\(t_1\) 以降、\(v_A\) は \(V\) の直線、\(v_B\) は 0 と \(2V\) の間を振動します。振動の周期が前半より長くなっていることに注目。
III(6)　A がすべらない μ の条件答 \(\mu > 2\tan\theta_3 + \dfrac{V}{g\cos\theta_3}\sqrt{\dfrac km}\)

必要な静止摩擦力が最大になる瞬間

A は等速なので、A にはたらく力はつり合っています。ばねの伸びを \(s\) とすると、必要な静止摩擦力（上向き）は

$$f = mg\sin\theta_3 + ks$$

ばねが最も伸びたときに \(f\) が最大。(5) の単振動の振幅は \(A = \dfrac{V}{\omega_2} = V\sqrt{\dfrac mk}\) なので \(s_{\max} = d_0 + A\)。

$$f_{\max} = mg\sin\theta_3 + k d_0 + kV\sqrt{\frac mk} = 2mg\sin\theta_3 + V\sqrt{mk}$$

最大摩擦力をこえない

$$f_{\max} < \mu mg\cos\theta_3 \qquad\therefore\quad \mu > 2\tan\theta_3 + \frac{V}{g\cos\theta_3}\sqrt{\frac km}$$

「すべらない条件」は、必要な静止摩擦力が最も大きくなる瞬間を探して \(\mu N\) と比べるのが定石です。

アニメーションで確かめよう：右のグラフの摩擦力が、点線の \(\mu N\) に届かなければ A はベルトに乗ったまま。\(\mu\) を条件より小さくすると、A がベルトに対してすべり出します。
