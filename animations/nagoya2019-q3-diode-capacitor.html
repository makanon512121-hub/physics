ダイオードとコンデンサーの回路：動作点・充電・電荷の再分配（名古屋大学 2019年 第3問）

折れ線の特性をもつダイオードを含む回路で、電圧と電流を「回路の式（負荷直線）」と「素子の特性」の交点として求めます。後半は直列コンデンサーの充電、スイッチを切りかえた後の電荷の再分配と、抵抗で失われるエネルギーを、電流の流れ・I–V グラフ・電圧のグラフ・エネルギーの棒グラフで確かめます。

問題文は 名古屋大学の公式ページ（試験問題・解答例等） で確認してください。図と解説はこのサイトのオリジナルです。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。図の色：ダイオード（赤）、C₁（青）、C₂（紫）、C₃（緑）、電流（オレンジの点の流れ）。

⑴　S₁ を閉じたときの VD と ID答 \(V_\mathrm D=\dfrac34V,\ \ I_\mathrm D=\dfrac{V}{4R}\)

S₂ が開いているので、電流は「電池 → R₁ → D → 電池」の1本の道だけを流れます。

キルヒホッフの第2法則（電池 → R₁ → D の閉回路）

$$V=R\,\cfr{I_\mathrm D}+\cfrc{V_\mathrm D}$$

ダイオードの特性（式①，ON の区間 \(V_\mathrm D>\frac V2\) と仮定）

$$I_\mathrm D=\frac{2V_\mathrm D-V}{2R}$$

①を代入すると \(V=V_\mathrm D-\dfrac V2+V_\mathrm D\) なので \(V_\mathrm D=\dfrac34V\)、\(I_\mathrm D=\dfrac{V}{4R}\) です。\(\frac34V>\frac12V\) なので、ON と仮定したことと合っています。

着眼点：グラフの交点（動作点）として読む

回路の式を \(I_\mathrm D=\dfrac{V-V_\mathrm D}{R}\) と書くと、I–V グラフ上の右下がりの直線（負荷直線）になります。ダイオードの特性の折れ線との交点が、実際の電圧と電流です。

式の立て方：非直線の素子があるときは、(1) 素子以外の部分でキルヒホッフの法則を書き、(2) 素子の特性と連立します。特性が場合分けされているときは、どちらかの区間を仮定して解き、最後に仮定が正しいか確かめます。
アニメーションで確かめよう：左下の I–V グラフで、オレンジの負荷直線と赤い特性の交点（●）が \(V_\mathrm D=\frac34V\) にあります。
⑵　S₂ を閉じた瞬間に ID = 0 となる抵抗値 X答 \(X=R\)

閉じた瞬間、C₁ と C₂ には電荷がないので電圧も 0 です。つまりその瞬間だけ、コンデンサーは導線と同じはたらきをし、R₂ の右端の電位は 0 になります。

\(I_\mathrm D=0\)（ダイオードが OFF）なら、電流は R₁ と R₂ を直列に流れ、D の電圧は R₂ の電圧と同じです。

抵抗の直列接続（電圧は抵抗値に比例して分かれる）

$$\cfrc{V_\mathrm D}=\frac{R_2}{R+R_2}V$$

ダイオードが OFF の条件

$$\frac{R_2}{R+R_2}V\le\frac V2\qquad\therefore\ R_2\le R$$

よって \(X=R\) です。

着眼点：負荷直線が下がる

R₂ を並列につなぐと、D から見た回路は「起電力 \(\dfrac{R_2}{R+R_2}V\)、内部抵抗 \(\dfrac{RR_2}{R+R_2}\) の電池」と同じになります。R₂ が小さいほど負荷直線の切片が左に下がり、\(V_\mathrm D=\frac V2\) を下回ると交点が \(I_\mathrm D=0\) の水平部分に移ります。

式の立て方：スイッチを入れた「瞬間」のコンデンサーは、直前と同じ電荷（ここでは 0）をもつ電池として扱います。電荷 0 なら導線、十分時間がたった後は電流 0 の断線として扱います。
アニメーションで確かめよう：設定の \(R_2/R\) を 1 より小さくすると、S₂ を閉じた瞬間に D の電流（赤い線）が 0 に落ちます。コンデンサーが充電されて電圧が上がると、やがて D に再び電流が流れ始めます。
⑶ (ア)(イ)　時刻 t₁ の C₁ の電荷と C₂ の電圧答 (ア) \(\dfrac15CV\)　(イ) \(\dfrac1{10}V\)

コンデンサーの電荷（\(Q=CV\)）

$$\cacc{Q_1}=C\cdot\frac V5=\frac15CV$$

C₁ の下の極板と C₂ の上の極板をつなぐ導線は、どこにもつながっていない孤立した部分です。はじめ電荷 0 なので、ずっと合計 0 のままです。よって C₂ の上の極板には \(+Q_1\) があり、C₂ の電荷も \(Q_1\) です。

電気量保存（孤立した部分）と \(V=Q/C\)

$$\cfic{V_2}=\frac{Q_1}{2C}=\frac1{10}V$$
式の立て方：直列のコンデンサーは「間の孤立部分の電気量 ＝ 一定」から電荷が等しくなります。電圧は電荷 ÷ 電気容量なので、容量の大きい C₂ の電圧は C₁ の半分です。
アニメーションで確かめよう：S₂ を閉じると C₁ と C₂ の極板に同じ数の ＋・− が増えていきます。右下のグラフで、青（C₁）がいつも紫（C₂）の2倍の電圧になっています。
⑶ (ウ)　時刻 t₁ に R₂ を流れる電流答 \(\dfrac{9V}{50R}\)

R₂ の電流を \(I\) とします。分かれ道（D の上の点）でキルヒホッフの第1法則を使うと、R₁ を流れる電流は \(I_\mathrm D+I\) です。

キルヒホッフの第2法則（D → R₂ → C₁ → C₂ の閉回路）

$$\cfrc{V_\mathrm D}=2R\,\cfr{I}+\frac V5+\frac V{10}$$

キルヒホッフの第2法則（電池 → R₁ → D の閉回路）

$$V=R(I_\mathrm D+\cfr{I})+\cfrc{V_\mathrm D}$$

①より \(RI_\mathrm D=V_\mathrm D-\dfrac V2\) なので、2つ目の式は \(2V_\mathrm D+RI=\dfrac32V\) になります。1つ目の \(V_\mathrm D=2RI+\dfrac3{10}V\) を入れて

$$5RI=\frac32V-\frac35V=\frac9{10}V\qquad\therefore\ I=\frac{9V}{50R}$$

このとき \(V_\mathrm D=\dfrac{33}{50}V>\dfrac V2\) なので、ダイオードは ON のままです。

式の立て方：未知数（\(I,\ I_\mathrm D,\ V_\mathrm D\)）の数だけ式を集めます。第1法則で電流の文字を減らし、第2法則は「独立な閉回路の数」だけ書きます。コンデンサーは、そのときの電圧をもつ電池と考えます。
アニメーションで確かめよう：\(t_1\) で一度止まります。I–V グラフでは、負荷直線（C₁・C₂ の電圧 \(\frac3{10}V\) が入った形）と特性の交点が \(V_\mathrm D=\frac{33}{50}V\) にあります。「いまの値」の R₂ の電流が \(0.18\,V/R\) です。
⑶ (エ)(オ)　C₁ と C₂ の合成容量と、蓄えられたエネルギー答 (エ) \(\dfrac23C\)　(オ) \(\dfrac3{100}CV^2\)

直列接続の合成容量

$$\frac1{C_{12}}=\frac1C+\frac1{2C}\qquad\therefore\ C_{12}=\frac23C$$

電荷 \(\frac15CV\) と全体の電圧 \(\frac V5+\frac V{10}=\frac3{10}V\) の比をとっても \(\frac23C\) になります。

静電エネルギー（\(U=\frac12CV^2\)）

$$\cfic{U_{12}}=\frac12C\Bigl(\frac V5\Bigr)^2+\frac12\cdot2C\Bigl(\frac V{10}\Bigr)^2\nobreak=\frac3{100}CV^2$$

合成容量を使って \(\frac12\cdot\frac23C\cdot\bigl(\frac3{10}V\bigr)^2\) と計算しても同じです。

式の立て方：直列は「電荷が共通」、並列は「電圧が共通」と覚え、共通なものを使って合成容量やエネルギーを計算します。
アニメーションで確かめよう：右下の棒グラフで、C₁ と C₂ のエネルギーの比が 2 : 1 になっています（電荷が同じなら \(U=Q^2/2C\) は容量に反比例）。
⑶ (カ)　十分に時間がたった後の C₃ の電圧答 \(\dfrac{3}{40}V\)

S₂ を開くと、C₁・C₂・R₃・C₃ は電池から切り離された閉じた回路になります。C₁C₂（容量 \(\frac23C\)、電荷 \(\frac15CV\)）から C₃ へ電荷が移り、電流が 0 になると両者の電圧が等しくなります。この値を \(V'\) とします。

電気量保存（上側の極板の合計）

$$\frac15CV+0=\frac23C\,V'+2C\,\cgrav{V'}\qquad\therefore\ V'=\frac{3}{40}V$$

C₁ と C₂ の間の孤立部分は合計 0 のままなので、C₁C₂ はこの後も1つの \(\frac23C\) のコンデンサーとして扱えます。C₁C₂ と C₃ は並列（電圧が同じ）になり、全体の容量は \(\frac23C+2C=\frac83C\) です。

式の立て方：スイッチの切りかえ後は、(1) 孤立した導体部分ごとに「電気量の合計 ＝ 切りかえ前の値」、(2) 最終状態では電流 0 なので「抵抗の電圧 0 → つながったコンデンサーの電圧が等しい」を使います。
アニメーションで確かめよう：S₃ を閉じると、R₃ を通って電流が流れ、緑（C₃）の電圧が上がり、青・紫の合計（C₁C₂）が下がって \(\frac3{40}V\) でそろいます。
⑶ (キ)　t₁ から t₂ の間に R₃ で消費されたエネルギー答 \(\dfrac{9}{400}CV^2\)

この間、電池はつながっていないので、静電エネルギーの減少分がすべて R₃ のジュール熱になります。

エネルギー保存則

$$\cfr{W}=\frac3{100}CV^2-\frac12\cdot\frac83C\Bigl(\frac3{40}V\Bigr)^2\nobreak=\frac3{100}CV^2-\frac3{400}CV^2\nobreak=\frac9{400}CV^2$$

着眼点：R₃ の値によらない

R₃ を変えると電流の大きさと流れる時間は変わりますが、失われるエネルギーは変わりません。一般に、電圧 \(V_0\) の容量 \(C_a\) を電荷 0 の \(C_b\) につなぐと、失われるエネルギーは \(\dfrac12\cdot\dfrac{C_aC_b}{C_a+C_b}V_0^{\,2}\) です。ここでは \(C_a=\frac23C,\ C_b=2C,\ V_0=\frac3{10}V\) で \(\frac9{400}CV^2\) となり、一致します。

式の立て方：抵抗で失われるエネルギーは、電流を時間で積分しなくても「はじめのエネルギー − 終わりのエネルギー（＋電池がした仕事）」で求められます。
アニメーションで確かめよう：棒グラフで、C₁C₂ のエネルギーが減り、C₃ のエネルギーと R₃ のジュール熱（電流の2乗 × 抵抗を時間で足したもの）に分かれます。設定の \(R_3/R\) を変えると、電流のグラフの形は変わっても、ジュール熱の最終値は \(\frac9{400}CV^2\) のままです。
