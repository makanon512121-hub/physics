積木の単振動と摩擦：ばね・粗い床・積木くずし（東京大学 2017年 第1問）

同じ直方体の積木を使った3つの場面です。ばねにつるした積木の単振動、粗い床に乗るほど摩擦力が大きくなるために起こる単振動、積み重ねた積木の1本を引き抜くときの最大静止摩擦力を調べます。どれも「力を正しく数え、運動方程式やつり合いの式に入れる」ことが中心です。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。色は図と式で共通です：変位・加速度・動く積木（青）、重力・垂直抗力（緑）、ばねの力・張力・引く力（オレンジ）、摩擦力（赤）、振動の中心（紫）。

I(1)　ばねの最大の伸び答 \(\dfrac{2Mg}{k}\)

振動の中心は「つり合いの位置」

重力があっても、ばね振り子は力がつり合う位置を中心とする単振動をします。その位置の伸びを \(x_{\rm c}\) とします。

力のつり合い（中心）

$$\cfr{k\,x_{\rm c}}=\cgrav{Mg}\qquad\therefore\ \cfic{x_{\rm c}}=\frac{Mg}{k}$$

放した位置 \(x=0\) は速さが 0 なので振動の端です。単振動は中心について対称なので、反対側の端は中心からさらに \(x_{\rm c}\) 進んだ所です。

$$x_{\max}=2\cfic{x_{\rm c}}=\frac{2Mg}{k}$$

別解：力学的エネルギー保存則

いちばん下でも速さは 0 です。放した位置といちばん下で、エネルギーを比べます。

力学的エネルギー保存則

$$0=-\cgrav{Mg\,x_{\max}}+\cfr{\frac12k\,x_{\max}^{\,2}}\qquad\therefore\ x_{\max}=\frac{2Mg}{k}\quad(x_{\max}\neq0)$$

重力がした仕事 \(Mgx_{\max}\) が、すべてばねの弾性エネルギーになっています。

式の立て方：単振動の振幅は「速さ 0 の位置（放した点）と中心の距離」です。中心は合力が 0 になる位置なので、まずつり合いの式で中心を出します。重力などの一定の力は中心をずらすだけで、周期は変えません。
アニメーションで確かめよう：積木は紫の破線（つり合いの位置）を中心に、0 から \(2x_{\rm c}\) までを往復します。下のエネルギーの棒グラフで、緑（重力がした仕事）とオレンジ（ばねのエネルギー）がいちばん下で等しくなります。\(M\) や \(k\) を変えても、最大の伸びはいつも中心の2倍です。
I(2)　積木の加速度答 ア \(-\dfrac kM\)，イ \(\dfrac{Mg}k\)

変位 \(x\) の位置で、積木には下向きに重力 \(Mg\)、上向きにばねの力 \(kx\) がはたらきます。

運動方程式（下向き正）

$$M\cacc{a}=\cgrav{Mg}-\cfr{kx}\qquad\therefore\ \cacc{a}=-\frac kM\Bigl(\cacc{x}-\cfic{\frac{Mg}k}\Bigr)$$

着眼点：a = −ω²(x − 中心) の形

運動方程式をこの形に整理すると、2つのことが同時に読めます。かっこの中で引いている \(\dfrac{Mg}{k}\) が振動の中心、前の係数が \(\omega^2=\dfrac kM\) です。周期は \(2\pi\sqrt{\dfrac Mk}\) で、重力があってもなくても同じです。

式の立て方：単振動の問題では、運動方程式を \(a=-K(x-x_{\rm c})\) の形にまとめます。\(K=\omega^2\) から周期、\(x_{\rm c}\) から中心が分かり、初めの条件（どこで速さ 0 か）と合わせれば運動がすべて決まります。
アニメーションで確かめよう：右の a–x グラフで、点は傾き \(-\dfrac kM\) の直線の上を往復し、紫の点（\(x=\dfrac{Mg}k\)）で \(a=0\) になります。\(k\) を大きくすると直線が急になり、周期が短くなります。
II(1)　積木1の加速度答 ウ \(-\dfrac{\mu'g}{6L}\)，エ \(\dfrac{3L\sin\theta}{\mu'}\)

なぜ摩擦力が x に比例するのか

積木1の重さ \(Mg\) は底面 \(3L\) に一様にかかります。粗い床に乗っているのは底面の \(\dfrac{x}{3L}\) だけなので、その部分が受ける垂直抗力は \(\dfrac{x}{3L}Mg\) です。動摩擦力はその \(\mu'\) 倍なので

動摩擦力 ＝ μ′ × 垂直抗力

$$\cfrc{f}=\mu'\cdot\cgrav{\frac{x}{3L}Mg}$$

2つの積木の運動方程式

ひもの張力を \(T\) とします。ひもでつながった2つの積木は、同じ大きさの加速度 \(a\) で動きます。

運動方程式（積木1：右向き正，積木2：斜面下向き正）

$$M\cacc{a}=\cfr{T}-\cfrc{f},\qquad M\cacc{a}=\cgrav{Mg\sin\theta}-\cfr{T}$$

2式を足すと \(T\) が消えます。

$$2M\cacc{a}=\cgrav{Mg\sin\theta}-\cfrc{\frac{x}{3L}\mu'Mg}\qquad\therefore\ \cacc{a}=-\frac{\mu'g}{6L}\Bigl(\cacc{x}-\cfic{\frac{3L\sin\theta}{\mu'}}\Bigr)$$

着眼点

摩擦力が位置に比例するので、ばねと同じ「戻す力」になります。中心は摩擦力が斜面方向の重力と等しくなる位置 \(\mu'\dfrac{x}{3L}Mg=Mg\sin\theta\) です。また \(T=\dfrac12Mg\sin\theta+\dfrac{x}{6L}\mu'Mg>0\) なので、運動中にひもはたるみません。

式の立て方：ひもでつながった物体は、まず物体ごとに運動方程式を立てて足し、張力（内力）を消します。「全体の質量 × a ＝ 外から引く力の和」と同じ式になります。摩擦力のように位置で変わる力は、垂直抗力が位置でどう変わるかから求めます。
アニメーションで確かめよう：積木1の底面のうち、粗い床に乗った部分（赤い斜線）が増えるほど摩擦力の矢印が長くなります。下の右のグラフで、赤い直線（摩擦力）と緑の水平線（\(Mg\sin\theta\)）が交わる点が振動の中心です。
II(2)　動き始めてから止まるまでの時間答 \(\pi\sqrt{\dfrac{6L}{\mu'g}}\)

(1) の形から、積木1は中心 \(\dfrac{3L\sin\theta}{\mu'}\)、角振動数 \(\omega\) の単振動の一部をします。

単振動の角振動数

$$\omega=\sqrt{\frac{\mu'g}{6L}}$$

速さ 0 で放した \(x=0\) は振動の端です。次に速さが 0 になるのは反対側の端で、ここまでが半周期です。

$$t_0=\frac{\pi}{\omega}=\pi\sqrt{\frac{6L}{\mu'g}}$$

反対側の端で止まったあとは、動摩擦力が静止摩擦力に変わるので単振動は続きません。止まった位置で \(\mu'\dfrac{x_0}{3L}Mg=2Mg\sin\theta>Mg\sin\theta\) なので、静止摩擦係数が \(\mu'\) 以上なら再び動き出すことはありません。

式の立て方：「速さ 0 → 速さ 0」の時間は半周期、「端 → 中心」は4分の1周期です。単振動の一部だけを使う問題では、運動がどこから始まり、どこで終わるかを中心と端の位置で確認します。
アニメーションで確かめよう：下の左の x–t グラフは、なめらかな S 字（コサインの半分）になります。止まるまでの時間は \(\theta\) によらず、\(\mu'\) を大きくすると短くなります。
II(3)　ちょうど x₀ = 3L で止まる条件答 \(\mu'=2\sin\theta\)

止まる位置は、中心について \(x=0\) と対称な端です。

単振動の対称性（端 ＝ 中心 × 2）

$$\cacc{x_0}=2\times\cfic{\frac{3L\sin\theta}{\mu'}}=\frac{6L\sin\theta}{\mu'}=3L\qquad\therefore\ \mu'=2\sin\theta$$

着眼点：x₀ が 3L を超えるとどうなるか

\(\mu'<2\sin\theta\) だと、積木1は \(x=3L\) を超えます。そこから先は底面全体が粗い床に乗るので、摩擦力は \(\mu'Mg\) で一定になり、運動は単振動ではなくなります（加速度一定）。さらに \(\mu'<\sin\theta\) なら減速せずに進み続けます。問題文の「\(x_0\le3L\)」は、単振動の式が最後まで使える範囲を指定しています。

式の立て方：力の式が場合で変わるとき（ここでは \(x\le3L\) と \(x>3L\)）は、求めた答えが前提の範囲に入っているかを最後に確かめます。
アニメーションで確かめよう：はじめは \(\mu'=2\sin\theta\) にしてあり、積木1の左端がちょうど粗い床の端に乗ったところで止まります。\(\mu'\) を少し下げると、右のグラフで摩擦力の線が \(x=3L\) で折れて水平になり、止まる位置が大きくずれます。
III(1)　引き抜く直前の力答 \(5\mu_1Mg\)

各面の垂直抗力は「上に乗っている重さ」

面に加わる力は一様なので、真ん中の積木 A の上面（面積 \(3L^2\)）には、上の2段（重さ \(6Mg\)、底面積 \(9L^2\)）の \(\dfrac{3L^2}{9L^2}\) が乗ります。下面には自分の重さも加わります。

垂直方向の力のつり合い

$$\cgrav{N_2}=6Mg\times\frac13=2Mg,\qquad \cgrav{N_1}=\cgrav{N_2}+Mg=3Mg$$

動き出す直前、A の上面と下面の静止摩擦力はどちらも最大になっています。

力のつり合い（引く向き）＋最大静止摩擦力 \(\mu N\)

$$\cfr{F}=\cfrc{\mu_1N_2}+\cfrc{\mu_2N_1}=2\mu_1Mg+3\mu_1Mg=5\mu_1Mg\quad(\mu_2=\mu_1)$$

補足：摩擦力は接触面積によらない

A の上面は3本の積木とそれぞれ \(L^2\) ずつ接していますが、最大静止摩擦力は面ごとの垂直抗力の和 \(N_2\) だけで決まります。面積が半分になれば単位面積あたりの垂直抗力が2倍になるので、合計は変わりません。

着眼点：ほかの動き方と比べる

A だけが動くのは、それが最も小さい力で起こる動き方だからです。A が上の2段ごと動く（2段目が両側の積木の上をすべる）には \(4\mu_1Mg+3\mu_2Mg=7\mu_1Mg\)、全体が動くには \(9\mu_2Mg=9\mu_1Mg\) が必要です。

式の立て方：積み重ねた物体の摩擦では、①各面の垂直抗力を「その面より上の重さ」から求め、②動く物体が接するすべての面で最大静止摩擦力 \(\mu N\) を足します。
アニメーションで確かめよう：引く力 \(F\)（オレンジ）を少しずつ増やします。下の棒グラフの中で最も低い棒に \(F\) が届いた瞬間、その動き方が起こります。\(\mu_2/\mu_1\) を小さくすると、全体がすべる方が先になります（\(\mu_2<\dfrac13\mu_1\)）。
III(2)　2本が同時に動く μ₂ の条件答 オ \(\dfrac16\mu_1\)

今度は1段目と2段目が同じ向きなので、A の上の B は A といっしょに動けます。A と B がいっしょにすべり出すとき、すべる面は「B と3段目の間」と「A と床の間」です。

垂直抗力（上に乗っている重さ）

$$\cgrav{N_3}=Mg\ \ (\text{B の上面}),\qquad \cgrav{N_1}=3Mg\ \ (\text{A の下面})$$

動かない部分が持ちこたえる条件

3段目の積木は B から前向きに \(\mu_1N_3=\mu_1Mg\) の摩擦力を受けます。A、B 以外の積木（3段目と両側の柱）をひとまとまりと見ると、これを止めているのは床と両側の1段目 E、E′ の間の静止摩擦力だけで、その最大値は \(2\mu_2\cdot3Mg\) です。

力のつり合い（動かない部分）＋最大静止摩擦力

$$\cfrc{\mu_1N_3}<2\,\cfrc{\mu_2\cdot3Mg}\qquad\therefore\ \mu_2>\frac16\mu_1$$

実際には摩擦力は両側で半分ずつ、\(f_1'=\dfrac12\mu_1Mg\) が E と床の間にはたらきます。途中の面（C と D、D と E）の静止摩擦力も同じ \(\dfrac12\mu_1Mg\) で、どれも最大値より小さいので、そこではすべりません。

別解：起こりうる動き方をすべて比べる

A を引いたときに起こりうる動き方と、それに必要な力（動く部分が接する面の最大静止摩擦力の和）は次の通りです。

$$\begin{aligned}&\text{A だけ}&&2\mu_1Mg+3\mu_2Mg\\&\text{A と B}&&\mu_1Mg+3\mu_2Mg\\&\text{A, B と3段目}&&2\mu_1Mg+3\mu_2Mg\\&\text{全体}&&9\mu_2Mg\end{aligned}$$

「A と B」は上の3つの中でいつも最小なので、残るのは全体との比較だけです。\(\mu_1+3\mu_2<9\mu_2\) から同じ \(\mu_2>\dfrac16\mu_1\) が得られます。

式の立て方：どこがすべるか分からないときは、①動く部分の候補を挙げ、②それぞれに必要な力を最大静止摩擦力の和で求め、③最も小さい力のものが先に起こると判断します。もう1つの方法は、動かない部分のつり合いで「静止摩擦力 ＜ 最大静止摩擦力」を確かめることです。
アニメーションで確かめよう：右の断面図の目盛りは、各面の静止摩擦力が最大値の何割かを表します。\(\mu_2/\mu_1\) を \(\dfrac16\) より小さくすると、床と E の間の目盛りが先にいっぱいになり、積木全体がすべります。
