光ピンセット：光の運動量で微粒子をつかむ（東京大学 2021年 第3問）

光は運動量をもつ光子の流れです。透明な微粒子を通り抜けるとき、屈折で光の向きが変わると光の運動量が変わり、その反作用で微粒子が力を受けます。屈折の法則 → 運動量の変化 → 作用・反作用 → 力のつり合いの順に、2本の光で微粒子が光の交点に引き寄せられるしくみを確かめます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。微粒子の屈折率 \(n\)、半径 \(r\)、光線1本が単位時間に運ぶエネルギー \(Q\)、光速 \(c\) です。アニメーションの力は、光線を近似なしで追跡して計算しています。

I(1)　入射角と屈折角の関係答 \(\sin\theta = n\sin\phi\)

真空（屈折率 1）から屈折率 \(n\) の物質へ入るときの屈折の法則です。

$$1\cdot\sin\cfrc{\theta} = n\sin\cacc{\phi}$$

球の中では、入射点 A と射出点 B がどちらも中心 O から距離 \(r\) にあるので、三角形 OAB は二等辺三角形です。よって B での入射角（球の内側から）も \(\phi\)、B から出る角も \(\theta\) になります。入るときと出るときで同じ角度の組が現れるのが球の特徴です。

式の立て方：屈折は必ず「境界面の法線」からの角度で考えます。球の場合、法線は中心を通る直線（半径の延長）です。
アニメーションで確かめよう：\(D/r\)（光線と中心のずれ）を大きくすると \(\theta\) が大きくなり、\(\theta-\phi\) も大きくなります。下のグラフは \(\theta\) と \(\phi\) の変化です。\(n=1\) にすると曲がらなくなります。
I(2)　時間 \(\Delta t\) に出た光の運動量答 \(p = \dfrac{Q\Delta t}{c}\)

時間 \(\Delta t\) に光源から出るエネルギーは \(E = Q\Delta t\) です。光の集まりでは \(p = \dfrac{E}{c}\) なので

$$\cacc{p} = \frac{Q\Delta t}{c}$$

\(n\) は使いません。問われているのは真空中での運動量で、ここでは球に入る前と出た後の光だけを比べるためです。

式の立て方：光の力の問題は「単位時間あたりのエネルギー \(Q\) → 単位時間あたりの運動量 \(Q/c\)」を最初に作ります。単位時間あたりの運動量の変化が、そのまま力になります。
アニメーションで確かめよう：入射光の上に、時間 \(\Delta t\) の間に出た光の集まり（長さ \(c\Delta t\)）を青で示しています。下の図の青い矢印がその運動量 \(p\) です。
I(3)　光が受ける運動量の変化答 \(\Delta p = 2p\sin(\theta-\phi)\)，向きは C → O

向きが変わる角度を求める

A で光は \(\theta-\phi\) だけ曲がり、B でも同じ向きにさらに \(\theta-\phi\) 曲がります。合計の曲がり角は \(2(\theta-\phi)\) です。

大きさが同じで向きだけ変わるベクトルの差

入る前の運動量 \(\vec p_1\) と出た後の \(\vec p_2\) は大きさが同じ \(p\) で、なす角が \(2(\theta-\phi)\) です。2つを始点をそろえて描くと二等辺三角形になり、底辺の長さが変化量です。

$$\cfrc{\Delta p} = |\vec p_2 - \vec p_1| = 2p\sin(\theta-\phi)$$

向きは \(\vec p_2-\vec p_1\) で、二等辺三角形の頂角の二等分線に垂直です。図では入射光と射出光の延長の交点 C から、中心 O に向かう向きになります（OC は ∠ACB の二等分線で、AB に垂直）。

式の立て方：運動量の変化は「後 − 前」のベクトルの引き算です。大きさが等しい2つのベクトルなら、なす角を \(\delta\) として \(|\Delta\vec p| = 2p\sin\frac{\delta}{2}\) です。成分で計算するなら、2つのベクトルの二等分線の方向と、それに垂直な方向に軸をとると、片方の成分が打ち消し合って楽になります。
アニメーションで確かめよう：下の図で \(\vec p_1\)（青）と \(\vec p_2\)（水色の破線）の先端を結ぶ赤い矢印が \(\Delta\vec p\) です。上の図の赤い矢印（C から O へ）と同じ向きです。
I(4)　微粒子が光から受ける力答 \(f = \dfrac{2Q}{c}\sin(\theta-\phi)\)，向きは O → C

光の運動量を変えたのは微粒子です。作用・反作用の法則より、微粒子は光が受けた力積と逆向きで同じ大きさの力積を受けます。単位時間あたりにすると力になります。

$$\cgrav{f} = \frac{\cfrc{\Delta p}}{\Delta t} = \frac{2p\sin(\theta-\phi)}{\Delta t} = \frac{2Q}{c}\sin(\theta-\phi)$$

向きは光の運動量変化（C → O）と逆の O → C です。光が曲がる側と反対側に微粒子は押されます。光は微粒子の中心の方へ曲げられるので、微粒子は光線の方へ引き寄せられます。

式の立て方：「光（や気体分子）が物体から受ける力積」を先に求め、作用・反作用で物体が受ける力にする、という2段階で立てます。単位時間に \(N\) 個ぶつかるなら、力 ＝ \(N\) × 1個あたりの力積 です。
アニメーションで確かめよう：緑の矢印が微粒子が受ける力です。光線を中心から遠ざける（\(D/r\) を大きくする）と力が強くなり、向きはつねに光線の方を向いています。
I(5)　角度が小さいときの力答 \(f \fallingdotseq \dfrac{2(n-1)Qd}{cr}\)

OD は AB に垂直なので、直角三角形 OAD から

$$\sin\phi = \frac{\cfic{d}}{r}$$

角度が小さいとき \(\sin\theta\fallingdotseq\theta,\ \sin\phi\fallingdotseq\phi\) なので、屈折の法則は \(\theta\fallingdotseq n\phi\) です。

$$\sin(\theta-\phi)\fallingdotseq\theta-\phi\fallingdotseq(n-1)\phi\fallingdotseq(n-1)\frac{d}{r}$$ $$f\fallingdotseq\frac{2(n-1)Q\cfic{d}}{cr}$$

力は、中心 O から球の中の光の道すじまでの距離 \(d\) に比例します。光線が中心を通れば \(d=0\) で力は 0、光線が中心からずれるほど力が大きくなります。この比例関係が II・III で微粒子が捕まる理由です。

式の立て方：近似は「どの量が小さいか」を決めてから、すべての角度をその小さい量の1次式で書きます。ここでは \(\phi\) を \(d/r\) で表し、\(\theta\) を \(n\phi\) で表して1つの小さい量にそろえました。
アニメーションで確かめよう：下のグラフは、近似なしの力（実線）と近似式（破線）を \(d/r\) に対して描いたものです。\(d/r\) が小さい範囲で一致し、大きくなるとずれます。
II(1)　中心 O が交点 F に一致するとき答 力は働かない

2本の光線はどちらも中心 O を通ります。中心を通る光線は球面に垂直に入射し（入射角 0）、曲がらずにまっすぐ抜けます。運動量が変わらないので、微粒子は力を受けません。

I(5) の言葉でいえば、どちらの光線も \(d=0\) です。

II(2)　中心 O が交点 F の下にあるとき答 上

I(4) より、それぞれの光線から受ける力は、中心 O からその光線の道すじの方へ向かう向き（O → C）です。O が F より下にあると、左下から来る光線は O の左上側を、右下から来る光線は O の右上側を通ります。

左の光線からの力は左上向き、右の光線からの力は右上向きで、大きさは等しいです。水平成分は打ち消し合い、上向きの成分が残ります。合力は上、つまり F に近づく向きです。

式の立て方：複数の力の合力は、対称性で打ち消し合う成分を先に見つけます。左右対称な配置なら、水平成分が消えて鉛直成分だけが残ります。
アニメーションで確かめよう：細い緑の矢印が各光線からの力、太い矢印が合力です。\(\Delta y\) を負にする（O を F の上にする）と、合力は下向き（やはり F の方）になります。微粒子はどちらにずれても F に引き戻されます。
II(3)　合力の大きさとずれ \(\Delta y\) の関係答 イ（\(\Delta y\) に比例する）

I(5) より、1本の光線からの力は \(d\) に比例します。\(d\) は「O から光の道すじまでの距離」で、ずれ \(\Delta y\) が小さいとき \(\Delta y\) に比例します（O が F と一致すれば \(d=0\)、\(\Delta y\) を2倍にすれば光線との距離も2倍）。合力はその鉛直成分の和なので、やはり \(\Delta y\) に比例します。

実際に計算すると、光線が鉛直となす角を \(\alpha\) として、O から各光線（の延長）までの距離は \(\Delta y\sin\alpha\) なので、1本あたり \(f = \dfrac{2(n-1)Q\sin\alpha}{ncr}\Delta y\)、その鉛直成分は \(f\sin\alpha\) です。

$$f' = \frac{4(n-1)Q\sin^2\alpha}{ncr}\,\Delta y$$
式の立て方：比例・反比例を問われたら、因果の鎖（ずれ → 距離 \(d\) → 力 \(f\) → 合力 \(f'\)）の各段階が比例かどうかを確認します。全部比例なら最後も比例です。
アニメーションで確かめよう：下のグラフは合力の鉛直成分（近似なし）を \(\Delta y\) に対して描いたものです。原点付近では直線（破線の近似式）に乗っていて、ばねのような復元力になっています。
III(1)　垂線の長さ \(h\) と \(d\)答 \(h = \Delta x\cos\alpha\)，\(d = \dfrac{1}{n}\Delta x\cos\alpha\)

\(h\)：直線と点の距離

直線 AF は鉛直と角 \(\alpha\) をなし、OF は水平で長さ \(\Delta x\) です。O から直線 AF に下ろした垂線は、OF と角 \(\alpha\) をなす（直線 AF の向きは水平と \(90^\circ-\alpha\)）ので

$$\cfr{h} = \Delta x\cos\alpha$$

\(d\)：屈折の法則につなぐ

\(h\) は「入射光をまっすぐ延ばした直線」と O の距離なので、A での入射角 \(\theta\) について \(h = r\sin\theta\)。\(d\) は「球の中の光の道すじ」と O の距離なので \(d = r\sin\phi\) です。屈折の法則 \(\sin\theta = n\sin\phi\) から

$$\cfic{d} = \frac{h}{n} = \frac1n\Delta x\cos\alpha$$
式の立て方：球（円）と直線の問題では「中心から直線までの距離 ＝ \(r\sin\)（入射角）」が強力です。入射前の直線には \(\theta\)、球の中の直線には \(\phi\) が対応し、屈折の法則がそのまま距離の比 \(h:d = n:1\) になります。
アニメーションで確かめよう：オレンジの線分が \(h\)、紫の線分が \(d\) です。\(n\) を変えると \(d\) だけが変わり、\(h/d\) がつねに \(n\) になります。
III(2)　2本の光線からの合力 \(f'\)答 \(f' = \dfrac{4(n-1)Q}{ncr}\Delta x\cos^2\alpha\)

I(5) の式に III(1) の \(d\) を入れると、光線1本からの力の大きさは

$$f_1 = \frac{2(n-1)Q}{cr}\cdot\frac{\Delta x\cos\alpha}{n}$$

向きは光線（の延長）に垂直な向きからわずか \(\theta-\phi\) だけ傾いた向きで、近似ではそれを無視して光線に垂直と考えます。光線は鉛直と \(\alpha\) をなすので、力は水平と \(\alpha\) をなします。2本の力の鉛直成分は打ち消し合い、水平成分 \(f_1\cos\alpha\) が2つ足されます。

$$\cgrav{f'} = 2f_1\cos\alpha = \frac{4(n-1)Q}{ncr}\Delta x\cos^2\alpha$$

向きは F の方（左）で、ずれ \(\Delta x\) に比例する復元力です。これが外力 \(f_0\) とつり合います。

式の立て方：同じ大きさの力が対称に2つあるときは「1本の大きさ × 必要な方向の成分 × 2」で合力を立てます。どの角度が成分に効くかは、力の向き（ここでは光線に垂直）から決めます。
アニメーションで確かめよう：細い緑の矢印が各光線からの力、太い矢印が合力の水平成分です。\(\alpha\) を大きくすると \(\cos^2\alpha\) が小さくなり、合力が弱くなります。光を斜めから当てるほど、水平方向にはつかみにくくなります。
III(3)　外力 \(f_0\) の数値答 \(f_0 \fallingdotseq 1\times10^{-12}\ \rm N\)

微粒子は静止しているので \(f_0 = f'\) です。数値を代入すると

$$f_0 = \frac{4\times(1.5-1)\times5\times10^{-3}}{1.5\times3\times10^{8}\times1\times10^{-5}}\times1\times10^{-6}\times\cos^2 45^\circ = 1.1\times10^{-12}\ \rm N$$

有効数字1桁で \(1\times10^{-12}\ \rm N\) です。1 pN（ピコニュートン）は細菌や細胞の中の分子モーターが出す力と同じくらいの大きさで、光ピンセットはこの大きさの力を測る道具として使われています。

式の立て方：数値計算は、指数部分（\(10^{-3}\times10^{-6}\div(10^{8}\times10^{-5})\)）と係数部分を分けて計算すると間違いにくくなります。
アニメーションで確かめよう：外力 \(f_0\) を変えると、微粒子は \(f_0\) と光の力がつり合う位置まで動いて止まります。初期値の \(f_0 = 1.1\ \rm pN\) で \(\Delta x\) が約 \(1\ \mu\rm m\) になります。\(f_0\) を大きくしすぎると、光の力が追いつかず微粒子が流されます。
