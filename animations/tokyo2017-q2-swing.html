磁場中のブランコ：電磁誘導による減衰・つり合い・共振（東京大学 2017年 第2問）

鉛直上向きの磁場の中で、導体棒をつるしたブランコを振らせます。棒が動くと誘導起電力で電流が流れ、その電流が磁場から受ける力が運動を変えます。電源なし・直流電源・交流電源の3つの場合で、回路の式と運動方程式がどう組み合わさるかを見ていきます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。左の図は導体棒の向きから見たブランコです（棒は紙面に垂直）。色は図と式で共通です：角度・速度（青）、重力（緑）、電流が磁場から受ける力（オレンジ）、電流・ジュール熱（赤）、誘導起電力・電源の電圧（紫）。

I(1)　θ = 0 を速さ v で通るときの電流答 \(I_1=\dfrac{vBL}{R}\)

起電力を生むのは「磁場を横切る速度」

導体棒が磁場を横切ると、棒の中の電荷がローレンツ力を受けて起電力が生じます。磁場は鉛直なので、起電力に効くのは速度の水平成分だけです。\(\theta=0\) では速度がちょうど水平です。

誘導起電力（磁場に垂直な速度成分 × B × 長さ）

$$\cfic{V}=\cacc{v}BL$$

キルヒホッフの第2法則

$$\cfic{vBL}=R\,\cfrc{I_1}\qquad\therefore\ \cfrc{I_1}=\frac{vBL}{R}$$

角度 \(\theta\) の位置では、速度の水平成分は \(v\cos\theta\) なので起電力は \(vBL\cos\theta\) です。

式の立て方：動く導体棒は「起電力 \(v_\perp BL\) の電池」に置きかえます（\(v_\perp\) は磁場に垂直な速度成分）。あとは普通の回路と同じく、閉じた回路を1周して「起電力の和 ＝ 電圧降下の和」を書きます。
アニメーションで確かめよう：右の回路図で、棒は紫の電池として描かれ、その電圧 \(vBL\cos\theta\) は速さとともに変わります。最下点を通るたびに電流（赤い矢印）が最大になり、往きと帰りで向きが逆になります。
I(2)　止まるまでに発生するジュール熱答 \(Q=Mgl(1-\cos\alpha)\)

電流が流れると、棒は磁場から運動を妨げる向きの力を受け、力学的エネルギーが減っていきます。減った分はすべて抵抗のジュール熱になります。

エネルギー保存則（力学的エネルギーの減少 ＝ ジュール熱）

$$\cfrc{Q}=\underbrace{Mgl(1-\cos\alpha)}_{\text{はじめ}}-\underbrace{0}_{\text{最後（最下点で静止）}}=Mgl(1-\cos\alpha)$$

着眼点：電磁力の仕事率 ＝ ジュール熱の発生率

棒が受ける力 \(IBL\) の、速度の向きの成分は \(IBL\cos\theta\) です。この力が1秒あたりにする負の仕事は \(IBL\cos\theta\cdot v=I\cdot(vBL\cos\theta)=I\cdot RI=RI^2\) となり、ジュール熱の発生率とちょうど等しくなります。電磁誘導は、運動エネルギーを電気エネルギーに変える変換器です。

式の立て方：過程の途中が複雑でも、はじめと終わりの状態が分かればエネルギー保存則で熱量が出せます。「力学的エネルギー ＋ 発生した熱 ＝ 一定」と書きます。
アニメーションで確かめよう：下の右の棒グラフで、緑（力学的エネルギー）が減った分だけ赤（ジュール熱の合計）が増え、2つの和はいつも一定です。
I(3)　抵抗を 2R にすると、振幅が半分になるまでの時間は答 ア（長くなる）

同じ速さで動いているとき、抵抗を大きくすると電流 \(\dfrac{vBL\cos\theta}{R}\) が小さくなり、運動を妨げる力も小さくなります。

ジュール熱の発生率（同じ速さ v で比べる）

$$\cfrc{RI^2}=\frac{(vBL\cos\theta)^2}{R}\qquad\Rightarrow\qquad R\to2R\ \text{で半分}$$

エネルギーが失われる速さが遅くなるので、振幅が半分になるまでの時間は長くなります。

参考：減衰の式

微小振動では、運動方程式は \(Ml\ddot\theta=-Mg\theta-\dfrac{B^2L^2l}{R}\dot\theta\) です。速度に比例する抵抗力がはたらく減衰振動で、振幅は \(e^{-\gamma t}\)（\(\gamma=\dfrac{B^2L^2}{2MR}\)）で小さくなります。振幅が半分になる時間 \(\dfrac{\ln2}{\gamma}\) は \(R\) に比例し、\(2R\) にすると2倍になります。

式の立て方：電磁誘導による力は、電流 \(I=\dfrac{v_\perp BL}{R}\) を力 \(IBL\) に入れて「速度 × \(\dfrac{B^2L^2}{R}\)」と書けます。速度に比例するブレーキなので、比例係数が大きいほど早く止まります。
アニメーションで確かめよう：抵抗 \(R\) のブランコ（実線）と \(2R\) のブランコ（破線）を同時に放します。下のグラフで、破線の振幅の減り方がゆっくりです。読み取り欄に、振幅が半分になった時刻を表示します。
II(1)　θ = π/4 で静止させる電流答 \(I_2=\dfrac{Mg}{BL}\)

電流が流れる棒は、磁場から水平な力 \(I_2BL\) を受けます（向きは電流と磁場に垂直）。棒にはたらく力は、重力・導線の張力・この力の3つです。

力のつり合い（導線に垂直な方向）

$$\cfr{I_2BL}\cos\frac{\pi}{4}=\cgrav{Mg}\sin\frac{\pi}{4}\qquad\therefore\ \cfrc{I_2}=\frac{Mg}{BL}$$

導線に垂直な方向で書くと、張力が式に入りません。重力と電磁力の合力が導線の方向（\(\tan\theta=\dfrac{I_2BL}{Mg}=1\)）を向く、と考えても同じです。

式の立て方：未知の力（ここでは張力）があるときは、その力に垂直な方向のつり合いを書くと、未知の力を消せます。
アニメーションで確かめよう：オレンジの矢印（\(I_2BL\)）と緑の矢印（\(Mg\)）が同じ長さで、その合力が導線の延長上を向きます。電源の電圧は \(V_0=RI_2\) にしてあります。
II(2)　π/4 のまわりの微小振動の周期答 \(P=2\pi\sqrt{\dfrac{l}{\sqrt2\,g}}\)

振れ幅が小さく電流が \(I_2\) のままとみなせるなら、棒にはたらく重力と電磁力の合力は大きさ \(\sqrt2Mg\)、向きは \(\theta=\dfrac\pi4\) の方向で一定です。これは大きさ \(\sqrt2g\) の見かけの重力と同じです。

見かけの重力 ＋ 単振り子の周期

$$g'=\frac{\sqrt{(Mg)^2+(I_2BL)^2}}{M}=\sqrt2\,g,\qquad P=2\pi\sqrt{\frac{l}{g'}}=2\pi\sqrt{\frac{l}{\sqrt2\,g}}$$

振動の中心は見かけの重力の向き（\(\theta=\dfrac\pi4\)）です。

式の立て方：重力のほかに一定の力（一定の電場や磁場からの力、慣性力など）がはたらくときは、それらの合力を「見かけの重力」にまとめます。周期は \(g\) を \(g'\) に置きかえた式、振動の中心は \(g'\) の向きです。
アニメーションで確かめよう：読み取り欄の「周期（測定）」が \(P\) に一致し、電源なしの周期 \(2\pi\sqrt{l/g}\) より短くなっています。
II(3)　長い時間で見た振動答 イ（π/4 を中心に振動しながら、振幅がゆっくり小さくなる）

(2) では電流を一定としましたが、実際には棒が動くと誘導起電力が加わり、電流が少し変わります。

キルヒホッフの第2法則（電源 \(V_0=RI_2\) あり）

$$V_0-\cfic{v BL\cos\theta}=R\,\cfrc{I}\qquad\therefore\ \cfrc{I}=I_2-\frac{vBL\cos\theta}{R}$$

2項目の「動きによる電流」がつくる力 \(-\dfrac{vB^2L^2\cos\theta}{R}\) は、I と同じく速度に比例して運動を妨げます。振動の中心は \(\dfrac\pi4\) のままで、振幅だけがゆっくり小さくなります。\(\cos^2\dfrac\pi4=\dfrac12\) なので、減衰の速さは I の場合の半分です。

注意：「電流が流れるから熱で減衰する」だけでは不十分

この回路には電源があり、電源も仕事をします。減衰するかどうかは、電流を「電源による一定の電流」と「動きによる電流」に分け、後者が運動を妨げることを確かめて判断します。

式の立て方：電源と誘導起電力が両方ある回路では、電流を足し合わせ（重ね合わせ）で考えます。一定の部分はつり合いの位置を決め、速度に比例する部分は減衰を決めます。
アニメーションで確かめよう：下のグラフは長い時間の θ–t です。\(\dfrac\pi4\)（破線）のまわりで振動し、振幅がゆっくり小さくなります。抵抗 \(R\) を変えると、減衰の速さが変わります。
III(1)　一定振幅のときの誘導起電力答 \(V=\dfrac{2\pi\beta lBL}{T}\cos\dfrac{2\pi t}{T}\)

円弧に沿った速さは \(u=l\dfrac{d\theta}{dt}\) です。

速度 ＝ 半径 × 角速度

$$\cacc{u}=l\frac{d\theta}{dt}=\frac{2\pi\beta l}{T}\cos\frac{2\pi t}{T}$$

誘導起電力（\(\cos\theta\fallingdotseq1\)）

$$\cfic{V}=\cacc{u}BL\cos\theta\fallingdotseq\frac{2\pi\beta lBL}{T}\cos\frac{2\pi t}{T}$$

別解：ファラデーの法則

軸受を結ぶ線・2本の導線・棒で囲まれた面を、鉛直な磁場が貫きます。面を水平面に映した面積は \(Ll\sin\theta\) なので、磁束は \(\Phi=BLl\sin\theta\fallingdotseq BLl\theta\)。時間で微分すると同じ \(V=\dfrac{d\Phi}{dt}\) が得られます。

式の立て方：起電力は「\(v_\perp BL\)」と「\(\dfrac{d\Phi}{dt}\)」のどちらでも書けます。動く棒が1本なら前者、回路の形が変わるなら後者が便利です。
アニメーションで確かめよう：一定振幅になったあと、下の右のグラフで紫の実線（誘導起電力）は \(\theta\) が 0 のとき最大、端で 0 です。θ のグラフより4分の1周期だけずれています。
III(2)　交流電源の電圧の振幅答 \(A=\dfrac{2\pi\beta lBL}{T}\)

一定振幅の振動 \(\theta=\beta\sin\dfrac{2\pi t}{T}\) は、周期 \(T\) がもともとのブランコの周期（\(2\pi\sqrt{l/g}\)）と同じです。つまり重力だけで起こる自由な振動で、棒が磁場から受ける力は 0、電流も 0 です。

キルヒホッフの第2法則（電流 0）

$$\cfic{A\cos\frac{2\pi t}{T}}-\cfic{V}=R\cdot\cfrc{0}\qquad\therefore\ A=\frac{2\pi\beta lBL}{T}$$

電源の電圧が誘導起電力をちょうど打ち消し、回路に電流が流れない状態です。

着眼点：共振で振幅が育つしくみ

放した直後は棒が止まっているので、電源の電圧がそのまま電流を流し、棒を押します。電源の周期がブランコの周期と同じなので、押す向きがいつも速度の向きとそろい、振幅が大きくなります（共振）。振幅が大きくなるほど誘導起電力が電源電圧に近づいて電流が減り、両者が等しくなったところで振幅が一定になります。

式の立て方：一定振幅になった状態（定常状態）では、「その状態がずっと続くには何が必要か」を考えます。ここでは自由振動と同じ周期なので、電磁力 0、電流 0 が条件です。
アニメーションで確かめよう：下の右のグラフで、紫の破線（電源電圧）と紫の実線（誘導起電力）が重なっていき、赤（電流）が 0 に近づきます。β を変えると、必要な \(A\) が比例して変わります。
III(3)　抵抗を 2R にしたときの最大振れ角答 \(\beta'=\beta\)

抵抗を変えても、十分に時間が経った一定振幅の状態では電流は 0 です。抵抗の両端の電圧 \(RI\) は \(R\) によらず 0 なので、(2) と同じ式が成り立ちます。

キルヒホッフの第2法則（電流 0）

$$A=\frac{2\pi\beta' lBL}{T}=\frac{2\pi\beta lBL}{T}\qquad\therefore\ \beta'=\beta$$

抵抗が変えるのは、一定振幅になるまでの速さだけです（時定数 \(\dfrac{2MR}{B^2L^2}\) が2倍になります）。

式の立て方：定常状態の条件に、変えたもの（ここでは \(R\)）が入っているかを確かめます。入っていなければ、定常状態は変わりません。
アニメーションで確かめよう：\(R\)（実線）と \(2R\)（破線）のブランコを同じ電源で動かします。\(2R\) の方がゆっくり振幅が育ちますが、最後は同じ振幅 \(\beta\) にそろいます。
