レンズの像・望遠レンズ・光のボケ（東京大学 2026年 第3問）

遠くの物体の実像をレンズでスクリーンに映すとき、どこにスクリーンを置けばよいか、像の大きさは何で決まるか、凸レンズと凹レンズを組み合わせた望遠レンズの利点、そして光が波であるために生じる「ボケ」の大きさを、作図と波の計算で確かめます。

設定

スクリーン

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。

I(1)　スクリーンを焦点の位置に置けばよい理由

レンズの式

物体とレンズの距離を \(a\)、レンズと実像の距離を \(b\)、焦点距離を \(f\) とすると

$$\frac{1}{a} + \frac{1}{b} = \frac{1}{f}$$

明瞭な像を映すには、スクリーンを実像の位置（レンズから \(b\)）に置きます。いまは \(a = D,\ f = d\) なので

$$b = \frac{Dd}{D - d} = \frac{d}{1 - \dfrac{d}{D}}$$

\(D \gg d\) では \(\dfrac{d}{D} \approx 0\) なので \(b \approx d\)。つまりスクリーンを焦点距離 \(d\) の位置に置けばよい。（\(\dfrac{1}{D} \approx 0\) として \(\dfrac{1}{b} = \dfrac{1}{d}\) と答えてもよい。）遠くの物体から来る光は、ほぼ平行光線とみなせるからです。

アニメーションで確かめよう：\(D/d\) を大きくすると、像の位置（赤い点線）が焦点 F に近づきます。スクリーンをずらすと右上の「スクリーン上の像」がぼやけます（ここでは光線の広がりによるボケ）。
I(2)　像の高さと焦点距離答 (b)　\(h = \dfrac{Hd}{D}\)，長い

レンズの中心を通る光線は直進します。物体の先端からレンズの中心を通る光線を考えると、物体側と像側で相似な三角形ができ、

$$\frac{h}{H} = \frac{b}{D} \approx \frac{d}{D} \qquad\therefore\quad h = \frac{Hd}{D}$$

物体の大きさ \(H\) と距離 \(D\) が決まっていれば、像の高さは焦点距離 \(d\) に比例します。だから遠くのものを大きく写したいなら、焦点距離の長いレンズを使えばよい（望遠レンズ）。

アニメーションで確かめよう：焦点距離 \(d\) を2倍にすると、スクリーン上の像の高さ \(h\) も2倍になります。ただしスクリーンも遠くなり、装置が長くなってしまう……これが次の I(3)〜(5) のテーマです。
I(3)　凹レンズ L₃ の焦点距離と \(\tan\alpha\)答 \(\dfrac{3}{2}d,\ \ \dfrac{w}{15d}\)

配置の整理

凸レンズ L₂（焦点距離 \(5d\)）から \(4d\) の所に凹レンズ L₃、そこから \(3d\) の所にスクリーン S があります。光軸に平行に入った光は、L₃ がなければ L₂ の焦点 P₁（L₂ から \(5d\)、つまり L₃ を \(d\) だけ過ぎた所）に集まるはずでした。

L₃ にとっての「虚物体」

光は P₁ に向かって集まりながら L₃ に入るので、P₁ は L₃ にとって虚物体（レンズの後ろ側にある物体）です。レンズの式で、虚物体の距離を \(-d\)、実像（P₂）までを \(3d\)、凹レンズの焦点距離を \(-f_3\) とおくと

$$\frac{1}{-d} + \frac{1}{3d} = \frac{1}{-f_3} \qquad\therefore\quad f_3 = \frac{3}{2}d$$

\(\tan\alpha\)

L₂ を出た光は、\(5d\) 進む間に高さが \(w\) から 0 まで下がる直線上にあるので、\(4d\) 進んだ L₃ では高さ \(\dfrac{w}{5}\)。そこから \(3d\) 先の P₂ で光軸と交わるので

$$\tan\alpha = \frac{w/5}{3d} = \frac{w}{15d}$$
アニメーションで確かめよう：太い線が光線（あ）です。点線は L₃ がなかった場合に光が向かう P₁。L₃ の焦点距離や位置を変えると、像の位置（スクリーン）が動きます。「問題の配置に戻す」で \(f_3 = 1.5d\) に戻ります。
I(4)　同じはたらきをする単一の凸レンズ答 \(15d\)

焦点距離 \(f\) の凸レンズに、光軸から \(w\) の高さで平行光線が入ると、光は焦点（レンズから \(f\)）で光軸と交わり、そのときの角度は \(\tan\alpha = \dfrac{w}{f}\)。これが I(3) の \(\tan\alpha = \dfrac{w}{15d}\) と一致するので

$$f = 15d$$

この単レンズはスクリーンから \(15d\) の所に置くことになります。I(2) より、像の大きさは焦点距離に比例するので、組み合わせレンズは「焦点距離 \(15d\) のレンズ」と同じ大きさの像をつくります。

アニメーションで確かめよう：紫の破線が単レンズに置き換えた場合の光線です。\(w\) を変えても、2つの光線は同じ角度で P₂ に入ります。
I(5)　組み合わせレンズの利点答 鏡筒（装置）を短くできる

同じ大きさの像（焦点距離 \(15d\) 相当）を得るのに、単レンズではレンズからスクリーンまで \(15d\) 必要ですが、図の組み合わせでは L₂ からスクリーンまで \(7d\) で済みます。望遠レンズを短く（小さく・軽く）できるのが利点です。

参考

性質の異なるレンズを組み合わせると、色によって焦点がずれる「色収差」や、レンズの端と中央で焦点がずれる「球面収差」を打ち消しあうように設計でき、よりくっきりした像が得られます。

アニメーションで確かめよう：下の2本の帯で長さ \(7d\) と \(15d\) を比べています。L₃ を L₂ から離す（スクリーンに近づける）とどうなるかも試してみましょう。
II(1)　波面上の2点から Q までの光路差答 \(\Delta L = x(1 - \cos\beta) - y\sin\beta\)

考え方

レンズを出た直後の波面 W は、焦点 O を中心とする半径 \(d\) の球面です。波面上の点はすべて同じ位相なので、O にはすべての光が同じ位相で届き、明るくなります。O から少しずれた点 \(\mathrm{Q}(x,\,y)\) では、届く光の道のりにわずかな差ができます。

近似の計算

\(|x|,\ |y| \ll d\) なので、2次の小さな量 \(\dfrac{x^2 + y^2}{d^2}\) は捨て、\(\sqrt{1+\varepsilon} \approx 1 + \dfrac{\varepsilon}{2}\) を使います。

$$\overline{\mathrm{W_1Q}} = \sqrt{(d - x)^2 + y^2} = d\sqrt{1 - \frac{2x}{d} + \frac{x^2 + y^2}{d^2}} \approx d - x$$ $$\overline{\mathrm{W_2Q}} = d\sqrt{1 - \frac{2(x\cos\beta + y\sin\beta)}{d} + \frac{x^2 + y^2}{d^2}} \approx d - x\cos\beta - y\sin\beta$$

差をとると

$$\Delta L = \overline{\mathrm{W_2Q}} - \overline{\mathrm{W_1Q}} = x(1 - \cos\beta) - y\sin\beta$$

図形的な意味

Q がごく近いとき、遠くの点 W から Q までの距離は「\(d\) − （OQ を W の方向へ射影した長さ）」です。W₁ の方向への射影は \(x\)、W₂ の方向への射影は \(x\cos\beta + y\sin\beta\)。その差が \(\Delta L\) です（ヤングの実験の近似と同じ考え方）。

アニメーションで確かめよう：右の拡大図で Q をドラッグ（またはスライダー）すると、厳密な \(\Delta L\) と近似式の値がほぼ一致することがわかります。背景の明るさは、レンズの縦の断面上の点からの波を足し合わせた光の強さです。
II(2)　スクリーン上のボケの大きさ答 \(\dfrac{\lambda}{2\sin\beta}\)

スクリーン上（\(x = 0\)）では \(\Delta L = -y\sin\beta\)。これが半波長 \(\dfrac{\lambda}{2}\) になる \(y\) をボケの大きさとするので

$$|y|\sin\beta = \frac{\lambda}{2} \qquad\therefore\quad |y| = \frac{\lambda}{2\sin\beta}$$

なぜ \(\lambda/2\) で「ボケの端」なのか

上端 W₂ と中央 W₁ の差が \(\dfrac{\lambda}{2}\) のとき、下端と上端の差は \(\lambda\)。このときレンズの上半分からの波と下半分からの波がちょうど打ち消し合い、明るさがほぼ 0 になります。だからここが「明るい点の広がり」の端の目安です。

\(\beta\) が大きい（口径 \(R\) が大きい・焦点距離が短い）ほど、また波長が短いほどボケは小さくなります。

アニメーションで確かめよう：下のグラフはスクリーン上の明るさの分布です。縦の点線 \(\pm\dfrac{\lambda}{2\sin\beta}\) で明るさがほぼ 0 になります。レンズの半径 \(R\) や波長 \(\lambda\) を変えてみましょう。
II(3)　数値で計算する答 \(6.5\times10^{-7}\ \mathrm{m}\)，物体上で \(6.5\times10^{-4}\ \mathrm{m}\)

\(d = 12\ \mathrm{cm},\ R = 5.0\ \mathrm{cm}\) なので、直角三角形の辺の比 \(5 : 12 : 13\) より

$$\sin\beta = \frac{R}{\sqrt{d^2 + R^2}} = \frac{5}{13}$$ $$\frac{\lambda}{2\sin\beta} = \frac{5.0\times10^{-7}\times13}{2\times5} = 6.5\times10^{-7}\ \mathrm{m}$$

物体（\(D = 1.2\times10^2\ \mathrm{m}\) 先）と像の大きさの比は \(d : D = 0.12 : 120 = 1 : 1000\)（I(2) の \(h = \dfrac{Hd}{D}\)）。よって物体上では1000倍して

$$6.5\times10^{-7}\times1000 = 6.5\times10^{-4}\ \mathrm{m}\quad(\text{約 }0.65\ \mathrm{mm})$$

つまり 120 m 先の 0.65 mm より細かいものは、このレンズでは見分けられません。

アニメーションで確かめよう：このボタンで問題の数値になります。「いまの値」に計算の途中経過を出しています。
II(4)　スクリーン位置の許容範囲（焦点深度）答 \(|x| = \dfrac{\lambda}{2(1 - \cos\beta)}\)

Q を光軸上（\(y = 0\)）で動かすと \(\Delta L = x(1 - \cos\beta)\)。これが \(\dfrac{\lambda}{2}\) になるまでを許容範囲とするので

$$|x| = \frac{\lambda}{2(1 - \cos\beta)}$$

\(\beta\) が小さいと \(1 - \cos\beta \approx \dfrac{\beta^2}{2}\) はとても小さいので、許容範囲は横のボケ（\(\approx \dfrac{\lambda}{2\beta}\)）よりずっと長くなります。問題の数値では \(\dfrac{13}{2}\lambda \approx 3.3\ \mu\mathrm{m}\)（片側）で、横のボケ \(0.65\ \mu\mathrm{m}\) の約5倍です。カメラで絞りを絞る（\(\beta\) を小さくする）とピントの合う範囲が広がるのも、この関係からわかります。

アニメーションで確かめよう：拡大図の明るい部分が光軸方向（横）に細長く伸びています。下のグラフは光軸上の明るさです。\(R\) を小さくすると、明るい部分がさらに長く伸びます。
