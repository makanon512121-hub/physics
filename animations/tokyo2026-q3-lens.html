レンズの像・望遠レンズ・光のボケ（東京大学 2026年 第3問）

遠くの物体の実像をレンズでスクリーンに映すとき、どこにスクリーンを置けばよいか、像の大きさは何で決まるか、凸レンズと凹レンズを組み合わせた望遠レンズの利点、そして光が波であるために生じる「ボケ」の大きさを、作図と波の計算で確かめます。

設定

スクリーン

いまの値

解答解説

見出しを押すと開きます。「方針」と「解答」で式の流れをつかみ、くわしい説明は下の「式の立て方」「補足」で確かめてください。「この状況にする」で上のアニメーションがその設問の設定になります。

I(1)　スクリーンを焦点の位置に置けばよい理由

方針写像公式で実像の位置 \(b\) を求め、\(D \gg d\) の近似をする。

解答

写像公式（物体 \(a = D\)、焦点距離 \(f = d\)）

$$\frac{1}{D} + \frac{1}{b} = \frac{1}{d} \qquad\therefore\quad b = \frac{d}{1 - \dfrac{d}{D}}$$

\(D \gg d\) の近似

$$\frac{d}{D} \approx 0 \qquad\therefore\quad b \approx d$$

実像はほぼ焦点の位置にできるので、スクリーンを焦点（レンズから \(d\)）に置けばよい。

式の立て方：くっきりした像を映すには、スクリーンを実像のできる位置に置きます。実像の位置は写像公式 \(\dfrac{1}{a} + \dfrac{1}{b} = \dfrac{1}{f}\)（\(a\)：物体〜レンズ、\(b\)：レンズ〜像）で決まるので、\(a = D,\ f = d\) を入れて \(b\) について解きます。\(b\) を \(\dfrac{d}{1 - d/D}\) の形にしておくと、\(D \gg d\) で分母が 1 に近づくことがすぐに見えます。（\(\dfrac{1}{D} \approx 0\) として、はじめから \(\dfrac{1}{b} = \dfrac{1}{d}\) としてもかまいません。）
補足：遠くの物体の1点から出た光は、レンズに届くころにはほぼ平行光線になっています。平行光線は凸レンズの焦点面に集まるので、遠くのものの像は焦点の位置にできます。物体が近づくと（\(D\) が小さくなると）\(b\) は \(d\) より大きくなり、スクリーンを少し後ろに下げる必要があります。カメラのピント合わせでレンズを前に繰り出すのはこのためです。
アニメーションで確かめよう：\(D/d\) を大きくすると、像の位置（赤い点線）が焦点 F に近づきます。スクリーンをずらすと右上の「スクリーン上の像」がぼやけます（ここでは光線の広がりによるボケ）。
I(2)　像の高さと焦点距離答 (b)　\(h = \dfrac{Hd}{D}\)，長い

方針物体の先端からレンズの中心を通る光線（直進する）で、相似な三角形をつくる。

解答

倍率（レンズの中心を通る光線の相似）

$$\frac{h}{H} = \frac{b}{D} \approx \frac{d}{D} \qquad\therefore\quad h = \frac{Hd}{D}$$

\(h\) は \(d\) に比例するので、像を大きくするには焦点距離の長いレンズを使えばよい。

式の立て方：像の大きさを求めるときは、レンズの中心を通る光線は曲がらずに直進することを使います。物体の先端からレンズの中心を通る直線を引くと、物体側（高さ \(H\)、距離 \(D\)）と像側（高さ \(h\)、距離 \(b\)）で、レンズの中心を頂点とする相似な直角三角形ができます。ここで I(1) の \(b \approx d\) を使います。
補足：物体の大きさ \(H\) と距離 \(D\) が決まっていれば、像の高さは焦点距離 \(d\) だけで決まります。遠くのものを大きく写す望遠レンズが焦点距離の長いレンズなのはこのためです。ただし I(1) より、スクリーンもレンズから \(d\) 離れた所に置く必要があるので、焦点距離を長くすると装置も長くなってしまいます。これを解決するのが I(3)〜(5) の組み合わせレンズです。
アニメーションで確かめよう：焦点距離 \(d\) を2倍にすると、スクリーン上の像の高さ \(h\) も2倍になります。ただしスクリーンも遠くなり、装置が長くなってしまう……これが次の I(3)〜(5) のテーマです。
I(3)　凹レンズ L₃ の焦点距離と \(\tan\alpha\)答 \(\dfrac{3}{2}d,\ \ \dfrac{w}{15d}\)

方針L₂ がつくるはずの像 P₁ を、L₃ にとっての物体（虚物体）とみて写像公式を使う。\(\tan\alpha\) は光線の幾何で求める。

解答

写像公式（L₃：虚物体 P₁ は後方 \(d\)、像 P₂ は後方 \(3d\)）

$$\frac{1}{-d} + \frac{1}{3d} = -\frac{1}{f_3} \qquad\therefore\quad f_3 = \frac{3}{2}d$$

光線の幾何（L₃ での高さ \(\dfrac{w}{5}\)、P₂ まで \(3d\)）

$$\tan\alpha = \frac{w/5}{3d} \qquad\therefore\quad \tan\alpha = \frac{w}{15d}$$
式の立て方：組み合わせレンズは1枚ずつ順番に考えます。
① まず L₂ だけを考えます。光軸に平行に入った光は、L₂ の焦点 P₁（L₂ から \(5d\)）に集まろうとします。L₃ は L₂ から \(4d\) の所にあるので、P₁ は L₃ を \(d\) だけ過ぎた所です。
② 次に L₃ を考えます。光は P₁ に向かって集まりながら L₃ に入るので、P₁ は L₃ にとって「後ろ側にある物体」（虚物体）です。写像公式では、物体がレンズの後ろ側にあるとき \(a\) を負にします（\(a = -d\)）。像 P₂ はスクリーン上（後方 \(3d\)）なので \(b = 3d\)。凹レンズの焦点距離は負の値 \(-f_3\) として入れます。
③ \(\tan\alpha\) は、L₂ を出た光の直線をたどります。光線は \(5d\) 進む間に高さ \(w\) から 0 まで一定の割合で下がるので、\(4d\) 進んだ L₃ では高さ \(w\left(1 - \dfrac{4}{5}\right) = \dfrac{w}{5}\)。そこで折れ曲がり、\(3d\) 先の P₂ で光軸と交わります。
補足：凹レンズは光を広げるはたらきをするので、光が集まる点を P₁ から P₂ へ後ろにずらします（\(d\) 先 → \(3d\) 先）。そのかわり光軸と交わる角度は浅くなり（\(\tan\alpha\) が小さくなる）、これが次の I(4) で「焦点距離が長いレンズと同じはたらき」につながります。
符号に自信がないときは、作図で確かめるのが安全です。「凹レンズの前側の焦点に向かって入る光は、平行光線になって出ていく」ことなどを使い、得られた \(f_3\) で P₂ に集まるかを確かめてみましょう。
アニメーションで確かめよう：太い線が光線（あ）です。点線は L₃ がなかった場合に光が向かう P₁。L₃ の焦点距離や位置を変えると、像の位置（スクリーン）が動きます。「問題の配置に戻す」で \(f_3 = 1.5d\) に戻ります。
I(4)　同じはたらきをする単一の凸レンズ答 \(15d\)

方針単レンズに高さ \(w\) の平行光線を入れたときの角度を、I(3) の \(\tan\alpha\) と等しくおく。

解答

平行光線は焦点に集まる（単レンズ、焦点距離 \(f\)）

$$\tan\alpha = \frac{w}{f} = \frac{w}{15d} \qquad\therefore\quad f = 15d$$
式の立て方：「同じはたらき」とは、同じ平行光線を入れたときに同じ角度で P₂ に集まることです。焦点距離 \(f\) の凸レンズに高さ \(w\) で光軸に平行に入った光は、レンズから \(f\) 先の焦点で光軸と交わるので、角度は \(\tan\alpha = \dfrac{w}{f}\)。これを I(3) の結果と比べます。
補足：結果に \(w\) が残らないので、どの高さで入った平行光線も同じ角度で P₂ に集まります。つまり組み合わせレンズ全体は「焦点距離 \(15d\) のレンズ」とみなせます。I(2) より像の大きさは焦点距離に比例するので、この組み合わせは焦点距離 \(15d\) の単レンズと同じ大きさの像をつくります。単レンズの場合は、スクリーンから \(15d\) 前にレンズを置くことになります。
アニメーションで確かめよう：紫の破線が単レンズに置き換えた場合の光線です。\(w\) を変えても、2つの光線は同じ角度で P₂ に入ります。
I(5)　組み合わせレンズの利点答 鏡筒（装置）を短くできる

方針同じ大きさの像をつくるのに必要な長さを、単レンズと組み合わせレンズで比べる。

解答

I(4) の結果の比較（レンズ〜スクリーンの長さ）

$$\text{単レンズ：}15d \qquad \text{組み合わせ：}4d + 3d = 7d$$

同じ大きさの像を得るのに装置（鏡筒）を短く、小さく軽くできる。

式の立て方：I(4) で、組み合わせレンズと焦点距離 \(15d\) の単レンズは同じ大きさの像をつくることがわかりました。あとは「最初のレンズからスクリーンまで」の長さを比べるだけです。組み合わせでは L₂〜L₃ が \(4d\)、L₃〜スクリーンが \(3d\) です。
補足：凸レンズで光を集めかけ、凹レンズで少し広げて集まる点を遠ざけると、実際の長さより焦点距離の長いレンズとしてはたらきます。カメラの望遠レンズはこのしくみ（テレフォト型）で全長を短くしています。
また、性質の異なるレンズを組み合わせると、色によって焦点がずれる「色収差」や、レンズの端と中央で焦点がずれる「球面収差」を打ち消しあうように設計でき、よりくっきりした像が得られます。
アニメーションで確かめよう：下の2本の帯で長さ \(7d\) と \(15d\) を比べています。L₃ を L₂ から離す（スクリーンに近づける）とどうなるかも試してみましょう。
II(1)　波面上の2点から Q までの光路差答 \(\Delta L = x(1 - \cos\beta) - y\sin\beta\)

方針W₁Q、W₂Q を三平方の定理で書き、\(|x|,\ |y| \ll d\) の近似で1次まで残して差をとる。

解答

三平方の定理と近似 \(\sqrt{1+\varepsilon} \approx 1 + \dfrac{\varepsilon}{2}\)（2次の微小量を捨てる）

$$\overline{\mathrm{W_1Q}} = d\sqrt{1 - \frac{2x}{d} + \frac{x^2 + y^2}{d^2}} \nobreak \approx d - x$$ $$\overline{\mathrm{W_2Q}} = d\sqrt{1 - \frac{2(x\cos\beta + y\sin\beta)}{d} + \frac{x^2 + y^2}{d^2}} \nobreak \approx d - x\cos\beta - y\sin\beta$$

光路差

$$\Delta L = \overline{\mathrm{W_2Q}} - \overline{\mathrm{W_1Q}} \qquad\therefore\quad \Delta L = x(1 - \cos\beta) - y\sin\beta$$
式の立て方：レンズを出た直後の波面 W は、焦点 O を中心とする半径 \(d\) の球面です。問題の座標（O が原点）では、W₁ は \((d,\ 0)\)、W₂ は \((d\cos\beta,\ d\sin\beta)\) にあります（W₂ は O から見て光軸と角 \(\beta\) をなす方向）。Q \((x,\ y)\) までの距離を座標の差で書き、2乗して展開すると、\(d^2\)、\(d\) と \(x,\ y\) の積（1次）、\(x^2 + y^2\)（2次）の項が出てきます。\(|x|,\ |y| \ll d\) なので2次の項 \(\dfrac{x^2 + y^2}{d^2}\) を捨て、ルートは \(\sqrt{1+\varepsilon} \approx 1 + \dfrac{\varepsilon}{2}\) で外します。この「2乗して展開 → 小さい項を捨てる → ルートを近似で外す」は、ヤングの実験など干渉の問題で何度も使う手順です。
補足：波面上の点はすべて同じ位相なので、焦点 O には全部の光が同じ位相で届いて強め合います。O から少しずれた Q では道のりに差ができ、その差 \(\Delta L\) が明るさを決めます。
図形的には、Q がごく近いとき「遠くの点 W から Q までの距離 ≒ \(d\) −（OQ を W の方向へ射影した長さ）」です。W₁ の方向への射影は \(x\)、W₂ の方向への射影は \(x\cos\beta + y\sin\beta\) で、その差がそのまま \(\Delta L\) になっています。こう見ると、計算しなくても結果の形が予想できます。
アニメーションで確かめよう：右の拡大図で Q をドラッグ（またはスライダー）すると、厳密な \(\Delta L\) と近似式の値がほぼ一致することがわかります。背景の明るさは、レンズの縦の断面上の点からの波を足し合わせた光の強さです。
II(2)　スクリーン上のボケの大きさ答 \(\dfrac{\lambda}{2\sin\beta}\)

方針(1) で \(x = 0\)（スクリーン上）とし、\(|\Delta L| = \dfrac{\lambda}{2}\) となる \(|y|\) を求める。

解答

(1) の光路差（\(x = 0\)）とボケの端の条件

$$|\Delta L| = |y|\sin\beta = \frac{\lambda}{2} \qquad\therefore\quad |y| = \frac{\lambda}{2\sin\beta}$$
式の立て方：スクリーンは焦点を通り光軸に垂直なので、スクリーン上の点は \(x = 0\) です。(1) の結果に \(x = 0\) を入れると \(\Delta L = -y\sin\beta\)。問題の約束どおり、この大きさが半波長 \(\dfrac{\lambda}{2}\) になる所をボケの端とします。
補足：なぜ \(\dfrac{\lambda}{2}\) で「端」といえるのかを考えます。中央 W₁ と上端 W₂ の光路差が \(\dfrac{\lambda}{2}\) のとき、下端と上端の差は \(\lambda\) です。このとき、レンズの上半分の各点からの波と、それと \(\dfrac{\lambda}{2}\) ずれた下半分の各点からの波が対になって打ち消し合い、明るさがほぼ 0 になります。光をどれだけ上手に集めても、波である以上この大きさより小さな点にはならない、というのがこの設問の主題です。
\(\beta\) が大きい（口径 \(R\) が大きい・焦点距離が短い）ほど、また波長 \(\lambda\) が短いほど、ボケは小さくなります。天体望遠鏡の口径を大きくすると細かいものまで見分けられるのも、この関係によります。
アニメーションで確かめよう：下のグラフはスクリーン上の明るさの分布です。縦の点線 \(\pm\dfrac{\lambda}{2\sin\beta}\) で明るさがほぼ 0 になります。レンズの半径 \(R\) や波長 \(\lambda\) を変えてみましょう。
II(3)　数値で計算する答 \(6.5\times10^{-7}\ \mathrm{m}\)，物体上で \(6.5\times10^{-4}\ \mathrm{m}\)

方針\(\sin\beta\) を辺の比から出して (2) に代入し、I(2) の倍率で物体上の長さに直す。

解答

直角三角形の辺の比（\(d = 12\ \mathrm{cm},\ R = 5.0\ \mathrm{cm}\)）

$$\sin\beta = \frac{R}{\sqrt{d^2 + R^2}} = \frac{5}{13}$$

(2) の結果に代入

$$\frac{\lambda}{2\sin\beta} = \frac{5.0\times10^{-7}\times13}{2\times5} \nobreak = 6.5\times10^{-7}\ \mathrm{m}$$

倍率 \(\dfrac{h}{H} = \dfrac{d}{D} = \dfrac{0.12}{1.2\times10^2} = \dfrac{1}{1000}\)（I(2)）

$$6.5\times10^{-7}\times1000 = 6.5\times10^{-4}\ \mathrm{m}$$
式の立て方：\(\beta\) はレンズの端 W₂ から焦点 O を見たときの、光軸とのなす角です。光軸方向に \(d\)、縦に \(R\) の直角三角形なので、斜辺は \(\sqrt{d^2 + R^2} = 13\ \mathrm{cm}\)（\(5 : 12 : 13\)）。スクリーン上のボケを物体上の長さに直すには、I(2) の \(h = \dfrac{Hd}{D}\) を逆に使い、スクリーン上の長さを \(\dfrac{D}{d}\) 倍します。単位を m にそろえてから比をとると間違えません。
補足：物体上で約 0.65 mm ということは、120 m 先にある 0.65 mm より細かい模様は、このレンズではどうがんばってもぼやけて見分けられない、という意味です。これはレンズの出来の良し悪しではなく、光が波であることから決まる限界（回折限界）です。
アニメーションで確かめよう：このボタンで問題の数値になります。「いまの値」に計算の途中経過を出しています。
II(4)　スクリーン位置の許容範囲（焦点深度）答 \(|x| = \dfrac{\lambda}{2(1 - \cos\beta)}\)

方針(1) で \(y = 0\)（光軸上）とし、\(|\Delta L| = \dfrac{\lambda}{2}\) となる \(|x|\) を求める。

解答

(1) の光路差（\(y = 0\)）と許容範囲の条件

$$|\Delta L| = |x|(1 - \cos\beta) = \frac{\lambda}{2} \qquad\therefore\quad |x| = \frac{\lambda}{2(1 - \cos\beta)}$$
式の立て方：スクリーンを光軸に沿って前後にずらすことは、Q を光軸上（\(y = 0\)）で動かすことと同じです。(1) の結果に \(y = 0\) を入れ、(2) と同じく \(\dfrac{\lambda}{2}\) を基準にします。
補足：問題の数値では \(\cos\beta = \dfrac{12}{13}\) なので \(1 - \cos\beta = \dfrac{1}{13}\)、許容範囲は \(\dfrac{13}{2}\lambda \approx 3.3\ \mu\mathrm{m}\)（片側）。横のボケ \(0.65\ \mu\mathrm{m}\) の約5倍です。
\(\beta\) が小さいと \(1 - \cos\beta \approx \dfrac{\beta^2}{2}\) は \(\sin\beta \approx \beta\) よりずっと小さくなるので、光軸方向の許容範囲（\(\approx \dfrac{\lambda}{\beta^2}\)）は横のボケ（\(\approx \dfrac{\lambda}{2\beta}\)）より長くなります。明るい部分は光軸方向に細長い形をしているわけです。
カメラで絞りを絞る（\(\beta\) を小さくする）と、ピントの合う範囲（焦点深度）が広がります。そのかわり (2) の横のボケは大きくなるので、絞りすぎると細かい部分がぼやけます。
アニメーションで確かめよう：拡大図の明るい部分が光軸方向（横）に細長く伸びています。下のグラフは光軸上の明るさです。\(R\) を小さくすると、明るい部分がさらに長く伸びます。
