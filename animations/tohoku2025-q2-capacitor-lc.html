コンデンサーのつなぎかえ・電気振動・LC 並列共振（東北大学 2025年 第2問）

前半は、極板の間隔を変えられるコンデンサーを充電し、スイッチを切りかえて2つのコンデンサーの間で電荷を移します。抵抗を通すと電圧がそろって熱が出て、コイルを通すと電気振動が起こります。電荷の動き（点の流れ）、電気量・電圧のグラフ、エネルギーの棒グラフで追います。後半は、コイルとコンデンサーを並列にした交流回路で、2つの電流が逆向きに流れて打ち消し合う「並列共振」を、波形と回転ベクトルで確かめます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。図の色：コンデンサー1・電圧 VC（青）、コンデンサー2・電流 I₂（紫）、コイル（オレンジ）、抵抗・ジュール熱（赤）、電源（緑）。回路の点は電荷の流れ（電流）を表します。

問(1)⒜　コンデンサー2 の電気容量 C₂答 \(C_2=2C\)

平行板コンデンサーの電気容量は、極板の間隔に反比例します。間隔 \(d\) のとき \(C\) なので、間隔を \(\frac d2\) にすると2倍です。

平行板コンデンサーの電気容量（C = ε₀S/d）

$$C=\varepsilon_0\frac{S}{d},\qquad \cfic{C_2}=\varepsilon_0\frac{S}{d/2}=2C$$
式の立て方：極板の面積 \(S\) がわからなくても、「間隔以外は同じ」なら比で求められます。\(C\propto\dfrac{1}{\text{間隔}}\) なので、間隔が \(\frac12\) 倍なら容量は2倍です。
アニメーションで確かめよう：右のグラフは C₂ と間隔の関係（反比例）です。極板の間隔が \(d\) から \(\frac d2\) に縮むと、点が \(C\) から \(2C\) に上がります。
問(1)⒝　十分に時間がたった後の静電エネルギー U₁, U₂答 \(U_1=\dfrac12CV_0^{\,2},\ U_2=CV_0^{\,2}\)

十分に時間がたつと、回路のどこにも電流が流れなくなります。すると

・抵抗1 の電圧は \(R_1\times0=0\) なので、コンデンサー1 の電圧は電源と同じ \(V_0\) です。

・コイルの電流が変化しないので、誘導起電力 \(L\dfrac{di}{dt}\) も 0 です。コンデンサー2 の電圧もコンデンサー1 と同じ \(V_0\) になります。

キルヒホッフの第2法則（十分に時間がたった後）

$$V_0=R_1\cdot0+\frac{\cacc{q_1}}{C},\qquad \frac{\cacc{q_1}}{C}=\frac{\cfic{q_2}}{2C}+L\cdot0$$

静電エネルギー（U = ½CV²）

$$\cacc{U_1}=\frac12CV_0^{\,2},\qquad \cfic{U_2}=\frac12(2C)V_0^{\,2}=CV_0^{\,2}$$

補足：途中では電気振動が起こる

スイッチ1 を閉じた直後は、コイルとコンデンサーの間で電流が行ったり来たりし、抵抗1 で少しずつ熱になって収まります。最後の状態は \(R_1\) や \(L\) によりません。電源がした仕事 \(V_0\times3CV_0=3CV_0^{\,2}\) のうち、静電エネルギーになるのは半分の \(\frac32CV_0^{\,2}\) で、残りの半分は抵抗1 の熱です。

式の立て方：「十分に時間がたった後」の直流回路では、コンデンサーは「電流が流れない」、コイルは「電圧 0 のただの導線」として扱います。
アニメーションで確かめよう：右上のグラフで \(q_1\) と \(q_2\) が揺れながら \(CV_0\) と \(2CV_0\) に落ち着きます。\(R_1\) を変えると揺れ方は変わりますが、最後の値と、右下の棒（\(U_1\), \(U_2\), 熱）の最後の高さは変わりません。
問(2)⒜　状態1 のコンデンサー2 の電位差 VC2答 \(V_{\mathrm C2}=4V_0\)

スイッチ2 を端子 a から外すと、コンデンサー2 の下の極板はどこにもつながりません。電荷の逃げ道がないので、電気量は \(2C\cdot V_0=2CV_0\) のままです。間隔を \(2d\) にすると、電気容量は \(\frac C2\) になります。

Q = CV（電気量は一定）

$$2CV_0=\frac C2\cdot\cfic{V_{\mathrm C2}}\qquad\therefore\ V_{\mathrm C2}=4V_0$$

着眼点：電場は変わらず、間隔だけ広がる

極板の電気量が同じなら、極板間の電場 \(E=\dfrac{Q}{\varepsilon_0S}\) は間隔によりません。電圧は（電場）×（間隔）なので、間隔に比例して大きくなります。\(\frac d2\to2d\) で4倍なので、\(V_0\to4V_0\) です。

補足：増えたエネルギーはどこから？

コンデンサー2 の静電エネルギーは \(CV_0^{\,2}\) から \(\frac12\cdot\frac C2\cdot(4V_0)^2=4CV_0^{\,2}\) に増えます。増えた \(3CV_0^{\,2}\) は、引き合う極板を引き離すときに外から加えた力がした仕事です。

式の立て方：「スイッチを切ってから極板を動かす」→ 電気量 \(Q\) が一定。「電源につないだまま動かす」→ 電圧 \(V\) が一定。どちらが一定かを最初に決めます。
アニメーションで確かめよう：極板の間の線の本数（電場の強さ）は変わらないまま、間隔が広がるにつれて電圧が比例して増えます。設定の \(n\) を変えると、広げた後の電圧は \(2nV_0\) になります。
問(2)⒝　状態2 の電気量 q₁, q₂答 \(q_1=2CV_0,\ q_2=CV_0\)

スイッチ1 が開いているので、2つのコンデンサーの上側の極板と、それをつなぐ導線は、ほかのどこともつながらない「島」になっています。島の電気量の合計は変わりません。

電気量保存則（上側の極板の合計）

$$\cacc{q_1}+\cfic{q_2}=CV_0+2CV_0=3CV_0$$

スイッチ2 を b につなぐと、2つのコンデンサーと抵抗2 が1つの輪になります。電圧の高いコンデンサー2（\(4V_0\)）から低いコンデンサー1（\(V_0\)）へ電荷が移り、電流が 0 になるのは2つの電圧が等しくなったときです。

キルヒホッフの第2法則（十分に時間がたった後，抵抗2 の電圧は 0）

$$\frac{\cacc{q_1}}{C}=\frac{\cfic{q_2}}{C/2}$$

2つの式を連立して

$$q_1=2CV_0,\qquad q_2=CV_0\qquad(\text{電圧はともに }2V_0)$$
式の立て方：コンデンサーのつなぎかえは、(1) 孤立した部分の電気量保存、(2) 最後の電圧の関係（キルヒホッフの第2法則）の2本で決まります。孤立した部分は「スイッチや電源で外とつながっていない極板の組」を探します。
アニメーションで確かめよう：右上のグラフで2つの電圧が近づき、\(2V_0\) で一致します。右下の棒の合計（\(3CV_0\)）は最後まで変わりません。
問(2)⒞　抵抗2 で発生したジュール熱 Q答 \(Q=\dfrac32CV_0^{\,2}\)

電源はつながっていないので、エネルギーの出入りは「静電エネルギーの減少 → 抵抗2 の熱」だけです。

エネルギー保存則（減った静電エネルギー ＝ ジュール熱）

$$\cfrc{Q}=\Bigl\{\frac12CV_0^{\,2}+\frac12\cdot\frac C2(4V_0)^2\Bigr\}\nobreak-\Bigl\{\frac{(2CV_0)^2}{2C}+\frac{(CV_0)^2}{2\cdot\frac C2}\Bigr\}$$ $$=\frac92CV_0^{\,2}-3CV_0^{\,2}=\frac32CV_0^{\,2}$$

補足：直列の合成容量と電圧の差で一気に求める

電圧 \(V_1\), \(V_2\) の2つのコンデンサー \(C_1\), \(C_2\) を抵抗でつないで電圧をそろえるとき、熱は

$$Q=\frac12\cdot\frac{C_1C_2}{C_1+C_2}\,(V_2-V_1)^2$$

になります（直列の合成容量に「電圧の差」がかかっていたと考えた形）。この問題では合成容量 \(\frac{C\cdot\frac C2}{C+\frac C2}=\frac C3\)、電圧の差 \(3V_0\) なので \(\frac12\cdot\frac C3\cdot9V_0^{\,2}=\frac32CV_0^{\,2}\) と一致します。\(R_2\) の値によらないこともわかります。

式の立て方：抵抗の熱は \(RI^2\) を時間で足し合わせず、「はじめと終わりの静電エネルギーの差」で求めます。
アニメーションで確かめよう：\(R_2\) を変えると電流の減り方（速さ）は変わりますが、右下の「R₂ の熱」の最後の高さは同じです。\(n=0.5\)（間隔を変えない）にすると電圧の差がなく、熱は 0 です。
問(2)⒟　電気振動の電流の最大値 IM答 \(I_M=V_0\sqrt{\dfrac{3C}{L}}\)

状態1 からスイッチ2 を a につなぐと、コンデンサー1、コンデンサー2、コイルが1つの輪になります。抵抗がないので、エネルギーを失わずに電気振動が続きます。電流 \(i\) は、コンデンサー2 からコンデンサー1 へ電荷を運ぶ向きを正とします。

キルヒホッフの第2法則（コイルの電圧が電流の変化を決める）

$$L\frac{di}{dt}=\frac{\cfic{q_2}}{C/2}-\frac{\cacc{q_1}}{C}$$

電流が最大になる瞬間は \(\frac{di}{dt}=0\) なので右辺 = 0、つまり2つのコンデンサーの電圧が等しくなっています。電気量の合計 \(3CV_0\) も同じなので、このときの電気量は ⒝ と同じ \(q_1=2CV_0\), \(q_2=CV_0\) です。

エネルギー保存則（はじめ ＝ 電流が最大のとき）

$$\frac92CV_0^{\,2}=3CV_0^{\,2}+\frac12L\cfr{I_M^{\,2}}$$ $$\therefore\ \frac12LI_M^{\,2}=\frac32CV_0^{\,2},\qquad I_M=V_0\sqrt{\frac{3C}{L}}$$

着眼点：⒞ の熱がそのままコイルのエネルギーに

⒞ では抵抗2 で熱になった \(\frac32CV_0^{\,2}\) が、抵抗のない ⒟ では、電流が最大の瞬間にコイルのエネルギーになっています。どちらも「2つの電圧がそろった状態」を通るので、同じ量が出てきます。

別解：単振動として解く

\(i=\dfrac{dq_1}{dt}=-\dfrac{dq_2}{dt}\) を使って上の式を時間で微分すると

$$\frac{d^2i}{dt^2}=-\frac{3}{LC}\,i$$

となり、角振動数 \(\omega=\sqrt{\dfrac{3}{LC}}\) の単振動です（2つのコンデンサーの直列の合成容量 \(\frac C3\) とコイルの振動）。\(q_1\) は中心 \(2CV_0\) のまわりを振幅 \(CV_0\) で往復するので

$$I_M=\omega\times CV_0=V_0\sqrt{\frac{3C}{L}}$$
式の立て方：電気振動で「電流が最大」のときはコイルの電圧 \(L\frac{di}{dt}=0\) です。これでコンデンサーの電荷が決まり、あとはエネルギー保存則で \(I_M\) が出ます。
アニメーションで確かめよう：右下の棒で、静電エネルギーとコイルのエネルギーがやりとりされ、合計は一定です。コイルの棒が最大の瞬間、2つのコンデンサーの電圧がそろっています。\(n=2\) では、振動の端でコンデンサー2 の電気量がちょうど 0 になります。
問(3)⒜　コンデンサーの電圧 VC答 \(V_{\mathrm C}=-\dfrac{kI_0}{\omega C}\cos(\omega t+\theta)\)

間隔 \(kd\) のコンデンサーの電気容量は \(\frac Ck\) です。図の向きの電流 \(I_2\) は、点 x 側の極板の電気量 \(q\) を増やすので \(I_2=\frac{dq}{dt}\) です。

電流は電気量の時間変化（q を求める）

$$q=\int\cfic{I_2}\,dt=-\frac{I_0}{\omega}\cos(\omega t+\theta)$$

コンデンサーの電圧（V = q/C）

$$\cacc{V_{\mathrm C}}=\frac{q}{C/k}=-\frac{kI_0}{\omega C}\cos(\omega t+\theta)$$

\(-\cos x=\sin\bigl(x-\frac\pi2\bigr)\) なので、電圧は電流より \(\frac\pi2\) 遅れています。最大値の比は、コンデンサーのリアクタンス \(\dfrac{1}{\omega\cdot\frac Ck}=\dfrac{k}{\omega C}\) です。

式の立て方：積分を使わずに、「コンデンサーの電圧は電流より \(\frac\pi2\) 遅れ、最大値は（リアクタンス）×（電流の最大値）」から \(V_{\mathrm C}=\dfrac{k}{\omega C}I_0\sin\bigl(\omega t+\theta-\frac\pi2\bigr)\) と書いても同じです。
アニメーションで確かめよう：右上のグラフで、紫の \(I_2\) が山になってから \(\frac14\) 周期後に青の \(V_{\mathrm C}\) が山になります。右下の回転ベクトルでは、\(V_{\mathrm C}\) が \(I_2\) より 90° 後ろを回っています。
問(3)⒝　コイルの電流 I₁答 \(I_1=-\dfrac{k}{\omega^2LC}I_0\sin(\omega t+\theta)\)

コイルとコンデンサーは並列なので、コイルにかかる電圧（上側が高い向き）も \(V_{\mathrm C}\) です。

コイルの自己誘導（電流の変化と電圧）

$$L\frac{d\cfr{I_1}}{dt}=\cacc{V_{\mathrm C}}=-\frac{kI_0}{\omega C}\cos(\omega t+\theta)$$

両辺を L で割って時間で積分（直流の成分はない）

$$\cfr{I_1}=-\frac{k}{\omega^2LC}I_0\sin(\omega t+\theta)$$

\(I_1\) は \(I_2\) と同じ \(\sin(\omega t+\theta)\) の形で、符号が逆です。コイルの電流は電圧より \(\frac\pi2\) 遅れ、コンデンサーの電流は \(\frac\pi2\) 進むので、2つはいつも逆向き（逆位相）に流れます。

式の立て方：「並列なら電圧が共通」です。共通の電圧 \(V_{\mathrm C}\) を先に求めてから、それぞれの素子の電流を求めます。コイルの電流は電圧より \(\frac\pi2\) 遅れ、最大値は（電圧の最大値）÷ \(\omega L\) です。
アニメーションで確かめよう：グラフのオレンジ（\(I_1\)）と紫（\(I_2\)）は、いつも逆向きです。\(k\) や \(\omega\) を変えると、大きさの比 \(\dfrac{k}{\omega^2LC}\) が変わります。
問(3)⒞　共振が起きる極板の間隔 D答 \(D=\omega^2LCd\)

コイルとコンデンサーは、平均すると電力を消費しません。回路の平均の消費電力が 0 になるのは、抵抗に電流が流れないときだけです。

キルヒホッフの第1法則（抵抗を流れる電流）

$$\cfrc{I_1+I_2}=\Bigl(1-\frac{k}{\omega^2LC}\Bigr)I_0\sin(\omega t+\theta)$$

いつも 0 になる条件（間隔 D = kd）

$$1-\frac{k}{\omega^2LC}=0\qquad\therefore\ k=\omega^2LC,\quad D=kd=\omega^2LCd$$

別解：LC 並列共振の式から

コイルとコンデンサーの並列部分は、\(\omega=\dfrac{1}{\sqrt{LC'}}\)（\(C'\) はコンデンサーの容量）のとき、2つの電流が打ち消し合って外に電流が流れなくなります（並列共振）。\(C'=\dfrac{Cd}{D}\) を入れると \(\omega^2=\dfrac{D}{LCd}\) で、同じ答えです。

このとき電流はコイルとコンデンサーの輪の中だけを行き来し、電源からは電流が出ません。電流が最大になる直列共振とは逆の現象です。

式の立て方：「平均の消費電力が 0」を「抵抗の電流がいつも 0」と言いかえ、電流の和がどの時刻でも 0 になる条件を係数から決めます。
アニメーションで確かめよう：間隔 \(k\) を動かすと、右下のグラフで消費電力が変わり、\(k=\omega^2LC\)（点線）でちょうど 0 になります。そのとき抵抗を流れる赤い点が止まり、オレンジと紫の点だけが輪の中を行き来します。
問(3)⒟　共振のときの I₀ と θ答 \(I_0=\dfrac{V_1}{\omega L},\ \theta=\dfrac\pi2\)

抵抗に電流が流れないので抵抗の電圧は 0 で、電源の電圧がそのままコンデンサー（とコイル）にかかります。

キルヒホッフの第2法則（抵抗の電圧は 0）

$$\cacc{V_{\mathrm C}}=\cgrav{V_1\sin\omega t}$$

⒜ の結果に \(k=\omega^2LC\) を入れると \(\frac{k}{\omega C}=\omega L\) なので

$$-\omega L\,I_0\cos(\omega t+\theta)=V_1\sin\omega t$$

\(\theta=\frac\pi2\) とすると、左辺は \(-\omega LI_0\cos\bigl(\omega t+\frac\pi2\bigr)=\omega LI_0\sin\omega t\) となり、どの時刻でも成り立ちます。

$$\theta=\frac\pi2,\qquad \cfic{I_0}=\frac{V_1}{\omega L}$$

（\(\theta=-\frac\pi2\) でも式の形は合いますが、そのとき \(I_0\) が負になります。\(I_0\) は最大値で正なので \(\theta=\frac\pi2\) です。）

別解：位相のずれから直接

コンデンサーの電流は電圧より \(\frac\pi2\) 進むので、電圧 \(V_1\sin\omega t\) に対して電流は \(\sin\bigl(\omega t+\frac\pi2\bigr)\) の形、つまり \(\theta=\frac\pi2\) です。最大値は電圧 ÷ リアクタンスで \(V_1\cdot\omega\dfrac Ck=\dfrac{V_1}{\omega L}\) です。

\(I_0\) は \(R\) によりません。抵抗に電流が流れないので、抵抗の大きさは関係なくなるからです。

式の立て方：「どの時刻でも成り立つ」式は、\(\sin\) と \(\cos\) の係数を比べるか、\(\omega t=0\) や \(\frac\pi2\) など計算しやすい時刻を代入して条件を出します。
アニメーションで確かめよう：緑の電源電圧と青の \(V_{\mathrm C}\) がぴったり重なり、紫の \(I_2\) は \(\frac14\) 周期だけ先に山になります。\(R\) を変えても \(I_0\) は変わりません。
