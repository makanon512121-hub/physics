回転する導体棒とコンデンサー（東京大学 2026年 第2問）

鉛直上向きの一様な磁場の中で、円形レールの上を導体棒（長さ l）が回転します。レールと回転軸は抵抗 R を通して、スイッチで直流電源 V（X 側）かコンデンサー C₁（Y 側）につながります。回転する棒が「コンデンサーのようにふるまう」ことを、グラフとエネルギーで確かめましょう。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

スイッチ

棒は一様な細い棒として、回転軸まわりの慣性モーメントを β = Ml²/3 で計算しています。値は動きが見やすいように選んだ例です（静電容量が数 F と大きいのはそのためです）。

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。ここでは α = Bl²/2 とします。

I　回転する棒の起電力答 α = Bl²/2

棒が横切る面積

短い時間 Δt の間に、棒は角度 ω₁Δt だけ回ります。棒が通過した部分は半径 l、中心角 ω₁Δt の扇形なので

ΔS = 12l²·ω₁Δt

ファラデーの法則

この面を貫く磁束は ΔΦ = BΔS。単位時間あたりに横切る磁束が起電力なので

E₁ = ΔΦΔt = 12Bl²ω₁　→　α = 12Bl²

別の見方（ローレンツ力）

回転軸から r の位置の電荷は速さ rω で動くので、棒に沿って q·rω·B の力を受けます。棒に沿って足し合わせると起電力は Bω(0 + l)/2 × l = Bl²ω/2（平均の速さ lω/2 の棒が vBl を生むと考えても同じ）。

アニメーションで確かめよう：青い扇形が直前の短い時間に棒が横切った面積です。ω₁ を2倍にすると扇形も起電力も2倍、l を2倍にすると4倍になります。
II(1)　スイッチを X に入れた直後のモーメント答 Bl²V/(2R)

直後は棒がまだ止まっている（ω = 0）ので、棒の起電力は 0。回路の電流は

I₀ = VR

棒の各部分（長さ Δx）には同じ大きさの力 I₀BΔx がはたらきます。力は棒全体に一様に分布しているので、合力 I₀Bl が棒の中点（軸から l/2）にはたらくと考えてよく、

N = l2·I₀Bl = Bl²V2R

（「太さ一定・密度一様」は重心＝中点を示すための条件ではなく、ここでは力の分布が一様であることがポイントです。積分で書くと ∫₀l x·I₀B dx = I₀Bl²/2。）なお N = αI₀ と書けることにも注目しておきましょう。

アニメーションで確かめよう：棒に並んだ小さな矢印がどれも同じ長さ（一様な力）で、太い矢印が中点にはたらく合力です。「再生」すると回り始めます。
II(2)　回り始める向き答 上から見て反時計回り（図の（あ）の向き）

電源の正極から出た電流は、抵抗 → 端子 P → レール → 棒（先端から回転軸へ）→ 端子 O と流れます。磁場は紙面の裏から表向き（鉛直上向き）。フレミングの左手の法則（F = IL×B）で、棒は上から見て反時計回りに押されます。

アニメーションで確かめよう：オレンジの点が電流の流れ、棒の上の赤い矢印が力の向きです。
II(3)　十分時間がたった後の角速度答 ω₂ = V/α = 2V/(Bl²)

棒が回り始めると、I で求めた起電力 αω が電源と逆向きに生じます（逆起電力）。電流は

I = V − αωR

と小さくなり、回転を速める力のモーメント αI も小さくなります。ω が一定になるのはモーメント 0、つまり I = 0 のとき。キルヒホッフの第2法則で

V = αω₂　→　ω₂ = Vα = 2VBl²

摩擦がないので、電流 0 になればそのまま一定の角速度で回り続けます。最終の角速度は R や棒の質量によりません（それらは近づく速さだけを決めます）。

アニメーションで確かめよう：グラフの ω が点線 V/α に近づき、電流 I は 0 に近づきます。R や M を変えても最終値は同じで、近づく速さだけが変わります。エネルギーを見ると、電源がした仕事のちょうど半分が運動エネルギー、残り半分がジュール熱になっています。
III　コンデンサー1に切り替えた後のエネルギー答 C₁α²ω₃²/2

スイッチを Y に切り替えると、回る棒が電池の役目をしてコンデンサー1を充電します。このとき流れる電流は棒の回転を妨げる向きの力を生むので、棒は減速します（レンツの法則）。

やがて ω が一定（ω₃）になるのは、電流が 0 のとき。抵抗の電圧も 0 なので、コンデンサーの電圧は棒の起電力 αω₃ に等しくなり

U₁ = 12C₁(αω₃)² = 12C₁α²ω₃²　（= C₁B²l⁴ω₃²/8）
アニメーションで確かめよう：ω が下がっていき、コンデンサーの電圧 αω と q/C₁ が等しくなった所で止まります。C₁ を大きくすると、ω₃ は小さくなります。
IV(1)　回る棒＝仮想コンデンサー2答 Q₂ = βω/α，C₂ = β/α²

エネルギーで対応させる

端子 O–P 間の電圧は棒の起電力 V₂ = αω。運動エネルギーをこの電圧で書き直すと

12βω² = 12·βα²·(αω)²

これを 12C₂V₂² と見比べて C₂ = β/α²。電荷は Q₂ = C₂V₂ = βω/α。

電流でも対応している

棒の回転の運動方程式は βΔωΔt = αI。両辺を α で割ると I = Δ(βω/α)/Δt。つまり流れこんだ電荷の分だけ βω/α が増えるので、Q₂ は「本当に流れこんだ電荷の合計」になっています。だからこの見方が正しく使えるのです。

（参考：一様な棒なら β = Ml²/3 なので C₂ = 4M/(3B²l²)。重い棒ほど「容量の大きいコンデンサー」です。）

アニメーションで確かめよう：回路図の棒の部分に「コンデンサー2」の目盛りを重ねて表示しています。ω に比例して Q₂ がたまり、エネルギーの棒グラフで ½βω² と Q₂²/(2C₂) が一致します。
IV(2)(3)　コンデンサー2つで考える答 U₁ = C₁C₂²V²/{2(C₁+C₂)²}，ω₃ = C₂V/{α(C₁+C₂)}

(2) 電荷の分配

X 側で十分時間がたつと、コンデンサー2の電圧は V、電荷は C₂V。Y に切り替えると、空のコンデンサー1とつながり、電流が 0 になるまで電荷が移動します。最後は2つの電圧が等しく（v とする）、電荷の和は変わらないので

C₁v + C₂v = C₂V　→　v = C₂VC₁ + C₂ U₁ = 12C₁v² = C₁C₂²V²2(C₁ + C₂)²

(3) ω₃ を求める

コンデンサー2の電圧は棒の起電力 αω₃ なので αω₃ = v。

ω₃ = C₂Vα(C₁ + C₂)

（C₂ = β/α² を代入すると ω₃ = βV/{α(α²C₁ + β)}。これは「角運動量に相当する βω と電荷 αq の和が保存する」ことからも導けます。）

エネルギーは減っている

切り替え前の 12C₂V² と、切り替え後の2つのコンデンサーのエネルギーの和を比べると、差 12·C₁C₂C₁+C₂V² がジュール熱として抵抗で失われます（抵抗 R の値によらない）。

アニメーションで確かめよう：このボタンでは X で充電 → 自動で Y に切り替え、までを続けて再生します。グラフの点線は式で予想した ω₂ と ω₃。C₁ = C₂ にすると ω₃ = ω₂/2 になることを確かめてみましょう。
