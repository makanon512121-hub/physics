共振の2つの顔：RLC回路とサイクロトロン共鳴（東京大学 2016年 第2問）

交流回路の電流と、回る電場に押される荷電粒子。見た目はまったく違いますが、どちらも「ある角周波数で電力の吸収がいちばん大きくなる」共振を起こします。左の図で動きを、右の図でフェーザー図（回路）や力のつり合い（粒子）を、下のグラフで共振曲線を見比べてください。

問題文は 東京大学の公式ページ（試験問題の公表） で確認してください。図と解説はこのサイトのオリジナルです。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。図の色（I）：電源電圧 V（赤）、抵抗の電圧 VR（青）、コイルの電圧 VL（紫）、コンデンサーの電圧 VC（緑）、電流 I（オレンジ）。図の色（II）：電場の力 qE（赤）、速度 v（青）、ローレンツ力 qvB（紫）、抵抗力 kv（オレンジ）、mvω（緑）。

I(1)　電流の振幅 I₀ と tan δ答 \(I_0=\dfrac{V_0}{\sqrt{R^2+\bigl(\omega L-\frac1{\omega C}\bigr)^2}},\ \ \tan\delta=\dfrac{\omega L-\frac1{\omega C}}{R}\)

直列回路では、どの素子にも同じ電流 \(I=I_0\sin\omega t\) が流れます。そこで、各素子の電圧を電流で表してから足し合わせます。

各素子の電圧

$$\cacc{V_R}=RI=RI_0\sin\omega t,\qquad \cfic{V_L}=L\frac{dI}{dt}=\omega LI_0\cos\omega t,\qquad \cgrav{V_C}=\frac QC=-\frac{I_0}{\omega C}\cos\omega t$$

コンデンサーの電荷は \(I=\dfrac{dQ}{dt}\) より \(Q=-\dfrac{I_0}{\omega}\cos\omega t\) です。\(V_R\) は電流と同じ位相、\(V_L\) は \(\dfrac\pi2\) 進み、\(V_C\) は \(\dfrac\pi2\) 遅れます。

キルヒホッフの第2法則（電圧の和）

$$\cfrc{V_0}\sin(\omega t+\delta)=RI_0\sin\omega t+\Bigl(\omega L-\frac1{\omega C}\Bigr)I_0\cos\omega t$$

右辺を三角関数の合成でまとめると、振幅は \(I_0\sqrt{R^2+\bigl(\omega L-\frac1{\omega C}\bigr)^2}\)、位相のずれは \(\tan\delta=\dfrac{\omega L-1/(\omega C)}{R}\) です。左辺と比べて

$$I_0=\frac{V_0}{\sqrt{R^2+\bigl(\omega L-\frac1{\omega C}\bigr)^2}},\qquad \tan\delta=\frac{\omega L-\frac1{\omega C}}{R}$$

着眼点：フェーザー図（回転するベクトル）

\(\sin\) で振動する量を「角速度 \(\omega\) で回るベクトルの縦成分」と考えると、位相のずれはベクトルの向きの差になります。\(\cacc{V_R}\) を電流と同じ向きに、\(\cfic{V_L}\) をそこから 90° 先に、\(\cgrav{V_C}\) を 90° 後ろに描いて、矢印をつなげた先が \(\cfrc{V_0}\) です。\(V_L\) と \(V_C\) は逆向きなので打ち消し合い、残りの \((\omega L-\frac1{\omega C})I_0\) と \(RI_0\) が直角三角形をつくります。三平方の定理から \(I_0\) が、三角形の角から \(\tan\delta\) がすぐに読めます。

式の立て方：直列回路では「共通な電流」を \(I_0\sin\omega t\) とおき、各素子の電圧を電流で書いてキルヒホッフの第2法則で足します（並列回路なら共通なのは電圧です）。あとは \(\sin\omega t\) と \(\cos\omega t\) の係数を比べるか、フェーザー図の直角三角形を使います。
アニメーションで確かめよう：右のフェーザー図では、\(V_R\) の先から \(V_L\)（紫）と \(V_C\)（緑）を逆向きに描き、その和（灰色の点線）と \(V_R\) をつないだ先が \(V\)（赤）になっています。各矢印の縦成分が、左の回路の電圧の棒の長さと一致します。\(\omega\) を動かすと紫と緑の矢印の長さが変わり、赤い矢印の向き（\(\delta\)）が電流（オレンジ）より前になったり後ろになったりします。
I(2)　電源が供給する電力の時間平均 P̄答 \(\overline P=\dfrac{RV_0^2}{2\bigl\{R^2+\bigl(\omega L-\frac1{\omega C}\bigr)^2\bigr\}}\)

コイルとコンデンサーはエネルギーをたくわえては返すだけなので、1周期で平均すると電力を消費しません。電源の電力の平均は、抵抗で消費されるジュール熱の平均に等しくなります。

抵抗の消費電力（ジュール熱）の時間平均

$$\overline P=\overline{RI^2}=RI_0^2\,\overline{\sin^2\omega t}=\frac12RI_0^2=\frac{RV_0^2}{2\bigl\{R^2+\bigl(\omega L-\frac1{\omega C}\bigr)^2\bigr\}}$$

別解：電源の電力 VI を直接平均する

\(\overline{VI}=V_0I_0\,\overline{\sin(\omega t+\delta)\sin\omega t}=\dfrac12V_0I_0\cos\delta\) です。フェーザー図の直角三角形から \(\cos\delta=\dfrac{R}{\sqrt{R^2+(\omega L-\frac1{\omega C})^2}}\) なので、同じ結果になります。\(\cos\delta\) は力率と呼ばれ、電圧と電流の向きがそろっているほど電力が大きくなります。

式の立て方：時間平均は \(\overline{\sin^2\omega t}=\dfrac12\)、\(\overline{\sin\omega t\cos\omega t}=0\) を使える形に変形します。「平均で電力を使うのは抵抗だけ」と分かっていれば、\(\dfrac12RI_0^2\) がいちばん速い道です。
アニメーションで確かめよう：下の左のグラフの黒い線が瞬間の電力 \(VI\) です。電圧と電流の符号が違う区間では \(VI<0\)（コイルやコンデンサーから電源へエネルギーが戻る）になります。平均（黒の点線）は \(\frac12\cos\delta\) で、\(\omega\) を共振に近づけると負の区間が消えていきます。
I(3)　電力が最大 P₀ のときの抵抗値 R答 \(R=\dfrac{V_0^2}{2P_0}\)

I(2) の式で \(\omega\) によって変わるのは分母の \(\bigl(\omega L-\frac1{\omega C}\bigr)^2\) だけです。これが 0 のとき \(\overline P\) は最大です。

共振の条件

$$\omega L=\frac1{\omega C}\quad\Longrightarrow\quad \omega_0=\frac1{\sqrt{LC}}$$

最大電力

$$P_0=\frac{RV_0^2}{2R^2}=\frac{V_0^2}{2R}\qquad\therefore\ R=\frac{V_0^2}{2P_0}$$

着眼点：共振では L と C が「消える」

共振のときは \(\cfic{V_L}+\cgrav{V_C}=0\) がいつでも成り立ちます。電源から見ると、回路は抵抗 \(R\) だけをつないだのと同じで、電圧と電流の位相もそろいます（\(\delta=0\)）。ただし \(V_L\) と \(V_C\) それぞれは 0 ではなく、電源電圧より大きくなることもあります。

式の立て方：「最大・最小」を問われたら、まず式の中で変数（ここでは \(\omega\)）が入っている部分を一か所に集めます。2乗の項が 0 になるときが最大・最小の候補です。
アニメーションで確かめよう：この設問では \(\omega=\omega_0\) にしてあります。フェーザー図では紫と緑の矢印が同じ長さで逆向きになり、赤とオレンジがそろいます。回路の棒グラフでも \(V_L\) と \(V_C\) が常に逆向きで同じ長さです。\(R\) を小さくすると、この2本がどんどん長くなります。
I(4)　電力が半分になる ω₁, ω₂ から L を求める答 \(L=\dfrac{V_0^2}{2P_0\,\Delta\omega}\)

I(2), I(3) の式を比べると、\(\overline P=\dfrac{P_0}2\) になるのは分母が \(R^2\) の2倍のときです。

電力が半分になる条件

$$\Bigl(\omega L-\frac1{\omega C}\Bigr)^2=R^2$$

\(\omega L-\dfrac1{\omega C}\) は \(\omega\) とともに増えるので、小さい方の \(\omega_1\) では \(-R\)、大きい方の \(\omega_2\) では \(+R\) です。

$$\omega_2L-\frac1{\omega_2C}=R,\qquad \omega_1L-\frac1{\omega_1C}=-R$$

2式を足すと \((\omega_1+\omega_2)\Bigl(L-\dfrac1{\omega_1\omega_2C}\Bigr)=0\) より \(\omega_1\omega_2=\dfrac1{LC}\)。2式を引くと \(\Delta\omega\Bigl(L+\dfrac1{\omega_1\omega_2C}\Bigr)=2R\) なので、これを入れて \(2L\,\Delta\omega=2R\) です。

$$\Delta\omega=\frac RL\qquad\therefore\ L=\frac R{\Delta\omega}=\frac{V_0^2}{2P_0\,\Delta\omega}$$

着眼点：半分の電力は δ = ±45°

\(\overline P=P_0\cos^2\delta\) と書けるので、電力が半分になるのは \(\cos^2\delta=\frac12\)、つまり \(\tan\delta=\pm1\) のときです。フェーザー図では \((\omega L-\frac1{\omega C})I_0\) と \(RI_0\) が同じ長さの直角二等辺三角形になります。また \(\omega_1\omega_2=\omega_0^2\) なので、共振の角周波数は \(\omega_1\) と \(\omega_2\) の相乗平均です。

\(\Delta\omega\) は共振の鋭さを表し、\(R\) が小さいほど、\(L\) が大きいほど鋭い共振になります。

式の立て方：\(\pm\) の2つの条件式が出たら、「足す」と「引く」の両方を試します。ここでは足すと \(\omega_1\omega_2\) が、引くと \(\Delta\omega\) が出てきて、2次方程式を解かずに済みます。
アニメーションで確かめよう：この設問では \(\omega\) を \(\omega_1\) 付近にしてあります。下の右のグラフで点が半分の高さの線に乗り、フェーザー図の \(\delta\) が約 −45° になります。\(R\) や \(L\) を動かして、読み取り欄の \(\Delta\omega\) と \(R/L\) がいつも一致することを確かめてください。
II(1)　速度に平行な方向と垂直な方向の力のつり合い答 平行：\(qE\cos\delta=kv\)　垂直：\(mv\omega=qvB+qE\sin\delta\)

粒子にはたらく力は3つです。

  • 電場からの力 \(qE\)：速度から角 \(\delta\) だけ回転の向き（円の内側寄り）にずれた向き
  • ローレンツ力 \(qvB\)：速度に垂直。磁場が紙面の表から裏、粒子が反時計回りなので、フレミングの左手の法則より円の中心向き
  • 抵抗力 \(kv\)：速度と逆向き

等速円運動なので、速度方向の加速度は 0、中心方向の加速度は \(\dfrac{v^2}r=v\omega\)（\(v=r\omega\) を使いました）です。

運動方程式（等速円運動）

$$\text{速度方向：}\ 0=\cfrc{qE\cos\delta}-\cfr{kv},\qquad \text{中心方向：}\ m\cgrav{v\omega}=\cfic{qvB}+\cfrc{qE\sin\delta}$$

粒子と一緒に回る見方

問題文の「力の釣り合い」は、粒子と一緒に回転する立場で見ると自然です。この立場では中心から外向きに遠心力 \(mr\omega^2=mv\omega\) が加わり、すべての力がつり合います。

$$\cfrc{qE\cos\delta}=\cfr{kv},\qquad \cgrav{mv\omega}=\cfic{qvB}+\cfrc{qE\sin\delta}$$
式の立て方：円運動は「速度（接線）方向」と「中心方向」に分けます。中心方向の加速度は \(\dfrac{v^2}r=r\omega^2=v\omega\) のどれでも同じなので、問題で与えられた文字（ここでは \(v\) と \(\omega\)）で書ける形を選びます。
アニメーションで確かめよう：右の図は粒子と一緒に回る見方です。オレンジの抵抗力と赤の縦成分、緑の遠心力と紫＋赤の横成分が、いつも同じ長さでつり合っています。左の図では、赤い矢印（電場）が青い矢印（速度）と一定の角 \(\delta\) を保ったまま一緒に回ります。
II(2)　速さ v と tan δ答 \(v=\dfrac{qE}{\sqrt{k^2+(m\omega-qB)^2}},\ \ \tan\delta=\dfrac{m\omega-qB}{k}\)

II(1) の2式を \(qE\cos\delta\)、\(qE\sin\delta\) について整理します。

$$qE\cos\delta=kv,\qquad qE\sin\delta=(m\omega-qB)\,v$$

2式の比（割り算）

$$\tan\delta=\frac{m\omega-qB}{k}$$

2式の2乗の和

$$(qE)^2=\bigl\{k^2+(m\omega-qB)^2\bigr\}v^2\qquad\therefore\ v=\frac{qE}{\sqrt{k^2+(m\omega-qB)^2}}$$

着眼点：δ の符号の意味

\(\omega=\dfrac{qB}m\) のとき、磁場の力だけで円運動の向心力をちょうどまかなえます（磁場中の荷電粒子が自然に回る角速度です）。このとき \(\delta=0\) で、電場は速度と同じ向きに押すだけなので、速さが最大になります。\(\omega\) がこれより小さいと磁場の力が強すぎるので、電場は少し外向き（\(\delta<0\)）に、大きいと内向き（\(\delta>0\)）に向いて不足分を補います。

式の立て方：\(A\cos\delta=X,\ A\sin\delta=Y\) の形の2式は、「割ると \(\tan\delta\)」「2乗して足すと \(A^2\)」が定番です。I(1) の三角関数の合成と同じ計算です。
アニメーションで確かめよう：\(\omega/\omega_0\) を1より小さくすると左の図の赤い矢印が青より外側に、1より大きくすると内側に向きます。下の右のグラフの \(\delta\) の曲線と、読み取り欄の \(v\) の値が最大になる位置を確かめてください。
II(3)　電場がする仕事率 P答 \(P=\dfrac{kq^2E^2}{k^2+(m\omega-qB)^2}\)

仕事率は「力 × 速度方向の成分 × 速さ」です。ローレンツ力は速度に垂直なので仕事をしません。

仕事率

$$P=\cfrc{qE\cos\delta}\cdot v=\cfr{kv}\cdot v=kv^2=\frac{kq^2E^2}{k^2+(m\omega-qB)^2}$$

粒子の速さは一定で運動エネルギーは変わらないので、電場が与えたエネルギーはすべて抵抗力（中性ガス）に熱として渡されます。これは I(2) で「電源の電力 ＝ 抵抗のジュール熱」となったのと同じ構図です。

式の立て方：仕事率 \(P=\vec F\cdot\vec v=Fv\cos\theta\) です。等速運動なら「仕事率の和 ＝ 0」から、電場の仕事率 ＝ 抵抗力が奪う仕事率 \(kv^2\) と考える方が速いことがあります。
アニメーションで確かめよう：下の左のグラフが \(P/P_0\) の共振曲線です。\(k\) を小さくすると山が高く鋭くなり、\(k\) を大きくすると低くなだらかになります（縦軸は \(P_0\) でそろえてあります）。
II(4)　共振のデータから質量 m を求める答 \(m=\dfrac{P_0B^2\,\Delta\omega}{2E^2\omega_0^2}\)

共振の条件と最大値

$$m\omega_0=qB\ \Rightarrow\ \omega_0=\frac{qB}m,\qquad P_0=\frac{q^2E^2}{k}$$

仕事率が半分になる条件

$$(m\omega-qB)^2=k^2\ \Rightarrow\ \omega=\omega_0\pm\frac km\qquad\therefore\ \Delta\omega=\frac{2k}m$$

未知の \(q\) と \(k\) を消します。\(q=\dfrac{m\omega_0}B\)、\(k=\dfrac{m\,\Delta\omega}2\) を \(P_0\) の式に入れると

$$P_0=\frac{m^2\omega_0^2E^2}{B^2}\cdot\frac2{m\,\Delta\omega}=\frac{2m\omega_0^2E^2}{B^2\,\Delta\omega}\qquad\therefore\ m=\frac{P_0B^2\,\Delta\omega}{2E^2\omega_0^2}$$

着眼点：2つの共振を並べてみる

I　RLC回路II　荷電粒子
応答の大きさ\(I_0=\dfrac{V_0}{\sqrt{R^2+(\omega L-\frac1{\omega C})^2}}\)\(v=\dfrac{qE}{\sqrt{k^2+(m\omega-qB)^2}}\)
位相のずれ\(\tan\delta=\dfrac{\omega L-\frac1{\omega C}}R\)\(\tan\delta=\dfrac{m\omega-qB}k\)
エネルギーを奪うもの抵抗 \(R\)：\(\frac12RI_0^2\)抵抗力 \(k\)：\(kv^2\)
共振\(\omega_0=\dfrac1{\sqrt{LC}}\)\(\omega_0=\dfrac{qB}m\)
半値幅\(\Delta\omega=\dfrac RL\)\(\Delta\omega=\dfrac{2k}m\)

どちらも「電力 ＝ \(P_0\cos^2\delta\)」で、電力が半分になるのは \(\delta=\pm45^\circ\) のときです。半値幅に 2 の違いがあるのは、\(m\omega-qB=m(\omega-\omega_0)\) がちょうど \(\omega\) の1次式なのに対し、\(\omega L-\dfrac1{\omega C}=\dfrac{L(\omega+\omega_0)(\omega-\omega_0)}{\omega}\) は共振の近くで \(2L(\omega-\omega_0)\) になる（傾きが2倍）からです。実際、粒子の速度の1成分（たとえば \(v_y\)）だけを見ると、回路の電流と同じ形の「抵抗のある強制振動」の式に従います。

補足：この方法はサイクロトロン共鳴と呼ばれ、結晶の中を動く電子の「見かけの質量（有効質量）」を測る実験に実際に使われています。共振の位置 \(\omega_0\) と幅 \(\Delta\omega\) を測れば、質量と抵抗の強さが両方わかります。

式の立て方：「〜を用いて表せ」で使えない文字（ここでは \(q\) と \(k\)）があるときは、条件式の数を数えて、その文字を順に消去します。\(\omega_0\) の式で \(q\)、\(\Delta\omega\) の式で \(k\) が消せます。
アニメーションで確かめよう：この設問では \(\omega/\omega_0=1+k/(m\omega_0)\)（電力が半分になる \(\omega_2\)）にしてあります。下の右のグラフで \(\delta=45^\circ\)、左のグラフで \(P/P_0=0.5\) になっていることを確かめてください。\(k\) を変えると、半値幅 \(\Delta\omega\) がいつも \(2k/m\) になります。
