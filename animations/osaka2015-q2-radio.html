ゲルマニウムラジオ：コイル・くし形コンデンサー・RLC 並列回路の同調と混信（大阪大学 2015年 第2問）

ラジオの部品を自作するところから始めます。ソレノイドコイルの自己インダクタンス、くし形の可変コンデンサー（重なりの幅 x で容量が変わる）を求め、それを RLC 並列回路にして放送局の電波を選びます。ダイヤル（x）を回すとインピーダンスの山が動き、ねらった局の周波数で山の頂上になります。山の幅 Δω と混信の関係も、2つの放送局で確かめます。

設定

いまの値

解答解説

見出しを押すと開きます。「この状況にする」で上のアニメーションがその設問の設定になります。図の色：コイル・電流 IL（オレンジ）、コンデンサー・電流 IC（紫）、抵抗・電流 IR（赤）、電圧 V₂・インピーダンス（青）、放送局の電波（緑）。数値の例は、問題の文字に実際のラジオに近い値を入れたものです。

問1　コイルの自己インダクタンス L答 \(L=\dfrac{\pi\mu a^2N^2}{l}\)

十分に長いソレノイドの内部には一様な磁場ができます。単位長さあたりの巻き数は \(\frac Nl\) です。電流 \(I\) を流したとき

ソレノイド内部の磁場（H = nI）と磁束密度（B = μH）

$$H=\frac NlI,\qquad B=\mu\frac NlI$$

1巻きを貫く磁束（Φ = BS）

$$\Phi=B\cdot\pi a^2=\mu\frac Nl\pi a^2I$$

電流が \(\Delta I\) 変わると磁束は \(\Delta\Phi=\mu\frac Nl\pi a^2\Delta I\) 変わります。コイル全体では \(N\) 巻き分の起電力が出ます。

ファラデーの電磁誘導の法則と、自己インダクタンスの定義

$$V=-N\frac{\Delta\Phi}{\Delta t}=-\frac{\mu N^2\pi a^2}{l}\frac{\Delta I}{\Delta t},\qquad V=-\cfr{L}\frac{\Delta I}{\Delta t}$$

2つを比べて

$$\cfr{L}=\frac{\pi\mu a^2N^2}{l}$$

着眼点：N が2回効くので N² に比例

巻き数 \(N\) は「磁場の強さ（\(\propto N\)）」と「磁束を受け止める巻き数（\(\times N\)）」の2か所で効きます。だから \(L\propto N^2\) で、巻き数を2倍にすると \(L\) は4倍です。断面積 \(\pi a^2\) と透磁率 \(\mu\) には比例し、同じ巻き数を長く引き延ばす（\(l\) を大きくする）と磁場が弱まって \(L\) は小さくなります。

式の立て方：自己インダクタンスは「(1) 電流 → 磁場 → 磁束 を式にする、(2) 電磁誘導の法則で起電力を出す、(3) \(V=-L\frac{\Delta I}{\Delta t}\) と比べる」の3段階で求めます。
アニメーションで確かめよう：電流（青）が増えている間、コイルには増加を妨げる向きの起電力（赤）が出ます。\(N\) を2倍にすると \(L\) が4倍になることを、いまの値で確かめましょう。
問2　2枚の極板が重なった部分の電気容量 C₁答 \(C_1=\dfrac{\varepsilon bx}{d}\)

電場ができるのは極板が向かい合っている部分だけです。その面積は、奥行き \(b\) と重なりの幅 \(x\) の積 \(bx\) です。

平行板コンデンサーの電気容量（C = εS/d）

$$\cfic{C_1}=\varepsilon\frac{bx}{d}$$

\(C_1\) は重なりの幅 \(x\) に比例します。極板をずらして \(x\) を変えれば、容量を連続的に変えられます。

式の立て方：\(C=\varepsilon\frac Sd\) の \(S\) は「極板の面積」ではなく「向かい合っている部分の面積」です。ずれた極板では重なった部分だけを数えます（\(d\) が \(b\), \(x\) より十分小さいので、はみ出た部分の電場は無視できます）。
アニメーションで確かめよう：上の極板が横にずれると、重なった部分（色のついた面）が変わり、右のグラフの点が直線の上を動きます。
問3　くし形コンデンサー全体の電気容量 C答 \(C=(2M-1)C_1\)

2つのくしの極板は、上から交互に並んでいます。合計 \(2M\) 枚なので、となり合う極板のすき間は \(2M-1\) か所です。どのすき間も、片方のくしの極板と、もう片方のくしの極板にはさまれた \(C_1\) のコンデンサーです。

片方のくしの極板はすべて同じ電位、もう片方もすべて同じ電位なので、\(2M-1\) 個のコンデンサーはすべて並列です。

並列の合成容量（容量の和）

$$\cfic{C}=(2M-1)C_1$$

補足：これがラジオの「バリコン」

このくし形のコンデンサーは、つまみを回して重なり \(x\) を変える可変コンデンサー（バリコン）のしくみです。間の極板は上下両面が使われるので、枚数のわりに大きな容量が得られます。たとえば \(b=2\,\mathrm{cm}\), \(d=0.5\,\mathrm{mm}\), \(M=10\) の空気のコンデンサーなら、\(x=2\,\mathrm{cm}\) で約 \(135\,\mathrm{pF}\) です。

式の立て方：多くの極板が並ぶコンデンサーは、「すき間ごとに1個のコンデンサー」と考え、各極板がどちらの電極につながっているかで直列か並列かを決めます。交互に同じ電極につながるときは、すべて並列です。
アニメーションで確かめよう：色のついたすき間の数が \(2M-1\) です。\(M\) を変えると、グラフの直線の傾き（\(x\) あたりの容量）が \((2M-1)\) 倍で変わります。
問4　抵抗・コイル・コンデンサーを流れる電流の最大値答 抵抗 \(\dfrac{V_2}{R}\)，コイル \(\dfrac{V_2}{\omega_1L}\)，コンデンサー \(\omega_1CV_2\)

3つは並列なので、どれにも同じ電圧 \(V_2\sin\omega_1t\) がかかります。それぞれの素子で、電圧と電流の関係を使います。

抵抗（オームの法則，同じ位相）

$$\cfrc{I_R}=\frac{V_2}{R}\sin\omega_1t$$

コイル（リアクタンス ωL，電流は π/2 遅れる）

$$\cfr{I_L}=\frac{V_2}{\omega_1L}\sin\Bigl(\omega_1t-\frac\pi2\Bigr)$$

コンデンサー（リアクタンス 1/(ωC)，電流は π/2 進む）

$$\cfic{I_C}=\omega_1CV_2\sin\Bigl(\omega_1t+\frac\pi2\Bigr)$$

最大値は順に \(\dfrac{V_2}{R}\), \(\dfrac{V_2}{\omega_1L}\), \(\omega_1CV_2\) です。

式の立て方：並列回路では「共通の電圧」を基準にして、各素子の電流を（電圧）÷（リアクタンス）と位相のずれで書きます。コイルは遅れ、コンデンサーは進みです。
アニメーションで確かめよう：周波数 \(f\) を上げると、コイルの電流は小さく、コンデンサーの電流は大きくなります。右下の回転ベクトルで、\(I_L\) と \(I_C\) がいつも反対向きなのがわかります。
問5　V₂ が最大になるときの Z と I₂答 ⒜ 最大，\(Z=R\)，\(I_2=\dfrac{V_2}{R}\)

電源から見ると、抵抗 \(r\) と並列部分が直列につながっています。並列部分のインピーダンス \(Z\) が大きいほど電流が流れにくく、\(r\) での電圧降下が小さくなるので、並列部分にかかる \(V_2\) は大きくなります。よって \(V_2\) が最大になるのは \(Z\) が最大のときです。

RLC 並列回路のインピーダンス

$$Z=\frac{1}{\sqrt{\dfrac{1}{R^2}+\Bigl(\omega C-\dfrac{1}{\omega L}\Bigr)^2}}$$

根号の中は \(\omega_1C-\dfrac{1}{\omega_1L}=0\) のとき最小になり、\(Z\) は最大になります。

$$\omega_1C=\frac{1}{\omega_1L}\qquad\therefore\ \omega_1^{\,2}=\frac{1}{LC}$$

このときのインピーダンスと電流（V = ZI）

$$\cacc{Z}=R,\qquad I_2=\frac{V_2}{R}$$

着眼点：コイルとコンデンサーの電流が打ち消し合う

\(\omega_1C=\frac{1}{\omega_1L}\) は、問4 の \(I_L\) と \(I_C\) の最大値が等しくなる条件です。2つは逆位相なので和は 0 になり、外から流れ込む電流は抵抗の分 \(\frac{V_2}{R}\) だけになります。コイルとコンデンサーの間では大きな電流が行き来していますが、外には出てきません（並列共振）。

式の立て方：\(Z\) を最大にするには、分母の根号の中を最小にします。\(\frac1{R^2}\) は変わらないので、2乗の項を 0 にする条件を探します。
アニメーションで確かめよう：ダイヤルが自動で回り、容量 \(C\) が変わります。右上のグラフで \(Z\) が山になるところで \(Z=R\) になり、右下の回転ベクトルでは \(I_L\) と \(I_C\) の長さがそろって打ち消し合います。
問6　ω₁ の放送局を聴くための C答 \(C=\dfrac{1}{\omega_1^{\,2}L}\)

ねらった局の角周波数 \(\omega_1\) で \(V_2\) が最大になればよいので、問5 の条件をそのまま使います。

並列共振の条件

$$\omega_1^{\,2}=\frac{1}{LC}\qquad\therefore\ \cfic{C}=\frac{1}{\omega_1^{\,2}L}$$

このように回路の共振を電波の周波数に合わせることを「同調」といいます。ラジオのダイヤルを回すことは、バリコンの重なり \(x\) を変えて \(C\) をこの値に合わせることです。

補足：数値で見ると

\(L\approx197\,\mu\mathrm H\) のコイルで \(f_1=1000\,\mathrm{kHz}\)（\(\omega_1=2\pi f_1\)）の局を受けるには \(C\approx129\,\mathrm{pF}\) が必要です。問3 のバリコン（\(M=10\)）なら重なり \(x\approx1.9\,\mathrm{cm}\) です。

式の立て方：「特定の周波数だけを選ぶ」問題は共振の条件 \(\omega=\frac{1}{\sqrt{LC}}\) を使います。直列でも並列でも同じ式です。
アニメーションで確かめよう：重なりの幅 \(x\) をスライダーで動かして、右上の山の頂上を放送局 A の線に合わせましょう。合ったとき右下のダイヤルの針が A を指し、受信の強さが最大になります。
問7　V₂/I₂ が半分になる角周波数の差 Δω答 \(\Delta\omega=\dfrac{\sqrt3}{CR}\)

\(V_2=I_2Z\) なので \(\dfrac{V_2}{I_2}=Z\) です。\(\omega_1\) では \(Z=R\) なので、半分になるのは \(Z=\frac R2\) のときです。

Z = R/2 の条件

$$\frac{1}{R^2}+\Bigl(\omega C-\frac{1}{\omega L}\Bigr)^2=\frac{4}{R^2}\qquad\therefore\ \omega C-\frac{1}{\omega L}=\pm\frac{\sqrt3}{R}$$

両辺に \(\omega RL\) をかけると \(\omega\) の2次方程式になります（これがヒントの形です）。

$$CRL\,\omega^2\mp\sqrt3L\,\omega-R=0$$

解の公式（ω > 0 の解）

$$\cacc{\omega_2}=\frac{\sqrt3L+\sqrt{3L^2+4CR^2L}}{2CRL},\qquad \cacc{\omega_3}=\frac{-\sqrt3L+\sqrt{3L^2+4CR^2L}}{2CRL}$$ $$\Delta\omega=\omega_2-\omega_3=\frac{2\sqrt3L}{2CRL}=\frac{\sqrt3}{CR}$$

別解：2つの式の差をとる

\(\omega_2C-\frac{1}{\omega_2L}=\frac{\sqrt3}{R}\) と \(\omega_3C-\frac{1}{\omega_3L}=-\frac{\sqrt3}{R}\) を引き算します。上の2つの解の積は \(\omega_2\omega_3=\frac{1}{LC}=\omega_1^{\,2}\) なので、\(\frac{1}{\omega_2}-\frac{1}{\omega_3}=-\frac{\omega_2-\omega_3}{\omega_2\omega_3}=-LC\,\Delta\omega\) となり

$$C\Delta\omega+C\Delta\omega=\frac{2\sqrt3}{R}\qquad\therefore\ \Delta\omega=\frac{\sqrt3}{CR}$$

\(\omega_1\) は \(\omega_2\) と \(\omega_3\) のちょうど真ん中ではなく、積の平方根（相乗平均）になっています。

式の立て方：分数の入った式は、両辺に \(\omega\) をかけて分母を払い、\(\omega\) の2次方程式にします。\(\pm\) の2つの式から、正の解を1つずつ選びます。
アニメーションで確かめよう：右上のグラフの点線（\(Z=\frac R2\)）と山が交わる2点が \(\omega_2\), \(\omega_3\) です。\(R\) を大きくすると山が高く鋭くなり、右下のグラフのとおり \(\Delta\omega\) は \(\frac1R\) に比例して小さくなります。
問8　混信を避けるには Δω は？答 ⒝ 小さいほうがよい

\(\Delta\omega\) は、\(Z\)（\(=\frac{V_2}{I_2}\)）の山の幅です。山が細いほど、ねらった局の周波数から少しずれただけで \(Z\) が急に小さくなり、となりの局の電波からはほとんど電圧が生じません。よって \(\Delta\omega\) は小さいほうがよいです。

山の幅（問7）

$$\Delta\omega=\frac{\sqrt3}{CR}$$

補足：どうすれば山が細くなる？

受信する局を決めると \(C=\frac{1}{\omega_1^{\,2}L}\) なので、\(\Delta\omega=\frac{\sqrt3\,\omega_1^{\,2}L}{R}\) です。並列の抵抗 \(R\) を大きくする（イヤホン側で電流を使いすぎない）、コイルの \(L\) を小さくして \(C\) を大きくする、と山が細くなり、混信しにくくなります。

式の立て方：「選択性がよい」とは「周波数がずれると応答が急に落ちる」ことです。山の幅 \(\Delta\omega\) を、ねらう局ととなりの局の周波数の差と比べて考えます。
アニメーションで確かめよう：放送局 B の周波数を A に近づけたり、\(R\) を小さくしたりすると、B の受信の強さが上がって混信します。\(R\) を大きくすると \(\Delta\omega\) が小さくなり、B だけが小さくなります。
